**배치는 rest 정합이 아니다.** 중앙값은 전 대역 1.000인데 **꼬리에 20~30배가
저장돼 있다**. 그리고 **앞판만 그렇다 — 뒤판은 완전 정합(신장총 0.0cm)**.

최악 6개(전부 좌우 대칭 쌍 = 계통적):
```
30.1배 앞판(±21.70,2.59)→(±21.73,3.25)  rest 6.6mm
27.9배 앞판(±10.52,0.46)→(±10.73,1.14)  rest 7.1mm
26.1배 앞판(±22.50,2.74)→(±22.38,3.47)  rest 7.4mm
```
전부 패턴 **y 0.5~3.5cm · |x| 10~22.5cm = 앞판 어깨선 대역**이다. rest가 7mm인
엣지가 3D에서 20cm 벌어져 있다.

## 2. f1 기여의 공간 분해 — **생략**
프로브는 패스 경계에서 링 길이만 읽는다. "어느 제약의 수정이 링 정점을
움직였는가"는 `clothPhysics` 반복 내부에 계기를 넣어야 나오고 그건 수정 금지
대상이다. → 1의 3장 병렬로 갈음.

## 3. 21회차 시점 분리의 사유 회수 (원문 인용)

> 넥밴드는 **봉제 완료된 옷의 부품**이다. 착장 중 유지력은 하드 핀이 담당하고
> **(잔차 0.00mm 실증)** 링이 조여 있을 이유가 없다.
> — [[2b-21-링시점분리]] "변경(변수 하나 · 새 상수 0)"

**그 전제는 이미 소멸했다.** 현행 코드:
```ts
// 착장 앵커는 **기본 off**(§4 개정: 앵커 층위 4연속 실패로 소진).
// 롤백 수단으로만 보존한다 — `PINDRESS=1`.
const PINDRESS = process.env.PINDRESS === "1";
...
pinCorners: false,
anchors: () => (PINDRESS ? anchorList : []),
```
21회차가 "링을 풀어도 된다"고 판단한 근거는 **하드 핀이 유지력을 담당한다**는
것이었는데, 그 하드 핀·앵커가 이후 회차에서 전량 반납됐다. 지금 S1은
**유지력도 없고 목선 제약도 없는** 구간이다.

→ "f1부터 활성화" 처방의 유효성 판정 입력: 21회차의 실패는 **링 제약이 나쁘다**가
아니라 **램프 시작 시점이 10프레임 일렀다**였다(21회차 국소화 원문). 링 제약
자체는 그 회차에 병목을 **풀었다**(seamGap 27.8 → 16mm 아래). 재배선 금지는
지켰고, 사유가 회수됐으므로 다음 회차 판정 재료로 넘긴다.

## 4. 사전 등록 판정 → **① 국면 1 = 배치 층위 확정**

t=0에 큰 정합 이탈이 앞판·링 인접에 저장돼 있고(신장총 3242cm) f1~f8에 그만큼
풀린다. 둘째 갈래("t=0이 전 대역 ~1.00")는 **중앙값만 보면 참이지만 꼬리에서
거짓**이다 — 중앙값 1.000에 최대 30.07배.

처방 후보는 **배치의 rest 보존**(다음 회차 판정). 처방 집행 없음.

### 다음 회차 1순위 용의자 (미검증)
최악 엣지가 전부 **앞판 어깨선 대역**이고 **앞판만**이라는 점 — 20회차가 앵커
목표를 능선 표면 + `COLLISION_MARGIN`으로 올렸고, 그 대상이 "**어깨 시접 앞판
쪽 정점 38개**"였다. 배치 시점에 그 38개가 능선으로 옮겨졌다면 이웃 엣지가
정확히 이 모양으로 저장된다. **`S0FIX=0`으로는 안 변한다**(교정 0정점) — 즉
S0 투영 교정이 아니다. 확인은 다음 회차.

## 정정 (34회차) — 원문은 위에 그대로 둔다

1. **§1의 "t=0 (배치 직후 · 첫 적분 전)" 지도는 실제로 "핀 발화 직후" 지도였다.**
   상태기계가 `setAnchorHard`(dressingMachine 196행) → `beforeStep`(219행) 순서라
   `_frame===0`의 지도는 이미 하드 핀이 돈 뒤다. **진짜 배치 직후**는 34회차가 신설한
   34게이트가 잰다 — 몸판 n=24318 최대 **1.000016** 최소 0.999986 · 신장총 **0.0cm** ·
   압축총 0.0cm(전 대역 정합). 라벨 하나가 회차 판정을 옮겼다 → [[함정13-jitter]] 사례 추가.
2. **§3 "21회차 전제 소멸" 판정은 34회차가 취소했다.** 하드 핀은 반납되지 않았고
   (`anchors: () => []`는 소프트 경로만 껐다) S1 봉합 전 구간에서 활성이다.
   → [[2b-21-링시점분리]] 정정 절 · [[함정17-반납된전제]]
3. **§4 "저장분이 f1~f8에 풀린다" 해석은 무효.** 34회차가 배치 저장분을 0으로 만든
   뒤에도 f8 앞판 최대가 32회차 3.330 → **8.107**로 오히려 악화했다. 신장은 저장분을
   푸는 것이 아니라 **f1~f8에 새로 만들어진다**. §4의 "① 국면 1 = 배치 층위 확정"도
   따라서 뒤집혔다 — 34회차 판정은 **갈래 ②**(두 시점은 별개 층위)이고 국면 1은 종결.
