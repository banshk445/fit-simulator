# 2b-18 — 2a-thin 방식 (몸 밖 여유 원뿔)

## 0. 앞 회차 정정 (중요)
[[2b-17-하이브리드배치]]가 "링(48.27cm)과 몸 밖 원통(최소 외접원 78.68cm)은 치수에서
배타적"이라고 적었는데 **틀렸다**. `2πR(h)`는 단조가 아니라 **단봉**이고, 이분법이
단조를 전제해 대역 끝에 붙은 것이었다.

```
y143 105.70 · y144 66.94 · y145 54.37 · y146 **48.26** ← 최소, 패턴 48.27과 0.01cm
y147 63.50 · y148 78.54 · y150 85.09   ← 위로는 턱·머리가 다시 키운다
```
**목선 크기의 원이 y146.0(반경 7.68cm)에 실재한다.** 목선이 목밑둘레에서 도출된
값이라 목 기둥 + 오프셋에 정확히 떨어진다 — 우연이 아니다. → [[몸에서-가져와라]]

## 변경 (변수 하나)
목선 포함 전 패널을 몸 밖 원뿔에. top 원은 위 최소 지점, 아래로는 그 높이 몸
최대 반경 + 오프셋.
```
top = 2πR(h) 최소 잔차 높이(단봉이므로 훑기) → y146.11
h(y) = top − y·(top − 밑단)/총장 ·  θ = 앞 ±u·앞몫·π / 뒤 ±(π − u·뒤몫·π)
```

## 결과

| 채널 | 12/13회차 | 17회차 A | **18회차** |
|---|---|---|---|
| 배치 관통 | 580 | 107 | 134 |
| 자기교차(원본) | 0 | 298 | 290 |
| **뒤집힘** | 22 | 108 | **35** |
| 시접 갭 어깨/옆선 | 0.0/3.0 | 0.0/0.0 | **0.0/0.0cm** |
| top 원 둘레 vs 패턴 | — | (포화) | **48.139 vs 48.243cm** |
| **링 원주(배치)** | −0.30 PASS | 119.90 | **119.89 ✗** |

top 원은 맞았는데 링이 119.89cm. 원뿔이 어깨에서 급격히 벌어져(R: 7.68 → 16.8 → 21.5)
목선이 그 경사를 타고 내려간다 — 목선은 패턴 y 0~9.12cm에 걸쳐 있고 이 높이 법칙에선
월드 146.11 → 137.2까지 내려간다.

## 국소화 — "몸 밖 · 길이 보존 · 어깨 용접"은 셋 중 둘만

```
(가) 높이별 반경 원뿔  몸 밖 ✓ 용접 ✓ 길이 보존 ✗ (링 2.5배)
(나) 일정 반경 원통    길이 보존 ✓ 이지만 불가능:
       옷 총 둘레 110.0cm < 어깨 외접원 140.7cm — 감쌀 만큼 큰 원통엔 이 옷이 안 감긴다
(다) 평면 두 장        몸 밖 ✓ 길이 보존 ✓ 이지만 **어깨 용접과 충돌**:
       앞뒤판이 어깨선에서 한 점이어야 하는데 평면 두 장은 2D ≈ 40cm 벌어져 있다
```
**스파이크가 성립했던 이유가 여기서 드러난다 — 2a-thin에는 어깨 용접이 없었다**
(어깨도 램프 대상이었다). [[2b-08-구조전환]]의 "제조 순서 복원"(어깨 사전 봉제)이
평면 배치와 배타적이다.

## 판정 (전략층)
배치 사상 층위의 실패가 이제 **배타 구조**로 정리됐다. 더 이상 "사상을 더 잘 짜면"의
문제가 아니라, 유지할 은행 자산 중 **무엇을 반납할지**의 선택이다.

## 다음 수 (택일 — 사용자 판정)
- (a) **어깨 용접 해제** → 어깨를 램프로 되돌리고 평면 배치(2a-thin 원형).
  등거리·몸 밖·접힘 0이 한꺼번에 성립. 대가는 8회차 은행 반납, [[2b-01-낙하]] 재발 위험
- (b) 원뿔 경사 완화 — 어깨를 덜 감싼다. 관통 ↔ 링 길이의 교환곡선을 재게 됨
- (c) 하모닉 좌표 재개 ([[2b-16-vN재정의]] 은행)

## 은행 (유지)
- top 높이 도출: `2πR(h)` 단봉 최소 → y146.11 · 둘레 48.139 vs 48.243
- 링 안착 **예측**(정착 후 대조용): 몸 윤곽 둘레 = 링 길이인 높이 → **y144.54**
- 미러 규약: 시접 테이블 쌍에서 확인 — 어깨 38쌍 · 옆선 62쌍 갭 0.0cm
- [[2b-15-sliceOutline]]은 **계기로만** 존치. 배치 곡면으로 쓰면 모서리·형상 변화가
  접힘을 만든다(17회차 실측 108 vs 1770)
