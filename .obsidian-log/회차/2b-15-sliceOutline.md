# 2b-15 — sliceOutline 계기 신설

## 변경
`src/lib/bodyOutline.ts`, `npm run check:outline`. 각도별 레이캐스트로 표면 교점 직접 취득
(껍질·최근접·bin 반경 전부 폐기). 분해능 도출(상수 0), 옵셋은 **표면 법선 방향**
(반경 방향이면 오목 구간에서 누움).

## 3자 대조 (사전 등록 기준 통과)
| 계기 | 변중점 최심 |
|---|---|
| A 볼록껍질 | 7.22cm |
| B bin 반경 | 3.58cm |
| C 레이·drop | 2.85cm |
| **C 레이·fallback** | **0.00cm** |

빈 각도(팔 구멍) 규칙 = fallback 채택. 판정자 3종 병기(레이 패리티/골격 오라클/표면거리)로
순환 검증 방지.

## 배치 부활 1회 — 주 지표 개선, 다른 채널 폭발
관통 580→196 (계기는 제 일을 함, 4배 개선). 목선 이분법 계단 −0.135→0.000.
**그러나 자기교차 1200·뒤집힘 1906 폭발 → 원복.**

## 국소화
**vN 법칙의 특이점** — 상단 경계(4분 타원) 끝점 접선이 수직이라 목점에서 d(topY)/dx→∞.
값은 연속, 도함수는 발산. 위치 증거: 자기교차가 정확히 목점 옆 좁은 띠.

## 판정
vN을 상단 경계 **호장 좌표**로 재정의(계기는 유지). x 기반 매개화의 마지막 잔재.
→ [[../원리/몸에서-가져와라]] 4번째 적용 예정.

**사전 등록 대체안** (실패 시): 몸 밖 느슨한 원통 배치로 회귀(2a-thin 스파이크 방식).
