# 2b-20 — 앵커 목표 상향

## 변경 (변수 하나)
앵커 목표를 능선 **표면**(거리 0) → **표면 + 옷 오프셋**으로. 오프셋은
`COLLISION_MARGIN`에서 도출(0.28cm 같은 하드코딩 없음). 능선점은 정의상 그 x의
최상단 표면점이라 바깥 방향이 +y다.

**근거**: 목표가 표면 위면 천이 **원리적으로 도달할 수 없다** — 충돌 해소가 항상
오프셋만큼 밖으로 밀기 때문. 앞판만 핀으로 박히고 뒤판은 영원히 밖에 머문다.

## 검증
```
앵커 목표 y 143.26~145.57cm · 표면 이탈 15.00mm(= 오프셋)
[앵커·배선검증] 승모근 상단 대비 여유 **최소 10.82mm** @|x|18.02 → 전 열에서 위 OK
하드 핀 잔차 0.00mm 유지(f=60~360 · 6회)
링 원주 48.24 vs 48.27cm · 링 높이 y141.51cm — **둘 다 변경 전과 동일**
t=0 게이트 4/4 통과 유지
```

## 국소화 — 분기 ⓑ 재판정: **기전이 바뀌었다**
```
              19회차                       20회차
앞 목점  (8.97,144.07,−4.19) 표면 0.00cm    (8.97,145.57,−4.19) 표면 1.50cm 밖
뒤 목점  (10.60,143.13,−6.05)               (10.66,144.31,−5.94) 표면 1.10cm 밖
중점     표면거리 **0.01cm = 몸 위**         표면거리 **1.22cm = 몸 밖**
```
19회차가 특정한 "몸을 사이에 두고 마주 봄"은 **해소됐다**. 갭은 그대로다.

**새 기전** — 뒤 목점이 세 힘 사이에 끼여 있다:
1. 시접 당김(앞판 핀 쪽으로 안·위)
2. 충돌 밀어냄(표면거리 1.10 < 오프셋 1.50 → 매 프레임 바깥으로)
3. **넥밴드 원주 상한** — 발화 22155회 = **58.9/프레임 · 링 42쌍 전 엣지가 매
   프레임 상한** = 상시 하중 지지

즉 목점 2쌍은 "몸에 막힌" 게 아니라 **링이 이미 한계라 더 못 당긴다**.
→ [[보조힘은-대체품]]: 링 제약이 낙하를 막는 대체품인데, 그 하중 지지가 이번엔
봉합을 막는 쪽으로 작동한다.
