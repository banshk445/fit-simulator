## 0. 정의 어긋남 2건 (코드 실측 · 둘 다 과거 회차 정정)

### (가) 49회차 ablation이 자른 면은 "자석분 경계"가 아니다

`bvhFromArrays.ts:239-244`가 목표를 `표면점 + margin·n`으로 잡으므로
이동량 `Δ·n = margin − d`이고 **국면이 셋**이다:

```
국면1  d > margin(15mm)  Δ·n < 0  안쪽으로 끌어당김  = "자석분"
국면2  0 < d < margin     Δ·n > 0  바깥으로 밀어냄(껍질 안착) — 관통 아님
국면3  d < 0              Δ·n > 0  관통 해소
```

49B(`ADSORB_PENONLY=1`)는 `outward ≥ 0`이면 skip이므로 **국면1+2를 함께 껐다.**

→ **50회차가 잰 비용(cov 24.9% · 관통 342 · hit 0.161)은 "자석분 제거"가 아니라
"자석분 + 15mm 껍질 안착 제거"의 비용이다.**
**표적 문장과 실험 대상이 어긋나 있었다.**
→ [[2b-49-α구동력확정]] 「정정 (52회차)」 절 · [[2b-50-지지대안과49정정]]

**부수**: 그 절단 방향에 **`0.25` 손 상수**가 공유 파일에 박혀 있고(`bvhFromArrays.ts:234-235`)
축은 **몸 깊이중심보다 7.2cm 뒤**다 — `dressPattern.ts:584` 주석의 **"새 상수 0"이
그것을 안 셌다.**

### (나) 51회차 진단 계기가 리졸버와 다른 메시를 봤다 — **이번 회차 정정(메인 세션 귀책)**

`nyOf`가 `wholeMesh`(전신·팔 포함)를 썼는데 자석을 만드는 리졸버는
`frontMesh`/`backMesh`(**torso-only · z중점 반쪽 시트**)에 질의한다. **2줄 교체 후 재측정**:

링 뒤판     중앙 0.769 · >0 100%       중앙 0.755 · >0 100% · ≥0.857 33.3→29.6%

밑단 뒤판   중앙 0.114 · >0 65.7%      중앙 0.117 · **>0 68.6%**     +2.9pp

**51회차 결론은 유지된다**(링 100% 유지 · 밑단 앞 1/4만 켜짐 · 뒤 2/3 켜짐 = **R3 그대로**).
