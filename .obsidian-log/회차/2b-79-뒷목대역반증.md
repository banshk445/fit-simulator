## §4 §2 사전 반증

### 4-1 (b) — **옷이 내려앉지 않았다**

```
뒤목 경계 중앙 world y   **144.01** (z −8.95)      vs 목밑점 **145.23** → **−1.22cm**
뒤목 최상                145.11                    → 목밑점 −0.12
앞목 경계 중앙           137.61 (z +9.35)          → 목밑점 −7.62 (**V 처짐**)
옷 최상점                **145.24**(뒤판 #3243)    = 목밑점 **+0.01cm**
기준                     능선 최상단 147.95 · ridgeAnchorY(x=8.12) 144.31 · 어깨관절 137.54
```

**링 y 하한 137.55는 앞목 중앙이다**(뒷목이 아니다).
→ 45회차 「정착 링 y 상단이 목밑점에 안착」이 **재현·확장**된다.
**뒷목선 낙하로 읽을 근거가 실측에 없다 → 드레이프 층위 아님.**

### 4-2 (c) — **표적 진술과 다른 자리다** (갈래 3의 근거)

`deriveShoulderBand`의 마스크는 **팔 축 선분에서 반경 9cm**(선분 길이 18.0cm · 끝점 x±27.3)라
**정의상 삼각근·윗팔**이고 뒷목이 아니다.

```
대역 1421표본   |x| 최소 **10.97** · p5 14.45 · 중앙 19.8cm    → **|x|<11cm 표본 0개**
노출 637        |x| p5 15.1 / 중앙 **18.2** / p95 32.9
                y   p5 115.2 / 중앙 **130.5** / p95 141.5
y 2cm bin 노출률  y114~118 101/135(75%) · y120~124 2/151(1%) · y128~134 273/431(63%)
노출 질량       ① y114~118·|x|28 = **소매단 아래 맨팔**(옷 소매 최저 y116.02)
                ② y128~134·|x|16~19 = **삼각근**(소매가 뜨는 자리 = 화면 결함 ①)
                ③ 어깨 상단
```

**표적이 가리키는 뒷목 아래(|x| 0~11cm)는 이 집합에 없다.**
가장 가까운 부분집합은 `top-back`(|x| 11.6~22.9 · y 133.6~143.5 · n=201 · 노출 98 = 48.8%)이고
637의 **15%**다.

### 4-3 (a) — `backNeckDropM`은 **종속 변수** · 손 상수 2종이 간접으로 섞인다

```
easeScale     = 1 + NECKLINE_EASE_M(0.020) / neckBaseGirthM                  ← 손 상수 ①
neckHalfWidth = bisect(w ↦ 2·len(curve(w, w + FRONT_NECK_EXTRA_M(0.010))), neckBaseFrontM·easeScale)
                                                                             ← 손 상수 ②가 곡선 형상을 고정
backNeckDrop  = bisect(b ↦ 2·len(curve(neckHalfWidth, b)), neckBaseBackM·easeScale)
실측  목너비 8.12 · 앞목 9.12 · **뒤목 5.19** · 목선 48.27 vs 몸 목밑 46.27@y145.23(여유 2.00)
      앞/뒤 배분 56.15 : 43.85%로 몸과 **0.00pp 일치**
```

**자유 미지수가 아니다** — 목너비가 앞쪽 식에서 먼저 확정되고 뒤목은 거기서 따라 나온다.

### 4-4 (d) — **재단 근거가 저장소에 없다. 단 폐기 이력이 있다**

`v2-design.md` · `pattern-redesign.md` · `.obsidian-log/` 전량에 뒷목선의 몸 기준 위치를 정하는
재단 수치가 **없다.** 유일한 흔적이 `patternDraft.ts:36-42`다.

```
:37  "뒤목깊이가 2cm 고정이므로 목너비가 1cm 이상이면 항상 앞>뒤"
:39  "뒤목깊이 — **도출한다**(표준값 2cm 고정을 버렸다)"
```

**표준 뒤목깊이 2cm를 이 저장소가 알고 있었고 의도적으로 폐기했다.**
폐기 사유 = 「총 둘레만 맞추고 배분을 상수로 두면 앞 29.45 / 뒤 18.82 vs 몸 25.98 / 20.29로
어긋난다」. 그 결과가 현행 **5.19cm = 표준의 2.6배**다.

**값 도입은 하지 않았다**(59회차 `w` 선례 · [[../함정/함정14-기준선의존]]).

### 4-5 (e) — 해시 영향

```

            (전부 `pos2`/`tris`)
**안 깬다**  배치 · 충돌 · 렌더 · **계기**(`positions`와 `pos2`가 분리돼 있다)
```

**병기 없이 바꾸면 25~78회차 대조가 끊긴다**(병기 필수).

## §5 계기 결함 **2건** (이번 회차 핵심)

### 5-1 **계기 결함 ① — `rayMin 5mm`가 어깨 상단 노출의 71%를 만든다**

`coverageMetric.ts:336`. 주석(303-306)은 「표면 자기 자신(두께 0의 몸 메시)을 안 맞히도록」이라
적었으나 **레이가 쏘는 `tris`는 옷 삼각형뿐이고 몸 메시가 들어 있지 않다** —
이 하한이 걸러내는 것은 **전부 실제 옷 히트**다.

```
top-back 노출 98개의 최근접 옷 정점 거리 중앙 **6.2mm** vs 피복 판정 103개 **8.7mm**
  → **노출로 찍힌 쪽이 오히려 옷에 더 가깝다**

tMin        전체              top-back
5mm(현행)   637/1421 (44.8%)   98/201 (48.8%)
3mm         547      (38.5%)   53     (26.4%)
0mm         507      (35.7%)   **28   (13.9%)**
버킷별 5→0  top-back-l 47→13 · top-back-r 51→15 · top-front-l 27→13 · top-front-r 21→10
            mid 349→314 · **bot 142→142(불변)**
```

효과가 **top 대역에만 집중**된다 = 어깨 상단에서 옷이 몸에 5mm 이내로 붙어 있는데 계기가
그걸 노출로 센다. `bot`은 전혀 안 움직인다(**진짜 맨살**).

※ **하한 제거가 옳다는 판정이 아니다** — 관통도 t<5mm로 들어오므로 제거하면 관통을 피복으로
셀 수 있다([[../함정/함정11-관통vs노출]]). 위는 **현행 값이 얼마를 만들고 있는가**의 실측이다.

→ [[../함정/함정19-계기가다른대상]] **사례 추가**(주석이 말하는 대상 ≠ 실제 대상).

### 5-2 **계기 결함 ② — 「y124↑ 병기 1038/1038」은 인자 누락 산물**

`dressPattern.ts:2377-2386`의 `computeBodyCoverage` 호출에 **6번째 인자 `clothTris`가 없다**
(바로 아래 `:2387-2397`의 `covSh` 호출에는 있다) → `clothTrisOverride` undefined →
`clothTriangles(sim, [])` → **삼각형 0개** → 전 레이 미스 → **전량 노출**.
y≥124cm 표본 수를 직접 세면 **정확히 1038**이다.

```
46·47·48회차 등재 원인  「`collectBandSamples`가 대역마다 표본 재생성」  → **틀렸다**
실제                   1038은 1421의 **정상 부분집합**이다
현 상태                **이 채널은 지금도 고장 나 있고 보조 수치로 쓸 수 없다**
```

**§3이 지시한 「47회차 기각 채널 재시도」의 결론은 — 재시도할 채널 자체가 깨져 있다는 것이다.**

→ **46 · 47 · 48회차 노트에 정정 블록**을 넣었다(**원문 무삭제**) ·
[[../함정/함정25-말없는실패경로]] **사례 3 등재**.
