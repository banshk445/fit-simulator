## §4 사전 반증 3건 (strategist · **실행 전**) — **이 절을 §5보다 앞에 둔다**

**§0(3)과 §1의 전제가 둘 다 거짓이었다.** 판정 절보다 먼저 읽혀야 한다.

### 4-1 반증 1 — §1의 전제 「어느 시접 쌍의 어디인지 산출된 적이 없다」는 **거짓**

```
`dressPattern.ts:3280-3303`  **35계기 6번**이 **매 실행 무조건** 인쇄한다 —
                             종류별 max|평균 + **상위 10쌍의 kind · 패턴좌표 · 3D 좌표**
등재 위치                    42회차(`metrics-log.md:8123-8131`) · 68회차(`:10428-10429`)
등재 내용                    **11.14mm = side 최대 · 패턴 (±27.50, 24.00) = 겨드랑이 아래
                             옆선 최상단 · 7.20mm 초과 쌍은 정확히 4개 · 그 4쌍은 같은 2정점**
```

**이 회차의 §1 전제가 무너진 것이다.** 함정 판정은 §12-1.

### 4-2 반증 2 — 「11.14mm이 0.76 / 1.76cm와 같은 자릿수」는 **의미 있는 대조가 아니다**(4중)

```
(i)   **다른 양이다** — maxSeamGap = **옷↔옷** 두 정점 거리(`dressPattern.ts:1837-1848`) ·
      1.76 / 1.00cm = **몸 표본 → 최근접 옷**(`:3028-3035`)
(ii)  **89회차 데이터가 이미 반증한다** — 슬릿이 원인이면 정점 최근접과 삼각형 최근접이
      ~g/2(0.36~0.56cm) 갈려야 한다. 실측 벌어짐은 **0.06~0.13cm**이고
      **0.76cm 차는 채널을 바꿔도 살아남는다**
(iii) **자리가 다르다** — 11.14mm은 겨드랑이 아래 옆선 최상단 ·
      패치창 최근접은 소매 capBack **s 3.0~8.6cm**
(iv)  **대표값이 틀렸다** — 비교 가능한 값은 max가 아니라 **중앙 7.20mm이고 전 종류에서 상수**다.
      **공간적으로 균일한 장은 같은 창 안의 노출/피복 대비를 원리적으로 못 만든다**
```

### 4-3 반증 3 — `11.14mm` 분해: **7.20mm는 설계상 당연하다**

```
시접 쌍은 **등식 거리 제약**이다(`clothPhysics.ts:462` — dist < rest면 diff<0이라 **밀어낸다**)
→ SEAM_REST_LENGTH **6.0mm은 목표이자 능동 하한** · 시접은 0으로 닫히지 않는다
그 위에 limitStrain **1.2배**(`:699-712`)가 천장 **7.20mm**을 만든다

11.14mm = 6.00(설계 rest) + 1.20(1.2배 천장 = 7.20) + **3.94(천장 초과 = 이상분 · 4쌍 / 2정점)**
```

42회차가 이미 등재했다: 「이 채널로 A와 ablation을 가르는 것은 **함정 1의 재현**이다」(`:8136`).

### 4-4 **그럼에도 §1을 집행한 이유**

```
전제가 거짓이어도 **다음 셋은 42·68회차에 없다** —
  ① `seamGroups` 기준 **10그룹 분해**(42·68은 종류 **4종**까지였다)
```

### 12-2 판정 ② — 「**마진 < 후보 간격 건수는 삼각부등식상 항등이라 판정력이 0이었다**」
### → [[../함정/함정13-jitter]] **86회차 스냅 사례의 후속 실증**(신설 0 · 함정 27 아님)

**대상**: 86 §10-3이 세운 스냅 4-튜플 규범의 **이진 판정판**
(「마진이 후보 간격보다 작으면 대조에 쓰지 않는다」)을 **건수 채널**로 구현하면
**26/26 · 22/22**가 나온다. **삼각부등식 |d1 − d2| ≤ |p1 − p2|이라 항상 참**이다.

```
① 함정 27(arity)인가   **아니다.** 채널은 **(건수, 분모) 2-튜플**을 이미 낸다(26/26 · 22/22).
                      **4-튜플의 네 값도 전부 산출된다.** 결함은 **네 값을 부등식으로 축약한
                      파생 채널이 항등**이라는 것 — **분모가 없는 것이 아니라 값역이 한 점**이다
② 함정 13인가          **그렇다. 규범 6의 「값역」 항목**이다 —
                      **80회차(문턱이 값역 밖 → 절대 발동 불가)** · **85회차(동어반복 자기검사 →
                      항상 통과)** 와 **같은 구조**다. 이번은 **조건이 항등이라 항상 포화**다.
                      「위태로운 표본 수」라는 이름이 주장하는 것과 계산되는 것이 다르다
③ 새 사례로 세우는가   **세우지 않는다. 86회차 스냅 사례(89회차 후속 실증이 이미 붙어 있는 자리)에
                      후속 실증 블록으로 붙인다.** 대상이 **같다**(스냅 4-튜플 규범).
                      86이 「값이 두 판본」 · 89가 「부호까지 두 판본」 · 90이 「**그 규범의
                      이진 판정판이 항등**」 — **같은 대상의 진행**이다
④ 신규 함정인가        **아니다.** 계기 채택 체크리스트의 정본은 **규범 6**이고,
                      별도 함정을 세우면 **체크리스트가 두 군데로 갈라진다**
                      (80·85·86·88·89회차가 같은 근거로 같은 판단을 했다)
```

**규범 6 「값역」 항목 확장 — 스냅 4-튜플은 비로 낸다**

```
**마진과 후보 간격은 부등식이 아니라 「비」로 낸다.** 부등식 판정은 **삼각부등식상 항등**이라
어떤 실행에서도 참이 되어 **판정력이 0**이다.
**문턱은 여기에 박지 않는다** — 90회차가 쓴 눈금(86회차 확정 아티팩트 **0.0024**)은
**갈래 문언이 지목한 사례**이지 사전 도출 문턱이 아니다([[../함정/함정14-기준선의존]]).
문턱은 **그 채널을 판정에 채택하는 회차가 실행 전에 도출**한다.
```

**부수 — 갈래 문언 쪽의 결함도 같이 등재한다**: 갈래 D 문언에 **수치 문턱이 없었다**
([[../원리/사전등록]] 규범 4 · **arity 미달**). 이 캠페인이 반복해서 걸린 형식이다.
