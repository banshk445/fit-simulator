### (f) **해소** — margin은 결정항에 «실제로» 닿는다. **97·98과 다른 국면이다**

`bvhFromArrays.ts` `createResolver` 클로저에서 margin이 쓰이는 곳은 **2군데**이고,
그 중 **물리에 사는 것은 1군데**다:

```
:235      closestPointToPoint(…, 0, detectionRadius)        ← margin 없음
:249-251  target = hit.point + n · margin                   ← ① **목표점(물리)**
:253-259  if (magnet) { d = q·n; if (d > margin) relax *= w }  ← ② magnet 전달 시에만
:260-262  positions += (target − positions) * relax
```

기준선은 `magnetArg = undefined`(`dressPattern.ts:707`)이므로 **물리에 국면 분기가 아예 없다.**
이동량은 전 정점에 대해 **한 식**이다:

```
Δ·n = PUSH_RELAXATION × (margin − d) = 0.4 × (margin − d)
```

| 회차 | 처치가 닿는 항 | 결정항 `hit.point + n·margin`에 닿나 |
|---|---|---|
| 97 `MAGNET_D0`/`ADSORB_PENONLY` | `relax` 가중 · 정의역 | **아니오**([[../함정/함정31-절제작용점]] 사례 1) |

| **99 margin 리터럴** | **`:249-251` 목표점 상수** | **예** |

등재돼 있다.

**이번 국면의 차이 — 겹친 것이 «실행 이력»이 아니라 «판정 이력»이다**

```
97   「**같은 env를 다시 켠다**」          — 등가가 **문자열**로 보인다(grep 1회)
98   「**다른 스위치인데 식이 등가**」      — 등가가 **산술**로만 보인다
99   「**같은 처치가 이미 판정 «종료»**」   — `docs/metrics-log.md:908-913` · `:931-935`가
     **「margin이 안착 거리를 강제한다」 인과 사슬을 «기각»**했고 좁힌 결론까지 등재해 뒀다.
     겹친 것은 **실행이 있었다**가 아니라 **그 처치의 «판정»이 끝나 있었다**다
```

**별개 양식인가 — 갈라 본다**

```
「판정 이력과 겹쳤다」로 세우면   대상이 **여전히 회차 전제의 「없다」**다.
                             99 전제 1을 그대로 풀면 「이 산출이 아직 없다」 = **부재 주장**이고,
                             거짓임을 보인 **수단**만 grep → 식 대조 → **판정 블록 열람**으로 바뀌었다

                             (96 §7-3 · 97 §7-1 · 98 §5-2가 같은 근거로 신설하지 않았다)
새 국면                       **부재 확인이 「실행이 있었나」로 끝나지 않는 첫 사례** —

판정                         **실패 양식 18 «재발 블록 4»**(95·96·97·98·99 **다섯 회차 연속** ·
                             90까지 세면 여섯 번째) · **귀책 표기 0**(95~98과 같다 ·
                             대장 번호 부여는 전략 세션 몫)
```

**「볼트가 이미 «금지»해 둔 것을 발주했다」가 새 국면인가 — «새 국면이다. 그러나 양식 18 안이 아니다»**

```
사실        `docs/metrics-log.md:9860`이 **그 처치를 명시적으로 금지**하고 있었다 —
            「`COLLISION_MARGIN`은 근거가 정성적이라 **값을 스윕하면 함정 14 정면.
            도출을 바꾸는 것만 허용 범위**」. **99 프롬프트에 그 조항의 처분이 없다**(전제 8)
대상이 다르다  양식 18의 대상은 회차 전제의 **「없다」(부재 주장)**다.
            전제 8은 「**없다**」가 아니라 「**해도 된다**」이고, 볼트는 **그 반대를 명시**했다 —
            **부재 주장이 아니라 «등재된 금지 조항의 처분 누락»**이다
그러면 신설하나  **이 회차는 신설하지 않는다.** 신설하려면 「**어느 조항이 처분 대상인가**」의
            **판별 절차**가 필요한데 이 회차는 그 절차를 도출하지 않았다
            ([[../원리/사전등록]] 규범 4·5 = 문턱·절차는 **채택 회차가 실행 «전»에** 도출).
            **선례**: 92회차도 같은 형태에서 「**규범을 신설·개정하지 않았다 — 자리만 남긴다**」로 끝냈다
등재         **사실 등재만 · 양식 신설 0 · 규범 신설 0 · 문턱 0.**
            [[../원리/사전등록]] 재발 블록 4에 **「금지 조항 미처분」을 «자리»로 병기**한다
```
