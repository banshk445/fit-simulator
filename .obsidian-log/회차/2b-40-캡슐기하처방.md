## 1. 사전 등록 문턱 3종이 전부 결함 — 실행했어도 판정 불가였다

1. **`정착 뒤판 링 반경 최소 ≥ 7.36cm`** — 링이 정착하는 y137~145의 **뒤쪽 섹터
   몸 표면 반경은 3.40~7.81cm**다. 링을 실제 몸 뒤쪽 표면에 올려놓는 **성공 처방도

   비등방 단면이다([[함정14-기준선의존]]).
2. **`covShoulder 52.9%`** — 기준선 60.9와 ablation 44.8의 **산술 중점**이다.
   CLAUDE.md 규약("문턱은 **달성이 실증된** 수준에서 도출")에 걸린다. 실증값은 44.8이다.
3. **`링 배율 1.60`** — **도출 근거가 저장소 어디에도 없다**(metrics-log · 회차 노트 ·

→ [[사전등록]] 실패 양식 4(문턱을 명시했는데도 판정 불가).

## 3. 캡슐 y 상한 — 도출은 되나 **구조상 적용 불가**

"실제 몸 반경 ≥ 캡슐 반경 15.92cm인 최고 y"의 답이 **채널마다 다르다**:

```
① body.slices 등가반경 girthM/2π      **공집합** (전 높이 최대 13.37 @y125.54)
①' slices 반폭/반깊이                  공집합 (최대 반폭 15.81 @y78.04 = 최하단)
②  원본 메시 최대반경 · 팔 제외         **y = 132cm**
③  원본 메시 최대반경 · 팔 포함         **y = 142cm**  (삼각근·상완 18~26cm)
```

정의가 방향·팔 포함을 고정하지 않아 **10cm 이상 흔들린다**. `girthM` 편향(볼록껍질·
최근접점·24 bin)은 전부 반경을 **낮추는** 방향이라 y 상한을 낮게 민다. 단 편향 없는
채널 ②에서도 y132 위로 15.92를 못 넘으므로 **"y133 이상에서 몸은 캡슐만큼 굵지
않다"는 결론 자체는 편향 무관하게 성립**한다.

**그런데 적용이 안 된다** — `applyCapsuleCollision`은 `t`를 [0,1] 클램프해 끝단이
**반구**다(`torsoCapsule.ts:77-80`). 상단을 Y로 내려도 y>Y의 밀어내기 반경은
√(17.42²−(y−Y)²)로 0이 아니다:

```
Y=142.5(채널③) → 정착 링 전 구간이 Y 아래 = 효과 0.00cm
Y=132.5(채널②) → 링 y135 17.16 · y138 16.40 · y140.86 15.29  (−0.3~−2.1cm)
반경 0이 되려면 Y ≤ 140.86 − 17.42 = **123.44cm** = 가슴 전체 프록시 제거 ≈ ablation
```

`torsoCapsule.ts:196-206` 주석이 정확히 이 이유로 `topY = shoulderY + 0.3`을 잡았다.
→ **몸에서 정직하게 도출한 경계가 구조상 적용 불가** = 회차 프롬프트가 지정한 정지 사유.

## 4. 부수 발견 — 캡슐 반경의 출처가 몸이 아니다

`torsoCapsule.ts:216` `chestRadius = chestM/(2π)`이고 `chestM`은 **슬라이더 절대값**
(`useFitStore.ts:99` 기본 100cm → 15.915cm). 그런데 `Mannequin.tsx:267`은 같은
슬라이더를 **상대 배율**로만 쓴다 → 기본값에서 메시는 스케일되지 않는다.
그 메시 실측 가슴둘레는 **84.01cm**(등가반경 13.37 · 최대 반폭 12.91 · 반깊이 11.52).

**캡슐은 자기 설계 높이(가슴)에서조차 몸보다 1.19배 크고, 몸의 어떤 높이·어떤
방향보다도 큰 반경을 뒤쪽에 들이민다**(`backExtentM` 8.19 vs 15.92).
