# 2b-31 — f1 국소화 (+32.07cm는 어디서 오는가)

물리·제약 **0줄**. 신설: 패스별 링 길이 프로브(읽기 전용). `GarmentFrameEnv.probe`는
미설정이면 호출조차 없다.

## 패스 실행 순서 (코드에서 그대로)
```
서브스텝 {
  frictionIterationReset
  sim.step(dt, g, collisionResolver, iterations, collisionEvery, damping, maxDisp, iterExtra)
    └ 적분 → [반복 × n: 거리 제약 → (collisionEvery마다) 충돌(흡착) → iterExtra{order, 반복내 마찰, applyAnchors}]
  friction(SDF)
  selfCollision
  order
  clampOverstretchedConstraints   ← limitStrain(1.2) × 2패스
  limitCollarStrain(1.02)
  syncWeldedPositions
}
```
**`limitCollarStrain` 이후에 위치를 쓰는 패스는 `syncWeldedPositions` 하나**이고
용접 0쌍이라 빈 루프다(19회차 반납). 즉 목선 전용 제약이 **마지막 발언권**을 갖는다
— 순서로는 면책된다. 그런데도 뚫린다.

## 1. f1 (표적 프레임) — 서브스텝 1개, 순변화 +32.07cm

| 패스 | Δ | 양의 기여 중 |
|---|---|---|
| **0b 구간**(적분 + 거리 제약 1회차) | **+34.68cm** | **53.3%** |
| **1b 구간**(거리 제약 나머지 반복 + 반복내 마찰) | **+15.88cm** | **24.4%** |
| **5. limitStrain(1.2)** | **+14.55cm** | **22.3%** |
| 3. selfCollision | **+0.00cm** | 0.0% |
| 6. limitCollarStrain(1.02) | **+0.00cm** | 0.0% |
| 1a. 충돌(흡착) | −5.53cm | (감소) |
| 1. sim.step 잔여 | −27.52cm | (감소) |

**양의 기여 총합 65.11cm vs 순변화 32.07cm** — 한 프레임 안에서 링이 벌어졌다
줄었다를 반복하며 순변화의 2배를 왕복한다. 서브스텝 내부 진동이 크다.

### 적분은 무죄
f1의 관성 `max|pos−prev|` = **0.000mm**(배치 직후 prev가 제대로 동기화돼 있다).
남는 적분 입력은 균일 중력 `g·dt²` = 2.725mm뿐이고, 균일 중력 + 관성 0은
**강체 평행이동**이라 거리를 바꾸지 않는다. → 0b 구간 +34.68cm는 전량
**거리 제약 반복 1회차**다.
※ 한계: `clothPhysics`를 못 건드려 적분/거리제약 경계에 프로브를 직접 못 넣었다.
  위는 논증이고 직접 실측이 아니다. 계기 삽입 지점이 생기면 확인할 것.

## 2. 사전 등록 판정 → **첫째 갈래: 표적 확정**

거리 제약 계열(0b + 1b) = **50.56cm = 양의 기여의 77.7%**. 과반을 크게 넘는다.
→ **표적 = 거리 제약 반복.** 다른 후보는 종결한다.

### 30회차 후보표 전량 기각 — 정정
30회차가 지목한 1·2순위가 **둘 다 무죄**다:
- **자체충돌 +0.00cm**(f1·f8) / −0.04 / +0.02 — 링을 벌리지 않는다
- **흡착 −5.53cm**(f1) — 오히려 **줄인다**

30회차의 "능동 유지원"은 맞았지만 지목한 대상이 틀렸다. 근거였던 "능동 위치
투영이니까"는 **후보를 좁히는 논거가 못 된다** — 거리 제약도 위치 투영이다.

### 3번(ablation) 미실행
사전 등록대로 — 1에서 과반이 갈렸으므로 자체충돌/흡착 ablation은 돌리지 않았다.
**자기교차 6414 은행 해제 판정 요청도 없음**(자체충돌이 지목되지 않았다).

## 3. 다른 프레임 — 시점에 따라 지배 패스가 바뀐다

| 프레임 | 순변화 | 최대 양의 기여 |
|---|---|---|
| f1 | +32.07cm | 0b 거리제약 53.3% |
| f8 | +3.21cm | 1b 거리제약+마찰 56.1% · 0b 40.1% · limitStrain 3.8% |
| f62(S1 최대) | +0.08cm | 0b 51.1% · **흡착 48.9%** · limitStrain **−6.34** |
| 정착 | +0.00cm | **limitStrain 56.9%** · 흡착 25.8% · 0b 17.1% |

**정착에서 링을 벌리는 최대 기여는 `limitStrain`이다.** 신장을 막으라고 있는
패스가 링을 늘린다 — 목선 대역 안쪽의 과신장 엣지를 줄이면서 그 끝점(= 링 정점)을
바깥으로 민다. 27회차 strain 지도(상위 11이 전부 목선 곡선 바로 안쪽)와 자리가
정확히 같다. 30회차의 "능동 유지원"의 정체는 이쪽이다.

## 4. 목선 전용 제약은 신장이 만들어지는 내내 **꺼져 있다**
`limitCollarStrain` 기여가 f1·f8·f62 전부 **0.00cm**다. 21회차의 시점 분리로
봉합(f120) 전까지 링 전용 상한이 일반 상한에 위임되기 때문이다. 링이 1.000 →
2.08배가 되는 구간(f1~f8)에 목선 제약은 배선상 **무효**다.
