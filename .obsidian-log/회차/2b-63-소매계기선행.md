## §4 관통 패널 귀속 — **A의 관통 50 중 소매 47 (94.0%)**

62회차 §8이 **최우선 등재**한 결여("관통 계기 2종이 소매분을 못 가른다")를 해소했다.

```
A  정착 후 총 50 — 앞판 0 · 뒤판 3 · 소매L 23 · 소매R 24 │ **소매 합 47 (94.0%)**
   패널 × y  소매L·y130~143 22 / 소매R·y130~143 22 / 뒤판·y130~143 3 /
             소매R·y94~129 2 / 소매L·y94~129 1

S3 정착 후 총 60 — 앞판 0 · 뒤판 5 · 소매L 30 · 소매R 25 │ **소매 합 55 (91.7%)**
```

### 사전 등록 갈래 판정 ①

> **"관통 50이 소매에 몰리면 61 §6의 게이트 상한 50→3이 실측 확인"**
> → **몰렸다. 확인.**

### 45회차 라벨 정정이 **실측으로 확정**됐다

y130~143 **47건 중 44가 소매**, 3이 뒤판.
61회차는 **산술 추론**(소매 캡 world y 130.7~141.3cm 계산)으로 라벨을 정정했고,
63회차가 **패널 귀속 실측**으로 같은 결론을 냈다.
→ 2b-45 노트에 **실측 확정 블록** 추가(원문 무삭제).

### 62회차 S3 재평가 자료 — **두 소매 채널이 반대 방향이다**

```
자기교차 소매 관여   114 → **10**   (개선)
관통② 소매분         47 → **55**    (악화)
```

62회차 §5가 *"소매를 실제로 구분하는 채널은 전부 크게 개선됐다"*고 적은 것과
**엇갈린다.** 당시엔 관통 소매분이 산출 불가라 이 대조가 불가능했다.

**어느 쪽이 옳은지 이 회차에서 판정하지 않는다** — [[함정22-두계기다른판정]] 계열
(두 계기가 같은 표적에 다른 판정). 62회차 노트에 **정정 블록**으로 추가한다.

## §5 부수 계기 2건

### (가) β-1 뒤판 행 추가 — 62 §8 해소

출력 **6행 → 12행**(앞/뒤 × 0/1/2홉 × x±). 62회차가 *"β-1은 앞판만 출력된다
(뒤판 행 없음 — 산출 불가)"*로 등재한 결여를 해소했다.

### (나) 소매 방향 분해를 **하네스 채널로 승격**

61회차가 일회성 프로브로 냈던 소매 엣지 신장비 방향 분해를 상설 채널로 올렸다.

**자기검사 통과**:

```
t=0 원주 대역 1.1994   vs 61회차 프로브 1.2021
t=0 최대     1.206     vs 닫힌형식 예측 **1.206939** — 일치
```

### 새 사실 — **정착에서 방향 관계가 완전히 역전된다**

```
                t=0(A)    f8(A)     정착(A)      정착(S3)
0~15°(원주)     1.1994    1.0283    1.0289       1.0195
75~90°(축)      1.0035    0.9923    **1.0627**   **1.0708**
```

**배치는 원주만 늘리는데, 정착에서는 축이 가장 늘어난다.**
→ 정착 소매 신장의 **주축은 배치 신장이 아니라 중력·현수 방향**이다.
61회차가 *"33회차 이월분(균일 신장 1.108)은 t=0 배치값이고 정착 결함이 아니다"*로
낸 결론을 **방향 축에서 재확인**한 것이다.

## §6 S3 필드 공유 격리 — **조건부 가능**(사실 확인 · 집행 금지)

62회차 실패의 주소는 *"필드가 전 정점 공유 → 소매를 격리할 수 없다"*였다.
그 격리가 가능한지만 확인했다(strategist · 제안 금지 · 사실만).

### 필드 층위 — **원리적 불가**

`bakeSdf`는 **복셀 루프뿐이고 정점 개념이 0**이다. 필드를 정점별로 가를 수 없다.

### 소비 시점 — **가능**

```
마찰 3함수가 전부 (positions, prevPositions, pinned, n) 시그니처
**정점 간 결합이 0**
소매 = 인덱스 꼬리 **연속 구간 [4296, 5244)**
→ 호출자가 subarray 로 잘라 두 필드를 따로 먹이면 된다
   (같은 관용구가 dressPattern.ts:650 에 이미 있다)
```

**58회차 `magnet.w`(정점 인덱스를 안 받는 스칼라 훅 — 치명 1)와 다른 점이 이것이다.**

### 비용

```
굽기 2회      ≈ **660ms 1회성**
필드 크기      517KiB
프레임 비용    불변
변경 범위      **15~25줄 전부 dressPattern.ts 안**
→ **패턴 해시 불변 · v1 0줄 · 12콤보 불요**
단서: sdfCollision.ts 를 건드리면 즉시 v1 워커 + 12콤보 정의역(import 6곳)
```

### 경계 효과는 51 · 58회차와 **형태가 다르다**

암홀 시접 **124쌍**을 사이에 둔 **마찰 상태의 계단**이고,
**접선 투영은 부호에 불변**이므로 증상이 *"반대로 끌린다"*가 아니라
*"한쪽 고착 / 한쪽 자유"*다.

### 비대칭에 **코드 근거가 있다**

`checkPattern.ts:157-162` — 배치 시점 **앞판 412 · 뒤판 143 정점**을 골격 규칙이
오분류해 판정을 **레이 패리티로 바꾼 이력**. 즉 **골격 기준은 몸판에서 이미 크게 틀린다.**
(소매에서는 3.7%였다 — 62 §3.)

> **"격리 가능으로 나오면 S3 재시도 후보로 등재(집행은 다음 회차)"**
> → **조건부 가능 → 등재.**
