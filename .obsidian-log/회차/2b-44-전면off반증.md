## 반증 ① — "전면 off는 39·42에서 2회 재현됐다"는 **거짓**

`[39·ablation 상태]` 라인을 전 실행 로그에서 전수 확인:

```
r39.log on · r39-nocap.log **OFF** · r42-base.log on · r42-A.log on ·
r42-B.log on · r42-taper.log on · r43.log on
```

**`TORSOCAP=0`은 저장소 이력에서 정확히 1회 실행됐다(39회차).**
42회차 4열의 ablation 열과 `00-현재상태.md`의 ablation 수치
(61.80 / 1889 / 2.661 / 50 / 11.14)는 **39회차 값의 전재**이지 재측정이 아니다.

→ **n=1 · 재현성 판정 이력 0.** 43회차가 A에 적용한 판정 기준(재현성이 1차 관문)을
그대로 쓰면 **ablation은 재현성 칸이 비어 있다.**

부수: 그 1회는 `singleDeepest` 도입 **이전** HEAD였다. `SINGLE_DEEPEST`는 몸통 캡슐
호출에만 전달되므로 `TORSOCAP=0`에선 무영향 → 재현은 원리적으로 가능하나 **확인 안 됐다.**

## 반증 ② — 43회차 마스크 기준이 **max() 인질**

43회차 (a)의 `몸최대 ≥ 17.42` 기준은 **옆(삼각근·어깨너비)이 항상 지배**한다.
링이 실제로 얹히는 **뒤쪽**은 전 높이에서 캡슐이 바깥이다:

```
높이    앞쪽 여유(캡슐−몸)   뒤쪽 여유
y110      +0.64cm           **+15.70cm**
y128      +2.53cm           **+9.87cm**
y132        —               **+9.24cm**
뒤 섹터(±30°) 여유: y100~123 +11.6~+16.6cm · y128~137 +9.3~+10.9cm
```

원인: `buildTorsoProxyCapsules`가 축 (x,z)를 **어깨뼈 중점**으로 잡는데 fixture에서
z = −2.79cm이고 메시 깊이중심은 y110 +4.75 / y128 +0.88
→ **캡슐축이 몸 깊이중심보다 7.2cm 뒤**다.

**그리고 y80~93 "유지 대역"은 손·전완 오염 산물이다.** 팔 제외 선분(`length 0.22m`)이
어깨 y137.54 → y118.67까지만 덮어 **y118 아래에서 0개를 제외한다**:

```
y85  전체 334정점 중 r>30cm **284개**(중앙 52.09cm) = 손·전완
     r<30cm 50개의 최대는 17.05cm (push 16.62 → +0.43cm)
```

→ **진짜 유지 대역은 y70~83**(밑단·엉덩이, 초과 +0.5~3.2cm)이고,
**y94~123(30cm)에서 캡슐 push에 도달하는 정점은 사실상 0개**
(예외 y100 2 / y105 6 / y107 2, 최대 +0.22cm), y124~129도 초과는 정점의
**8~17% · ≤0.55cm**다.

결론("전면 off ≈ P3")은 여전히 서지만 **근거가 max 채널이 아니라 per-vertex 분해여야
한다.**

## 등재 ③ — 승격이 잃는 것 (반증은 아니나 판정 전 등재)

1. **`TORSOCAP=0`은 43회차가 통과 3/3으로 확정한 새 기준선 A를 no-op으로 만든다** —
   `SINGLE_DEEPEST`는 몸통 캡슐 호출(`:604`)에만 전달된다.
2. **`rStar` 식이 정의상 소멸한다.** 43회차가 `[stale]`로 표기했지만 `singleDeepest`가
   켜지면서 전제("정점당 캡슐 1개")가 **오히려 참이 됐다**(43회차 per-vertex 카운트 =
   링 62/62 정확히 1개). A 로그 f62: **r\* 예측 원둘레 102.13cm vs 실측 정착 링
   102.93cm = 0.8% 이내.** 현재 저장소에서 **정착 링 길이를 예측하는 유일한 검증된
   식**이다. 그 식으로 계산하면 캡슐 기여 = 0.35×17.415/0.75 = **8.13 / 16.21cm = 50.2%**.
3. `spikeDressing.ts:141-155`는 `unified`의 **독립 복제본**이고 몸통 캡슐을 무조건
   부른다 → 어느 방식이든 **착장 경로 2개가 서로 다른 접촉 스택**을 갖게 된다.

## (b) 관통 위치 분해 — **채널이 이미 있고 한 번도 인쇄된 적이 없다**

`makeParityInside`는 **per-vertex 술어**이고 패널·y대역 분해 블록이
`dressPattern.ts:2057-2066`(`DIAG=1` 안)에 이미 있다. 그런데 **전 실행 로그에
`[dress·diag]`가 없다** — `DIAG=1` 실행 **0회**.

**비수밀 근사의 신뢰도는 대역 의존이다**(비-2회 2,760개 높이 분포):

```
y80~100 합 1,130 = 전체의 **41%**   ← 관통 분해 신뢰도 최저
y100~130  36~40/5cm (기저)
y130~135 80 · y140~145 94           ← 링 대역, 기저의 2.2~2.6배
```

**관통 깊이 채널은 없다** — `countInside`는 이진 플래그 개수다. 120 → 50이
"깊은 50 vs 스치는 120"일 수 있다(`closestPointUnsigned`가 이미 있어 새 기계는 불필요).

## (c) 계기 확장 — 둘 다 정의역 한 줄

`capsuleHitCount`는 **이미 전역 인덱스 함수**이고 제한은 `ringOrder.map(...)` 한 줄뿐.
밀어내기 크기는 `compSequential`의 `snapA/snapB`가 **전 정점에 대해 이미 있고**
`seg(from,to,idx)`가 임의 인덱스 배열을 받는다 → y대역별 idx만 추가하면 된다.

## (d) maxSeamGap 악화 — **240쌍 중 2정점의 max. 236쌍은 불변**

```
종류별 최대|평균(mm)   side          armhole       shoulder     sleeveUnder
39 기준선             8.98|7.25     7.41|6.83     7.20|6.86    7.20|7.18
A                    10.31|7.23     8.76|6.98     7.20|7.09    7.20|7.14
ablation             11.14|7.23     9.18|6.96     7.20|7.08    7.20|7.04
```

**악화는 전부 side·armhole의 최대에서 오고 평균은 안 움직인다**(side 7.23 → 7.23).
7.20mm를 넘는 쌍은 A·ablation 둘 다 **정확히 4개**이고, 그 4쌍은 **같은 2정점**이다
(3D 좌표가 side 행과 armhole 행에서 동일) — 패턴 (±27.50, 24.00) =
**겨드랑이 아래 옆선 최상단**, 좌우 대칭 2정점 × 2종류.
천장 7.20mm(= `SEAM_REST_LENGTH` 6.0 × `limitStrain` 1.2) 대비 10.31 / 11.14 =
**1.43배 / 1.55배**. 원인은 (i) 2패스 미수렴 또는 (ii) **측정 시점** — 서브스텝 마지막
반복에 충돌이 강제 발화하고 그 뒤 거리 제약 패스가 없다. 그 코너의 두 정점은 앞판·뒤판
**서로 다른 BVH**로 끌리므로 리미터가 완벽히 수렴해도 흡착 변위 차만큼 갭이 열린다.
**현 채널로는 안 갈린다.**

→ **이 채널로 A와 ablation을 가르는 것은 함정 1(max 인질)의 재현이다.**
