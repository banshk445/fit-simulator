# 2b-25 — 링 폐곡선화

## 변경 (변수 하나 · 새 상수 0)
`necklineRing`을 폐곡선으로 닫는다(앞목 사슬 + 뒤목 사슬 + **목점 접합 2구간**).

> **부호가 뒤집힌다.** [[2b-24-목점앵커제외]]에서 두 열린 사슬의 수축이 목점을
> 서로 **반대로** 밀어냈다. 닫으면 접합 구간이 원주의 일부가 되므로 같은 수축이
> 목점을 **당긴다**.

구현은 ①(목점 쌍을 링 엣지로 추가). ②(적용 범위만 확장)를 선호했으나
`limitCollarStrain`이 **엣지 단위** 기계라 총 원주 항이 없어 clothPhysics 수정
없이는 불가능. 접합 rest는 **시접 target**에서 도출 — 예전에 이 접합을 뺀 이유
(rest가 배치 거리 31cm로 굳는다)가 평면 배치에서 해소된다.

## 검증
```
링 폐곡선화: 엣지 60 + 접합 2 = 62 · 정점 62 · 전 정점 차수 2 OK
             순회 복귀 62/62 OK(단일 순환) · 접합 rest 6.0mm(= 시접 target)
```

## 결과 — **DONE 첫 도달**
```
f=120 S1→S2(갭 10.0mm) → f=240 S2→S3(봉합 유지 120f) → f=260 **DONE**
되열림 **0회** · RETRY **0회** · 발산 0 · 정착 f=260(예산 720)
목점 쌍 최종 갭 **6.1 / 6.1mm**(target 6.0) — **240/240 봉합**
```
**예측대로 부호가 뒤집혔다**: 24회차는 링 길이 ↔ 갭이 반대 위상 진동이었는데,
이번엔 링 104.14~104.27cm로 거의 일정하고 갭이 12.8 → 12.4mm **단조 감소**.
