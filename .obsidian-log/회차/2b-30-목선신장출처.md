# 2b-30 — 목선 신장의 출처

물리·제약 **0줄**. 전 진단은 `RINGTOTAL=0`(25회차 비트 재현) 위에서 — 26회차
상한을 교란 요인에서 제외. 신설 계기 3건(단계 분해 · 대역 잔차 · 중력 0 ablation).

## 1. 4.2의 정체 — **제약이 아니다**

| 이름 | 값 | 정체 |
|---|---|---|
| `COLLAR_STRAIN_LIMIT` | 1.02 | **집행**. `env.collarStrainLimit` → `sim.limitCollarStrain()`, 대상 = `necklineRing` 62쌍, 매 서브스텝 하드 위치 투영 1회 |
| `limitStrain`의 `maxStretch` | **1.2** | **집행**. clothPhysics **하드코딩 리터럴**. `clampInSubstep: true`로 매 서브스텝 2패스, 전 `constraints` 대상 |
| **4.2** | — | **제약 아님.** 제품 코드에 그 상수가 없다. CLAUDE.md의 **게이트 문턱**(v1 기준선 3.38 대비 +25%)이고 `clothConfig`엔 주석으로만 등장 |

→ 4.2를 "하드 상한"으로 부른 문서·보고를 **정정**한다. [[함정13-jitter]] 계열
(계기·문서의 이름이 실제와 다른 사례). 진짜 상한은 **1.2**다.

### 1급 발견 — 집행 제약 위반
집행되는 상한이 1.2인데 실측 최대 신장비는:
```
25회차 상태(RINGTOTAL=0)   6.687  = 상한의 **5.6배**
26회차 상태(상한 on)      10.691  = 상한의 **8.9배**
```
`limitStrain`의 유일한 면제 조항(양끝 모두 핀)에 해당하는 제약은 목선 대역
2620개 중 **0개**다. 면제로 설명되지 않는다. 계기 정합도 확인했다 —
`maxStrain()`이 순회하는 `constraintPairs`는 `limitStrain`이 순회하는
`constraints`와 **같은 배열**이다(getter가 그대로 노출).

## 2. 링 길이 단계 분해 (rest 확정 48.24cm)

```
배치 t=0   48.24cm (1.000배)   ← 배치는 무죄
f1         80.31   (1.665배)   ← 첫 물리 프레임 하나에서 +32.07cm
f8        100.43   (2.082배)
S1 최대   123.73   (2.565배) @f62
S1 이탈   105.51   (2.187배)
S2 진입→이탈 104.14 → 104.56   (+0.42cm)
S3 진입→이탈 104.56 → 104.54   (−0.02cm)
```
**판정 = (ii) 봉합 과정에서 만들어졌다.** 배치 시점에는 없었고(1.000배), 정착
중에 자라지도 않는다(S2+S3 합쳐 +0.4cm). 전량이 **S1**(시접 rest 램프) 구간,
그중에서도 **첫 8프레임에 이미 2.08배**다. 25회차 봉합 전 최대 123.73은
**f62 · S1**이다.

## 3. 회수 불능 vs 능동 유지 (one-shot)

### 3a. 중력 0 ablation — **미회수**
정착 도달 후 중력만 0으로 300프레임:
```
링 104.54cm(2.167배) → 101.56cm(2.105배) · rest 48.24cm
회수율 5.3%  (여분 56.29cm 중 2.97cm)
경과 f+30 101.71 · f+60 101.13 · f+150 101.49 · f+300 101.56  ← 진동, 수렴 아님
```
**기하 하한 가설도 같이 기각된다**: 링이 앉은 높이(중심 y138.15)의 몸 단면은
**63.95cm**인데 링은 101.56cm = **1.588배**다. 몸이 안에 꽉 차서 못 줄어드는
것이 아니다. → [[함정16-수치근접]]

### 3b. 목선 대역 제약 잔차 (정착 시점, 집행 상한 1.2 기준)
```
25회차 상태  신장비 중앙값 1.151 · p99 3.279 · 최대 6.687
             상한 초과 위반 1155/2620(44%) · 잔차 중앙값 0.00mm · p99 24.32 · 최대 44.57mm
26회차 상태  신장비 중앙값 1.188 · p99 7.872 · 최대 10.691
             위반 1231/2620(47%) · p99 54.27 · 최대 50.81mm
```
중앙값은 상한 **바로 아래**(1.151/1.188 vs 1.2) — 대다수 제약은 지켜진다.
꼬리가 못 지킨다: 44~47%가 초과하고 p99 잔차가 24~54mm다. **"못 지킨다"** 쪽.

## 4. 사전 등록 판정 → **③ 중력 0에서 미회수 = 능동 유지원 존재**

목선 층위가 아니다. 다음 회차 표적으로 후보를 지목한다:

| 후보 | 판정 | 근거 |
|---|---|---|
| 앵커 잔류 | **배제** | 정착 시 앵커강도 0.000 · `anchors: () => []`(PINDRESS off) |
| 핀 | **배제** | `pinCorners: false` · 하드 핀 0개 · 대역 내 양끝 핀 제약 0개 |
| 시접 스케줄 | **배제 방향** | S2/S3는 rest=target 고정이고 부호가 **수축**이다 |
| **자체충돌** | **1순위** | 최소거리 강제 = 능동 **팽창** 위치 투영, 매 서브스텝. 뭉친 목선 대역·자기교차 6414 은행과 자리가 같다 |
| **흡착 접촉** | 2순위 | 탐지 반경 안 정점을 margin 거리로 흡착(Stage 1b 판정으로 2b는 흡착 모드). 능동 위치 투영이고 `clampInSubstep`보다 **먼저** 돈다 |

**처방 집행 없음**(사전 등록대로).

## 부수 1급 관측 — 26회차 상한은 평형이 아니라 **눌러 둔 값**
26회차 상태에서 중력 0 구간을 돌리면 링이 **54.05 → 101.98cm로 튀어 오른다**.
25회차 자유 평형 101.56과 사실상 같은 값이다(0.4cm 차).
※ 이 구간은 중력과 함께 하네스의 프레임당 축소도 빠지므로(축소는 `onFrame`에
   있고 ablation은 `session.step`을 직접 돈다) **두 변수 동시 제거**다 — 귀속은
   못 한다. 그러나 "손을 떼면 자유 평형으로 복귀한다"는 사실 자체는 성립하고,
   27회차의 잔여 일량 36.8cm/프레임이 **바로 이 스프링을 누르는 힘**이었음을
   설명한다. → [[2b-26-링총길이상한]]
