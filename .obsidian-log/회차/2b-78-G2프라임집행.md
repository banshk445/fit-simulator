## §3 집행 전 브라우저 재측 (프롬프트 §2) — **77회차 이식본과 일치**

```

          = **45.3% × 63.3%** · 문턱 **미발동**
흰 배경    대표색 (30.46, 28.35, 33.78) · bbox **723×668 @(0,0)**
```

문턱 판정은 완전 일치**한다.

## §4 처방 (프롬프트 §1) — `findPrintBoundingBox` **안에서만**

```
1  1패스에서 후보 화소를 **마스크(Uint8Array 128²)로도 기록** — bbox 산출식 **불변**
2  문턱에 **안 걸리면 즉시 반환** → **재스캔에 도달하지 않는다**
3  걸렸을 때만 **8-연결 성분 분해** → **프레임 경계에 닿는 성분 제외** → bbox 재계산
4  다시 문턱 검사 → 통과하면 반환
5  여전히 걸리면 **기존대로 프린트 버림**
```

```
새 상수      **0** — 문턱값 · 색거리 · 근백색 술어 **전부 안 씀**(**위상만** 쓴다)
값 조정      **0**
판별자       **재스캔 발동 · 성분 수 · 제외 수 · 재스캔 후 bbox**를 인쇄
             ([[../함정/함정25-말없는실패경로]] 준수 — 재스캔 경로가 말을 한다)
```

### 5-1 컷아웃 불변 — **비트 일치 + 직접 증거**

대표색 · bbox · 프레임 비율이 **71 / 76회차와 완전 일치**하고 **`rescan: null`** —
**재스캔이 아예 실행되지 않았다.**

이것이 「**1패스 미발동 자산은 경로가 정의상 동일**」의 **직접 증거**다 —
**G2 대신 G2′를 고른 근거가 실측으로 확인됐다**(§7-1).

### 위험 갈래 재확인 — (e)는 **여전히 실측 불가**

크롭 경계에 프린트가 **닿는** 자산이 저장소에 **0개**라 (e)를 실측할 수 없다.
그런 자산에서는 **프린트를 통째로 버릴 수 있다**(경계 접촉 성분으로 제외되므로).

→ **한계로 등재했고 값은 넣지 않았다.** 그런 자산이 생기면 **재판정**한다.
