(구 경로 비트 동일성 하드 게이트 위반). **이것이 참이면 집행 금지다.**」 → **참이다.**

`buildArmCapsules`를 메시 실측화하면 **v1 제품 경로와 v1 게이트 하네스가 함께 바뀐다.**
CLAUDE.md 하드 게이트 「**구 코어 12콤보 비트 동일성 깨짐 = 즉시 실패**」에 정면으로 걸린다.

**게이트 분모 경로는 안 닿는다 — 첫 조항은 통과다**

```
patternGarment.ts:546  armGirthM = 2 * Math.PI * ARM_COLLISION_RADIUS   ← **상수를 직접 읽는다**
checkPattern.ts:108    report(checkDraft(g.draft, g.meta.armGirthM), …)
patternDraft.ts:448    암홀 ≥ armGirthM + ARMHOLE_ARM_CLEARANCE_M
patternDraft.ts:470    소매 둘레 > armGirthM
→ **`buildArmCapsules`를 경유하지 않는다.** 상수를 안 바꾸는 한 **게이트 분모는 불변**이다
```

즉 **두 조항의 판정이 갈렸다** — 게이트 분모(첫 조항)는 통과, 공유(둘째 조항)는 **위반**이다.
**둘째 하나로 집행 금지가 성립한다.**

**v2만 바꾸려면 필요한 분기 — 코드 사실만 · 제안 아님**

```
`garmentFrame.ts`에 **별도 함수**를 두고 `dressPattern.ts:686`만 그것을 부르면
v1 3경로(`garmentWorker.ts:470` · `paramSweep.ts:441` · `spikeDressing.ts:127`)가 **안 닿는다**
```

**이번 회차 프롬프트가 지정한 처방 형태는 그것이 아니다** — 지정 문언은
「`buildArmCapsules`가 … 취하도록 **바꾼다**」이고, **형태를 바꾸는 것은 사후 설계 변경이므로
하지 않았다.** (분기 지점은 **코드 사실로만** 남긴다 — 다음 회차의 재설계 재료다.)

### 4-2 (b) 반경 정의 — **등가와 max가 둘 다 반증에 걸렸다**
