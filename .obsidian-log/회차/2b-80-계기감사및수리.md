## §4 §2 결함 ③(참조축) — **판별 불가 · 교체 안 함**

```
각도차 중앙값   (a) 팔축 **0.0°**   (b) 몸통축 **0.0°**   → 차이 **0.0° < 15°**
```

**문턱이 이 계기에서 도달 불가능한 값이었다.** `orientOutward`가 법선을 **회전시키지 않고
부호만** 정하므로 각도차가 `{0°, 180°}` **이산**이고, 중앙값은 「**뒤집힘률이 50%를 넘는가**」만
답한다 — 15° 같은 연속 문턱은 원리적으로 발동할 수 없다.
**문턱을 사후에 바꾸지 않았다**([[../함정/함정14-기준선의존]]).

### 4-1 진리값 부호 규약 — **3중 실측 후 무보정 채택**

```
역방향 와인딩      **0**
부호부피          **+52,529.9 cm³**   = 51회차와 일치
패리티 오라클      정상 **190** / 반전 **1**
```

**65회차 「팔 대역 뒤집힘 31.1%」는 와인딩이 아니라 법선↔방사참조 `cos<0` 비율임이 재확인**됐다.

### 4-2 **둘 다 진리와 어긋난다는 사실은 확정**

```
뒤집힘   (a) 팔축   **224 (15.8%)**
        (b) 몸통축  **500 (35.2%)**
진리 법선 기준이면 637 → **446 (31.4%)**
(a)가 뒤집은 224 중 **207 (92.4%)이 노출로 계수**된다(**대부분 mid**)
```

→ **참조 방식 자체가 별개 표적**(§7 등재 · **구현 금지**).
