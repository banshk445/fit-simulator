### 7-1 (가) 「저해상 캡처로 «위치»를 판정하고 회차를 발주했다」

**대상**: 94 §0-4의 1순위 문언 「옆선 세로 열개 — **옆선 봉제선 위치와 일치**」(94는 **저해상
근접 4장** 기준) → 95 고해상 자산에서 균열 2줄은 **실루엣 «안쪽»** · **등 중앙에서 좌우 1/3
지점** · **앞뒤 양면 같은 위치**이고 **어느 봉제선인지 화면으로는 확정 불가**(§0-1 · 정정 문언 ·
**귀책 = 전략 세션**). **대상은 같은 기준선 A**(자산이 갈린 것이지 상태가 갈린 것이 아니다).

**대조 — [[../함정/함정19-계기가다른대상]] 시그니처인가**

```
19의 시그니처   **계기가 «다른 대상»을 잰다** — 입력 경로(34 · 77) · 촬영 대상(73 · 74) ·
                정의역(57) · 주석 대상(79)이 빗나간다
이번            **대상은 맞았다** — 94회차 4장은 `CAPTURE_URL` **명시**로 촬영됐고(94 §0(5)) ·
                **이미지를 열어 확인**했고 · **같은 기준선 A**다.
                틀린 것은 **자산의 «분해능»이 물음(어느 봉제선인가)의 판별 요구에 못 미친다**는 것
시험            19의 규범 전량(입력 경로 인쇄·확인 / 이미지 열람 / 정의역 확인 / 주석 대상 확인)을
                **100% 지켜도 이번 결함이 남는다** → **19 사례 «아님»**
```

**대조 — [[../함정/함정30-창폭과창위치]] 시그니처인가**

```
30의 정의    창의 **폭이 갈라야 할 신호의 폭과 겹치거나** 위치가 어긋나서 —
             **채널은 정상 산출되고 답도 나오는데 그 답이 물음에 답하지 않는다**
             (**판별력 0이 아니다**)
이번         **답이 나왔다** — 「옆선 봉제선 위치와 일치」라는 위치 진술이 산출됐고
             **그 위에서 95회차가 발주**됐다. 그런데 그 답은 물음에 답하지 않았다
             (95 자산에서 균열은 봉제선이 아니라 **실루엣 안쪽 1/3 지점**)
규범 ①       **바로 이 항목이다** — 「창의 «폭»을 신호의 «폭»과 같은 단위로 맞대 적는다」.
             94는 **자산의 분해능**과 **갈라야 할 거리(균열 ↔ 옆선 봉제선)**를 맞대지 않았다
값역 확인     100% 해도 남는다 — 화면 자산에는 「도달 가능 범위」로 잡히는 값역이 없다
             (**95 §3형 «판별력 0» 포화가 아니다**)
```

**판정 = [[../함정/함정30-창폭과창위치]] 사례 추가**(**신설 0 · 함정 19 아님**).
**적용 대상 확대**: 30의 「창」은 지금까지 **문턱 창 · 갈래 술어 · 관측 시점**이었는데,
**화면 자산의 «분해능·시야»도 같은 자리에 선다**. **문턱은 박지 않는다**(90회차 관행) —
얼마의 분해능이면 되는지는 **그 자산을 판정에 채택하는 회차가 실행 전에 도출**한다
([[../원리/사전등록]] 규범 4·5 · [[../함정/함정14-기준선의존]]).

**미실측**: 94 자산의 픽셀 분해능 수치 · 균열 ↔ 봉제선 거리 · **균열 폭** — **이 회차 실측 0**.

### 7-2 (나) 이번 포화(흡착 평형점 고정)가 95 §3 포화(하드 천장)와 같은 함정인가

**판정 = [[../함정/함정13-jitter]] 규범 6(값역) 사례 추가**(**신설 0 · 하나만 고른다**).
80(문턱이 값역 밖 → 발동 불가) · 85(검사량이 한 점 → 항상 통과) · 90(조건이 항등 → 항상 포화) ·
95(값역 상한이 상수 곱 → 대표값 항상 포화)와 **같은 줄**이고, 이번은
**값역이 «열려 있는데»(p99 18.7~26.6mm) 리졸버 평형점이 대표값을 끌어당겨 포화**다.
**새 국면 1건**: **대표값 포화 ≠ 채널 전체 포화** — 꼬리는 살아 있다.

### 7-3 **두 회차 연속 부재 주장 거짓**을 [[../원리/사전등록]]에 등재할 것인가 — **등재한다**

```
판정   **실패 양식 «신설» 0 · 실패 양식 18(부재 주장 미검증)에 «재발 블록» 추가**
근거   90(신설 계기 · 전략 세션 귀책) → 95(재발 1건) → 96(**2건이 둘 다 거짓**)은
       **같은 양식의 진행**이다. 새 양식을 세우면 규범 18과 대장이 두 군데로 갈라진다
       (85·86·89·90·95가 함정 13에 붙일 때 쓴 것과 같은 근거)
차이   **95·96은 «규범 18이 이행돼» 거짓이 실행 전에 드러났다** — 90은 거짓 전제 위에서
       회차가 끝났고, 95·96은 **선행 확인이 회차 정의역을 축소**했다(둘 다 코드 0줄)
귀책   **이 회차는 귀책을 표기하지 않는다**(95도 하지 않았다 · 대장 번호 부여는 전략 세션 몫)
```
