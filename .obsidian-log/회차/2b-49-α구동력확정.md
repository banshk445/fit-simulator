## 등재 2건

**① α 구동력 확정 — 단 자석분이 지지력을 겸한다.**
흡착의 **자석분**(비관통 정점을 표면 + margin으로 끌어당기는 몫)이 밑단 프릴의

즉 자석분은 **지지력도 함께** 담당한다.
**처방은 "빼기"가 아니라 "지지를 다른 층에서 만들고 빼기"여야 한다**는 조건이
실측으로 붙었다. 원리 정본 → [[보조힘은-대체품]](49회차 사례 추가).

### 정정 (52회차) — **ablation이 자른 면은 "자석분 경계"가 아니다**

원 진술은 지우지 않는다. 위 「변경」의 `ADSORB_PENONLY=1` = "흡착 **관통-only**"라는
라벨은 **자른 집합을 좁게 적은 것**이다.

`bvhFromArrays.ts:239-244`가 목표를 `표면점 + margin·n`으로 잡으므로
이동량 `Δ·n = margin − d`이고 **국면이 셋**이다:

```
국면1  d > margin(15mm)  Δ·n < 0  안쪽으로 끌어당김  = "자석분"
국면2  0 < d < margin     Δ·n > 0  바깥으로 밀어냄(껍질 안착) — 관통 아님
국면3  d < 0              Δ·n > 0  관통 해소
```

49B는 `outward ≥ 0`이면 skip이므로 **국면1+2를 함께 껐다.**

→ **재표기**: 위 「정정(50회차)」 표의 B@f960 값
(cov **24.9%** · covShoulder **64.5%** · 관통 **342** · 자기교차 **913** ·
정착 링 **71.80cm** · hit **0.161/0.055**)은 ~~"자석분 제거"의 비용~~이 아니라
**"자석분 + 15mm 껍질 안착 제거"(국면1+2)의 비용**이다.
**표적 문장과 실험 대상이 어긋나 있었다.**

**부수**: 그 절단 방향에 **`0.25` 손 상수**가 공유 파일에 박혀 있고
(`bvhFromArrays.ts:234-235`) 축은 **몸 깊이중심보다 7.2cm 뒤**다 —
`dressPattern.ts:584` 주석의 **"새 상수 0"이 그것을 안 셌다.**
