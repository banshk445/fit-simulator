# 2b-34 — 핀 rest 처방(B: 위치 램프) + 34게이트 신설

옷 해시 `9f7ba80b3497` / fixture `9e8b2bf13925`(32·33회차와 동일).
실행 `RINGTOTAL=0 PATTERNCORE=1 npm run dress:pattern` · dress 43s(wall) ·
스크립트 자체보고 21.1s(DONE 도달) · capture 47s. 로그 `/tmp/r34b.log`.

## 1. 변경 — 처방 (B) 위치 램프

`sim.pin`의 **순간이동**을 목표까지 `RAMP_FRAMES`(120, 상태기계 기존 값)·같은
smoothstep으로 나눠 이동하는 것으로 교체. `pinned=1`은 유지 = **유지력 반납 아님.**

(A) 조건부 발화는 **기각**: 배치 시점 거리 20cm ≫ rest 6.6mm · margin 15mm이므로
"한 번도 발화 안 함"이 되고, 이는 하드 핀 반납과 동치다(이번 회차 금지 변수).

## 2. 검증 — 34게이트(신설·영구) 배치 rest 보존

문턱 값 = **뒤판 32회차 실측**(최대 1.000 · 신장총 0.0cm) — 같은 기계가 이미 낸 값.
허용분 **±3.25e−5**는 **저장 형식에서 도출**: rest는 pos2(Float64) 2D 거리인데
3D는 Float32 → 2·maxCoord·2⁻²⁴ / minRest.
1e−6로 잡은 1차 시도는 실측 ±1.6e−5에 걸려 **throw**했다 — float32가 표현하지
못하는 정밀도였다.
소매·시접 쌍은 게이트 대상 밖(원통 감기 = 비등거리 / rest가 3D 갭 등록·램프 대상).

```
[34게이트] (i) 진짜 배치 직후·핀 발화 전
   몸판 n=24318 최대 1.000016@821 최소 0.999986 신장총 0.0cm 압축총 0.0cm
   소매 n= 5086 최대 1.206003@4296 최소 0.999994 신장총 957.8cm
[34게이트] (ii) 핀 발화 직후   몸판·소매 **전 항목 비트 동일**
"재배치" 라벨 없음 — S0 배치 관통 0 → 교정 0정점 → place() 재호출 없음
```
→ **핀이 더 이상 rest를 찢지 않는다.**

## 7. 계기 정정 3건
1. **핀은 S1에서만 발화**한다(dressingMachine 196행 S1 / 212·215행 이후 false).
   → 30회차 "핀 면제 0개"는 정착(S3/DONE) 측정이라 **유효**.
2. **32회차의 "t=0(배치 직후)" 지도는 핀 발화 직후 지도였다** —
   `setAnchorHard`(196행) → `beforeStep`(219행) 순서. → [[함정13-jitter]] 사례.
3. **하드 핀은 반납되지 않았다** → 32회차의 "21회차 전제 소멸" 판정 **취소**.
   단 근거였던 "잔차 0.00mm 실증"은 램프 도입으로 무효(f=60 잔차 105.65mm).
