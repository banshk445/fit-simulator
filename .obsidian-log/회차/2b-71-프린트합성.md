## §3 처방 — 2파일

**B(패널별 map 분리)** — `panelSurface(i)`가 패널 인덱스별 `{map, color}`를 준다.
인덱스는 `patternGarment.ts:39-43`(FRONT=0 / BACK=1 / SLEEVE_L=2 / SLEEVE_R=3) 그대로.
머티리얼 인스턴스는 **이미 메시마다 별개**다([[2b-70-프린트배치후보]] §5-2)
→ **구조 변경이 아니라 배선**.

**A(프린트 합성)** — v1 `compositeGarmentTexture` 재사용.
**앞판 = 대표색 + 가슴 프린트 / 뒤판·소매 = 대표색 단색.**
단색은 합성 캔버스 **(0,0) 픽셀**에서 뜬다(v1 `Garment.tsx:344-348`과 같은 출처).
`averageGarmentColor`는 **쓰지 않았다**([[2b-70-프린트배치후보]] §5-1 — 죽은 코드이고
폐기 사유가 실측으로 기록돼 있다).

**v2 적응 — 새 상수 0**

```
panelW = OUTPUT_SIZE × uMax
destW  = panelW × PRINT_WIDTH_FRACTION
destX  = (panelW − destW) / 2

uMax = 1 이면 기존 식으로 **정확히 환원**된다(v1 계산 동치)
uMax는 **앞판 uv 속성의 최댓값을 직접 떠서** 쓴다 — 별도 술어 · 상수 0([[../함정/함정12-계기하드코딩]])
```

**상속 상수 10건은 하나도 조정하지 않았다**(§0③ 조건 — 아래 §8).

## §4 계기 결함 1건 — 구현 중 자체 발견 · 수정

1차 판별자가 `PRINT_MAX_FRAME_FRACTION` 발동을 `printBox === null`로 판정했는데,
`findPrintBoundingBox`는 **"프린트 없음"과 "프레임 초과" 둘 다 null**을 낸다
→ **두 사유를 못 가른다.**

문턱 판정 **직전 상자**를 `onOversize` 콜백으로 밖에 넘기게 고쳤다. 이제 `maxFrameFired`는
**문턱이 실제로 걸렸을 때만** 참이고, 프레임 비율도 문턱 전 상자에서 나온다.
