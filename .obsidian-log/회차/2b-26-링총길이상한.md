# 2b-26 — 링 총 길이 상한

## 변경
[[2b-25-링폐곡선화]]가 남긴 한 줄("링이 rest로 수렴하지 않는다 · 104.54 vs 49.44 =
2.11배")의 처방. **엣지별 상한 강화로 대체하지 않았다** — [[2b-21-링시점분리]]가
"제약당 상한은 총 길이를 못 막는다(2.68배)"를 이미 실측했다.

총 길이는 **전역 양**이라 PBD 반복 안의 국소 제약으로 표현되지 않는다. clothPhysics를
안 건드리려면 솔버 **밖**이 유일한 경로 — `step` 직후 **매 프레임 1회**, 링 무게중심
기준 **등방 축소**(모든 현이 같은 배율 → 총 길이가 정확히 상한). **상시** 적용.

**계수는 근거에서 도출했고 화면에 맞춰 내리지 않았다** → [[함정14-기준선의존]] 회피.
```
풀오버 목선의 설계 최대 신장 = 머리 통과. 그 이상은 착용이 아니라 손상.
머리 최대 둘레 54.05cm@y160.54 / 링 rest 49.44cm = **1.093**(도출 · 체형 따라 이동)
```

제약을 늘린 채 균형을 잡는다(정점 11).
