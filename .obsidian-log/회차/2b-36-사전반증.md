# 2b-36 — 사전 반증 (계기 미실행)

**계기를 한 번도 돌리지 않았다.** strategist 1회 위임(도구 56회 · 643s), 코드 읽기만,
실행 0. 회차 프롬프트 규칙 — "반증에 걸리면 계기를 돌리지 말고 정지(회차를 아낀다)".
수치·판정 전량 `docs/metrics-log.md` 2026-07-31 36회차 블록.

## 1. 가장 큰 반증 3건

### ① A1/A2 — 링은 폐곡선이 아니고 엣지는 60개다
`necklineRing`은 폐곡선이 아니라 **열린 사슬 2개**(patternGarment.ts:268-279).
`ringLenM()`은 `necklineRing`만 순회하므로 **접합 2엣지를 제외**한다
(dressPattern.ts:330-340). 배열 순서도 `[e, mirror(e), …]`라 **배열 순회 ≠ 곡선 순회**.
**엣지는 60개이고 62는 정점 수다**(로그 16행 `엣지 60 + 접합 2 = 62 · 정점 62`).
rest 48.24cm는 그 60엣지 실측 합이므로 참.

**제외된 접합 2엣지는 t=0에 62.09cm이고 S1 동안 1.2cm로 봉합된다** —
설명 대상(f1 ΔL **+12.71cm**)보다 **한 자릿수 큰 항이 채널 밖에서 움직이고 있다**.

### ② A3 — "핀 인접 링 엣지"는 공집합
앵커는 링 정점을 **명시 배제**하고 뽑힌다(dressPattern.ts:596-599, 24회차 →
[[2b-24-목점앵커제외]]). 링 엣지는 링 정점끼리만 잇는다 →
**링 60엣지 중 앵커를 끝점으로 갖는 엣지 0개.**

### ③ E1 — 사전 등록 판정문이 시점 오류
핀 해제 **f=110** · 소프트 앵커도 **f=240에 0.000** · 정착 **f=294엔 앵커가 없다**.
핀 잔차 79.84mm는 f=120 값이다. "핀 vs 흡착 대립"은 **f≤110 한정 진술**이고
정착 판정에 쓸 수 없다. → [[함정13-jitter]] "시점" 사례 재발(32·34에 이어 3회째).

## 3. 반증이 **답을 준** 항목 — 계기 4는 코드 읽기만으로 풀렸다

```
SEAM_REST_LENGTH = 0.006      (clothConfig.ts:127)
limitStrain maxStretch = 1.2  (clothPhysics.ts:700 · this.constraints **전체** 순회)
                    →  1.2 × 6.0mm = **정확히 7.20mm**
```
35회차 상위 10쌍 중 **6개가 정확히 7.20mm**다([[2b-35-흡착국소화]] §5).
"시접 240쌍 균일 초과"의 상단은 **리미터 천장**이고, 7.20을 넘은 4건
(8.98 / 8.81 / 7.41 / 7.39)은 2패스 미수렴분이다.
→ **벌리는 힘은 관측값보다 세다**(천장에 눌려 있다).
26회차 "상한은 증상 상한"과 같은 형태 → [[2b-26-링총길이상한]].

부수 코드 사실 1건: 서브스텝 **마지막 반복에 충돌이 강제 발화**하고
(clothPhysics.ts:479 `iter === iterations - 1`) 그 뒤 거리 제약 패스가 없다.
시접 갭 측정은 그 뒤 값이다 → 갭은 **흡착이 마지막으로 만진 상태**를 잰다.

## 4. 계기 라벨 정정 2건 (코드 수정 · 물리 0줄)

```
dressPattern.ts:752   "링 62엣지 환산 둘레"  → **[폐기 채널]** 표기(35회차 결론) + 62 제거
dressPattern.ts:1171  "링 62엣지 전체가 … *2*62"  → `g.necklineRing.length`(=60)에서 도출
```
`ringLenM`이 순회하는 집합은 60엣지인데 라벨이 62(=정점 수)를 주장했다 → [[함정13-jitter]].
적분 상한값도 62로 계산돼 있었다 — **33.79 → 32.70cm**(느슨한 쪽이라 판정은 안 뒤집혔다).

## 5. 전략 세션 정정 2건 (귀책 = 지시자)

1. **34회차 화면 "어깨 이음선 벌어짐 = maxSeamGap" 판정은 오독이었다.**
   shoulder는 4종 중 **최소**(최대 7.20mm)이고 240쌍 **균일 초과** 분포다.
   최악은 **side 8.98mm**(겨드랑이 아래 옆선). → [[2b-34-핀rest처방]] §6 정정 절.
2. **계기 결함 — 35회차의 "반경 방향 분해" 지시는 링 길이를 원리적으로 못 재는
   설계였다.** [[함정13-jitter]] 규범("채택 시점에 식부터 재도출")을 **지시자가 어긴
   사례**다. 36회차의 접선 분해 지시도 **정의역(60 vs 62)을 확인하지 않은 채** 나갔다
   — 같은 결함의 2회차.

## 6. 판정 — **정지** (계기 미실행)

사전 등록 갈래 4개가 **전부 계기 1·2의 산출을 입력으로 받는데**, 그 두 계기의
**정의역과 부호 기준이 거짓 전제 위에 있다**. E1은 판정문 자체가 시점 오류다.
**갈래를 사후에 고쳐 쓰지 않는다** — 계기를 재설계해 다음 회차에 다시 등록한다.

실행 가능으로 남은 것:
- **계기 4** — 전제 참. 후보 목록에 `limitStrain` 천장(7.20mm) 추가 필요.
- **계기 3의 C3** — 단 표적면을 `frontMesh`/`backMesh`로, **소매 제외**.
