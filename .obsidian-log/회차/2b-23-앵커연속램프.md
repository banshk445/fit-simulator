# 2b-23 — 앵커 연속 램프아웃

## 변경 (변수 하나 · 새 상수 0)
S2 진입의 `setAnchorStrength(0)` 즉시 전환 → **S2 구간 연속 램프아웃**
(시작값 = S2 진입 시점 강도 · 길이 = 기존 rampFrames · 곡선 = 기존 smoothstep).
`dressingMachine` 수정은 이번 회차 지시로 허용. → [[함정07-제어]] 위반 해소.

## 결과 — **궤적 비트 동일**

| | 22회차 | 23회차 |
|---|---|---|
| S1→S2 | f=120 갭 10.0mm 앵커 0.380 | 동일 |
| S2 이탈 | f=121 갭 25.6mm | 동일 |
| RETRY·ABORT | f=122 / 190·191 / **259** | 동일 |
| f=121 앵커강도 | 0.000 | **0.380** |
| f=121 **핀 잔차** | 88.70mm | **88.70mm** |

**앵커 강도만 다르고 갭·잔차·궤적이 전부 같다.**

## 국소화 — [[2b-22-램프시점정합]]의 귀속이 **반증**됐다
되열림은 f=120의 **S1 스텝 안에서** 일어났고 그때 두 실행 모두 강도 0.380이었다.
f=121에 찍힌 값은 이미 벌어진 결과다. S2 계단은 원인이 아니었다.

### 새 시그니처 — 되열림의 주체는 **앵커 자신**
```
f=120  갭 10.0mm(닫힘) · 앵커 0.380 · 시접 rest 램프 완료(6mm)
f=121  갭 **25.6mm**(최대 = shoulder 목점) · **핀 잔차 88.70mm**
f=128~140  앵커 1.000 · pinned=1 인데도 갭이 18.7 → 21.7mm에서 **진동**
```
핀 잔차 88.70mm = **앞판 목점이 앵커 목표에서 8.87cm 떨어져 있다**.
시접 쌍은 능선 목표가 **아닌 곳**에서 10.0mm까지 만났는데, 앵커는 앞판만
그 목표로 끌어당겨 **쌍을 벌린다**.

> **앵커는 봉합을 유지하는 힘이 아니라 봉합을 찢는 힘이었다.**

f=128~140의 진동이 [[2b-03-링스케줄]]에서 확정한 "앵커 강도 = 봉합 진행에서 도출"
규칙의 **양의 되먹임** 정상 상태다: 닫히면 앵커가 빠지고 → 앞판이 풀려 다시 열리고
→ 하드 핀이 재고정돼 앞판을 목표로 되끌어 또 벌린다.

## 판정 (전략층)
22·23회차가 같은 곳을 두 번 짚었고 두 번째가 첫 번째를 뒤집었다. 계기(전이 근방
프레임별 진단)가 없었으면 둘 다 못 봤다 — [[함정10-백로그이름]] 계열의 자기 검증.
남은 것은 앵커의 **목표**이지 앵커의 **스케줄**이 아니다.
