# 2b-24 — 목점 앵커 제외

## 변경 (변수 하나 · 새 상수 0)
앞판 어깨 앵커 38개 중 **목점 2개 제외**. 힘을 더하는 게 아니라 **중복을 없앤다** —
목점은 링의 끝점이라 [[2b-02-넥밴드]]의 원주 제약이 이미 위치를 정하는데, 앵커까지
걸면 두 목표가 경쟁한다([[2b-23-앵커연속램프]] 실측 잔차 8.87cm).
식별은 도출: **"링 정점이면서 어깨 시접의 정점"**(공유 코너의 정의). 인덱스 하드코딩 0.

## 검증
```
[앵커·제외검증] 어깨 시접 38쌍 중 앵커 **36개(제외 2개)**
                제외분 패턴 (8.12,0.00) (−8.12,0.00) · 전부 링 정점 OK(앞뒤 모두)
남은 앵커 36개 핀 잔차 0.00mm 유지
```

## 결과 — 정체 지속, 그러나 **앵커 무죄 확정**

| | 23회차 | 24회차 |
|---|---|---|
| S1→S2 | f=120 갭 10.0mm | 동일 |
| S2 이탈 | f=121 갭 25.6mm | 갭 **25.4mm** |
| ABORT | f=259 (28.1mm) | f=263 (**32.9mm**) |
| 링 최대 → 최종 | 129.50 → 101.26cm | 123.73 → **96.40cm** |

**목점을 앵커에서 뺐는데도 f=121의 최대 갭 시접이 여전히 목점(8.12, 0.00)이다.**
앵커가 없는데 같은 쌍이 같은 크기로 벌어진다 → **앵커는 무죄**.
(23회차의 "앵커가 찢는다"도 이로써 반증. 두 회차 연속 귀속이 뒤집혔다.)

## 국소화 — 벌리는 힘은 **넥밴드 원주 제약의 수축**
```
f=128 갭 16.0mm(최대 side)    링 103.41cm
f=129 갭 15.9mm(**목점**)      링 101.90cm
f=130 갭 **19.0mm**(목점)      링  98.35cm   ← 링 3.6cm 수축 → 갭 3.1mm 열림
f=131 갭 15.7mm(목점)          링 102.53cm   ← 링 늘어남 → 갭 닫힘
f=132 갭 **20.3mm**(목점)      링  98.67cm
```
**링 길이와 목점 갭이 정확히 반대 위상으로 진동한다.** 칼라 발화는 매 프레임 20~30회.

**기전**: `necklineRing`은 **앞목·뒤목 두 개의 열린 사슬**이다(패널 간 접합은 rest
오염 때문에 일부러 뺐다 — patternGarment 주석). 그 두 사슬의 **끝점이 곧 목점**이고,
각 사슬이 수축하면 앞목점은 앞판 중심으로, 뒤목점은 뒤판 중심으로 —
**서로 반대로 당긴다.**

수축력이 큰 이유는 링이 **2.0~2.7배 팽창**해 있어서고, 그 팽창은
[[2b-21-링시점분리]]의 상한 해제 때문이다. 제약당 상한은 **총 길이를 못 막는다**
(21회차에 2.68배로 실측).

## 판정 (전략층)
22·23·24회차가 같은 현상을 세 번 짚었고 매번 앞 회차를 뒤집었다. 이제 남은
용의자는 **링 자신**이다 — 낙하를 막으려고 넣은 부품이 봉합을 막고 있다.
→ [[보조힘은-대체품]]의 두 번째 반전.

## 다음 수 (순위 갱신)
- (a) **링 상한을 총 길이 기준으로**([[2b-21-링시점분리]] 후보 b). 팽창 자체를
  막는다. 이번 힘 분해가 가리키는 **1순위**
- (b) `necklineRing`에 **패널 간 접합(앞목점↔뒤목점)을 넣어 사슬을 닫는다**.
  지금은 두 사슬이 서로를 반대로 당긴다. rest가 배치 거리라 뺐던 것인데
  평면 배치에서는 그 값이 곧 봉합 목표다 — 재검토 대상
- (c) 사전 등록분(중점 목표) — **앵커가 무죄**가 됐으므로 순위 하락
