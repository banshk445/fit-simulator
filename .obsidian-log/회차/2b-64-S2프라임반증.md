## §4 (c) — **축을 어디에 놓아도 안 된다** (이번 회차 핵심)

판정식의 축은 `{x, z}` 2성분 = **y축에 평행한 수직 직선 하나**다. 정점마다 달라질 수
없고 프레임 중간 갱신도 불가하다(루프가 리졸버 내부).

```
팔 축 dir = (0.5145, −0.8575, 0) → 수직에서 **31.0°**
겨드랑이를 향한 면 법선 (−0.858, −0.515, 0)과 수직축 방사 r̂ ≈ (+1, 0)의 내적 = **−0.986**
  → outward < 0 → 표면 밖인데 "관통"으로 분류 → **자석이 그대로 켜진다**

오분류 실측 (S3 정착 948정점 · 전량 캡슐 밖)
  축 = 몸통 캡슐(현행)     소매L **46.4%** · 소매R **47.0%**
  축 = 팔 trueShoulder     소매L **50.2%** · 소매R **49.8%**   ← **개선되지 않는다**
  오분류 y 범위 114.6~136.2cm = **소매 전 길이**
```

어깨점을 지나는 수직선과 팔 중심선이 원위부에서 최대 **14.1cm** 벌어진다 —
팔 반경 **4.56cm**의 **3배**다.

팔 축을 제대로 쓰려면 시그니처를 **선분(또는 정점별 축)**으로 바꿔야 하고,
그것은 `bvhFromArrays.ts` 수정 = **v1 워커 + 12콤보 정의역**이다.

## §6 (f) — **세 번째 후보 등재** (이번 회차 두 번째 소득)

겨드랑이 회색이 **①소매↔몸 관통**인지 **②소매↔몸판 자기충돌**인지 **못 가른다**
(패널조합 × y 교차표 채널이 없다).

그런데 **③ 시접 슬릿의 배경 투과**라는 세 번째 후보가 있고,
**어느 계기도 그것을 세지 않는다.**

```
암홀 시접 갭   평균 6.96 · 최대 11.14mm   (target 6.0mm)
48 · 49회차가 δ③으로 **"정점 위치 불변에서 예상된 현상"**을 이미 등재
겨드랑이에서는 그 틈 뒤 배경이 **몸**이라 흰색이 아니라 **회색**으로 보인다
FitCanvas.tsx:114 가 <Mannequin/> 을 **항상** 마운트 →
  **"몸이 보인다"만으로는 ①·③을 못 가른다**
```

**약한 신호 1건**: S3에서 ②는 **91% 감소**(96→10 · 17→0)했는데 ①은 **47→55로 악화**했고,
전략 세션이 관통을 본 화면은 **S3 캡처**다 → **②일 가능성은 낮다.**
**단 확정이 아니다.**

**판별에 필요한 것 2건**

```
① 같은 프리셋 A vs S3 **cuff 대조 캡처**
   (45회차 off cuff는 프레이밍이 달라 A/B 대조가 아니다)
② **clean-cuff** — **한 번도 촬영된 적이 없다.**
   클린 렌더는 시접 브리지를 감추므로 ③이면 회색이 사라진다
```
