# 2b-57 — 프릴 계기 검증 · **48계기 진폭 채널 무효**

수치·판정 전량 `docs/metrics-log.md` 커밋 **0562e0a** + **eb5f361** 블록.
기점 c769985. **물리 0줄 · 처방 0건.**

**표적**: 프릴 계기의 **신뢰 회복**. 계기(정착 A 3.86 → D0 10.84mm · **+181%**)와
화면(육안 *"D0가 A보다 나쁘지 않음"*)이 정반대·미판정이라 **후보 2(밑단·옆선 계열)를
판정할 수 없었다.**

**사전 등록 판정 → 갈래 1**: *"계기 A에서 D0 상태의 주입 신호 복원 실패 →
48계기는 부양 상태에서 무효. D0의 10.84mm는 계기 산물이고 화면이 옳다."*

---

## §1 사전 반증(strategist) — 더 근본적인 반증 2건

### 반증 1 (치명) — **대상 불일치**(함정 19)

`hemWobble`의 `interior` 필터가 사슬 양끝 **W/2씩** 제외한다
(`dressPattern.ts:1076`). `chainOf`가 **패턴 x로 정렬**하므로(`:1045`)
**사슬 끝 = 옆선 시접**이다.

```
W=16 → 앞뒤 사슬 4끝 × 8cm = **32cm** ≈ 밑단 폐곡선 112cm의 **29%**
그 29%가 정확히 **옆선 4곳 근방**이다
```

→ **화면 표적은 「옆선 프릴」인데 인용해 온 숫자는 옆선을 구조적으로 제외한 채널이다.**

옆선을 **실제로 재는 β-1**이 같은 두 로그(54회차)에 **이미 있고**
**6/6 채널 −63~92%로 화면과 일치**한다(0홉 −66/−70 · 1홉 −71/−92 · 2홉 −63/−90).
**단서**: β-1도 세로 사슬이라 수평 접선 `|t|` 조건수 문제가 **여기서는 활성** →
**크기의 하계**로 읽는다.

### 반증 2 (치명) — **자기검사의 적용 범위**

48회차 주입 형상이 **직선 기준선**(`:1106-1110`)이라 **곡률 편향을 원리적으로 검사하지
못한다**(R=∞에서 정확히 0). 그리고 주입 **λ=8cm는 W=16에서 이득이 정확히 1.000인
유일점**이다.

```
곡률 편향 잔차 ≈ R(1 − sinθ/θ),  θ = (W/2)/R
밑단 둘레 110cm 원 근사 R=17.5cm → **요동 0에서 6.0mm**   (A 실측 중앙 3.86mm)
```

**요동이 정확히 0인 매끄러운 타원 밑단이 "중앙 2~6mm · 최대 ~15mm"를 찍는다** —
A 실측과 구별되지 않는다.
※ **57계기 A도 직선 기준선을 썼으므로 곡률 편향은 여전히 미검사다.**

### 반증 4 — 진폭 ↔ 파장 **결합 ×1.44**

```
A  λ 19.08cm → 이득 0.816
D0 λ 12.91cm → 이득 1.175      →  형상이 안 변해도 파장만 바뀌면 **+44%**
```
→ **55회차가 두 채널(진폭·파장)을 독립으로 읽은 표는 무효.**

### 반증 5 — 파장 채널에 유효숫자가 없다

19.08 → 12.91은 **flips 4 → 6**이다. 인접 정수 하나로 **15.5 / 11.1**.
λ가 **8/8 표본에서 창 폭을 따라간다**(0.8~1.4·W).

### 반증 6 — 최대 채널이 W에 인질

같은 상태에서 **A 앞판 W8 6.01mm@#107 / W16 13.84mm@#1192**.

### 방향 안정 채널 4개는 **전부 D0가 더 매끄럽다**

```
말림(축 고정)          4.80 → 0.33   (−93%)
사슬 3D 호장                  −2.3%
투영 볼록껍질 둘레            +7.9%
접힘계수              0.720 → 0.652
```
**프릴 채널만 방향 벡터를 계산한다.**
→ 55회차의 *"두 채널이 정반대라 계기로는 가릴 수 없다"*는 **두 채널을 대칭으로 놓은
것인데 대칭이 아니다**(조건수 문제 있는 쪽 vs 없는 쪽).

## §2 계기 A — 부양 자기검사(`hemLiftTest`)

D0를 본뜬 **불균일 부양 프로파일**(39mm → 105mm 봉우리 · `0.039 + 0.066·sin⁴(πt)`) 주입.

```
① 주입+부양   주입 A=10.0mm λ=8.00cm → 측정 최대 17.1mm 중앙 6.8mm · λ 8.98cm
② 부양만      주입 A= 0.0mm          → 측정 최대  6.9mm 중앙 3.4mm · λ 40.74cm
```

**진폭 복원 실패** — 10.0 → 17.1이고, **주입 0에서 6.9mm가 나온다**
(10 + 6.9 ≈ 17.1 로 거의 **선형 합성**). **파장 채널은 복원됐다.**

## §3 계기 B — 폐곡선 밑단 반경(`hemRenderReport` · **영구**)

사슬별 이동평균이 아니라 **폐곡선 평균 반경 기준**(눈이 보는 것).

```
정착  A   반경 평균 13.17cm · 편차 중앙 40.37mm p99 121.84 · 부호변화 4 · y 75.14~80.03
      D0  반경 평균 15.93cm · 편차 중앙 30.33mm p99  89.37 · 부호변화 2 · y 58.63~60.83
```

→ **D0가 더 매끄럽다** — 48계기(+181%)와 **정반대**, **화면과 같은 방향**.

**한계 명기**: 편차 절대값이 큰 것은 밑단이 원이 아니라 **납작한 타원**
(폭 31.61 · 깊이 15.87cm)이기 때문이다. **절대값은 "원에서 벗어난 정도"이고
프릴만이 아니다 — A vs D0 대조만 유효.**

  **사후 화해가 아니라 원인 규명**이다.
