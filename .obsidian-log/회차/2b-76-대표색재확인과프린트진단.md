|---|---|---|

→ 두 대표색이 **소수점 둘째 자리까지 사실상 동일**하고 **둘 다 원단 검정**이다.
**(a) 통과** — 71 §6이 이월한 「흰 배경 실사진으로 재확인」의 **재확인 자체는 됐다**.

### 단 — 「테두리 유효 비율이 오르는가」는 **오르지 않는다**

```
테두리 8% 띠 표본 14,720   불투명·비백색   컷아웃 119(0.8%) / 흰 배경 **122(0.8%)**
최빈 버킷                  컷아웃 (36,36,36) 89 / 흰 배경 (36,36,36) **90**
```

이유: `borderRepresentativeColor`가 **알파<10과 근백색(>235)을 둘 다 버린다.**
투명이든 흰색이든 같은 필터에 걸려 나가고, 남는 것은 **띠에 걸친 옷 가장자리뿐**이다.

→ **71·72회차가 이월한 「흰 배경 실사진으로 재확인 필요」는 이 축에서 재확인해도 같은 값이다.**
**대표색 근거가 얇다(0.8%)는 사실은 자산 교체로 해소되지 않는다** — 이월 문구를 그렇게 갱신한다(§7).

## §5 §3 (b) 프린트 미반영 — **원인 확정 · 코드 결함이 아니다**

