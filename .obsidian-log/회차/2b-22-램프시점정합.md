# 2b-22 — 램프 시작 시점 정합

## 변경 (실질 1줄)
링 1.02 램프의 시작을 자체 판정식 → **상태기계의 S2 진입 구독**으로.
새 조건식을 만들지 않는다 — S1→S2의 AND 조건이 **진실의 단일 출처**다.

> §4: **봉합은 판정되는 순간이 아니라 상태로 확정된 뒤에 조인다.**
> [[2b-21-링시점분리]]은 판정식이 참이 된 순간(f=110) 조여서 갭을 되열었고,
> 그것이 전이 자체를 막았다(10프레임 차).

## 검증
```
램프 시작 프레임 = S2 진입 프레임 = **f=120 일치** ✓ · 그 시점 seamGap 10.0mm
```

## 결과 — **S1→S2 전이 첫 성공**
```
f=120 S1 → S2  램프 완료 seamGap **10.0mm**   ← 21회차엔 도달 못 한 전이
f=121 S2 → S0  **S2 봉합 이탈(25.6mm)** → RETRY1
f=190 정체(25.8) → RETRY2 · f=259 **ABORT**(28.1mm)
넥밴드 발화 33.6 → 27.3/f · 링 최대 129.50 → 최종 101.26cm(rest 48.24)
maxStrain 6.161 · cov 10.5% · 경과 20.0s
```

## 국소화 — 되열림은 **링이 아니라 하드 핀 해제**
이번에 신설한 전이 근방 프레임별 진단이 그 한 프레임을 잡았다.
```
f=120 S1→S2  갭 10.0mm · 앵커 0.380
f=121 S2     갭 **25.6mm**(최대 = shoulder 패턴 8.12,0.00 = **목점**)
             링상한 2.1841 · 링길이 105.4 → **101.62cm(수축 중)**
             앵커 **0.000** · **pinned=0** · **핀 잔차 88.70mm**
f=123 S1     앵커 1.000 · pinned=1 · 잔차 0.00mm (재고정)
```
**링은 무죄다** — 상한이 그 시점 실측과 같아 급조임이 없었고 길이는 줄고 있었다.
되열린 것은 앵커다: S2 진입 규약("앵커강도 1→0, S2 진입 시 0")이 하드 핀을
**한 프레임에** 없앴고 앞판 목점이 목표에서 **8.87cm 튕겨나갔다**.

**봉합을 유지하던 것은 시접 제약이 아니라 하드 핀이었다.**
→ [[보조힘은-대체품]]의 정면 사례. 보조힘을 뺄 때 대체품이 없다.

## 판정 (전략층)
병목이 또 한 칸 앞으로 갔다: 승모근 교착(19) → 앵커 목표 도달 불가(20) →
넥밴드 상한(21) → **앵커 해제 계단**(22). 매 회차 한 층씩 벗겨지고 있고,
이번엔 상태기계 규약 자체가 지목됐다.
