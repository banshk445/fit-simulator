## 0. 정지 사유 3건

### R1(구조 · 치명) — 처방이 지목한 지점이 기준선에서 **죽은 코드**다

```ts
if (penetrationAxis?.enabled) {   // 기준선: penAxis === undefined → 진입 안 함
  ...
  if (outward >= 0) continue;     // ← 50회차가 "지점 1곳"이라 한 그 줄
}
this.faceNormal(...);             // :238 — 여기부터가 실제 기준선 경로
```

`dressPattern.ts:586-589`가 `ADSORB_PENONLY ? {...} : undefined`이고 기본 off,
`garmentWorker.ts:128`도 `enabled: false`다.
**기준선에는 "자석분"과 "관통 해소"를 가르는 분기가 아예 없다** — 탐지반경 15cm 안
전 정점이 같은 한 줄로 표면+margin에 끌린다.

→ C1 집행은 "`continue` 1곳 수정"이 아니라 **① 관통 판정 상시화 + ② 그 부호 출처 결정 +
③ 술어**로 **변경 축 2~3개**다.
**50회차 요약("지점 1곳 · 비용 옵셔널 인자 1")은 오기** → [[2b-50-지지대안과49정정]] 정정 등재.

### R2(전제 · 방향 반대) — **"와인딩 뒤집힘"이 이 fixture에서 반증됐다**

```
와인딩 불일치 2매 엣지  whole 0 · front 0 · back 0
부호부피(발산정리)      +52,530cm³ (front +21,762 · back +30,036)
패리티 오라클 반전      표본 2,093면 중 **0**
```

세 검사가 **독립적으로 같은 답**이다 → `faceNormal`은 **전 면에서 몸 바깥**을 향한다.
**술어는 그 함정으로 무효화되지 않는다.**

대신 `bvhFromArrays.ts:113-120`·`:197-201`의 "`signedClearance` 금지" 근거와
`coverageMetric.ts:273-278`의 mid-back 93% 오판 설명이 **이 fixture 기하에 대해서는 거짓**이고,
같은 파일 `:124-125`가 이미 반대로 적고 있어 **저장소 안에서 두 주석이 충돌**한다(아래 등재).

**확인 불가 · 승격 금지**: v1 런타임은 fixture가 아니라 **스킨드 메시에서 매번 굽는다** →
**워커 경로에서 같은 3검사를 돌리기 전까지 "전역 반증"으로 올리지 말 것.**

### R3(범위) — `n·ŷ>0`은 **국소화가 아니다**

```
착의 대역 전체 ny>0    front **47.8%** · back **46.1%**   = 절반이 off
뒤판 중배부 y110~125   **0.0%**                            = 전량 off(흡착+마찰 동시 상실)
밑단(표적)             front 25.0% on · **back 42.3% on**  = 구동력 절반 잔존
```

**50회차가 잰 전역 제거의 부작용이 걸리는 대역과 술어가 끄는 대역이 겹친다** —
"국소화라서 부작용이 작다"는 전제가 **실측으로 지지되지 않는다.**

## 1. 문턱은 몸에서 도출 불가

도출 가능한 유일한 값은 마찰각(`MU_STATIC 0.6` → cosθ = 1/√1.36 = **0.857**)인데
**앞판 어깨·링 대역을 0.0%로 만든다**(지지 대역 전멸).
그보다 낮은 값은 근거 없는 손 상수 = **문턱 규범 직격**.
→ **부호 단독이 유일한 무-파라미터 선택지**이고 그 대가는 아래.

**부호 단독의 새 결함**: 인접면 `n·ŷ` 부호 반전율이 front y120~125 **24.4%**,
`|ny|<0.05` 비율 **41.1%** → 이진 술어는 **삼각형 단위로 켜졌다 꺼지는 얼룩 장**이 된다
(M2-3이 버린 "BVH 면 법선의 삼각형 단위 튐"과 같은 형태).

**선례가 이진이 아니다**: C1이 인용한 `LOCAL_MU_GAIN`(`clothConfig.ts:202-212`)은
`μ_eff = μ_iter·(1 + gain·max(0, n.y))` = **연속 가중**이고 **SDF 기울기 법선**을 쓴다
(BVH 면 법선이 아니다).

## 2. 51회차 진단 계기 (처방 아님 · 공유 파일 0줄 · 12콤보 불요)

`faceNormal`은 private이지만 두 public 메서드의 **차**로 복원된다:
`n = closestSurfacePoint(p, margin=1, r) − closestPointUnsigned(p, r)`.


**사전 반증 (d)·R3이 정착 실측으로 확인됐다**: 링은 앞뒤 100% 위보기(술어 하에서 유지) ·

그리고 **마찰각 문턱은 링 앞판을 0.0%로 만든다**(도출 문턱이 지지 대역을 전멸시킨다는
예측 적중).

**50회차가 C1의 한계로 적은 "위보기 면 집합 확인 계기 부재"는 이것으로 해소.**
