## §3 §0 전략 세션 판정 등재 — 88 §9 갈림 처리

### 3-1 88 §9 네 갈래의 처리 (전략 세션 판정 · 이 회차가 수령)

```
ㄱ  충돌 기하 기여가 하향됐다 — 남은 기전 후보는 무엇인가
ㄷ  「노출이 θ 대역 양 끝에서 일어난다」를 새 표적으로 세울 것인가
      → **ㄱ·ㄷ는 통합 답을 받는다.** 「노출 표본의 옷이 몸 **안**에 있는가 **밖**에 있는가」를
        먼저 물으면 두 갈림이 **한 번에** 답해진다 — 안이면 남은 후보의 집합이 바뀌고(ㄱ),
        θ 양 끝이라는 자리도 다른 뜻이 된다(ㄷ)
ㄴ  README 재개 선행 조건 2건(팔축 부호거리 샘플러 · 면적계)을 만들 것인가
      → **보류.** 이번 회차에서 착수하지 않는다
ㄹ  표적 ①을 내려놓을 것인가
      → **아직 아니다.** §1을 물어보기 전에는 내려놓을 근거가 없다
```

**갈림을 소진한 것은 ㄱ·ㄷ의 「선결 질문」뿐이다** — ㄱ·ㄷ 자체는 §1이 갈래 B로 나오면서
**소진되지 않았고**, ㄴ은 보류 · ㄹ은 미착수로 남는다.

### 3-2 이 회차의 근거 3건 (**전부 등재분 인용 · 이번에 새로 만든 근거가 아니다**)

```
88 §4-5   노출 θ 대역에서 `유효반경 5.16 − 실제 팔 반경` 중앙이 **s=4에서 음수**
          (좌 −0.11 · 우 −0.22cm) = 그 방향에서는 **실제 팔이 캡슐보다 굵다**
          → 소매가 **캡슐 밖·팔 안**에 놓일 자리가 실재한다
88 §4-4   **피복 대역이 노출 대역 안에 완전히 들어간다**(양팔) — 노출/피복이 **θ로 안 갈린다**
          → 「노출」이 공간적으로 분리된 현상이 아닐 가능성
README    「천이 몸 안으로 최대 **2.7cm** 파묻혀 …」(README.md:290-296) —
2.7cm     **파묻힘 진술이 저장소에 이미 있다**. 대조는 §2(미집행)의 표적이었다

그것이 갈래 A의 문언이다.** §1 실측은 **그 방향으로 가지 않았다**(§4-5).

```

**48표본 중 34건(70.8%)의 사잇각이 60~120°** — 최근접 옷이 몸 표면에 거의 **접선 방향**으로 놓여 있다
좌 노출은 중앙이 **91.16°** 로 **정확히 직각**이다
⇒ 부호(안/밖)는 이 표본 집합에서 **잡음에 지배된다.**

```

### 5-2 **갈래 D로 넘기지 않았다 — 그 이유를 판정과 같은 자리에 적는다**

```
① 갈래 D의 문언은 **「(a)에서 부호를 못 정하는 표본이 10건 이상」** 이고
   (a)는 **패리티 판정 불가**를 가리킨다 — 그 값은 **0건**이다(§4-2)
② **사잇각 채널은 이번에 새로 만든 것**이라 **사전 등록 갈래에 없다**
③ 따라서 **사후 갈래 신설·문턱 변경을 하지 않는다** → [[../함정/함정14-기준선의존]] ·
   [[../원리/사전등록]]. **판정은 갈래 B로 두고**, 이 사실을 **판정과 같은 자리에 등재**한다
```

**이 절은 판정을 바꾸지 않는다.** 바꾸는 것은 **갈래 B를 읽는 방법**이다 —
「혼재」를 기전의 진술로 읽을 수 있는지가 **미확정**이라는 것이 이 회차의 산출물이다.

                   그 항목은 **86회차가 이미 확장해 둔 자리**다 —
                   「**집합의 원소를 고르는 규칙(최근접 스냅 · argmin)도 정의역의 일부다**」
③ 새 사례로 세우는가  **세우지 않는다. 86회차 사례(끝점 스냅)에 후속 실증 블록으로 붙인다.**
                   대상이 **같다**(최근접 스냅이 값을 정한다). 86이 보인 것은
                   **「값이 두 판본」**(8.26 ↔ 9.92cm)이고, 89가 보인 것은
                   **「부호까지 두 판본」**(9/48)이다 — **같은 대상의 진행**이다.
                   **선례**: 88회차가 함정 18에서 **같은 근거로 같은 판단**을 했다
                   (같은 대상의 사례가 둘로 갈리면 **규범이 두 군데에서 각각 자란다**)
```

**판정 갈래는 갈리지 않았다** — 정점 10/26 · 삼각형 11/26으로 **둘 다 갈래 B**다(§4-4).
그러나 **등재값은 전부 정점 최근접 기준**이다(음수 표본의 (s, θ) · 부호거리 중앙 ·
좌우 비대칭 −0.13 / +1.76cm). **§6이 다음 회차 표적으로 오르는 값이 바로 그 열이다.**

**미적용 등재**: 86 §10-3의 4-튜플 **(값 · 질의점→정점 거리 · 1·2위 마진 · 후보 간격)** 을
**이 채널에 적용하지 않았다**(§6 · §10). 적용 여부는 **§11 ㄱ 갈림**이다 —
**이 노트는 처방을 적지 않는다.**
