## §2 축① — **거동 무변화 실증 통과** (이번 회차의 머리)

`d`를 **밀어내는 그 법선으로 복원**한다(`d = (p − hit.point)·n`) —
**새 BVH 질의 0 · 새 상수 0 · 자기정합**(판정 부호와 밀어내는 방향이 같은 법선).

```

```

→ **축①은 처방이 아니다(계산 동치가 실증됐다).**
