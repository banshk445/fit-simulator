## §1 치명 2건

### 치명 1 — **배선 전제가 거짓**

`magnet.w`는 `(ny:number)=>number`(`bvhFromArrays.ts:219`)로 **정점 인덱스를 받지 않는다.**
프롬프트 §2가 명시한 *"53회차 magnet 인자 재사용 + 밑단 대역 게이트"*는
**현 배선으로 불가능**하다.

우회 2종도 막힌다:

```
skipLocalStart/EndExclusive   **연속 구간 1개**만 표현한다
밑단 정점                     미러 복제(patternMesh.ts:494-508)로 **두 덩이**로 갈린다
```

→ **공유 파일 수정 필수** → **12콤보 필수**.

### 치명 2 — **Δ20이 판정을 인질로 잡는다**

`dressPattern.ts:2081-2086`이 **전 정점 max만** 쌓고 **argmax를 기록하지 않는다.**

```
A 기준선 Δ20 5.16mm   vs 문턱 5.6   →  여유 **0.44mm**
49회차 B(자석 **전역** off)  →  **Δ20 6.41로 ABORT**
```

자유 경계는 **플러터의 자연 위치**인데 **어느 정점이 max였는지 기록이 없다** — **함정 1 정면.**

## §2 중 5건

### 중 1 — 대역 정의 불가 → **프롬프트 자기모순**

밑단 **사슬**은 손 상수 0으로 정의된다(제도상 `y = lengthM` 직선 · `HEM_STRICT = 1e-9`).
그러나 **"대역"은 불가**다:

```
loose(1cm) 70 = strict 70      1cm를 잡아도 정점이 **한 개도 안 는다**
→ k홉이 필요하고 `k ≤ 4`는 **손 상수**(함정 14)
```

§2가 *"대역 정의는 (a)를 따르고 손 상수 도입 금지"*라 했으므로
**두 조건이 동시에 만족될 수 없다.**

### 중 2 — 43회차 P3 **두 번째 뿔** 잔존

첫 뿔(집합 고정성)은 회피된다 — 술어가 `g.pos2` **패턴 좌표**다.
그러나 *"근거가 t=0에서만 참"*이 남는다: ⓑ 근거의 몸 둘레 **76.07**은 밑단이 y **76.96cm**일 때의
슬라이스인데 **밑단 높이는 실행 중 움직인다**(A 정착 **75.14~80.03** · D0 **58.63~60.83**).

**새 지점**: 게이트가 실제로 걸리는 건 `d>margin`인 정점뿐인데
A 정착 밑단은 **국면2가 74.3%/65.7%**다
→ 고정 집합 70개 중 **26~34%만 매 호출 대상이고 그 부분집합은 재계산된다.**

### 중 3 — 마찰: **55회차 ⓓ에 실측 근거가 없다**

```
FRICTION_CONTACT_BAND = 20mm
A 밑단 d 중앙 14.2 / 14.4mm   →  **밑단은 지금 마찰 밴드 안에 있다**
D0의 39.0mm                   →  밴드 밖 = **마찰 전량 상실**
```

55회차 ⓓ *"밑단 마찰은 애초에 지지에 안 쓰인다"*는, 하중 계기 `holdSeries`가
`ring/shoulder/other` **3분류**라 **밑단이 other에 묻혀 산출 불가**였던 것을 **단정으로 쓴 것**이다.

### 중 4 — 규범 문서가 **반대 방향을 이미 등재**

`docs/v2-design.md:427` — 「밑단 … 34cm 여분이 **자유 경계 → 최소 굽힘 에너지 형상 = 프릴**」.
**후보 2는 밑단을 더 자유롭게 만든다.**

### 중 5 — 국면2 **단방향 래칫**

자석을 끄면 margin 안으로 들어온 정점은 `0.4·(margin−d)`만큼 **밖으로만** 밀리고
되돌리는 항이 없다 → **진동의 정류로 바깥 누적 가능.**
