# 2b-08 — 구조 전환 (선봉제 + 목 스레딩), 전단사 사상, 목밑둘레 발견

## 변경
어깨 시접 사전 봉제(applyWelds 46쌍) + 목 스레딩 배치. 근거 = 제조 순서 복원
(실제 재봉은 어깨를 평면에서 먼저 봉제) + 링이 t=0부터 목을 감싸면 유지력 담당
→ 착장 앵커 자체가 불필요해질 가능성(2c 무핀 질문의 조기 답).

Coons 4변 분해는 착수 후 기각(암홀 x 비단조) → **전단사(transfinite) 사상**으로 교체.
코너 8개 몸 랜드마크 선사상(목점=ridge(s=0)) + 목선 부풂 이분법 + 내부 매개화.

## 진짜 뿌리 발견 (이 회차의 핵심)
사상 자체는 성립(코너 0.0000, 자기교차 436→72). 그러나 t=0 4/4 실패 — **원인은 사상이
아니라 패턴 입력**: neckHalfWidth가 목 기둥 최소 둘레(32.38cm@y148)에서 도출되는데
목선이 앉을 목밑(y≈145)의 최소 폐곡선은 41.1cm — 23% 부족.
"링 길이=패턴"과 "링이 몸 위" 두 조건이 동시 성립 불가.

→ [[../원리/몸에서-가져와라]] 원리의 첫 위반 사례이자 첫 적용 필요 지점.

## 부수 발견
게이트 실패인데 하네스가 물리 진행하는 배선 버그 발각(t0Fails 미사용).
무효 물리 실행에도 낙하 없음·봉합·DONE — 구조 자체는 작동한다는 예고.
