# 함정 31 — 절제가 표적의 **«결정항»**에 닿지 않는다

**정의**: 어떤 양을 「없애 보는」 처치(절제·차단·off 스위치)가 **자기 정의대로 전 경로에서
정확히 작동하는데도**, 표적 값을 **정하는 항**을 건드리지 않아 **표적이 원리적으로 안 움직인다.**
절제는 「무엇을 없애는가」가 아니라 **「표적의 결정항을 없애는가」**로 설계돼야 한다.

**반납 미완이 아니다.** 스위치는 자기가 끄겠다고 한 것을 다 껐다 —
남은 것은 **끄려던 대상의 다른 경로가 아니라 «다른 대상»**이다.

## 사례 1 — `MAGNET_D0` / `ADSORB_PENONLY`로 흡착 평형점 15mm를 흔들려 했다 (97회차 §2 · 집행 금지)

```
표적        정착 간극 중앙값 — 96 §4가 `COLLISION_MARGIN` **15.0mm** 흡착 평형점에
            포화한다고 판정한 그 값(4/5 집합이 ±0.8mm 안)
처치        `MAGNET_D0=1`(국면1 자석 차단) · `ADSORB_PENONLY=1`(관통-only)
결정항      국면2·3의 **목표점 `hit.point + n·margin`** (`src/lib/bvhFromArrays.ts`)
처치가 닿는 곳  `w`가 **`relax`에만** 곱해진다(`:252-261`) — **목표점은 손대지 않는다**
따름        15mm는 「양방향 끌개」에서 「**아래쪽 장벽**」이 될 뿐 —
            **중앙값이 원리적으로 15mm «아래»로 못 간다**
실측이 그 방향  54회차 D0: d 중앙 14.2 → **39.0mm**(**위로만**) · 국면2 74.3 → **5.7%**
            → 「평형점이 사라진다」의 반례가 **이미 등재돼 있었다**
결과        97 §2 = **집행 금지·정지**(거짓 전제 7건 중 전제 3 = 치명) ·
            그 기전 후보는 **미검정**으로 남는다(기각도 지지도 아님)
```

## 대조 — 절제가 **성공한** 판본 (94회차 §1 · 갈래 A)

```
94 ARMCAP=0   `if (ARMCAP)` 가드가 **호출 자체를 지운다** → 팔 캡슐이라는 변수가 «사라진다»
              = 표적(소매 상반 r)의 **결정항을 통째로 없앴다**
결과          상반 **12/12 하락** · 관통 약 6배 → **갈래 A 발화**(형상 결정자 = 팔 캡슐)
차이          94는 «결정항»을 없앴고, 97은 «가중치 항»만 껐다.
              **둘 다 스위치는 정상 작동한다** — 갈린 것은 **작용점**이다
```

## 규범 (97회차 실측·등재에서 도출된 것만)

1. 절제를 설계할 때 **표적 값을 정하는 항을 식에서 먼저 지목**하고,
   **그 항이 스위치의 정의역 안에 있는지 코드로 확인**한다.
   (「이 스위치가 무엇을 끄는가」가 아니라 **「표적의 결정항을 끄는가」**)
2. 표적이 **평형점·목표점 형태의 상수**면 — 가중치·감쇠·비율을 끄는 처치는
   **도달 «속도»만 바꾸고 «자리»는 안 바꾼다.** 자리를 바꾸려면 그 상수를 쓰는 항에 닿아야 한다.
3. **처치의 방향이 이미 등재된 실측에 있는지 먼저 본다** — 97의 반례(54회차 「위로만」)는
   **회차를 돌리기 전에 볼트에 있었다**.
4. **문턱은 박지 않는다.** 「얼마나 움직여야 검정인가」는 그 처치를 채택하는 회차가
   **실행 전에** 도출한다([[../원리/사전등록]] 규범 4·5 · [[함정14-기준선의존]]).

