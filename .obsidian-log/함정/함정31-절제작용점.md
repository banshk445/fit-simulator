# 함정 31 — 절제가 표적의 **«결정항»**에 닿지 않는다

**정의**: 어떤 양을 「없애 보는」 처치(절제·차단·off 스위치)가 **자기 정의대로 전 경로에서
정확히 작동하는데도**, 표적 값을 **정하는 항**을 건드리지 않아 **표적이 원리적으로 안 움직인다.**
절제는 「무엇을 없애는가」가 아니라 **「표적의 결정항을 없애는가」**로 설계돼야 한다.

**반납 미완이 아니다.** 스위치는 자기가 끄겠다고 한 것을 다 껐다 —
남은 것은 **끄려던 대상의 다른 경로가 아니라 «다른 대상»**이다.

## 사례 1 — `MAGNET_D0` / `ADSORB_PENONLY`로 흡착 평형점 15mm를 흔들려 했다 (97회차 §2 · 집행 금지)

```
표적        정착 간극 중앙값 — 96 §4가 `COLLISION_MARGIN` **15.0mm** 흡착 평형점에
            포화한다고 판정한 그 값(4/5 집합이 ±0.8mm 안)
처치        `MAGNET_D0=1`(국면1 자석 차단) · `ADSORB_PENONLY=1`(관통-only)
결정항      국면2·3의 **목표점 `hit.point + n·margin`** (`src/lib/bvhFromArrays.ts`)
처치가 닿는 곳  `w`가 **`relax`에만** 곱해진다(`:252-261`) — **목표점은 손대지 않는다**
따름        15mm는 「양방향 끌개」에서 「**아래쪽 장벽**」이 될 뿐 —
            **중앙값이 원리적으로 15mm «아래»로 못 간다**
실측이 그 방향  54회차 D0: d 중앙 14.2 → **39.0mm**(**위로만**) · 국면2 74.3 → **5.7%**
            → 「평형점이 사라진다」의 반례가 **이미 등재돼 있었다**
결과        97 §2 = **집행 금지·정지**(거짓 전제 7건 중 전제 3 = 치명) ·
            그 기전 후보는 **미검정**으로 남는다(기각도 지지도 아님)
```

## 사례 2 — `detectionRadius`를 낮춰 같은 15mm를 흔들려 했다 (98회차 §2 · 집행 금지 · **98 자체 판정**)

```
표적        같다 — 정착 간극 중앙값(흡착 평형점 `COLLISION_MARGIN` **15.0mm**)
처치        `COLLISION_DETECTION_RADIUS` **150mm**를 호출부에서 60 / 30 / 15mm로 낮춘다
            (`scripts/dressPattern.ts:709-710`이 2번 인자를 **명시**한다 — 배선은 정상)
결정항      사례 1과 같다 — 국면2·3의 **목표점 `hit.point + n·margin`**(`bvhFromArrays.ts:249-251`)
처치가 닿는 곳  `detectionRadius`는 리졸버 클로저 안 **단 1곳** —
            `:235` `closestPointToPoint`의 **maxThreshold**뿐이다. 목표점·`relax`·국면 판정에는
            **들어가지 않는다**
따름        15mm는 **하한 장벽**으로 남고 중앙값은 **위로만** 간다.
            R4(15mm = margin)는 임계가 **부호 없는** 거리 `|q|`이고 `d = q·n ≤ |q|`이므로
            **국면1(d>15)이 공집합** ⟹ **54회차 `MAGNET_D0`와 바깥쪽 정점 처분이 같다**
            (그 실측이 이미 «위로만»: d 중앙 14.2 → **39.0mm** · 국면2 74.3 → 5.7%)
결과        98 §2 = **집행 금지·정지**(거짓·미검증 전제 7건 중 전제 2 = 치명) ·
            97 §0-2 기전 후보는 **두 회차 연속 미검정**
```

**사례 1과 갈리는 점 / 갈리지 않는 점**(98 §5-1 자체 판정)

```
갈린다      97은 **가중치 항**(`w` → `relax`)을 껐고, 98은 **정의역**을 좁힌다 — 처치의 종류가 다르다
갈리지 않는다  **결정항이 처치의 정의역 «밖»에 있다**는 구조가 같다.
            R4는 「끌어당김」의 정의역을 아예 지우지만(**순수 단방향 밀어내기가 된다**)
            **목표점 상수는 그대로 남는다** → 규범 2가 그대로 적용된다
연속        **97 · 98 두 회차 연속**으로 같은 형태의 반증에 걸렸다(사실 등재)
규범 반영    **하지 않는다** — 규범 1이 이미 그 절차를 요구한다.
            두 회차 연속은 **새 규범이 필요하다는 사실이 아니라 «규범 1 미이행»의 이력**이다.
            **규범 신설 0 · 문턱 0 · 처방 0**
```

## 반례 — **닿는 사례** (99회차 §1(f) · **99 자체 판정** · 사례 아님 · 사실 등재)

**사례 1·2는 「안 닿는다」만 모은 목록이었다. 99가 「닿는다」가 확인된 첫 경우다.**

```
표적        같다 — 정착 간극 중앙값(흡착 평형점 `COLLISION_MARGIN` **15.0mm**)
처치        **margin 호출부 리터럴**을 15 → 5 / 3mm로 낮춘다(계획 · **집행되지 않았다**)
결정항      같다 — 국면2·3의 **목표점 `hit.point + n·margin`**(`bvhFromArrays.ts:249-251`)
처치가 닿는 곳  **그 목표점 상수 «자체»다.** 클로저에서 margin이 쓰이는 곳은 2군데이고
            물리에 사는 것은 `:249-251` **1군데**뿐이다(`:253-259`는 `magnet` 전달 시에만이고
            기준선은 `magnetArg = undefined` — `dressPattern.ts:707`)
            ⟹ 이동량은 전 정점 한 식: `Δ·n = PUSH_RELAXATION × (margin − d) = 0.4 × (margin − d)`
따름        margin 15에서 `+0.4(15−d) > 0`(바깥)이던 것이 margin 3에서 `0.4(3−d) < 0`(안쪽)으로
            **부호가 뒤집힌다** → **규범 2가 99에는 «적용되지 않는다»**
```

**이 반례가 함정에 주는 것 — «판별력»의 자료다**

```
① **판별 절차가 작동했다** — 규범 1(표적의 결정항을 식에서 먼저 지목하고 그 항이 처치의
   정의역 안에 있는지 **코드로 확인**)을 99가 **실행 «전»에 이행**했고 결과가
   97·98과 **반대**로 나왔다. 같은 절차가 세 회차에서 **두 번은 «안 닿는다» · 한 번은 «닿는다»**를 냈다
② **그런데 99도 정지했다** — 정지 사유가 이 함정이 «아닌» **다른 4가지**였다
   (v1 실측의 판정 종료 · 값 스윕 금지 조항 미처분 · 계기 거짓 인쇄 ·
    호출부 하나로는 배치·제도가 15mm로 남아 **원주 잉여** 발생)
   ⟹ **「흡착 축이 원리적으로 닫혔다」로 읽으면 «거짓»이다**
등재        **규범 신설 0 · 문턱 0 · 처방 0 · 사례 번호 부여 0**(사례가 아니라 **반례**다) ·
            99회차 실측 0(위 코드 인용은 전부 99 §1(f) 등재분)
```

→ [[../회차/2b-99-margin처방]] §1(f) · §5-2 · 「이 정지가 97·98과 «다른» 점」

## 대조 — 절제가 **성공한** 판본 (94회차 §1 · 갈래 A)

```
94 ARMCAP=0   `if (ARMCAP)` 가드가 **호출 자체를 지운다** → 팔 캡슐이라는 변수가 «사라진다»
              = 표적(소매 상반 r)의 **결정항을 통째로 없앴다**
결과          상반 **12/12 하락** · 관통 약 6배 → **갈래 A 발화**(형상 결정자 = 팔 캡슐)
차이          94는 «결정항»을 없앴고, 97은 «가중치 항»만 껐다.
              **둘 다 스위치는 정상 작동한다** — 갈린 것은 **작용점**이다
```

## 규범 (97회차 실측·등재에서 도출된 것만)

1. 절제를 설계할 때 **표적 값을 정하는 항을 식에서 먼저 지목**하고,
   **그 항이 스위치의 정의역 안에 있는지 코드로 확인**한다.
   (「이 스위치가 무엇을 끄는가」가 아니라 **「표적의 결정항을 끄는가」**)
2. 표적이 **평형점·목표점 형태의 상수**면 — 가중치·감쇠·비율을 끄는 처치는
   **도달 «속도»만 바꾸고 «자리»는 안 바꾼다.** 자리를 바꾸려면 그 상수를 쓰는 항에 닿아야 한다.
3. **처치의 방향이 이미 등재된 실측에 있는지 먼저 본다** — 97의 반례(54회차 「위로만」)는
   **회차를 돌리기 전에 볼트에 있었다**.
4. **문턱은 박지 않는다.** 「얼마나 움직여야 검정인가」는 그 처치를 채택하는 회차가
   **실행 전에** 도출한다([[../원리/사전등록]] 규범 4·5 · [[함정14-기준선의존]]).
