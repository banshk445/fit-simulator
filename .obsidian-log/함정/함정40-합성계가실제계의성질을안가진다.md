# 함정 40 — 합성계는 편하지만 **실제 계의 성질을 안 가질 수 있다**. 「작아서 빠르다」가 「같은 것을 잰다」는 아니다

## 무슨 일이 있었나

v4 이식을 검증하려고 **작은 합성계** 둘을 세웠다.

```
 strip  2행 × 32열 한 줄 천 — 늘어남 제약 62개 · **한쪽 열 2정점 고정**
 hinge  두 삼각형 힌지     — 굽힘 제약 **1개** · 한쪽 삼각형 3정점 고정 · 자유 정점 **하나**
```

둘 다 「v3 를 그대로 옮겼는가」를 재기에 충분해 보였다. 실제로 **층1(1스텝)** 에서는 잘 작동했다.

그런데 **층2(수렴 도달)** 에서 hinge 가 이렇게 나왔다:

```
 v3(f64)  110 프레임에 수렴 · 자유 정점 (0, −2.51e-04, −3.393e-01)
 v4(f64)  110 프레임에 수렴 · 차 **1.11e-16**            ⟹ 이식은 정확하다
 v4(f32)  **20,000 프레임에도 미수렴** · 차 **0.496 m**  ⟹ ?
```

「v4 의 굽힘이 틀렸나?」로 읽힐 수 있는 그림이었다. **판별력 검사가 그것을 부정했다** —
같은 v3 코드를 **초기값만 1e-7 흔들어** 자기 자신과 대조하니:

| 계 | 섭동 보존비 | 뜻 |
|---|---|---|
| strip | **0.000946** | 수축계 — 섭동이 사라진다 |
| hinge | **1.00** | ★ **중립** — 섭동이 그대로 남는다 |

**hinge 는 스칼라 제약 하나(이면각)에 자유 정점의 자유도가 셋이다** ⟹ 이면각을 바꾸지 않는
**2차원 중립 방향**이 남는다. 그 방향으로는 **v3 자신도** 초기값 차이를 끝까지 보존한다.
즉 **「최종 정점 좌표」가 이 계에서 유일하지 않다** — 무엇을 비교하든 구현에 대해 말해 주지 않는다.

## 왜 그렇게 되나

합성계는 **크기**를 줄이려고 만든다. 그런데 크기를 줄이면서 **구속도 함께 줄어든다.**
실제 계(정답지 옷 한 칸)에서는 정점 하나가 늘어남 제약 6개 · 굽힘 제약 12개 · 봉제 · 몸 충돌에
동시에 잡혀 있고 **평형이 유일**하다. 합성계는 그 성질을 **잃은 채로** 「같은 물리를 잰다」고 불린다.

```
 ★ 잃기 쉬운 성질 3종
   ① **평형의 유일성** — 제약 수 < 자유도면 중립 방향이 남는다
   ② **강체 모드의 구속** — 고정점·충돌이 없으면 병진·회전이 통째로 중립이다
   ③ **접촉·마찰** — 실제 계의 안정성이 거기서 오는데 합성계엔 없다
```

## 규범

1. **합성계는 «층1 전용»으로 쓴다** — 1스텝은 구속 구조와 무관하게 커널 산술만 잰다.
2. **긴 실행·도착점 비교는 «구속계»에서만 한다.** 정답지 한 칸처럼 실제 성질을 가진 계를 쓴다.
3. **새 시험계를 세울 때 «판별력 자가 대조»를 먼저 돌린다**(섭동 보존비 · [[../원리/검증은-도착점과-관측량으로]]).
   통과 못 하면 **그 시험은 돌리지 않는다** — 돌려 나온 수는 구현에 대해 아무것도 말하지 않는다.
4. **「작아서 빠르다」를 「같은 것을 잰다」로 읽지 않는다.** 무엇이 줄었는지 목록으로 적는다.
