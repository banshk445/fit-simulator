# 함정 30 — 창이 값역 «안»인데 **폭·위치가 신호와 어긋난다**

**정의**: 판정이 쓰는 **창**(문턱 창 · 갈래 술어 · 관측 시점)이 계기 값역 «안»에 있고
**실제로 발동하는데도**, 그 창의 **폭이 갈라야 할 신호의 폭과 겹치거나** **위치가 신호가
나는 구간 밖에 있어서** — 채널은 정상 산출되고 답도 나오는데 — **그 답이 물음에 답하지 않는다.**

**판별력 0이 아니다.** 이것이 [[함정13-jitter]] 규범 6(값역)의 기존 3사례와 갈리는 지점이다.
그쪽은 답이 **데이터와 무관하게 고정**되고(발동 불가 / 항상 통과 / 항상 포화), 이쪽은
**실행마다 다른 값이 나오고 갈래도 발동한다.** 실패는 **값이 아니라 창의 눈금**에서 온다.

## 사례 1 — 접촉 문턱 **±0.05cm** (93회차 판정 → 94 §0(1) · §4)

```
창          |r − 5.16| ≤ 0.05cm  → **창 폭 0.10cm**
갈라야 할 신호  상반 r 중앙 **5.00~5.11cm** ↔ 캡슐 유효반경 **5.16cm** = 간극 **0.05~0.16cm**
             → **창 폭과 신호 폭이 겹친다**
93 산출      접촉률 R **0.060** / L **0.074** → 갈래 B(「캡슐이 안 물린다」)
못 가른 것    6~7%가 「**멀다**」인지 「**창 «밖»의 근접**」인지 — **그 채널로는 원리적으로 못 가른다**
문턱 없는 채널로 다시 물은 결과(94 §1 = ARMCAP=0 절제):
   상반 r 중앙 **12/12 스테이션 하락**(R −1.34 · L −1.39cm) · 소매 관통 **23·24 → 137·143**
   → **갈래 A = 캡슐이 소매 상반 형상을 정한다**
```

**창은 값역 안에 있었고 실제로 발동했다**(948 중 31개가 창에 들었다). 값역 확인을 100%
해도 **폭이 겹친다**는 사실은 잡히지 않는다. **문턱은 사후에 고치지 않았다** —
93 갈래 B 문언·수치는 **한 자도 안 바꿨고**([[함정14-기준선의존]]), 94회차는
**문턱이 필요 없는 채널(절제)로 새로 물었다**.

## 사례 2 — 시간 대조의 두 창 (94 §2 · **판정 불가 · 정지**)

**(가) 갈래 술어의 창이 값역을 «분할»하지 않는다**

```
ㄱ  등록 4점 변동폭 **< 0.2cm**      실측 R **0.12** / L **0.04cm**   → **충족**
ㄷ  「**비단조**」(크기 하한 «없음»)   부호열 R `+,−,0` / L `+,−,−`     → **동시 충족**
→ 거의 불변인 계열은 **원리적으로 ㄱ·ㄷ 양쪽에 걸린다.**
  **문턱 사후 변경 금지**이므로 갈래를 고르지 않는다 → **판정 불가**
```

**(나) 관측 창이 신호 «뒤»에 열린다**

```
등록 4점     2s · 3s · 4s · 완주
추가 채널 f=0  배치 직후 r **전 정점 7.23cm 균일**
0 → 2s 이동   하반 **−0.52~−0.61cm** · 상반 **−2.14~−2.15cm**
등록 4점 변동폭 하반 **0.12 / 0.04cm** · 상반 **0.04 / 0.03cm**
→ **변화 전량이 첫 등록점 이전에 끝난다.** 등록 4점은 「소매가 정착 동안 움직였는가」를
  **원리적으로 못 잰다** — 추가 채널 **f=0 한 점**이 등록 4점 전량의 판정력을 무효화했다
```

부수 사실(같은 절 등재): 하반은 **배치 7.23cm에서 2초 안에 6.6~6.7cm로 내려간 뒤 완주까지
0.12cm 안에서 얼어 있다.** 그리고 §2의 전제 수치(「하반이 배치 원통 **5.73cm** 근처」)는
f=0 실측 **7.23cm**과 어긋나 **전제부터 성립하지 않았다.**

## 규범 (94회차 실측에서 도출된 것만)

```
① **창의 «폭»을 신호의 «폭»과 같은 단위로 맞대 적는다.**
   창 폭 0.10cm ↔ 갈라야 할 간극 0.05~0.16cm처럼 **둘이 겹치면 그 채널은 두 상태를 못 가른다**.
   문턱을 쓸 때 **(창 폭, 신호 폭, 둘의 비)** 를 갈래 옆에 함께 적는다
② **갈래 술어가 값역을 «분할»하는지 확인한다.**
   **크기 조건**(< 0.2cm)과 **형태 조건**(단조/비단조 · 부호열)을 나란히 세우면,
   형태 조건에 **크기 하한이 없는 한 두 갈래가 동시에 성립한다** — 이번이 실증이다.
   형태 조건에는 **크기 하한을 함께 쓰거나**, 크기 조건과 **다른 축**에 둔다
③ **관측 시점을 등록하기 전에 «신호가 언제 나는지» 여는 점을 먼저 잡는다.**
   창이 신호 뒤에 열리면 **등록점 전량이 판정력을 잃는다**. f=0 **한 점**이
   등록 4점 전부를 무효화했다 — 여는 점은 **등록점보다 싸다**(S0 경과 4.2s / 내부 0.8s)
```

**문턱은 여기 박지 않는다**(90회차 관행 — [[함정13-jitter]] 스냅 4-튜플 절). 위 규범은
**폭과 위치를 «맞대 적어라»**까지이고, 얼마면 겹치는지는 **그 채널을 판정에 채택하는 회차가
실행 전에 도출**한다([[../원리/사전등록]] 규범 4·5 · [[함정14-기준선의존]]).

## 구별 대상 (94회차 §8-2 자체 판정 — 왜 기존 함정에 안 붙였는가)

후보 전부에서 **「그 함정의 규범을 100% 지켜도 이번 결함이 남는다」**가 성립한다
(28·29 신설 때 쓴 것과 같은 시험).

```
[[함정13-jitter]] 규범 6 **값역**
   **가장 가까운 이웃이고, 다르다.** 기존 3사례는 **판별력 0**이 공통 시그니처다 —
   80(문턱이 값역 «밖» → 발동 불가) · 85(검사량이 한 점 → 항상 통과) ·
   90(조건이 항등 → 항상 포화). **이번은 판별력이 0이 아니다**:
   접촉률은 실행마다 다른 값(0.060 / 0.074 / 0.013)을 냈고 · 갈래 ㄱ·ㄷ은 **둘 다 발동**했고 ·
   등록 4점은 **전부 정상 산출**됐다. 값역 확인(연속/이산 · 도달 가능 범위)을 **100% 해도
   창 폭이 신호 폭과 겹친다는 사실은 안 잡힌다**(±0.05cm는 r 값역 4.56~7.27cm **안**이다).
   **한 줄 차이: 값역 = 답이 «고정»된다 / 30 = 답이 나오는데 «물음에 답하지 않는다»**
[[함정13-jitter]] 규범 6 **시점**
   **아니다.** 규범 6 시점 항목은 **라벨이 주장하는 시점과 실제 시점이 다르다**(32·34·36·41회차)인데,
   이번 등록 4점의 라벨은 **맞다**(2s는 2s다). 틀린 것은 **창이 열리는 위치**다
[[../원리/사전등록]] 규범 12
   **방향이 반대다.** 12는 「조건이 서로를 **배제**하면 어떤 실행도 통과 못 한다」(58→59회차)이고,
   이번은 **두 갈래가 동시에 통과**한다. 12를 100% 지켜도(동시 만족 «가능»한지 확인) 남는다
[[../원리/사전등록]] 규범 10
   **지켜서 생겼다.** 10은 「효과 채널의 시점을 정착에 맞추고 **과도 봉우리를 효과로 읽지 마라**」인데,
   등록 4점이 전부 정착 쪽이라 **0→2s 과도에서 끝난 변화**를 원리적으로 못 봤다
[[함정16-수치근접]]
   **아니다.** 값을 읽는 방식(상관 → 기전 승격)이 아니라 **창 설계**다.
   (다만 이번 해소 수단은 16의 규범 그대로다 — **캡슐을 끄자** 답이 나왔다)
[[함정18-중앙값]]
   **아니다.** 대표값–분포 관계가 없다. 병기를 100% 해도 창의 폭·위치는 그대로다
[[함정27-분모없는채널]]
   **아니다.** arity가 아니다 — 접촉률은 분모를 병기했다(232 / 230 / 948)
[[함정29-측정주체고정]]
   **아니다.** 주체는 93회차부터 이미 **옷 쪽**이다. 주체를 바꾼 «뒤»에 남은 결함이다
```

**신설 근거**: 이 볼트는 신설에 보수적이고 80·85·86·89·90회차가 전부 규범 6에 붙였다.
규범 6에 붙이면 **값역 항목이 「폭·위치」까지 지게 되고 시그니처가 섞인다**(판별력 0 ↔
판별력 있음). 27·28·29와 같이 **계기 «밖» 층위**다 — 결함은 채널의 계산이 아니라
**창의 설계**에 있다.
