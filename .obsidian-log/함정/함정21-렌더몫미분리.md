# 함정 21 — 화면 결함에 렌더 몫이 섞여 있다 (δ 3성분)

**정본**: 화면 판정에 쓰는 `PatternPreview.tsx` 경로는 옆선에 렌더 성분 3종을
**항상** 얹는다. 물리 결함으로 승격하기 전에 렌더 몫을 빼고 봐야 한다.

## δ 3성분 (47회차 코드 확인)

```
δ① 패널 4매를 **별개 BufferGeometry**로 만들고 각각 computeVertexNormals()
   (PatternPreview.tsx:130-144) → **패널 경계(=옆선)에서 법선이 원리적으로 불연속**
δ② 시접 브리지가 color="#6b7f8c" 단색 DoubleSide (:200)
   → 옆선에 **폭 6mm 회청 세로 띠가 항상 그려진다**
δ③ 패널 분리 렌더 → 시접 rest 6mm 간격이 화면에 **세로 틈**으로 보인다
   (코드 주석 자신이 등재, :146-148 — 물리적으로는 **4.9~9.1mm로 닫혀 있다**)
```

## 48회차의 분리

`?cleanrender=1`(캡처 전용 · 기본 off · **정점 위치 불변**)이 **δ①(법선 평균 용접) ·
δ②(브리지 숨김)를 끈다.** MD5 5/5 상이 · 물리 채널 8/8 불변.
**δ③은 남는다** — 위치를 안 건드렸으므로 시접 6mm 간격은 그대로 그려진다.

보존 2세트: `docs/captures/2b-48-current/` · `docs/captures/2b-48-clean/`.
**화면 재판정은 전략 세션 몫**(자체 선언 금지).

## 규범

**화면 결함을 물리 표적으로 승격하기 전에 렌더 성분을 뺀 화면과 대조한다.**
27회차 이후 "옆선" 관측은 전부 **렌더 몫 미분리 상태의 판정**이다(48회차 소급 주석).
