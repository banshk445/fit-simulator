# 함정 29 — 측정 주체를 한 번도 바꾸지 않았다 (**몸 쪽에서만 쟀다**)

**정의**: 표적 진술의 **주어**(무엇이 어떠하다)와 계기가 순회하는 **집합의 주인**이
다른데도, 여러 회차에 걸쳐 **한쪽에서만** 계기를 세우면 — 채널이 전부 정확하고
판정도 그 안에서 유효한 채로 — **그 진술을 검증할 수단이 한 번도 만들어지지 않는다.**

**성격은 계기 결함이 아니다.** 이름과 계산이 일치하고, 분모가 있고, 자체 검사가 통과하고,
그 채널이 진 판정도 유효하다. **결함은 채널 «하나»에 없다 — 채널 «집합» 전체가
같은 주체에 몰려 있다는 것이다.** 회차마다는 아무 신호가 없고, 이력을 옆으로 놓고 봐야 보인다.

## 사례 — 소매 대역 (79 → 92회차 = **12회차** · 93회차 판정)

```
79~92회차가 낸 채널  **전부 「몸 표본에서 옷을 본다」**
  79  top-back 201표본 최근접 옷 거리     82~90  covSh 대역 표본 · 패치창 48
  87  몸 메시 팔 단면(몸)                 88     패치창 방향 θ(몸 표본 기준)
  89  몸 표본 법선 부호                   90     몸 표본 최근접 옷(시접/자유가장자리 분류)
  91  **대역 1421 전체**의 최근접 옷 거리  92     같은 채널의 대조군
```

그동안 다뤄진 진술은 **소매를 주어로 한다**:
「옷이 팔에서 떠서 노출된다」(88 §5-4) · 「소매가 원통(팔)을 따른다」(92 §6-1 부호 질문).

**93회차 §1 선행 확인**([[../원리/사전등록]] 규범 18)이 부재를 실증했다:

```
옷 정점의 축 수직거리 r 분포를 내는 채널   **0건**(검색 6지점 전량)
`sleeveArmFrame`(팔 축 s·θ)               **있다** — 그러나 사용처 4곳이
                                          **전부 몸 표본 쪽**이고 **옷 정점에 쓴 곳 0건**
```

**축은 있었고, 없던 것은 그 축에 «옷 정점»을 얹는 소비자였다.**

**주체를 바꾸자 한 번에 나왔다**(93 §2 · 갈래 B):

```
접촉률(캡슐 표면에 붙은 소매 정점)  **0.060 / 0.074** — 948 중 **31개**
상하 r 중앙 차                     **1.59 / 1.67cm**(상반 5.0cm 거의 상수 / 하반 5.9~7.3cm)
방향편차                           **1.43~3.49cm**
옷 r min                           **4.56~5.06cm < 캡슐 유효반경 5.16cm**
→ **캡슐은 소매 정점의 93~94%에 활성 제약이 아니다.** 등방 가설 기각 ·
  92 §6-1 부호 질문은 **전제가 성립하지 않는다**
```

**12회차 동안 실패 신호가 0이었다.** 채널은 매번 정상 산출됐고, 노출·간극·부호·가장자리
판정은 전부 그 안에서 유효했으며, 91회차는 **모집단(1421 전량)으로 갈아타기까지 했다** —
그런데 갈아탄 모집단이 **여전히 몸 표본**이라 결함은 그대로 살아남았다.

## 규범

```
① **표적 진술의 «주어»와 계기 순회 집합의 «주인»이 같은지 확인한다.**
   「소매가 …이다」는 소매를 도는 채널이 답한다. 몸에서 옷까지의 거리는 **관계**이지
   옷의 **형상**이 아니다
② 계기 채택 4항목(축·시점·정규화·집합 — [[함정13-jitter]] 규범 6)에서 **「집합」을 쓸 때
   «누구의» 집합인지 적는다.** 「대역 1421」은 집합 이름이지 주체 이름이 아니다
③ **부재 주장 확인(규범 18)에서 «축이 있다»를 «채널이 있다»로 읽지 않는다.**
   같은 축의 사용처가 전부 한쪽 주체면 **그것이 부재의 실증**이다 — 사용처의 주체를 세어 적는다
④ 한 표적에서 여러 회차가 나오면 **채널 목록을 주체별로 세어 본다.**
   전부 한쪽이면 그 자체를 등재한다(회차 하나하나에는 신호가 없다)
```

## 구별 대상 (93회차 §11-2 자체 판정 — 왜 기존 함정에 안 붙였는가)

네 후보 전부에서 **「그 함정의 규범을 100% 지켜도 이번 결함이 남는다」**가 성립한다.

```
[[함정19-계기가다른대상]]
   **아니다.** 19의 시그니처는 「산출은 정상인데 **찍은 대상**이 표적이 아니었다 →
   **그 값으로 한 판정이 무효**」다(34 캡처가 v1 · 57 hemWobble이 옆선 29% 제외 ·
   73/74 촬영 대상 · 76→77 입력 · 79 주석 대상).
   이번은 **판정이 무효가 아니다** — 79~92의 값과 판정은 그 채널 안에서 유효하고
   라벨과 대상도 일치한다. 19의 규범 문언(입력 경로 · 주석 대상 · 저장소 밖 입력 ·
   이미지 열람 · **통계 정의역이 «화면 표적»을 포함하는지**)을 **100% 지켜도 남는다**:
   화면 표적(삼각근 회색 패치)은 **몸의 맨살**이고 몸 표본 정의역은 그것을 **포함한다**
[[함정24-가진채널미열람]]
   **아니다. 부재 주장이 참**이다(93 §1 검색 6지점 전량 · 옷 r 분포 채널 0건).
   24는 「옳은 채널이 이미 있었는데 안 봤다」인데 **아무도 산출한 적이 없다**
[[함정28-대리지표승격]]
   **가장 가까운 이웃이고, 다르다.** 28은 「**부분집합(창)이 모집단과 구별되는지 검증 안 함**」 —
   결함이 **같은 주체 안의 «집합 선택»**에 있다(패치창 48 ⊂ 대역 1421 · **둘 다 몸 표본**).
   **91회차가 28의 규범을 100% 지켜 모집단 전량으로 갈아탔는데도 이번 결함이 살아남았다** —
   가정이 아니라 **이력으로 실증된 잔존**이다.
   **한 줄 차이: 28 = «집합»의 특별함을 검증 안 함 / 29 = «측정 주체»를 한 번도 안 바꿈**
[[함정27-분모없는채널]]
   **아니다.** arity가 아니다 — 79~92 채널은 분모를 전부 갖고 있었다
```

**신설 근거**: 이 볼트는 신설에 보수적이고 80·85·86·87·88·89·90·92회차가 전부 기존 함정에
붙였다. 28이 「계기 층위가 아니라 **표적 관측량** 층위」라 예외였고, 이번은 그보다 **한 칸 앞** —
**「어느 쪽에서 재는가」**다. 규범 6에 붙이면 계기 채택 체크리스트가 **주체 선택까지 지게 된다**.
27·28과 같은 줄에 세우고 **상호 링크**한다.
