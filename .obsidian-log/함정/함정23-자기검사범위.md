# 함정 23 — 자기검사의 적용 범위가 실데이터를 덮지 않는다

## 사례 (48회차 통과 → 57회차 무효)

48회차 밑단 형상 계기는 **합성 주입 자기검사를 통과**했다
(주입 λ=8.00cm A=10.0mm → 측정 λ=8.62cm A=10.6mm). 그 통과를 근거로 9회차에 걸쳐
프릴 진폭 숫자가 인용됐다. 57회차 사전 반증이 **주입 조건 두 성분 모두 미검사**임을 냈다.

```
① 주입 형상이 **직선 기준선**(dressPattern.ts:1106-1110)
   → **곡률 편향은 원리적으로 검사되지 않는다**(R=∞에서 정확히 0)
   곡률 편향 잔차 ≈ R(1 − sinθ/θ), θ=(W/2)/R
   밑단 둘레 110cm 원 근사 R=17.5cm → **요동 0에서 6.0mm**(A 실측 중앙 3.86mm)
   = **요동이 정확히 0인 매끄러운 타원 밑단이 A 실측과 구별되지 않는다**
② 주입 **λ=8cm는 W=16에서 필터 이득이 정확히 1.000인 유일점**
   → 다른 파장 대역에 대해 자기검사는 아무것도 말하지 않는다
   (A λ19.08 → 이득 0.816 / D0 λ12.91 → 이득 1.175 · **결합 ×1.44**)
③ 실데이터는 **부양 상태**인데 주입은 부양 없이 돌았다.
   57회차 계기 A(부양 자기검사)에서 **주입 0mm가 6.9mm를 낸다**
   (주입 10.0 → 측정 17.1 = 거의 선형 합성) — **진폭 복원 실패**
```

**※ 57회차 계기 A도 직선 기준선을 썼으므로 ①은 여전히 미검사다.**

## 규범

**자기검사는 실데이터가 있는 조건에서 돌린다** — **기준선 곡률 · 파장 대역 · 부양 상태**.
주입 형상이 특수하거나(직선) 주입 파장이 필터 **이득 1의 특이점**이면,
**자기검사 통과는 실데이터 조건에 대해 아무것도 말하지 않는다.**

계기를 채택할 때 **축 · 시점 · 정규화 · 집합** 4항목을 재도출하는 것
([[함정13-jitter]])에 더해, **자기검사의 주입 조건이 실데이터 조건과 같은지**를
같은 자리에서 확인한다.

## 규범 추가 — **계기를 돌리면 「불가능한 값」이 나오는지부터 본다** (62회차 신설)

자기검사의 **최소형**이다. 정교한 주입 실험 이전에, 출력이 **원리적으로 불가능한
영역에 있는지**를 먼저 본다. 이것은 비용이 0이고 정의역·파장·부양 조건과 무관하다.

62회차 소매 부호 오라클의 1차 출력이 **「레이패리티 100.0% 오분류」**를 냈다.
레이 패리티는 **오라클과 독립인 채널**이고 두 채널이 **전 표본에서 정확히 반대**일
확률은 사실상 0이다 — **불가능한 값**이다. 원인은 오분류 집계의
**부호 사상 반전**(안→+1 / 밖→−1)이었고, 수정 후 **0.0%**로 정합했다.

```
불가능한 값의 예   0% 또는 100%가 정확히 나온다 · 독립 채널 둘이 완전 반대다
                   비율이 [0,1] 밖이다 · 부분집합이 전체보다 크다
                   대조군과 처리군이 **비트 단위로 동일**해야 할 곳에서 다르다(또는 그 반대)
```

**이 검사가 없으면 결함은 "그럴듯한 숫자"로 통과한다** — 실제로 이번 결함은
**계기가 정상 산출됐고 실패 신호가 없었다**(함정 19 · 함정 13과 같은 구조).
