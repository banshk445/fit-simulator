# 함정 6 — 마네킹 메시 와인딩 불일치
삼각형 와인딩이 불일치하는 영역에서 면 법선 부호가 뒤집힘. **부호 함정 3회 재발.**
정착 해법 = 안쪽 기준점과의 내적으로 방향 확정.

관련: [[../회차/2b-08-구조전환]] 이후 부호 문제들이 골격 기준으로 옮겨가며 재발 패턴 지속.

## 등재 (51회차) — **주석 충돌 · 이 fixture에서는 와인딩 뒤집힘이 반증됐다**

원문(위)은 지우지 않는다. 51회차 실측(fixture 기하 · 세 검사 독립 일치):

```
와인딩 불일치 2매 엣지  whole 0 · front 0 · back 0
부호부피(발산정리)      +52,530cm³ (front +21,762 · back +30,036)
패리티 오라클 반전      표본 2,093면 중 **0**
```

→ 이 fixture에서 `faceNormal`은 **전 면에서 몸 바깥**을 향한다.

**저장소 안에서 두 주석이 충돌한다**:

```

```

아니라 **스킨드 메시에서 매번 굽는다**. 워커 경로에서 같은 3검사를 돌린 뒤에 판정한다.
