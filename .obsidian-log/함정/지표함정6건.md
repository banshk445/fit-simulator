# 지표 함정 6건 (ⓐ~ⓕ)

여러 회차에 걸쳐 반복 관측된 지표 설계 실수 모음.

- **ⓐ 사실 하드코딩** — 데이터에서 도출해야 할 값을 상수로 박아둠. 여러 회차에서
  "상수 신설 0"이 목표로 등장하는 이유. → [[../원리/몸에서-가져와라]]
- **ⓑ max()는 무관한 지배점에 인질 (4회 재발)** — 최댓값 하나로 판정하면 엉뚱한 위치
  하나가 전체 판정을 좌우함. **maxAt 병기가 필수**로 굳어짐.
  - **사례 추가 (44회차) — 캡슐축이 몸 깊이중심보다 7.2cm 뒤.** 43회차 마스크 기준
    `몸최대 ≥ 17.42`는 **옆(삼각근·어깨너비)이 항상 지배**해서, 링이 실제로 얹히는
    뒤쪽은 전 높이에서 캡슐이 바깥이다(뒤쪽 여유 y110 **+15.70** / y128 +9.87 /
    y132 +9.24cm · 뒤 섹터 y128~137 +9.3~10.9cm). 원인은
    `buildTorsoProxyCapsules`가 축 (x,z)를 어깨뼈 중점(fixture z −2.79cm)으로 잡는데
    메시 깊이중심은 y110 +4.75 / y128 +0.88이라는 것. per-vertex 분해로 보면
    y94~123에서 캡슐 push 도달 정점이 사실상 0개다.
  - **사례 추가 (44회차) — maxSeamGap은 240쌍 중 2정점의 max다.** 39/A/ablation의
    악화 8.98 → 10.31 → 11.14mm는 전부 side·armhole의 **최대**에서 오고 평균은
    안 움직인다(side 7.23 → 7.23). 7.20mm 초과 쌍은 A·ablation 둘 다 정확히 4개이고
    그 4쌍은 **같은 2정점**(패턴 ±27.50, 24.00 = 겨드랑이 아래 옆선 최상단, 좌우 대칭).
    → **이 채널로 처방을 가르는 것은 이 함정의 재현이다.** → [[../회차/2b-44-전면off반증]]

- **ⓒ 재는 것과 같은 연산을 켜고 잰다** — 측정 대상과 측정 도구가 같은 보정을
  공유하면 순환 검증이 됨. [[../회차/2b-15-sliceOutline]]의 판정자 3종 병기가 이 함정 회피용.
- **ⓓ 정규화 없는 2차차분은 곡률계** — [[함정13-jitter]]의 근본 원인과 동일 계열.
- **ⓔ capsuleGap을 절대 목표로 오용** — 상대/비교 지표를 절대 문턱처럼 씀.
- **ⓕ 대역 정의의 기준 좌표계 불일치 (3회 재발)** — 대역을 몸 기준으로 잴지 옷 기준으로
  잴지가 매번 흔들림. 규범: "대역은 몸 기준, 옷 기준은 명시적 사유가 있을 때만".
