# 함정 22 — 같은 물리량을 두 계기가 다르게 판정한다

## 사례 (53회차 · 미판정)

**관통**을 재는 채널이 저장소에 둘 있고, 같은 정착 상태에서 **서로 다른 답을 낸다**.

```
국면3(`signedClearance` 기준 · 패널별 부호거리)   전 대역·전 시점 **0.0%**
게이트 채널 `관통(레이 패리티 · 비수밀 근사)`      정착 후 **50/5244**
```

전자는 패널별 부호거리, 후자는 3축 레이 패리티 근사다. **어느 쪽이 옳은지 미판정.**

## 대조 추가 (54회차 · 여전히 미판정)

D0 처방과 B@f960에서 관통이 크게 늘었을 때 **두 계기가 서로 다른 대역을 가리켰다.**

```
레이 패리티        A 50 → D0 **275** · B960 **342** (A의 5~7배)
국면3(signedClearance)  두 런 모두 **링 뒤판 11/27(40.7%)에 국한** ·
                        밑단·중배부는 0에 가깝다
```

크기만 다른 것이 아니라 **어디서 관통이 일어났다고 말하는지가 다르다.**
**판정 미해결 · 대조 재료 확보.** → [[2b-54-D0처방]]

## 종결 (55회차) — **모순이 아니라 집합 차이였다**

레이 패리티가 "관통"이라 센 정점 50건의 `signedClearance`를 직접 봤다.

```
[dress·diag] 함정22 대조 — n=3 (+ {"소매(리졸버 없음)": 47})
  d(mm) 최소 −4.9 p25 −4.9 중앙 −4.2 p99 −0.1
  **d≤0(국면3 일치) 3 · 0<d≤15(국면2) 0 · d>15(국면1) 0**
```

**몸판 3건은 국면3과 3/3 완전 일치**하고, **차이의 전부는 소매 47건**이다 —
소매는 **메시 리졸버가 null**이라(팔 캡슐만) `signedClearance` **질의 대상이 아니다**.

→ **국면3 채널은 몸판 리졸버 대역만 재고, 레이 패리티는 소매까지 센다.**
53·54회차의 "국면3 0.0% vs 레이 패리티 50/5244"는 **집합 차이**였다.
**어느 한쪽이 틀린 것이 아니다 — 정의역이 다르다.** **판정 종결.**
→ [[../회차/2b-55-겸직분해]] §1

## 두 번째 사례 (62 · 63회차) — 소매 채널 엇갈림


## **재개방 (66회차) — 해소 취소. 현재 상태 = 미판정**

**64회차 해소를 취소한다. 원문은 위에 남긴다(취소선).**

근거: 해소의 **유일한 근거가 화면**이었는데, 66회차가 65회차 판별자 4장
(같은 cuff 프리셋 · A/S3 × 일반/clean)을 대조해 그 겨드랑이 세로 띠를
**③ 렌더 몫(δ② 브리지 띠 + δ③ 시접 슬릿 배경 투과)으로 확정**했다.

```
① 띠가 **clean-cuff에서 소멸**한다 — 정점 위치 동일이므로 차이는 렌더뿐
② **A-cuff에도 같은 자리에 있다** → S3가 만든 것이 아니다
③ 두 clean 이미지의 물리 형상이 **사실상 구별 불가** → 화면은 판정자가 못 된다
```

**현재 상태**

```
자기교차 소매 관여 114→10  개선 (실측)
관통 소매분        47→55   악화 (실측)
방향              **여전히 반대**
화면              **둘 중 어느 쪽도 지지하지 못한다**
판정              **미판정 · 재개방**
```

이 함정의 형태로도 **첫 사례(정의역 차이)와 다르다** — 여기서는 정의역이 아니라
**판정자가 없다**. → [[../회차/2b-66-화면판정확정]] §4 · §6

## 규범

**게이트에 올릴 채널을 고르기 전에 두 계기의 불일치를 먼저 해소한다.**
불일치가 남아 있는 동안 어느 쪽 숫자도 통과/실패의 근거로 쓰지 않는다.
(Stage 2b 로드맵에 이미 등재된 "`자기교차` 채널명 정정" 예고와 같은 계열이다.)
