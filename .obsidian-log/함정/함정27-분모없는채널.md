# 함정 27 — 분모 없는 채널: 셈만 있으면 **불변과 포화가 구별되지 않는다**

**정의**: 채널이 **분자(셈)만** 산출하고 **표본 수(분모)** 를 산출하지 않으면,
그 채널의 값이 시간·구성에 따라 안 움직일 때 **「대상이 변하지 않았다(불변)」와
「창이 다 차서 더 셀 자리가 없다(포화)」를 원리적으로 구별할 수 없다.**
성격은 **arity 미달** — 2-튜플이어야 할 채널이 1-튜플이다.

## 사례 — 삼각근 패치창 (83회차 판정 → 84회차 수리·재판정)

83회차 §2가 표적 ①(후면 삼각근 패치)의 **층위**를 4점(`SECONDS=2|3|4` + 완주 =
f=120/180/240/260)으로 판별했다. 원 채널(old)이 **26 · 26 · 26 · 26**이었고
「**불변** = 최초 관측점부터 이미 열려 있다」 → **갈래 ㄱ(패턴 층위)** 로 판정했다.

```
83회차 채널   노출 **건수**만 센다(26 · 23 · 24 …)
빠진 것       그 창의 **표본 수(분모)** — 26이 창의 몇 %인지 말할 수 없다
결과          「불변」인지 「26이 창 전체 = 포화」인지 **판별 수단이 없다.**
             포화였다면 「최초 관측점부터 열려 있다」의 근거가 다른 뜻이 된다
```

83회차 노트 §7-1이 **스스로** 이 결함을 「arity 미달 · 다음 회차 수리 대상」으로 등재했고,
전략 세션이 「갈래 ㄱ 확정은 **분모 측정을 선결로 한다**」고 지적했다. **그 지적이 옳았다.**

**84회차 실측** — 채널을 2-튜플(노출/표본)로 고쳤다:

```
분모 = **48** (좌 24 / 우 24) · 3열(old/new/truth) · 4점 **전부 동일**
old  **26/48 = 54.2%** · 4점 불변      → **갈래 ㄱ′ = 83회차 갈래 ㄱ 확정**
```

**「포화」 가설은 반증됐다** — 26은 상한이 아니고 **창의 절반이 덮여 있다.**
결론(패턴 층위)은 유지됐지만, **유지된다는 것을 84회차 전에는 말할 수 없었다.**

## 규범

```
① 노출·위반·히트 **건수 채널은 반드시 (분자, 분모) 2-튜플**로 낸다.
   분모가 없으면 판정에 쓰지 않는다
② 분모는 **표본을 다시 세지 않고 계기 산출물에서 직접 뜬다** — [[함정12-계기하드코딩]].
   84회차 도출: `computeBodyCoverage` 루프에 `continue` 0건 →
   매 샘플이 `hits`(피복) 또는 `exposedExamples`(노출)에 정확히 한 번 들어간다 →
   합집합 = 표본 전량 → 분모 = `patch(hits) + patch(exposedExamples)`
③ 「불변」을 판정 근거로 쓰기 전에 **그 채널이 상한에 눌려 있지 않은지** 분모로 확인한다
```

## 구별 대상 (84회차 §5-4 자체 판정 — 왜 기존 함정에 안 붙였는가)

```
[[../원리/하드클램프-천장]]   이 원리는 하드 클램프가 **실재할 때** 「관측값은 평형이 아니라 천장」이고
                          규범은 「클램프가 걸려 있는지 **코드에서 확인**」이다.
                          84회차 실측은 **클램프가 아니었다**(54.2%) — 사례로 올리면 **거짓 사례**다.
                          이 함정은 그 앞 단계다: **천장인지 아닌지를 물을 수단 자체가 없는 채널**
[[함정13-jitter]]          이름과 측정 대상이 **어긋나지 않았다**(「패치창 노출 건수」는 노출 건수를 센다).
                          83회차 §7-2가 이미 같은 판정을 내렸다
[[함정18-중앙값]]           함정 18은 「**여러 통계 중 하나만** 봤다」이고 규범은 **4종 병기**(중앙값·p99·
                          maxAt·부호별 총량)다. 그런데 **넷을 다 병기해도 분모는 안 생긴다** —
                          넷 다 **같은 분자축 위의 통계**다. 함정 18을 100% 지켜도 이 결함은 남는다.
                          **가장 가까운 이웃이지만 같은 함정은 아니다**
```
