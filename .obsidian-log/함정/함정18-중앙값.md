# 함정 18 — 중앙값이 1.000이어도 꼬리가 결함일 수 있다

## 사례
32회차의 사전 등록 둘째 갈래는 "t=0이 전 대역 ~1.00이면 저장분 아님"이었다.
실측 중앙값은 **전 대역 정확히 1.000**이었다. 그 문장만 보면 참이다.

그런데 같은 대역의 p99가 11~20배, 최대가 **30.07배**였고 신장총이 앞판에서만
**2451cm** 쌓여 있었다. 결함은 중앙값이 아니라 **꼬리 전체**에 있었다.
중앙값 하나로 판정했다면 배치를 무죄로 놓고 엉뚱한 층위를 팠을 것이다.

## 규범
**대역 요약에 중앙값 단독 금지.** 최소 4종을 병기한다:
```
중앙값 · p99 · maxAt(어느 정점인가) · 부호별 총량(압축 총 cm / 신장 총 cm)
```
특히 **부호별 총량**이 중요하다 — 비율 분포는 국소 결함을 희석하지만 총량은
누적되므로 "얼마나 저장돼 있는가"를 직접 준다.

[[함정16-수치근접]]이 "일치하는 숫자를 기전으로 승격"이라면 이건 **"대표값을
분포로 승격"**이다. 둘 다 요약 통계를 실재로 착각하는 계열이다.
→ [[2b-32-t0정합지도]]

## 사례 추가 — **등가반경 한 값으로 캡슐과 실제 팔을 대조했다** (87회차 · 자체 판정)

87회차는 팔 충돌 캡슐(유효 반경 **5.16cm · s 무관 상수**)과 실제 팔 단면의
**등가반경(둘레/2π)** 을 맞대 **+0.38 ~ +0.67cm 여유**를 냈다. 그 한 값만 보면
「캡슐이 팔보다 크다」로 끝난다. **같은 단면의 방향 분포는 정반대를 말한다.**

```
등가반경(대표값)   4.78 / 4.56 / 4.49cm        →  차 **+0.38 ~ +0.67cm** = 여유
방향별 반경        min 3.58~3.99 · max 5.42~5.76 · 비원형도 **1.44~1.52**
캡슐 밖 둘레       **11.3 ~ 21.3%**            →  그 대역에서는 **부호가 뒤집힌다**
최대 돌출          **+0.26 ~ +0.74cm**
```

**32회차 사례와 같은 구조**다 — 그때는 중앙값 1.000 뒤에 p99 11~20배·최대 30.07배가
숨어 있었고, 이번에는 등가반경 하나 뒤에 **둘레의 1/5이 캡슐 밖**인 것이 숨어 있었다.
등가반경은 **둘레라는 적분량에서 역산한 스칼라**이고 중앙값과 같은 지위의 **대표값**이다.

**구별 대상**(87회차 §9-1 대조):

```
[[함정13-jitter]]        **계열만.** 「등가반경」이라는 이름은 **정확히 둘레/2π를 계산**한다
                       (이름 ≠ 미계산량). 다만 그 값을 「팔 반경」으로 부르며 등방 상수와
                       맞대는 순간 이름이 **방향별 반경**을 주장하게 되므로 규범 6에 닿는다.
                       별개 사안: `ARM_COLLISION_RADIUS`가 **s≈13cm 대역 · 평균-of-rays**로
                       잰 값인데 **s 3~8.6cm**에 쓰인다(규범 6 「집합」 — 87 §5-5 등재만)
[[함정27-분모없는채널]]   **아니다.** arity 미달이 아니다 — 등가반경은 분자/분모 구조를 갖지 않고
                       이번 결함은 **분포의 소실**이다. 함정 27이 함정 18을 가른 근거
                       (「4종을 병기해도 분모는 안 생긴다」)의 **반대 방향**이다 —
                       **병기를 하면 보인다**
[[함정16-수치근접]]      **아니다.** 값이 근접해 기전으로 승격한 것이 아니라
                       **값 하나가 분포를 대신했다**
```

**규범 확장 — 적용 대상을 「대역」에서 「방향(공간) 분포」로 넓힌다**:

```
대표값 단독 금지는 표본 대역뿐 아니라 **한 단면의 방향 분포**에도 적용된다.
둘레·면적처럼 **적분에서 역산한 스칼라**(등가반경 = 둘레/2π 등)는 대표값이며,
그것으로 **다른 대표값**(캡슐 반경 같은 등방 상수)과 대조하면
**부호가 방향에 따라 갈리는 것을 원리적으로 못 본다.**
→ 등가 스칼라로 기하를 대조할 때는
  **(대표값, min~max, 비원형도, 기준면 밖 비율, 최대 돌출)** 을 함께 낸다.
  **밖 비율이 0이 아니면 「여유가 있다」로 읽지 않는다.**
```

87회차는 이 병기 채널(캡슐 밖 둘레 % · 최대 돌출)을 **같은 회차에 만들어** 판정 옆에 세웠다.
→ [[../회차/2b-87-팔캡슐기하]] §6-2 · §9

### 88회차 후속 실증 — **부호가 실제로 뒤집혔고, 병기 4종으로도 부족했다** (자체 판정)

88회차가 **패치창이 실제로 있는 방향**(노출 θ 대역 · 팔 후면 |θ| 114~173°)에서 같은 차를
다시 쟀다. 87이 「어딘가에서 부호가 뒤집힌다」로 등재한 것이 **그 방향에서 실측됐다.**

```
87 등가반경 대조(방향평균)     +0.38 / +0.60 / +0.67cm            (s=4/6/8)
88 노출 θ 대역 대조(방향 특정) −0.11 / +0.13 / +0.47cm (좌) · −0.22 / +0.04 / +0.40cm (우)
s=4에서 **부호가 음수** = 패치창 방향에서는 **실제 팔이 캡슐보다 굵다**(캡슐이 **과소**)
판정      87 **갈래 B**(부분 기여) ↔ 88 **갈래 C**(기여 하향) — **대표값이 갈래를 바꿨다**
```

**87 사례와 중복이 아니다**: 87이 등재한 것은 「**분포가 소실된다**」(정적 관찰)이고
88이 낸 것은 「**그 소실이 판정 갈래를 바꾼다**」(부호 반전 실증)다.
**별건도 아니다** — 대상(등가반경이라는 대표값으로 등방 상수와 대조)이 **같다**.
그래서 **새 사례 항목을 세우지 않고 이 사례에 붙인다**(같은 대상의 사례가 둘로 갈리면
병기 규범이 두 군데에서 각각 자란다 — 80·85·86·87회차가 [[함정13-jitter]]에 대해 같은
근거로 네 번 판단했다).

**규범 확장 2 — 병기(분포 요약)도 방향과 결합되지 않으면 판정 채널이 아니다**

```
87이 세운 병기   (대표값, min~max, 비원형도, 기준면 밖 비율, 최대 돌출)
88이 보인 한계   그 병기는 전부 **방향 무관 분포 요약**이다 —
                「**어딘가에서** 밖이다」는 말하지만
                「**표적이 있는 그 방향에서** 밖인가」는 **원리적으로 못 말한다**.
                실제로 87은 「밖 11~21%」를 등재하고도 판정은 **여유(+0.38)** 로 냈다
규범            **표적 대역이 방향(또는 위치)으로 특정돼 있으면 분포 요약으로 대신하지 않는다 —
                그 방향에서 직접 잰다.** 대표값도, 병기한 분포 요약도,
                **관심 대역과 결합되지 않으면 판정 채널이 아니다.**
```

→ [[../회차/2b-88-방향반경과BVH]] §4-6 · §10-1

### 92회차 후속 — **처방 층위에서 막혔다: 스칼라 프리미티브에는 방향 분포를 담을 자리가 없다** (자체 판정)

87·88 사례는 **계기·대조 층위**였다(대표값이 분포를 지웠다 / 그 소실이 판정 갈래를 바꿨다).
92회차는 같은 대상이 **처방 층위**로 내려온 것이고, **선택 자체가 불가능**했다.

```
처방 후보 1  방향별 max   유효반경 = 실측 max 5.76 + margin 0.60 = **6.36cm**
                        vs 소매 S0 배치 원통 반경 **5.73cm** → **캡슐이 소매보다 크다**
                        (첫 프레임부터 소매 전 정점이 바깥으로 밀린다)
처방 후보 2  등가반경     87 §6-2의 **후면 돌출 +0.74cm가 여전히 캡슐 밖** →
                        **표적 방향에 처방이 안 닿는다**(88 규범 확장 2에 정면으로 걸린다)
제3안       비원형       `torsoCapsule.ts`의 `applyCapsuleCollision`이
                        `const r = capsule.radius + margin;` **스칼라 하나**로 판정한다 —
                        **방향별 반경을 받을 자리가 시그니처에 없다**
산술(등재값에서 도출)     r + 0.60 ≤ 5.73 → r ≤ **5.13cm**  ∧  r ≥ 방향별 max **5.76cm**
                        → **해가 없다.** 스칼라 하나로 두 조건을 동시에 만족할 수 없다
```

**88 규범 확장 2의 «처방 판»이다** — 88은 「표적 방향에서 **직접 재라**」는 규범을 세웠는데,
그 규범을 **처방으로 옮길 자리가 물리 프리미티브에 없다.** 즉 이 캠페인에서 대표값 문제는
계기를 고쳐서 끝나지 않고 **프리미티브의 자유도**로 이어진다.

**새 사례 항목을 세우지 않고 87·88 사례에 붙인다** — 대상(등방 스칼라 반경으로 비원형 단면을
대신한다)이 **같다**(87→88이 같은 근거로 하나로 유지한 전례).

**함정 27 아님**: arity(분자/분모)가 아니라 **자유도**(스칼라 1 vs 방향 함수)다.
**함정 13 아님**: 등가반경도 방향별 max도 **이름 그대로의 양**을 정확히 낸다.
→ [[../회차/2b-92-캡슐테이퍼]] §4-2 · §9-1
