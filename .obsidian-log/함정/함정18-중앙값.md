# 함정 18 — 중앙값이 1.000이어도 꼬리가 결함일 수 있다

## 사례
32회차의 사전 등록 둘째 갈래는 "t=0이 전 대역 ~1.00이면 저장분 아님"이었다.
실측 중앙값은 **전 대역 정확히 1.000**이었다. 그 문장만 보면 참이다.

그런데 같은 대역의 p99가 11~20배, 최대가 **30.07배**였고 신장총이 앞판에서만
**2451cm** 쌓여 있었다. 결함은 중앙값이 아니라 **꼬리 전체**에 있었다.
중앙값 하나로 판정했다면 배치를 무죄로 놓고 엉뚱한 층위를 팠을 것이다.

## 규범
**대역 요약에 중앙값 단독 금지.** 최소 4종을 병기한다:
```
중앙값 · p99 · maxAt(어느 정점인가) · 부호별 총량(압축 총 cm / 신장 총 cm)
```
특히 **부호별 총량**이 중요하다 — 비율 분포는 국소 결함을 희석하지만 총량은
누적되므로 "얼마나 저장돼 있는가"를 직접 준다.

[[함정16-수치근접]]이 "일치하는 숫자를 기전으로 승격"이라면 이건 **"대표값을
분포로 승격"**이다. 둘 다 요약 통계를 실재로 착각하는 계열이다.
→ [[2b-32-t0정합지도]]

## 사례 추가 — **등가반경 한 값으로 캡슐과 실제 팔을 대조했다** (87회차 · 자체 판정)

87회차는 팔 충돌 캡슐(유효 반경 **5.16cm · s 무관 상수**)과 실제 팔 단면의
**등가반경(둘레/2π)** 을 맞대 **+0.38 ~ +0.67cm 여유**를 냈다. 그 한 값만 보면
「캡슐이 팔보다 크다」로 끝난다. **같은 단면의 방향 분포는 정반대를 말한다.**

```
등가반경(대표값)   4.78 / 4.56 / 4.49cm        →  차 **+0.38 ~ +0.67cm** = 여유
방향별 반경        min 3.58~3.99 · max 5.42~5.76 · 비원형도 **1.44~1.52**
캡슐 밖 둘레       **11.3 ~ 21.3%**            →  그 대역에서는 **부호가 뒤집힌다**
최대 돌출          **+0.26 ~ +0.74cm**
```

**32회차 사례와 같은 구조**다 — 그때는 중앙값 1.000 뒤에 p99 11~20배·최대 30.07배가
숨어 있었고, 이번에는 등가반경 하나 뒤에 **둘레의 1/5이 캡슐 밖**인 것이 숨어 있었다.
등가반경은 **둘레라는 적분량에서 역산한 스칼라**이고 중앙값과 같은 지위의 **대표값**이다.

**구별 대상**(87회차 §9-1 대조):

```
[[함정13-jitter]]        **계열만.** 「등가반경」이라는 이름은 **정확히 둘레/2π를 계산**한다
                       (이름 ≠ 미계산량). 다만 그 값을 「팔 반경」으로 부르며 등방 상수와
                       맞대는 순간 이름이 **방향별 반경**을 주장하게 되므로 규범 6에 닿는다.
                       별개 사안: `ARM_COLLISION_RADIUS`가 **s≈13cm 대역 · 평균-of-rays**로
                       잰 값인데 **s 3~8.6cm**에 쓰인다(규범 6 「집합」 — 87 §5-5 등재만)
[[함정27-분모없는채널]]   **아니다.** arity 미달이 아니다 — 등가반경은 분자/분모 구조를 갖지 않고
                       이번 결함은 **분포의 소실**이다. 함정 27이 함정 18을 가른 근거
                       (「4종을 병기해도 분모는 안 생긴다」)의 **반대 방향**이다 —
                       **병기를 하면 보인다**
[[함정16-수치근접]]      **아니다.** 값이 근접해 기전으로 승격한 것이 아니라
                       **값 하나가 분포를 대신했다**
```

**규범 확장 — 적용 대상을 「대역」에서 「방향(공간) 분포」로 넓힌다**:

```
대표값 단독 금지는 표본 대역뿐 아니라 **한 단면의 방향 분포**에도 적용된다.
둘레·면적처럼 **적분에서 역산한 스칼라**(등가반경 = 둘레/2π 등)는 대표값이며,
그것으로 **다른 대표값**(캡슐 반경 같은 등방 상수)과 대조하면
**부호가 방향에 따라 갈리는 것을 원리적으로 못 본다.**
→ 등가 스칼라로 기하를 대조할 때는
  **(대표값, min~max, 비원형도, 기준면 밖 비율, 최대 돌출)** 을 함께 낸다.
  **밖 비율이 0이 아니면 「여유가 있다」로 읽지 않는다.**
```

87회차는 이 병기 채널(캡슐 밖 둘레 % · 최대 돌출)을 **같은 회차에 만들어** 판정 옆에 세웠다.
→ [[../회차/2b-87-팔캡슐기하]] §6-2 · §9
