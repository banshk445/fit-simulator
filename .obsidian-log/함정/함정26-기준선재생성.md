# 함정 26 — **기준선을 값으로만 들고 다녔다**. 재생성해 보지 않았고, 재생성에 필요한 것도 적지 않았다

기준선은 **숫자 목록이 아니라 재생산 절차**다. 숫자만 노트에 옮겨 적고 **한 번도 다시
내보지 않으면**, 그 숫자가 여전히 나오는지 아무도 모른 채 회차가 쌓인다. 그리고
차이가 드러난 날, **원인을 반증할 기록이 없다.**

## 사례 (81회차) — 캠페인 기준선 A가 오늘 재현되지 않는다

`v2-2b-78-baseline`(9fbd66c)은 **태그로 고정**돼 있었고 태그 메시지에 patternHash ·
fixture · dress-state md5 · A 17채널 전량이 적혀 있었다. 그런데 **그 태그를 임시
워크트리로 체크아웃해 그대로 실행하니 값이 다르게 나왔다.**

```
채널        등재 기준선 → 오늘 태그 실행
cov 몸통     118 → **119**
covShoulder  637 → **632**
자기교차     1889 → **1917**
maxStrain    2.661 → **2.463**   (argmax 2146은 동일)
관통②        50 → **51**
dress-state md5  14e50b89… → **a20ff9e3…**
```

**오늘 안에서는 완전 결정적이다**(3회 연속 바이트 동일). 즉 비결정성이 아니라
**오늘과 과거 사이의 차이**다.

### 반쪽 ① — **아무도 다시 내보지 않았다**

60 · 71 · 75 · 78 · 80회차가 「**A 17채널 비트 대조 전부 불변**」을 반복 등재했다.
그 다섯 회차의 실행은 **각자 그 시점의 값끼리 비교한 항등 비교**였고, **등재된 기준선
숫자와 대조한 것이 아니었다.** 그래서 값이 언제 옮겨갔는지 구간을 못 좁힌다.

```
주장 형태   "이번 실행이 기준선과 비트 동일하다"
실제 형태   "이번 실행의 전/후가 서로 비트 동일하다"
→ 둘은 다르다. 앞의 문장으로 적히면 **기준선이 검증됐다고 읽힌다**
```

### 반쪽 ② — **다시 내는 데 필요한 것을 안 적었다**

원인 격리에서 코드 · 입력 · 비결정성 · 의존성은 전부 배제됐고 **런타임(V8)만 남았다.**
그런데 **이전 회차 기록 어디에도 node 버전이 없다** → 그 후보를 지지도 반증도 못 한다.
**원인 미확정으로 정지**했다.

## [[함정08-fixture표류]]와 갈리는 지점 — **그 처방을 지켰는데도 발생했다**

함정 8의 처방은 「**커밋 고정 + 절대값에 프레임 수 · fixture 해시 병기**」다.
81회차 시점에 그것은 **전부 이행돼 있었다**(태그 · 해시 3종 · 프레임 600 · fixture 해시).

```
고정된 범위   저장소 **안** — 코드 · fixture · 패턴 메타
안 고정된 것   저장소 **밖** — 런타임 · OS · 툴체인
```

**함정 8은 입력이 조용히 바뀌는 것이고, 이것은 입력이 고정돼 있는데도 산출이 바뀌는 것이다.**

## 규범

- **기준선은 절차다.** 등재할 때 **재생성 명령 한 줄**을 값과 함께 적는다.
- **「기준선과 비트 동일」을 적으려면 기준선을 그 회차에 실제로 다시 내야 한다.**
  전/후 항등 비교만 했으면 **그렇게 적는다** — 두 문장은 다르다.
- **해시는 파일 상태가 아니라 재생성해서 대조한다**(→ [[../규칙/기점대조]]).
  파일 비교로 일치하는 해시와, 재실행해야 비교가 성립하는 해시를 섞어 놓으면
  **후자를 안 돌리고 「3종 동일」로 통과**한다. 81회차가 그 직전까지 갔다.
- **환경을 기록한다** — 최소한 `node --version`. 산출이 바뀐 날 **반증할 수 있는 유일한
  기록**이고, 없으면 원인 격리가 「후보만 남고 미확정」에서 끝난다.
- 재현이 깨지면 **그 자리에서 정지한다.** 흔들린 기준선 위의 추가 측정은 대조 기반이
  없고, 그때 나온 부호 역전은 **처방의 효과와 분리되지 않는다**(81회차 §4-6 —
  역전 4건을 **등재만** 하고 갈래 판정에 쓰지 않았다).
