## 결정적인 것 (블록 전재)

```
· 밑단 정의역은 **이미 코드에 있다**(dressPattern.ts:1675-1676, pos2 패턴 y 술어).
  두 번째 정의를 만들지 말 것. 단 문턱 1cm는 정련 최소 이격 11.2mm와 여유 1.2mm뿐 →
  엄격 술어와 **두 집합 개수를 병기**할 것
· 밑단은 패턴에서 직선이라 **패턴 x 정렬 = 호장 순서**(necklineRing의 곡선 문제 없음).
  대신 **미러 반쪽**·**segmentVerts 미노출**·**폐곡선 = 사슬 2개 + 접합 2구간** 회계
· "요동"을 **축 기준 반경으로 재면 35회차 실패가 재발한다** — 밑단 높이의 몸 단면은
  원이 아니고 가랑이 아래에선 **닫힌 곡선조차 아니다**. 기준선은 **사슬 자신의 저역통과**
  (고정 호장 창 · 창 2값 병기)
· **파장당 표본 < 4면 숫자를 쓰지 말고 산출 불가**(Nyquist 32mm)
· **f1이 필수** — 면내 압축의 **89~102%가 f1 한 프레임**에 생긴다
  (f0 앞0.0/뒤0.0 → f1 앞1669.6/뒤1790.5cm)
· 합성 주입 자기검사 1개(λ=8cm·A=1cm 사인파를 넣고 되돌아오는지)
```

## 강조 (프롬프트 지정)

1. **밑단 정의역 중복 정의 금지** — 코드에 이미 있다(`dressPattern.ts:1675-1676`).
2. **축 기준 반경 금지** — 쓰면 35회차 실패가 재발한다([[2b-35-흡착국소화]]).
3. **f1 필수** — 면내 압축의 89~102%가 f1 한 프레임이다. f8·정착만 재면 대상이 없다.
4. **파장당 표본 < 4 → 산출 불가로 보고**(추정치로 채우지 않는다).
5. **합성 주입 자기검사 1개**를 계기에 붙인다.

## 선행 조건 — **밑단 계열 처방은 계기를 먼저 살려야 한다** (59회차, 2026-08-05)

· **밑단 기하를 건드리는 처방을 등록하기 전에 술어 갱신을 같은 회차 범위에 넣는다**
