## 승격 — **소매는 `cuff` + `clean-cuff` 쌍이 필수다** (65회차)

소매를 판정할 때 두 장을 **같은 프리셋으로 함께** 찍는다.
근거: 클린 렌더가 **시접 브리지를 감추므로**, `clean-cuff`는
**시접 슬릿 배경 투과(δ③)와 실제 관통을 가르는 유일한 화면 판별자**다.
겨드랑이에서는 그 틈 뒤 배경이 **몸**이라 흰색이 아니라 **회색**으로 보이고,
`FitCanvas.tsx:114`가 `<Mannequin/>`을 **항상** 마운트하므로
**"몸이 보인다"만으로는 ①관통 · ③슬릿을 못 가른다**(64 §6).
→ [[../회차/2b-65-겨드랑이판별자]] §3 · [[../함정/함정21-렌더몫미분리]]

## 규범 추가 (66회차) — **국소 결함을 물리로 귀속하기 전에 clean 렌더 쌍을 먼저 본다**

65회차의 필수 뷰 승격 위에 얹는다. **뷰를 찍는 규칙이 아니라 귀속 순서의 규칙**이다.

```
1. 국소 결함을 본다
2. **같은 프리셋의 clean 판본을 먼저 본다** (가능하면 대조군까지 4장)
3. clean에서 사라지면 **렌더 몫** — 물리 표적으로 승격하지 않는다
4. clean에도 남으면 물리 몫 — 그때 승격한다
```

근거: 66회차가 겨드랑이 세로 띠를 **③(δ②+δ③) = 렌더 몫**으로 확정했다.
그 회색을 물리(관통)로 읽고 **소매 접촉 축을 61~64회차에 걸쳐 굴렸다**.
**48회차 옆선에 이은 두 번째 재발**이고, 재발 원인은 도구 부재가 아니라
**48회차에 이미 있던 `?cleanrender=1`을 안 쓴 것**이다.
→ [[../회차/2b-66-화면판정확정]] §5 · [[../함정/함정21-렌더몫미분리]] 사례 2

## 규범 추가 (69회차) — **원경/근경 프리셋을 가로질러 크기를 비교하지 않는다**

64회차의 「원경으로 국소를 **판정**하지 않는다」의 **크기 판정판**이다.
서로 다른 프리셋의 두 장에서 잰 길이·격자 칸을 **직접 비교하지 않는다.**
비교는 **한 장 안에서** 하고, 화면 배율이 다르면 **먼저 배율을 나눈다.**

```
front  거리 3.015m · fov 45  → 화면 세로 **2.498m**
cuff   거리 0.759m · fov 30  → 화면 세로 **0.407m**
                              → 같은 칸이 cuff에서 **6.14배** 크게 찍힌다
```

근거(69회차 실측): 「소매 UV 축척이 몸판과 다르다」는 **`img-cuff`와 `img-front`를
가로질러** 낸 판정이었다. **UV 축척은 4패널 전부 동일**(du/w = 0.01429/cm)하고,
같은 장 안에서 재면 1.2~1.3배인데 그중 팔 축 31.0° 경사가 1.167배 —
**남는 UV 몫은 6.5%뿐**이다. → **계기 차를 대상에 귀속한 것**([[../함정/함정19-계기가다른대상]]).

**같은 회차의 두 번째 오독**: `img-cuff` 겨드랑이의 검정 쐐기를 「미덮개 코너」로 읽었는데
그것은 **테스트 이미지의 화살표**였다(소매 UV 상자가 원본 좌상 사분면 + 화살표 왼쪽 날개).
→ **테스트 텍스처로 찍은 화면은 UV 상자를 먼저 확인하고 읽는다.**
→ [[../회차/2b-69-UV아틀라스반증]] §5 (**전략 세션 정정 21건째**)

## 프리셋 신설 3종 (91회차) — **기존 키는 한 값도 안 바꿨다**

```
sideXplus   pos [ 3, 1.3, 0]     target [0, 1.20, 0]  fov 45
sideXminus  pos [−3, 1.3, 0]     target [0, 1.20, 0]  fov 45
quarterBack pos [2.0, 1.6, −2.0] target [0, 1.25, 0]  fov 40
※ 이름의 좌/우는 **카메라가 선 쪽의 x 부호**다(88~90의 「좌(+x)/우(−x)」와 같은 규약 ·
  **해부학 좌우가 아니다**)
```

**27회차 프리셋 유지 조항에 걸리지 않는 근거**: 그 조항은 「**구도가 달라지면 회차 간 대조가
끊긴다**」이고 대상은 **기존 키의 값 변경**이다. 이번은 **신규 키 3개 추가**이고
`front/back/neck/cuff/hem/neckback` **6키는 비트 불변** →
**과거 회차와의 대조가 끊기지 않는다.** (**신규 키 추가 ≠ 기존 키 변경**)

산출물 `docs/captures/2b-91-전역/`(664×930 · 뷰포트만 · `?autofit=ff00c8`) ·
**4장 md5 전부 상이** = 프리셋이 실제로 다른 시점을 찍었다. **화면 판정 0 · 자체 선언 0.**
→ [[../회차/2b-91-전역간극]] §8

## 프리셋 변경

프리셋을 바꿔야 하면 **바꾼 회차를 노트에 남긴다**(CLAUDE.md §화면).
구도가 달라지면 회차 간 대조가 끊긴다 — cuff target 오조준으로 **25 · 26회차 V3가
무효**였다. 같은 이유로 **45회차 off cuff와 63회차 S3 cuff는 프레이밍이 달라
A/B 대조가 아니다**(64 §6).
