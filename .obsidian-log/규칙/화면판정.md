# 화면 판정 — 뷰별 정본 · **원경으로 국소를 판정하지 않는다**

> **이것은 26 → 27회차에 이미 한 번 겪은 실패다.**
> `FitCanvas.tsx:74-77`의 27회차 정정 주석이 그대로 적고 있다:
> 「기존 cuff는 target이 몸통 중심(0,1.15,0)이라 **몸통 원경**이 잡혔다
> (**26회차 캡처가 그래서 V3 판정 불가였다**)」.
> **64회차 §7④의 전략 세션 정정 19건째는 그 재발이다** — 원경 3장만 보고 V3를
> 상향("소매가 팔에 붙었다")했다가 **cuff 클로즈업이 반증**했다.
> → [[../회차/2b-64-S2프라임반증]] · [[../함정/함정19-계기가다른대상]]

## 뷰별 정본

```
소매    **cuff + clean-cuff (쌍 · 65회차 승격)**
밑단    **hem**
목선    **neck**
실루엣  **front / back**
```

**원경 뷰로 국소 항목을 판정하지 않는다.**

## 승격 — **소매는 `cuff` + `clean-cuff` 쌍이 필수다** (65회차)

소매를 판정할 때 두 장을 **같은 프리셋으로 함께** 찍는다.
근거: 클린 렌더가 **시접 브리지를 감추므로**, `clean-cuff`는
**시접 슬릿 배경 투과(δ③)와 실제 관통을 가르는 유일한 화면 판별자**다.
겨드랑이에서는 그 틈 뒤 배경이 **몸**이라 흰색이 아니라 **회색**으로 보이고,
`FitCanvas.tsx:114`가 `<Mannequin/>`을 **항상** 마운트하므로
**"몸이 보인다"만으로는 ①관통 · ③슬릿을 못 가른다**(64 §6).
→ [[../회차/2b-65-겨드랑이판별자]] §3 · [[../함정/함정21-렌더몫미분리]]

## 규범 추가 (66회차) — **국소 결함을 물리로 귀속하기 전에 clean 렌더 쌍을 먼저 본다**

65회차의 필수 뷰 승격 위에 얹는다. **뷰를 찍는 규칙이 아니라 귀속 순서의 규칙**이다.

```
1. 국소 결함을 본다
2. **같은 프리셋의 clean 판본을 먼저 본다** (가능하면 대조군까지 4장)
3. clean에서 사라지면 **렌더 몫** — 물리 표적으로 승격하지 않는다
4. clean에도 남으면 물리 몫 — 그때 승격한다
```

근거: 66회차가 겨드랑이 세로 띠를 **③(δ②+δ③) = 렌더 몫**으로 확정했다.
그 회색을 물리(관통)로 읽고 **소매 접촉 축을 61~64회차에 걸쳐 굴렸다**.
**48회차 옆선에 이은 두 번째 재발**이고, 재발 원인은 도구 부재가 아니라
**48회차에 이미 있던 `?cleanrender=1`을 안 쓴 것**이다.
→ [[../회차/2b-66-화면판정확정]] §5 · [[../함정/함정21-렌더몫미분리]] 사례 2

## 근거 (코드에서 뜬 것 — `FitCanvas.tsx:69-80` `CAPTURE_VIEWS`)

```
front  pos [0, 1.3,  3]   target [0, 1.00, 0]   fov 기본(45)   → **원경 3m**
back   pos [0, 1.3, −3]   target [0, 1.00, 0]   fov 기본(45)   → **원경 3m**
neck   pos [0, 1.5,  1.0] target [0, 1.38, 0]   fov 35
cuff   pos [0.30, 1.30, 0.75] target [0.27, 1.20, 0] fov **30** → **팔 축 직조준**
hem    pos [0, 0.95, 1.5] target [0, 0.82, 0]   fov 35
```

`cuff`만이 오른팔 커프 근방을 직접 겨눈다. **front/back은 3m 원경**이고
소매 국소 결함(들뜸 · 잔주름 · 관통)의 판정 대상이 아니다.

## 클린 렌더는 **판별자**다

```
?cleanrender=1  → **시접 브리지를 감춘다**(48 · 49회차 δ 분리)
```

따라서 **시접 슬릿의 배경 투과(δ③)와 실제 관통을 가르는 직접 판별자**다.
**국소 뷰의 클린 판본을 함께 찍는다.**

## 프리셋 변경

프리셋을 바꿔야 하면 **바꾼 회차를 노트에 남긴다**(CLAUDE.md §화면).
구도가 달라지면 회차 간 대조가 끊긴다 — cuff target 오조준으로 **25 · 26회차 V3가
무효**였다. 같은 이유로 **45회차 off cuff와 63회차 S3 cuff는 프레이밍이 달라
A/B 대조가 아니다**(64 §6).
