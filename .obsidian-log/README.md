# fit-simulator 개발 로그 볼트

옵시디언으로 여는 fit-simulator 2b 캠페인 로그. 지금까지의 대화(1~15회차)를 정리해 채웠다.

## 폴더 구조
- `00-현재상태.md` — 지금 이 순간의 스냅샷. **매 회차 끝나면 이것부터 갱신.**
- `회차/` — 회차별 노트. 각 노트는 변경/검증/결과/국소화/판정/다음수 구조.
- `함정/` — 재발 방지 함정 목록. README의 함정 목록과 대응.
- `원리/` — 여러 회차에 걸쳐 반복 검증된 원리 (예: "몸에서 가져와라").
- `규칙/` — 세션 관리 등 운영 규칙.
- `_templates/` — Templater 플러그인용 회차 노트 템플릿.

## Claude Code와 연동하는 법

### 방법 1 — 이 폴더를 저장소 안에 두기 (권장)
```
fit-simulator/
├── src/
├── docs/
└── .obsidian-log/     ← 이 볼트를 여기에 압축 해제
```
이러면 개발 CC 세션이 `.obsidian-log/회차/2b-16-xxx.md`를 직접 읽고 쓸 수 있다.
옵시디언 앱에서 `.obsidian-log/`를 볼트로 열면 실시간으로 보인다.

`.gitignore`에 `.obsidian-log/.obsidian/`만 추가하면 옵시디언 설정(로컬 캐시)은
커밋에서 빠지고 노트 내용(`.md`)만 버전 관리된다.

### 방법 2 — CC 프롬프트에 저장 지시 추가
매 회차 프롬프트 끝에 이런 줄을 표준으로 붙인다:

> 완료 후 `.obsidian-log/회차/2b-XX-제목.md`에 변경/검증/결과/국소화/판정을 정리해
> `_templates/회차-템플릿.md` 형식으로 저장하고, 관련 함정·원리 노트에 `[[2b-XX-제목]]`
> 백링크를 추가할 것.

이러면 텍스트 보고를 전략 채팅에 복붙하는 흐름은 그대로 두고,
부산물로 옵시디언 볼트가 자동으로 자란다.

## 추천 플러그인
- **Dataview** — frontmatter(`상태`, `층위`)로 회차 노트를 표로 쿼리
  (예: 실패한 회차만, 특정 층위만)
- **Templater** — `_templates/회차-템플릿.md`를 새 노트에 자동 삽입
- Git 동기화는 방법 1을 쓰면 저장소 git이 그대로 커버함

## 이어서 채워야 할 것
16회차(vN 호장 재정의)부터는 아직 진행 중이라 노트가 없다.
전략 채팅에서 판정이 나올 때마다 `회차/2b-16-...md` 형식으로 추가하면 된다.
