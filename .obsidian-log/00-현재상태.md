## 막고 있는 것
링은 **2.11 → 1.093배로 수렴**했고 **V1 목선 밀착이 처음 통과**했다.
그런데 자기교차가 7004 → 6414(−8.4%)로만 줄어 **"여분 천 = 자기교차" 귀속은
기각**됐다(사전 등록 규칙). 6400건은 다른 층에서 온다.
남은 화면 실패는 **V4 회색 0**(등 → **어깨 상단**으로 축소)이고, **V3 겨드랑이
들뜸과 같은 자리**다. 신규 부작용: maxStrain 6.687 → **10.691**(상한 4.2).

### 27회차 계기 결과
축소 잔여 일량이 정착까지 **36.8cm/프레임 유지** → 무언가 링을 계속 벌린다.
하중 배분 계기는 **산출 불가**(평형에서 포화). **strain 상위 11이 전부 목선 대역
안쪽** → 링을 벌리는 건 무게가 아니라 **목선 대역 천의 인장**.
**26회차 상한은 증상 상한이었다 — 여분이 둘레에서 변형률로 이동했다.**

### 30회차 진단 결과 (목선 신장의 출처)
**4.2는 제약이 아니다** — 제품 코드에 없다. CLAUDE.md 게이트 문턱(v1 기준선 3.38
+25%)이다. **진짜 집행 상한은 `limitStrain`의 하드코딩 1.2**(clampInSubstep=true,
매 서브스텝 2패스). `COLLAR_STRAIN_LIMIT` 1.02도 집행(necklineRing 62쌍).

**1급 — 집행 제약 위반**: 상한 1.2인데 최대 신장비 6.687(25회차)/10.691(26회차)
= **5.6배 / 8.9배**. 핀 면제 0개, 계기 집합 일치 확인.

**신장의 출처 = (ii) 봉합 과정**: 배치 t=0 1.000배 → f1 1.665배 → f8 2.082배 →
S1 최대 2.565배@f62 → S2·S3 합계 +0.4cm. **전량 S1**.

**중력 0 ablation = 미회수**(회수율 5.3%) → **능동 유지원 존재**. 기하 하한도
기각(링 앉은 높이 몸 단면 63.95cm vs 링 101.56 = 1.588배).
다음 표적 후보 — **자체충돌 1순위 · 흡착 접촉 2순위**. 앵커·핀·시접 스케줄 배제.

**26회차 상한은 눌러 둔 값**: 손 떼면 54.05 → 101.98로 복귀.

### 29회차 진단 결과 (계기 정합 + 링 y)
**rest 불일치 원인 확정** — 하네스 `ringRestM`이 `necklineRing` 합에 시접
2×6mm를 더했는데 `ringLenM()`은 접합을 안 센다(집합 불일치). **확정 rest 48.24cm**.
25·26·27회차 배율 전량 소급 정정: 2.114→**2.167** / 1.093→**1.120**. 집행은 무사
(절대값 비교), 보고 수치만 틀렸다. [[함정12-계기하드코딩]] 사례 추가.

**링 y 시계열 → 분기 ⓑ**: 링 둘레를 104.54→54.05로 절반 조여도 링 최상점은
**0.31cm만 움직인다**(141.55→141.24). 링 y는 둘레의 함수가 아니다 → 미끄럼 기전
배제. 목선 대역 **인장/하중 경로** 층위로 이동. 27회차 strain 지도와 정합.
`RINGTOTAL=0`이 25회차를 비트 재현.

**자유 평형 정식 채널**: 링 자유 평형 104.54cm vs 어깨 통과 둘레 107.00cm
@y137.54 단면 = **0.977배**.

**26회차 상한의 대가**: f1부터 발화해 최상점을 1.83cm 끌어내리고, 최종도 25회차보다
0.31cm 낮다. V1 실패 정정과 정합.

### 28회차 계기 결과 (경계 길이 감사)
삼각화 후 경계 실측 = 제도값(최대 편차 0.03cm) → **삼각화 무죄**. 목선 1.043배 ·
소매산 1.068배 · 밑단 1.446배로 전부 과다, 여분은 셋 다 **제도가 의도한 값**
(이즈 2.0 / 이즈 3.0 / 품 여유). 결함은 길이가 아니라 **여분을 받을 부품 부재**.
"링 1.48배"는 11·12회차 이전 폐기 수치 — 현재 링 rest/제도 = **1.00배**.
