## §0 판정 기준 — 실행 «전»에 등록

### §0-1 배경 (전략 세션 판정 수령분)

```
 v3-42 갈래 E 수령. 제3 기전(71~81%)의 명명 = **«전방 폐색»** — 근측 맨팔(주먹·팔뚝)이
 소매 밖에서 시선 축을 따라 시점에 가장 가깝고, 정사영이 그것을 어깨 위에 겹쳐 찍는다.
 back 의 2.8~6.3‰ 도 같은 족(목·승모근 ↔ 뒤판 목선 상단). 즉 **물리 결함 0 · 래스터 버그 0** ·
 M 의 정의역 한계(**#94**: 2D 실루엣은 «앞에 있는 몸»을 제외하지 못한다).
 전략 예측 2건(ㄴ 주 · back 반점 없음)이 빗나갔으므로 **이번 명명도 «가설»로 들어간다** —
 §1 이 확인하고, **반증되면 정지**한다.

 사용자 불합격의 재해석: 정당한 폐색 + 표본화 점묘 + 평면 셰이딩 각짐이 진단 래스터
 (원근 0 · 조명 0 · 2색 · 300×420)에서 «구멍»처럼 읽힌 것. ⟹ 다음 수 = **제품급 표시 층**.
```


### §0-3 ㉡ §2 제품급 표시 층 — `?v3=1` 패널의 «별도 씬»(v2 렌더러 무변경)

```
 구성 (전부 표시 전용 · 물리 0프레임 · blob 무변조)
   · **원근 카메라** — 진단 래스터의 정사영과 별개. 등재 3뷰 프리셋은 **진단용으로 무변경 유지**,
     제품 뷰는 «대응 구도» 3점으로 **명명해 신설**(`front-p` · `side-p` · `back-p`)
   · **조명** 주광 + 보조광 + 환경광 (값은 표시 층 재량 — **물리 채널 아님** · 목록화만)
   · **스무딩 셰이딩** 정점 노멀 보간 (v3-42 §4 등재: 각짐 34~36% 감소분 적용)
   · **옷 재질** 양면 + 표시 오프셋 **«불사용»** — 전방 폐색은 정당하므로 가릴 것이 없고,
     **관통 0 이 실측**됐으므로 오프셋의 근거도 없다. **쓰게 되면 그 이유를 등재**
   · **해상도** 캔버스 실제 픽셀(`devicePixelRatio` 반영)
 **#89 갱신**: 이 씬의 «렌더 기여» 목록을 같은 형식으로 **새로** 낸다(조명·톤매핑·노멀 생성 등)
```
