### §5-1 남은 한계 — **판정 뒤에 적는다**(기준 변경 0)

```
 (ㄱ) **정의역**: 이 판정은 「링이 몸에 «얹혀» 있는」 상태에서만 뜻이 있다.
      링이 몸에서 떠 있으면 `nearestBodyPoint` 투영이 안쪽으로 수축해 R 이 부풀고
      **헐렁한 목선이 실패로 읽힌다**. 이번 6개 상태는 전부 얹혀 있었다
      (몸 안쪽 정점 0 · C_ring − C_body = 0.4~7.4mm). **떠 있는 경우의 판정은 미정의**로 둔다.
 (ㄴ) **여유가 좁다**: R 이 0.988~1.001 에 몰린다. 판별폭은 사실상 **2πδ = 6.9mm**(≈1.25%)다.
      2.00mm 밀기가 R 을 0.9882 → 1.0007 로 **1.3%** 움직였다 ⟹ 문턱 근방 해상도는 있으나
      **여유는 작다**. ③a(v3-39 §4)와 같은 「통과여도 취약」 계열이다.
 (ㄷ) **2π 항등은 근사**(§1-6 (1)) — 직접 오프셋 대비 **2.66~3.67mm 후하다**.
      즉 **판정이 관대한 쪽**이다. 엄히 하려면 직접 오프셋으로 바꿔야 하고,
      그것은 **형태 변경**이라 이 판 밖이다(§0-2 가 형태를 고정했다).
```
