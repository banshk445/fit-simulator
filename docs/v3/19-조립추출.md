### ㉣ 검증 비용 — **N을 «지금» 도출한다**

**전량 정착(4종 136.2분 · gray 1점 18분)을 돌리지 않는다.** 근거와 N:

```
 근거  솔버는 결정적이고(난수 0 · v3-22~33 확인분) 발산이 0이다. 상태가 프레임 N에서
       «비트 동일»이면 이후 프레임은 **같은 순수 함수의 반복**이므로 영원히 같다.
       따라서 N은 「조립이 만드는 것이 «전부» 소비되는」 지점이면 족하다.
 조립의 시간 의존 산출은 **하나뿐이다** — 점진 봉제 램프(`RAMP_N` 프레임 동안
       이음선 정지 길이가 매 프레임 바뀐다). 그 밖(메시·배치·제약·물성·서브스텝)은
       **f = 0에 한 번** 만들어지고 변하지 않는다.
 ⟹ **N = RAMP_N + N_WIN**
       RAMP_N  d11에서 **76**프레임 (v3-33 실행 헤더 등재분)
       N_WIN   **10**프레임 = round(1/(DAMP·DT)) — 정착 판정 창(v3-22 등록분)
       ⟹ **N = 86** — 램프 전량 + 램프 «후» 정착 창 한 바퀴를 지난다
 비용  d11 gray 4.90 s/f × 86 ≈ **421초 ≈ 7분** · 전후 2회 = **약 14분**
 전량 1회 확인 여부는 **§3이 판단**하고 근거를 적는다(비용 18분)
```
