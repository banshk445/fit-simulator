## §1 층별 «실제로 옮긴 거리» — 가설의 절반만 맞다

솔버에 계측을 넣었다(`stepDiag` · **기본 off ⟹ 기존 경로 비트 동일**). 한 서브스텝 안에서

`|v|`와 짝지었다(계기 규범 — **부분과 전체를 함께**).

