### §1-2 도출 — Wang LUT의 정의역 상한

```

   G(0,0) = −0.25 + i/30,  G(1,1) = −0.25 + j/30,  G(0,1) = k/30,   i,j,k ∈ [0, 29]
```

### §2-2 비용 법칙의 확장 — 서브스텝 비를 곱한다

#34의 `ms/f = 5.333e-3·d^−3.143`은 **한 원단(k=100·ρ=0.187 · sub=246)**에서 잰 것이다.
비용은 `정점 × 서브스텝 × 투영단가`이고 **정점과 해상도는 4종이 같다**(§2-3) ⟹ 원단이
바꾸는 것은 **서브스텝뿐**이다. 따라서

```
 ms/f(원단) = ms/f(기준) × sub(원단) / sub(기준)
 sub(원단)  = substepsForCloth(dt, k, ρ, e_min) = ⌈dt·√(k/ρ) / (0.2294 · e_min)⌉
              e_min = 6.83mm (d=11.0mm 메시의 최소 엣지 — 4종 공통)
```

### §2-3 해상도는 **4종 모두 d = 11.0mm 고정**

S5의 완료 조건은 「**같은 패턴·같은 몸에서 원단만 바꿔** 형상이 갈린다」이다 ⟹
**메시가 같아야 대조가 성립한다.** 원단별로 d를 바꾸면 형상 차이가 «원단 때문인지
해상도 때문인지» 갈리지 않는다. **d 고정이 옳다.**

**산출 불가 1건**: 설계 R3의 파장 조건(`ℓ = (B/ρg)^(1/3)` ⟹ d ≤ ℓ/2)을 **원단별로 못 낸다** —
저장소에 **굽힘 B가 `gray-interlock` 1종뿐**이다(v3-01 §2-3의 「원단 파일 1종만 읽음」이
그대로 남아 있다). 추정치로 채우지 않는다. **다만 서브스텝은 영향받지 않는다** — 아래 표에서

## §0 기준 등록 — 「`ℓ`이 충분히 벌어졌다」를 «먼저» 정한다

### 먼저 «자기 귀책»을 적는다 — 노출 순서

이 판을 시작하며 회차 프롬프트가 가리킨 「v3-09 §1의 최소 인접 간격 0.40%」를 찾다가
**같은 절의 10종 `ℓ` 표를 «먼저 보았다».** 따라서 이 기준은 **선정 4종의 값을 본 «뒤»에
등록된다.** 그 사실을 숨기지 않고, 대신 **기준을 「우리 4종과 무관한 값」에 앵커**한다.

### 기준

```
 「충분히 벌어졌다」 = 선정 4종의 «최소 인접 ℓ 간격» > v3-09 §1이 등재한
                      «10종 전체의 최소 인접 간격 0.40%»
```

**앵커의 근거**: 0.40%는 **ARCSim 10종이 제공하는 가장 촘촘한 쌍**(tango-red-jet-set ↔
camel-ponte-roma)이고 **v3-09가 이미 등재한 값**이다 — 이 판이 고른 수가 아니고, 우리 4종이
무엇이든 바뀌지 않는다. 우리 선정의 가장 촘촘한 쌍이 그보다 «느슨»하면, 우리 선정은
**등재된 집합에서 가장 어려운 경우보다 엄격히 쉽다**. 그것이 이 기준의 뜻이다.

**이 기준이 «말하지 않는 것»(한계를 미리 적는다)**: 이것은 **`ℓ`의 분리**에 대한 기준이지
**시뮬레이션이 그 차이를 형상으로 «분해»하는가**에 대한 기준이 아니다. 후자는 S5의
재현 산포를 요구하는데 **그 산포는 미측정**이다 ⟹ 잔여로 등재한다(#47).

## §1 데이터 확보 — **가져올 필요가 없었다. 이미 저장소에 있다**

`docs/v3/09-요구재확인.md` §1에 **ARCSim 10종 전부의 `ρ` · `B[N·m]` · `ℓ[mm]` 표**가
등재돼 있다. `B = bending[0][0]`(바이어스 0° · 곡률 0 — 신장 ⓑ의 접선 1점과 같은 계열).
단위는 **v3-02 §0-3이 닫은 N·m 경로 그대로**이고 새 환산식을 만들지 않았다.

**⟹ #46은 「미확보」가 아니라 «미열람»이었다.** v3-24가 `docs/v3/01-물성조사.md` §2-3의
「원단 파일 1종만 읽음」만 보고 **이미 닫힌 v3-09 §1을 열지 않았다.**
**함정 24(가진 채널 미열람) 계열**이고, 그 결과 v3-24 §2-4의 `sub(굽)` 82/90/86/68은
