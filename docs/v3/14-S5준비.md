## §1 문턱 재도출 — 물성에서

### §1-1 무엇을 막으려는 값인가

후보 셋을 갈랐다.

| 후보 | 물성 데이터로 도출 가능한가 | 결과 |
|---|---|---|
| **비물리적 신장**(모델이 측정 범위를 벗어남) | **가능** | Wang LUT의 «정의역 상한»이 그대로 문턱이다 |
| 원단 파단 | **불가** | ARCSim 물성 파일에 **파단 변형률이 없다**(`stretching` 6×4 + `bending` 3×5뿐) |
| 수치 발산 | 불가·무관 | v3-04가 서브스텝 산정(r ≥ 0.95)으로 이미 닫았다. 신장 «크기»와 별개 축이다 |

⟹ **물성에서 나오는 문턱은 「모델 정의역」 하나다.**

### §1-2 도출 — Wang LUT의 정의역 상한

```
 dde.cpp `evaluate_stretching_samples`의 이산화(v3-02가 소스 원문에서 확인):
   G(0,0) = −0.25 + i/30,  G(1,1) = −0.25 + j/30,  G(0,1) = k/30,   i,j,k ∈ [0, 29]
 ⟹ 표본이 덮는 최대 그린 변형  G_max = −0.25 + 29/30 = 0.716667
 C = 2G + I 이므로 주신장  λ_max = √(2·G_max + 1) = **1.5599**
 그 밖에서 `stiffnessAt`은 **clamp**한다(외삽이 아니라 «상수 연장») ⟹ 그 지점부터
 강성이 측정값이 아니라 «격자 가장자리 값»이다 — 원단이 더는 그 원단이 아니다
```

**⟹ 재도출 문턱: 원소 주신장 λ ≤ 1.5599.**

### §1-3 통계 — 시험이 재는 것과 짝을 맞춘다

**국소(원소) 최대 주신장**이다. 근거: LUT 조회가 **원소마다** 일어나므로 정의역 이탈도
원소 단위로 일어난다. **v2의 `maxStrain` 5.670과 같은 통계**이고, 설계 §4 S4 ②가 쓴
**전역 링 원주 비와는 다른 통계**다(#45가 지적한 불일치가 여기서 닫힌다).

### §1-4 원단마다 다른가 — **아니다**

LUT의 이산화 격자(`−0.25 + i/30`)는 **`dde.cpp`에 상수로 박혀 있어 모든 원단에 공통**이다.
원단마다 달라지는 것은 격자 «위의 값»(강성)이지 격자 «범위»가 아니다.
⟹ **문턱 1.5599는 원단 무관**이다. 파단은 원단마다 다르겠지만 **그 데이터가 없다**(§1-1).

### §1-5 재판정 — 두 문턱은 «다른 것»을 잰다

```
 v3-21 최종(f=600) 원소 주신장 λ  (원소 13,728)
   중앙 1.0070 · p95 1.0697 · p99 1.1133 · **최대 1.3543**
   1.10 초과 원소 221 / 13,728 (1.6%) · **LUT 정의역 1.5599 초과 0 / 13,728**
   최대 위치 (24.5, 133.4, −0.6)cm — 오른쪽 암홀 대역
 재도출 문턱 1.5599 대비 ⟹ **PASS (여유 15.2%)**
 대조: v2 maxStrain **5.670** — 같은 통계로 **3.6배 정의역 밖** · v3는 **4.2배 작다**
```

**설계 §4 S4 ②(전역 링 원주 비 ≤ 1.10)는 «여전히 FAIL»이다**(1.1028).
두 문턱은 다른 것을 잰다 — 재도출된 것은 **「모델이 유효한가」**이고, 설계의 1.10은
**「옷이 제 구실을 하는가」**다. 후자는 **물성에서 도출되지 않는다**(갈래 B 부분).
⟹ **설계 문턱은 그대로 두고**(완화 0), 재도출 문턱을 **추가 채널**로 등재한다.
**v3-23의 A 판정(기하 강제)은 별개로 유지**된다 — 문턱 통과로 나온 판정이 아니었다.

## §2 S5 비용 산정

### §2-1 원단 4종 선정

v3-04 §2-B가 확보한 **ARCSim 10종의 k·ρ 표**에서 고른다(굽힘 B는 §2-3 참고).

| 원단 | k [N/m] | ρ [kg/m²] | 고른 근거 |
|---|---|---|---|
| `navy-sparkle-sweat` | 25.0 | 0.224 | **10종 중 가장 부드럽다** — 대역의 아래 끝 |
| `gray-interlock` (t-shirt) | 69.0 | 0.187 | **S4가 쓴 원단** — 기준점이자 대조의 앵커 |
| `white-swim-solid` | 209.2 | 0.204 | 중간 대역 · 기준의 **3배** 강성 |

**k가 81배 벌어지고 ρ도 1.7배 벌어진다** ⟹ 형상 차이가 «값으로 구별»될 여지가 크다.
10종 중 더 뻣뻣한 둘(`royal-target` 4070 · `white-dots-on-blk` 4055)은 뺐다 —
v3-04 §2-D가 이미 **예산 밖**으로 분류했고, 대역의 상한은 denim이 대표한다.

### §2-2 비용 법칙의 확장 — 서브스텝 비를 곱한다

#34의 `ms/f = 5.333e-3·d^−3.143`은 **한 원단(k=100·ρ=0.187 · sub=246)**에서 잰 것이다.
비용은 `정점 × 서브스텝 × 투영단가`이고 **정점과 해상도는 4종이 같다**(§2-3) ⟹ 원단이
바꾸는 것은 **서브스텝뿐**이다. 따라서

```
 ms/f(원단) = ms/f(기준) × sub(원단) / sub(기준)
 sub(원단)  = substepsForCloth(dt, k, ρ, e_min) = ⌈dt·√(k/ρ) / (0.2294 · e_min)⌉
              e_min = 6.83mm (d=11.0mm 메시의 최소 엣지 — 4종 공통)
```

### §2-3 해상도는 **4종 모두 d = 11.0mm 고정**

S5의 완료 조건은 「**같은 패턴·같은 몸에서 원단만 바꿔** 형상이 갈린다」이다 ⟹
**메시가 같아야 대조가 성립한다.** 원단별로 d를 바꾸면 형상 차이가 «원단 때문인지
해상도 때문인지» 갈리지 않는다. **d 고정이 옳다.**

**산출 불가 1건**: 설계 R3의 파장 조건(`ℓ = (B/ρg)^(1/3)` ⟹ d ≤ ℓ/2)을 **원단별로 못 낸다** —
저장소에 **굽힘 B가 `gray-interlock` 1종뿐**이다(v3-01 §2-3의 「원단 파일 1종만 읽음」이
그대로 남아 있다). 추정치로 채우지 않는다. **다만 서브스텝은 영향받지 않는다** — 아래 표에서
굽힘 산정(68~90)이 **네 원단 모두 멤브레인 산정보다 작다**. 파장 적정성만 미확인이다.

## §3 범위 후보 — **이 판에서 정하지 않는다**

**총 시간이 두 기준 모두 한 자리 시간(≤10h) 안이다** ⟹ **4종 전량이 값으로 가능하다.**

줄일 축이 필요해질 경우를 대비해 함께 적는다(**각 축이 「원단별 구별」을 깨는가**가 판단 기준):

| 줄일 축 | 절감 | 구별을 깨는가 |
|---|---|---|
| 프레임 600 → 300 | **−50%**(7.10 → 3.55h) | **안 깬다** — v3-21에서 f=300 이후 위치가 소수점까지 불변이었다. 단 **원단별 정착 프레임은 미측정**이라 부드러운 원단이 더 늦게 설 수 있다 |
| 원단 4 → 3 (denim 제외) | **−59%**(3.55 → 1.55h) | **깬다** — 뻣뻣한 대역이 빠지면 k 폭이 81배 → 8배로 줄어 「원단이 갈린다」의 검정력이 떨어진다 |
| 해상도 d 11 → 13.4mm | 약 −45%(#34 지수 3.14) | **깬다** — 형상 차이가 원단 때문인지 해상도 때문인지 갈리지 않는다(§2-3) |
| 부분 정착(정착 채널 도달 시 조기 종료) | 원단별로 다름 | **안 깬다** — v3-22 채널이 «형상 불변»을 직접 재므로 조기 종료가 곧 정착이다. **가장 값어치 있는 축** |

**권고 없음. 전략 세션이 고른다.**
