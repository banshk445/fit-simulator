## §1 #24 진단 — 가설 2건 반증 · 이상 재현 불가

v3-10 §3-④가 남긴 것: 충돌 비중이 4.8% → 0.0%로 «주는데» 총 ms가
51,756 → 1,064,541 → 1,094,410 → 670,536으로 **폭증·비단조**.

### 계기

`collisionStats`를 4칸에서 8칸으로 넓혀 **기록만** 추가했다(물리 무변경):
`[4]` 0이 아닌 최소 `depth` · `[5]` 0이 아닌 최소 `|Δx_t|` ·
`[6]` `|Δx_t| < 1e-300` 횟수 · `[7]` `depth < 1e-300` 횟수.
장면은 v3-10 ④와 같은 구 낙하(정점 625 · 두께 1 mm · μ=0.3 · damping 6), T=1.5 s,
**15프레임 구간마다 벽시계 시간을 따로** 찍었다.

### 실측

```

     1   30836    1.78e-10    1.85e-21            0              0
     4   29958     1.71e-9    1.85e-21            0              0
```

### 반증 1 — **하위정규수 가설**

최소값이 `depth` **1.78e-10 ~ 2.96e-7**, `|Δx_t|` **1.85e-21 ~ 2.22e-21**이다.
하위정규 대역 진입점은 **2.2e-308**이므로 **287자릿수 위**에 있고,
`<1e-300` 카운트가 **세 경우 전부 0**이다. ⟹ **하위정규수는 아니다.**

### 반증 2 — **마찰식 분모 가설**(전략 세션 보강분)

같은 값이 `μ·depth/|Δx_t|`의 분모도 함께 반증한다 — `|Δx_t|`가 1e-21 대에 머물고,
`every`가 커지면 **오히려 `depth`가 «커진다»**(1.78e-10 → 2.96e-7). 충돌을 드물게
해소할수록 한 번에 밀어내는 양이 크기 때문이다. **분모가 극소로 수렴하지 않는다.**

### 그리고 — **이상 자체가 재현되지 않는다**

`every` 1 / 4 / 16의 총 시간이 **30,836 / 29,958 / 29,559 ms**로 사실상 같고,
**구간별 시간이 평탄하다**(4,789~5,186 ms · 증가 추세 없음).

시뮬 1초당 벽시계로 환산하면:

```
이 판(T=1.5s)   every 1 : 20.6 s/s   every 4 : 20.0 s/s   every 16 : 19.7 s/s
v3-10(T=2.5s)   every 1 : 20.7 s/s   every 4 : 425.8 s/s  every 16 : 437.8 s/s
```

**`every=1`은 두 판이 20.6 vs 20.7로 일치한다.** 이탈한 것은 v3-10의 `every≥4`뿐이고,
같은 코드가 이 판에서는 정상 속도를 낸다.

**남은 후보 2건(단정 0)**
1. **1.5초 이후 발현** — 이 판은 T=1.5 s까지만 봤다. v3-10은 2.5 s였다.
   구간별 시간이 평탄했으므로 «점진적 악화»는 아니고, 있다면 **어느 시점의 전이**여야 한다.
2. **v3-10 실행 중 머신 경합** — 그 실행은 ①(3형상) → ②(이분 탐색 36회) → ④를
   한 프로세스에서 이어 돌렸다.

### 처분

**#24를 「미해소」가 아니라 「재현 불가 · 후보 2건」으로 갱신한다.**
v3-10 §3-④의 **총 ms 열은 무효를 «유지»**한다 — 재현되지 않으므로 그 값을 신뢰할
근거도 없다. **주기 N은 여전히 미정**이다.

**계기는 유지한다** — `collisionStats` 확장은 되돌리지 않는다. #24가 안 닫힌 한
다음 세션이 다시 필요로 한다(특히 후보 ①을 보려면 T를 늘려 같은 계기를 다시 걸어야 한다).

## §1′ 설계 결정 6건 — 구현 «전»에 확정

### 1. 기존 자산 재확인 — **공간 해시의 «형태»만 재사용 · 코드 재사용 0**

|---|---|---|

**코드는 한 줄도 가져오지 않았다** — v3는 v2를 임포트하지 않는다(설계 R4-3).
재사용한 것은 「균일 격자에 넣고 이웃만 본다」는 **구조**뿐이고, v3판은 **정점이 아니라
삼각형을 확장 AABB로 삽입**한다(아래 6).

### 2. 엣지–엣지 — **필요하다. 함께 넣는다**

정점–삼각형이 최소 요건이지만 **그것만으로는 부족하다.** 두 삼각형의 최근접 «특징 쌍»이
엣지–엣지인 배치 — **양쪽 정점이 전부 상대 삼각형 밖으로 투영되는 경우** — 에서는
정점–삼각형 거리가 계속 sep보다 커서 **한 번도 발화하지 않는데** 두 면은 이미 서로를
지나가고 있다. 접힘선끼리 X로 교차하는 자리가 정확히 그 배치이고, 구겨 쌓은 더미는
접힘선이 서로 교차하는 자리를 반드시 만든다.

⟹ 쌍마다 **정점–삼각형 6 + 엣지–엣지 9 = 15특징**을 재고 **sep 안인 것을 전부** 낸다.

> **처음에는 «가장 가까운 하나»만 냈다**(중복 밀기를 피하려고). 실측에서 그 판이
> **대조군보다 나빴다**(교차 58 vs 11): 면–면으로 겹친 두 삼각형을 점 하나로만 버티니
> 두 층이 가위질하듯 서로를 지나갔고, 최근접 특징이 정점↔엣지로 바뀔 때마다 법선이 튀었다.
> 중복 걱정은 해소 패스가 Gauss–Seidel로 바뀌며 사라졌다(아래 §2′).

### 3. 인접 제외 — **정점을 하나라도 공유하는 쌍(위상 0링)**

공유 정점 쌍은 거리가 **정의상 0**이라 제외가 필수다. 1링까지 넓히지 «않는다».

**대가(명시)**: 엣지 하나를 사이에 둔 **급격한 접힘**(접힘 반경 < 엣지 1개 대역)은
자기충돌이 막지 않고 **굽힘 제약만** 저항한다. 이 판의 메시에서 엣지가 10mm이고
sep이 2mm이므로, 반경 1.6mm 이하로 접히는 자리가 그 사각지대다. 넓게 제외하면
**진짜 접힘을 놓치므로** 0링에서 멈춘다.

### 4. 두께 — **S3와 같은 1 mm · 분리 거리는 2× = 2 mm**

S3는 몸 «표면»에서 thickness만큼 띄운다. 옷–옷은 양쪽이 다 옷이라 각 면이 상대에게서
thickness를 요구한다 ⟹ 합이 **2×thickness = 2 mm**.

### 5. 자기접촉 마찰 — **적용하지 않는다**

μ가 **출처 미확보**(#23 · ARCSim `Material`에 마찰 항이 없다)라 두 번째 마찰 항을 넣으면
근거 없는 상수를 하나 더 곱하는 것이 된다.

**영향(명시)**: 접힌 층끼리 **미끄러진다** — 구겨진 더미가 실제보다 더 풀리고, 접힘이
제자리에 머무는 힘이 굽힘·중력뿐이다. 완료 조건 ①②는 이 항 없이 판정된다.
**#23이 닫히면 자기접촉에도 같은 μ를 걸지 재검토한다**(신설 잔여로 등재).

### 6. 광역 셀 크기 — **두께·엣지 길이에서 도출 (손 상수 0)**

삼각형 AABB를 **thickness씩 양쪽으로 넓혀 «겹치는 모든 셀»에 넣는다.** 그러면 표면
거리가 sep 미만인 두 삼각형은 확장 AABB가 반드시 겹치고 ⟹ **셀을 최소 하나 공유한다.**
**셀 크기와 무관하게 누락이 0**이므로 셀 크기는 «정확성»이 아니라 «비용»만 정한다:
작으면 삽입 수가, 크면 헛 쌍이 는다. 둘이 갈리는 지점 = 확장 AABB의 전형 폭이므로

```
cell = mean(엣지 길이) + sep = mean(엣지 길이) + 2·thickness
```

엣지 길이는 **제약이 실제로 순회하는 집합**(`sp.tris`)에서 매 호출 직접 뜬다(함정 12).
중복 쌍은 **두 셀 범위의 «최소 모서리» 셀에서만 처리**해 Set 없이 중복 0·누락 0으로 만든다
(두 삼각형이 어떤 셀을 함께 점유하면 그 최소 모서리도 반드시 함께 점유한다).

## §2′ 구현 범위

`src/v3/solver.ts`에 **순수 추가**(+433줄): `SelfCollisionParams` · `selfStats` ·
`SolverParams.selfCollision?` · 광역/협역/해소 3패스. 해소는 **제약 투영 뒤 · 몸 충돌 앞**
(몸 관통이 더 단단한 조건이라 마지막에 둔다).

**해소 = Gauss–Seidel.** 간극을 **적용 시점의 위치에서 다시 잰다** — 두 형태 모두
`Σₖ coefₖ·xₖ` 가 두 특징 사이의 차 벡터이므로 4회 내적이면 나온다. `depth ≤ 0`이면
**건너뛴다**(이 가드가 없으면 음수 depth가 두 층을 «당기는» 항이 된다 — 절대 조항 위반).

> **협역이 잰 depth를 그대로 쓰면(Jacobi) 발산한다** — 한 정점이 여러 접촉에 걸릴 때
> 교정이 겹쳐 더해진다. 실측: 천이 **4.3 m 날아가고** |v| 172 m/s · 엣지 신장 3.39 ·
> 최대 침투가 sep에 포화. 서브스텝 h가 1e-4 s 규모라 **위치 교정이 속도에서 1e4배로
> 증폭**되는 것이 발산 경로다. Gauss–Seidel로 바꾸자 |v| 6.95 mm/s · 신장 1.002가 됐다.

**넣지 않은 것**: 흡착·인력 항 · 자기접촉 마찰 · CCD · 주기 N(자기충돌은 **매 서브스텝**) ·
봉제 · 실제 몸 메시.

## §3′ 시험 — G·①·②·④·⑤

시험 원단 = ARCSim `gray-interlock`(ρ=0.187 · B=23.19e-6) · 두께 1 mm · 경계 결손 교정(v3-06).

### G 교차 판정기 자기검사 — **6/6 PASS** (①을 판정할 자격)

판정기는 **엣지 6개 × 선분–삼각형(Möller–Trumbore)**. 두 삼각형이 제대로 교차하면 교차
구간의 양 끝점이 각각 어느 한쪽 엣지 위에 있으므로 **엣지 6개 중 최소 하나가 상대 내부를
관통한다** ⟹ 공면 겹침(측도 0)을 뺀 모든 교차가 이 6회로 잡힌다.

```
 A의 엣지가 B 내부를 관통              기대 true  실측 true  PASS
 B의 엣지가 A 내부를 관통(반대 방향)     기대 true  실측 true  PASS
 평행 두 층 5mm 간격                  기대 false 실측 false PASS
 거의 닿음 0.1mm(오검출 시험)          기대 false 실측 false PASS
 공면 · 서로 떨어짐                    기대 false 실측 false PASS
 엣지 공유(힌지)                      기대 false 실측 false PASS
```

> **자기검사가 결함을 하나 잡았다.** 6번이 처음에 FAIL이었다 — 한 엣지의 끝점이 상대
> 정점과 같아 `t=0·u=1`로 «경계 위»에 서는데 부등식이 닫혀 있어 true가 나왔다.
> 주석이 처음부터 「**내부**를 관통」이라 적고 있었으므로 **부등식을 그 정의에 맞췄다**
> (u·v·t를 열린 구간으로). **기댓값이 아니라 구현을 고쳤다.**
> 대가: 관통점이 정확히 엣지·정점에 얹히는 배치(측도 0)는 놓친다.

### ① 자기관통 0 — **PASS**

**장면 = 주름 접힌 천을 바닥에 떨어뜨려 눌러 쌓는다.** 정지 상태(rest)는 **평면 그대로**이고
