```
 §0-3 기준 «셋 전부»를 4종에서 만족하는 설정 = **d11 + 서브스텝 산정**(= v3-26 기준선)
   ⟹ **절감 1.0배 · gray 1,630초 · 제품 예산 95초의 17.2배**
 ①② 를 만족하고 ③이 «1종»만 실패하는 최선 = **d15 + 서브스텝 산정**
   ⟹ **2.67배**(gray 610초) · 실패는 swim 관통비 0.375(절대 관통 0.3672mm는 정상)
 gray 단독 최대 = **C2(d18 · SUBDIV=6) 50.9배 · 32초** — 그러나 4종에서 sweat가 ③ 위반
```

**⟹ 17.2배는 달성하지 못했다.** 등록 기준을 문자 그대로 적용하면 **안전한 절감은 1.0배**이고,
관통비 조항 1건을 계기 한계로 분리하면 **2.67배**다.

### §3-2 축별 안전 한계 (갈래 D의 산출물)

```
 축            gray 단독 안전 한계        4종 공통 안전 한계        깨지는 방식

 해상도         d18 (5.31×)              **d11 (1.0×)**           d15 swim · d18 denim 관통비 이탈
                                        (③ 완화 시 d15 = 2.67×)   R3 파장 조건은 d13부터 위반
```

**안전 한계가 «원단마다 다르다»**는 것이 이 판의 핵심 산출물이다 — gray 하나로 축을 재고
끝냈으면 **3.02~5.31배를 「안전」이라 잘못 적었을 것**이다. §0이 4종 검증을 요구한 것이
그것을 막았다.
