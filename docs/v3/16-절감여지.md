## §1 채널 정정 — **재설계가 아니라 「구현이 등록 정의에서 벗어난 것」의 복구**

### §1-1 무엇을 판정하려는 것인가

v3-16이 세운 것은 **「관통이 «설명된다»」**이지 「관통이 작다」가 아니다. 모형
`P_ext = P_smooth + 0.283·min(1, θ/(π/2))·h`가 실제 관통을 맞히는지를 «양쪽»에서 본다 —
그래서 구간이 `[0.5, 1.25]`로 **하한이 있다**(모형이 과대예측해도 「설명된 것」이 아니다).
**이 취지를 그대로 유지한다.**

### §1-2 결함의 정체 — **채널 설계가 아니라 «구현»이었다**

```
 v3-16이 «등록»한 통계 (scripts/v3Body.ts:972 주석 원문)
   「v3-16 §1 통계 — 점별 P_ext 의 **최댓값** (매끈한 항과 «같은» 통계로 맞춘다)」
   ⟹ 비 = (실측 최대 관통) / (점별 P_ext 의 **최댓값**)
   v3-16 실측 검증: 0.3581 / 0.4675 = **0.766** ✓ 등재값과 일치

 v3S4.ts가 «구현»한 통계 (v3-19에서 이 판까지)
   비 = (실측 최대 관통) / (**최대 관통이 «난 그 점»**의 P_ext)
   ⟹ 분자와 분모가 «같은 점»에 묶여 있다
```

**⟹ 두 통계가 다르다.** 등록 정의의 분모는 **접촉점 전체에서 잡은 최댓값**이라 표본이
많고 안정적인데, 구현은 **표본 하나**(최대 관통점)에 묶여 해상도가 바뀌어 그 점이 옮기면
분모가 통째로 달라진다. v3-27 §2-6이 값으로 본 「분모가 2배씩 튄다」가 **바로 이것**이다.

**이것은 v3-16 §1과 «같은 계열»의 사건이다** — 그때는 「매끈한 항은 점별 최대인데 크레이스
항만 전역 중앙」이었고, 이번은 「분자는 최대점인데 분모도 그 점에 묶였다」이다.
계기 규범 **「자기검사 실패 시 «구현·정의역»부터」**가 가리키는 자리다.

### §1-3 처분 — **등록 정의로 되돌린다. 새 채널을 만들지 않는다**

```
 판정 비 = (실측 최대 관통) / (점별 P_ext 의 **최댓값**)   ← v3-16 등록 정의 그대로
 구간    [0.5, 1.25]                                    ← 변경 0
 하한    유지. 취지가 서 있다(§1-1) — 모형 과대예측을 잡는 조항이다
```

**후보 ①(점별 비의 분포)·③(이웃 다수결)을 쓰지 «않는» 이유**: 둘 다 **새 채널**이고,
그러면 v3-16이 세운 판정과 «다른 것»을 재게 된다. **등록 정의가 이미 표본 하나에
의존하지 않는 형태**이므로 새로 만들 필요가 없다. **가장 작은 정정이 옳다.**

### §1-4 안전장치 — v3-16 원 장면에서 판정이 유지되는가

등록 정의는 **`scripts/v3Body.ts`에 그대로 살아 있고 이 판이 손대지 않는다.**
⟹ v3-16 원 장면(해석 형상 3종 + 실제 몸)의 판정이 유지되는지는 **`npm run v3:body`
재실행으로 값 확인**한다. **유지되지 않으면 이 정정은 무효**다(갈래 C).

**순서**: 이 §1을 커밋한 «뒤» §2 재판정을 계산한다. **§2 결과를 보고 채널을 고르지 않는다.**

### §0-1 한 조항이 «두 가지»를 묻고 있었다


v3-28 §2-2가 값으로 보였다 — **분자(실측 관통)는 안 변하고 분모만 2.5배 커진다.**
