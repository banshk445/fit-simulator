## §4 요건 질문 초안 — **답은 전략 세션 + 사용자**

### Q1 — **몸 그리드 «축»**: 어떤 몸 치수가 핏을 실제로 가르는가

```
 **기존 정본 3종으로는 답할 수 없다** — 세 상태는 **원단만 다르고 «몸이 동일»**하다
   (전부 `DEFAULT_BODY_SIZE` · `bodyScale` 미사용 · §1-2).
 ⟹ **민감도 «측정» 판이 필요하다.** 이 판은 **«형태»만** 낸다(**판 수·시간 산정 0** · #81).
 **측정 판의 형태 초안**
   ㉮ **축 하나씩 «단독» 변경** — 키 / 가슴둘레 / 어깨너비 / 팔 길이 (다리 길이는 티셔츠
      정의역 밖일 가능성이 높으나 **가정하지 않고 측정 대상에 둔다**)
   ㉯ **판정 채널 = 이미 있는 것만** — 5행 핏 표(정확 거리 · 중앙 · p25~p75 · 3국면) ·
      cov / O4 · 게이트 ③a·③b. **새 채널 0.**
   ㉰ **한 축이 «가른다»의 정의를 먼저 등재** — 예: 어느 행의 국면(눌림/밀착/여유)이
      **뒤집히는가**. 「값이 얼마 움직였다」가 아니라 **판정이 바뀌는가**로 잡아야
      그리드 간격이 «도출»된다(#117 계열 — 문턱과 정의역을 겹치지 않게).
   ㉱ **최소 실행 수의 형태** = 축 4~5개 × (기준 + 양끝) — **각 칸이 «한 번의 정착»**이다.
      **몇 판인지·몇 시간인지는 적지 않는다**(#81 · 산정은 사용자 소유).
 ⟹ **선행 결손**: §1-2 대로 **v3 가 본 스케일 몸을 받는 경로가 없다** ⟹
    **민감도 측정 «전에» 그 입력 경로가 먼저 서야 한다**(측정이 그것에 의존한다).
```
