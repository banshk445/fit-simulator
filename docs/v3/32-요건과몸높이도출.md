## §1 ㉡ 도출 «규칙» 확정 — **수치 대입 0**

> **이 절은 계기를 구현하기 «전»에 커밋된다**(v3-40 규율). 아래에 **숫자는 하나도 없다**.
> 결과를 보고 규칙을 고치지 않는다.

### §1-1 계기 **C(y)** — 「그 높이의 몸통 둘레」

**v3-40 의 C_body 계기 계열**(평면 정확 단면 + 볼록 껍질)을 **일반화**한다.

```
 ① **평면 정확 단면** — 몸 삼각형을 평면 y = const 로 자른다. 절단된 삼각형은 **선분 1개**를 낸다.
    선분의 두 끝점은 «절단된 **엣지**»로 식별한다(정점 쌍의 **정렬 키** — 정수 비교 · **문턱 0**).
    이 절단 자체는 `garmentScene.planeSection` 이 이미 하는 것과 **같은 기계**다.
 ② **연결 성분** — 같은 엣지를 공유하는 선분끼리 묶는다(union-find). 결과는 **닫힌 고리들**이다.
    **근접 문턱을 쓰지 않는다** — 인접성은 **메시 위상**에서 온다. ⟹ **새 수 0**.
 ③ **몸통 고리** = **축점**을 «내부»에 품는 고리. 축점 = **(x = 0, z = `AXIS_Z`)** —
    `AXIS_Z` 는 `garmentScene` 이 이미 몸에서 도출한 등재량이다(**새 수 0**).
    내부 판정 = 고리 선분에 대한 **광선 짝수-홀수 교차**(**문턱 0**).
 ④ **C(y) = 몸통 고리의 «볼록 껍질» 둘레.**
    껍질은 **monotone chain**(정확)으로 잡는다 — `ringOf` 의 **각도 표본(RTH)·δ 를 쓰지 않는다**
    ⟹ **이산화 파라미터가 하나 줄어든다**. 이것이 「일반화」의 내용이고, `ringOf` 와의 차이
    (δ = 0 · 각도 표본 없음)를 **사실로 등재**한다.
 ⑤ 몸통 고리가 없으면 **C(y) 는 «정의되지 않는다»**(NaN 을 만들어 채우지 않는다).
```

```
 **왜 볼록 껍질인가** — 「둘레」의 물리적 대응은 **줄자**이고, 줄자는 단면의 오목한 곳을 «건너뛴다».
 그것이 볼록 껍질이다. v3-40 이 목선 `C_body` 에 같은 이유로 껍질을 썼고(#100 계열),
 여기서 축만 일반화한다. **새 의미론 0.**
```

### §1-2 도출 «구간» — **위상 전이로만 정한다** (손 상수 0)

```
 **하한 `Y_LOW`** = **몸통 고리가 존재하는 최저 높이**.
   아래로 내려가면 가랑이에서 단면이 **1 → 2 성분**으로 갈리고, 갈린 두 고리는 **축점을 품지 않는다**
   (축점이 다리 «사이»의 빈 곳에 놓인다) ⟹ **몸통 고리가 사라지는 높이**가 전이점이다.
   이것이 §0-C 가 지목한 「단면 연결 성분 1→2 · 가랑이」다.
 **상한 `Y_UP`** = **겨드랑이** = **팔 고리가 몸통 고리에 «합쳐지는» 높이**.
   그 위에서는 단면 성분이 **3(몸통 + 팔 2) → 1** 로 바뀌고, 하나가 된 고리의 껍질 둘레는
   **더 이상 «몸통 둘레»가 아니다**(팔을 감싼다).
   ⟹ 그 위는 **정의역에서 뺀다.** **하한과 «같은 계열»의 위상 사실이고 손 상수 0**이다.
   **CC 가 확정한 것은 이 상한이다** — §0-C 는 하한만 지목했고, 상한을 두지 않으면
   ④ 의 「몸통 둘레」 의미론이 어깨 대역에서 깨진다(팔이 껍질 안에 들어온다).
 **`Y_NECK` 은 «바깥» 경계다** — §0-D 순서 정합이 요구하는 상한이며,
   **`Y_NECK` > `Y_UP`** 이 성립하면 그 조항은 자동으로 만족된다. 성립 여부를 **값으로 확인**한다.
 **`Y_UP` 이 위상에서 안 잡히면**(팔 고리가 끝내 분리되지 않는 몸) ⟹ **갈래 B 정지.**
```

### §1-3 극값 — **chestY · waistY**

```
 **chestY** = 구간 **(`Y_LOW`, `Y_UP`)** 안에서 **C(y) 가 최대**인 높이
 **waistY** = 구간 **(`Y_LOW`, chestY)** 안에서 **C(y) 가 최소**인 높이
 **극값이 구간 «끝»에 붙으면**(내부 극값 없음 · 단조) ⟹ **갈래 B 정지.**
   「끝에 붙는다」의 판정은 **격자 이웃 비교**다 — 최대/최소를 낸 격자점이 구간의 첫 칸 또는
   마지막 칸이면 «내부 극값 없음»으로 적는다. **문턱 0.**
```

```

### §3-2 규칙이 «닫히지 않는» 자리 — 세 사실

```
 **① 성분 수가 겨드랑이를 «가리키지 않는다».**
    높이를 따라 성분 수가 1 → 5 → 3 → 7 → 9 → **1 → 1 → 1** → 3 → 1 로 간다.
    「3→1 전이」가 **여러 번** 나오고, 그중 어느 것도 겨드랑이가 아니다
    (140~143cm 의 성분 1 은 **팔이 몸통에 융합된** 상태다).
 **② 이 몸의 팔은 «분리된 고리»가 되기 전에 몸통 고리에 융합된다.**
    §1-2 의 상한 전제는 「팔 고리가 몸통 고리에 합쳐지는 높이가 있다」였는데,
    실제로는 **팔이 몸통과 이어진 채 평면을 벗어난다**(135cm 이하에서 팔은 평면에 없다).
    ⟹ **전제가 이 몸에서 거짓이다.**
 **③ 가슴 최대가 «팔이 가리는 대역»에 있다 — 상한을 고쳐도 갈래 B 가 다시 발화한다.**
    팔이 전혀 섞이지 않는 대역(y ≤ 135cm)에서 C(y) 는 **108cm 의 최소 이후 135cm 까지 단조 증가**한다.
    즉 **그 대역 «안»에도 chest 극값이 없다** — 최대는 항상 구간의 위쪽 끝에 붙는다.
    ⟹ 상한을 135cm 로 낮추는 «수선»으로도 §1-3 의 chest 절은 닫히지 않는다.
    **(이 관찰은 수선안이 아니다 — 수선을 «하지 않기 위해» 값으로 남긴다.)**
```

### §3-3 **waist 절은 닫힌다** — 하한부의 성립 사실

```
 **Y_LOW = 82.827cm** 가 위상으로 깨끗하게 잡힌다(그 아래 성분 2 = 가랑이 · 결정성 2/2).
 **C(y) 의 «내부» 최소가 y ≈ 108cm 에 있다**(68.06cm · 양쪽으로 증가 · 팔 무관 대역 안).
 ⟹ **§1 규칙의 «하한 + waist» 절반은 이 몸에서 성립한다.** 닫히지 않은 것은 **상한과 chest** 다.
 **그러나 이 판은 waistY 를 «내지 않는다»** — §1-3 이 waist 를 `(Y_LOW, chestY)` 구간으로
 정의했고 chestY 가 없으므로 **정의역이 서지 않는다**. 위 108cm 는 **관찰이지 도출이 아니다.**
```

### §3-4 v2 는 이 자리를 무엇으로 닫았나 — **참고**(게이트 아님 · 값 인용 0)

```
 `src/lib/bodyMeasure.ts` 를 «읽어» 규칙만 적는다. **실행 0 · 값 인용 0 · `V2DIMS` 미사용.**
   · **팔 배제**: `torsoVerts` = 「최근접 **골격 선분**이 팔 선분이 아닌 정점」(`:331-353`)
     ⟹ **위상이 아니라 «골격»으로 판다.**
   · **상한**: `shoulderJointY` = 팔 골격의 `trueShoulder.y` 최대(`:326`) ⟹ 역시 **골격**.
   · **극값**: 허리 = `shoulderJointY` 아래 둘레 최소 · 가슴 = 「허리보다 위 · 어깨 관절 아래」의 최대
     (`:394-403` · 주석 「**상수 없이 국소 극값으로만 도출한다**」) — **극값 형태는 §1-3 과 같다.**
   · 슬라이스 두께 `SLICE_THICKNESS_M = 0.025`(`:42`).
 ⟹ **차이는 «극값 규칙»이 아니라 «팔을 어떻게 떼어내는가»다.**
   v2 = **골격 기반 분류** · §1 = **위상 기반 성분**. **이 몸에서 위상은 팔을 못 뗀다**(§3-2 ②).
 **v2 수치와의 나란한 표는 이 판에서 «내지 않았다»** — §0-D 의 참고 병기는 **도출이 선 뒤**의 조항이고
   도출이 서지 않았다. **추정치로 채우지 않는다.**
```

### §3-5 **왜 「새 수」인가** — 갈래 C 의 정체

```
 팔을 떼어내려면 위상 밖의 기준이 필요하다. 저장소에 있는 후보는 **골격**이고
 (`src/lib/bodySkeleton.ts` — CLAUDE.md 「은행」 절이 재사용 자산으로 등재했다),
 **v3 쪽 참조는 현재 0건**이다(`grep` 확인). 그것을 쓰려면 둘 중 하나다:
   ㉮ **v2 `src/lib` 임포트** ⟹ **G1 위반**(v2 임포트 0)
   ㉯ **v3 안에 골격 도출을 새로 세운다** ⟹ **새 층**이고, 이 판의 정의역 밖이다
 ⟹ **§0-E 갈래 C 의 조건 「등재량·위상 사실만으로 규칙이 안 닫힘(새 수 필요)」이 성립한다.**
 **손 상수를 도입하지 않았다**(예: `|x| ≤ 어깨/2` 같은 절단은 **옷 치수**라 몸 도출에 쓸 수 없다).
```

## §4 ㉣ 갈래 판정 — **B**(발화한 조항) · **원인은 C**

| 갈래 | 조건 | 실측 | 성립 |
|---|---|---|---|
| A | 요건 등재 + 도출 성립 + 검증 통과 | **도출 불성립** | 아니오 |
| **B** | **도출 형태 불성립 / 순서 어긋남** | **§1-3 「극값이 구간 끝에 붙으면 갈래 B」 조항이 실행 중 «발화»**(C 최대 색인 57/57) | **예 — 이것이 실행이 낸 판정이다** |

| E | 판정 불가 | — | 아니오 |

```
 **두 갈래가 동시에 성립하고 «둘 다 정지»다.** 사후에 하나를 골라 문언을 바꾸지 않았다 —
 **B 를 「실행이 낸 판정」으로, C 를 「그 원인」으로 갈라 적는다**(선례: v3-46 이 갈래 C 를
 「의무 원복」과 함께 적은 형식).
 **정지한다. 규칙을 고치지 않았고, 손 상수를 넣지 않았고, chestY/waistY 를 내지 않았다.**
```

### §4-1 이 판이 «닫은» 것 / «연» 것

```
 닫음  **4/5 요건이 «확정»으로 등재됐다**(§0-A · Q1~Q4 · G1~G6 · 완결 조건) — ㉠ 완료
