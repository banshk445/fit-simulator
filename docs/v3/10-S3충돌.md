## §1 설계 결정 5건 — 구현 «전»에 확정

### 1. 부호 판정 — **해석 SDF (닫힌 형식)**

이 판의 형상은 평면·경사면·구·원기둥이라 **부호 있는 거리가 닫힌 형식**으로 나온다.
BVH도 레이 패리티도 필요 없다. 메시 몸의 후보 3종은 **S4로 이월**하고 실패 조건만 등재한다:

| 후보 | 실패 조건 |
|---|---|
| 최근접점 + 면 법선 내적 | **날카로운 모서리·오목부**에서 뒤집힌다. v1 Stage 1a가 이 계열에서 **부호 모순 2.95%**를 등재했다 |
| 레이 패리티(`raycast`) | **비수밀**이면 정의 자체가 안 된다. 비용이 최근접점 질의보다 크다(정점 수 × 광선) |
| winding number | 비수밀에 강인하나 **모든 삼각형을 순회**해 가장 비싸다. 가속 구조가 따로 필요 |

### 2. 수밀성 — **실제 몸을 이 판에서 «안 쓴다»**

원본 마네킹은 수밀(열린 엣지 0)이지만 `splitFrontBack`이 몸통을 반 시트로 자르고(597)
`excludeArms`가 반경 9cm 구멍 둘을 뚫는다(189) — CLAUDE.md Stage 1a 동결분.
**구멍 반경이 복셀보다 훨씬 크므로 안과 밖이 연결되고 부호 규칙은 근사일 수밖에 없다.**
⟹ 회차 프롬프트가 미리 연 갈래 **F**를 따라 **해석 형상만** 쓰고, 실제 몸은 **S4 선행 과제**다.

### 3. 이산 + 두께 vs CCD — **이산으로 충분하다(값으로)**

판정 부등식은 `h·|v|max < 두께`다. 실측(§3-①):

```
h·|v|max = 0.0056 / 0.0008 / 0.0000 µm  (구 / 원기둥 / 평면)
두께     = 1000 µm
```
**5자릿수 이상 여유**다. ⟹ **CCD 불필요**. 이는 서브스텝이 1,211개라 가능한 것이고,
**서브스텝 예산이 줄면 이 부등식부터 다시 본다**(#15와 묶인다).

### 4. 마찰 — **쿨롱 · 위치 기반 · μ 출처 «미확보»**

형태: 관통을 법선으로 해소한 뒤, **이번 서브스텝의 접선 변위**를 `μ·depth`만큼까지 되돌린다.
정지/운동 마찰을 따로 두지 않는다 — `min(1, μ·depth/|Δx_t|)`가 둘을 함께 준다.

**왜 이 형태가 `tanθ_c = μ`를 주는가**(구현 전 유도):
경사 θ의 평형에서 한 서브스텝의 관통은 `depth ≈ h²g·cosθ`, 접선 변위는 `|Δx_t| ≈ h²g·sinθ`다.
마찰이 접선을 완전히 없앨 조건은 `μ·depth ≥ |Δx_t|` ⟺ **`tanθ ≤ μ`**. §3-②가 실측으로 확인한다.

**μ는 어디서 오는가 — 원단 파일에 «없다».** ARCSim `Material` 구조체는
`density · stretching · bending · damping · strain_min/max · yield_curv · weakening`뿐이고
마찰 항이 없다(v3-01 §1-1이 인용한 `src/cloth.hpp` 원문). ⟹ **이 판은 시험용 상수**
(0.2 · 0.4 · 0.8)를 쓰고 **출처 미확보를 등재한다(#23)**.

> **번호 주의**: 회차 프롬프트가 「#22 신설」로 적었으나 **#22는 v3-09가 이미
> 「양단 고정 계기 재설계」로 쓰고 있다.** 충돌 없이 **#23**으로 등재한다.

### 5. 충돌 주기 — **두 경로 다 구현 · 값만 낸다**

`CollisionParams.every`(기본 1). **N을 이 판에서 정하지 않는다**(프롬프트 금지 조항).

## §2 구현 범위

`src/v3/solver.ts`에 **순수 추가**: `Collider`(plane/sphere/cylinder) · `CollisionParams` ·
`collisionStats` · `SolverParams.collision?`. 해소는 **제약 투영 뒤 · 속도 갱신 앞**.

```ts
const d = sdf(col, x) - thickness;
if (d >= 0) continue;          // 밖 ⟹ «아무 일도 안 한다» (흡착 0)
pos += (-d) * n;               // 관통했을 때만 밀어낸다 (단방향)
// 접선 변위를 μ·depth 만큼까지 되돌린다
```

**넣지 않은 것**: 흡착·인력 항 · 자기충돌 · 실제 몸 메시 · 봉제 · CCD.
`collision`이 없으면 충돌 코드가 **한 줄도 돌지 않는다** — §5가 값으로 확인한다.

### ④ 비용 — **산출했으나 «총 ms 열은 계기 이상»** [갈래 G]

```
  every        질의    충돌ms      총ms   충돌비중   관통정점   최대깊이[mm]
   없음          —        —      42170        —        —            —
      1   1.14e+8     2473      51756     4.8%        0     0.000000
      4   2.84e+7      748    1064541     0.1%        0     0.000000
     16   7.13e+6      233    1094410     0.0%        0     0.000000
     64   1.78e+6       59     670536     0.0%        0     0.000000
  (sub=1211 · 정점 625 · T=2.5s · 충돌체 1개)
```

**쓸 수 있는 것**: 질의 수가 정확히 `1/every`로 줄고(1.14e8 → 2.84e7 → 7.13e6 → 1.78e6),
충돌 ms도 그대로 따라간다(2473 → 748 → 233 → 59). **충돌 코드 자체는 설계대로다.**
그리고 **every=64까지도 관통 정점 0**이다 — 이 장면에서는 주기를 64로 늘려도 관통이 안 생긴다.

**쓸 수 «없는» 것 — 총 ms 열**: 충돌이 차지하는 비중이 4.8% → 0.0%로 «주는데»
총 시간은 51,756 → 1,064,541 → 1,094,410 → **670,536 ms**로 폭증하고 **비단조**다.
작업량은 `every`와 무관하게 고정이므로 **작업량 효과가 아니다.**

> **원인 후보(단정 0)**: 충돌을 드물게 해소하면 접촉 정지 상태에서 위치·속도가
> **하위정규수(denormal)** 대역으로 내려가고, 그 산술이 수십 배 느려진다 —
> 「충돌 없음」(42,170 ms)과 `every=1`(51,756 ms)만 정상이고 `every≥4`가 전부 느린 것,
> 그리고 **비단조**인 것이 이 후보와 정합적이다. **확인은 다음 판**(#24).
>
> **⟹ 이 열은 #15 입력으로 «쓰지 않는다».** 주기 N도 **정하지 않는다**(프롬프트 금지 조항 준수).
