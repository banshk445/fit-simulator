## §1 산정식 유효성 — **갈래 D**

`substepsForCloth`는 **멤브레인** 원소 진동수 `ω_el = √(k/ρ)/d` 기반이다(v3-04 §2-B).
외팔보 장면에 그대로 넣으면:

```
paper nu=12 du=4.55mm → substepsForCloth(k=Eh=5e5) = 35,739
paper nu=32 du=1.61mm → substepsForCloth(k=Eh=5e5) = 100,717
```

**실행 불가한 값이다.** 그런데 이 장면에서 멤브레인 **정확도**는 필요 없다 —
하중 `w = ρg = 0.981 N/m²`라 변형이 ~1e-6이고, §2-B (가)가 이를 실측으로 확인한다
(kMem을 5e5 → 1e2로 **4자릿수** 내려도 오차가 0.07pp만 움직인다).

⟹ **산정식은 굽힘 장면에서 «과대»이면서 동시에 «부적합»하다.** 필요한 것은
굽힘 제약의 고유 진동수다. 유도하면

```
굽힘 제약의 유효 강성 1/α = ke·l²/(4a),  |∇θ| ≈ 1/h_wing,  w = 1/m_절점
⟹ ω_bend² = (1/α)·Σw|∇C|²  ∝  (1/d)·(1/d)·(1/d²)  ⟹  **ω_bend ∝ 1/d²**
```

**멤브레인은 `ω ∝ 1/d`인데 굽힘은 `ω ∝ 1/d²`다.** 해상도를 2배로 하면 굽힘은
서브스텝이 **4배** 필요하다. 이것이 v3-04 §2-B 예산표의 **누락분**이고, #15 재산정 사유다.

**실측 증거**(v3-05 진단 스윕): 같은 sub=1024에서 격자를 더 곱게 하면 발산 대역으로 넘어간다 —
`nu=12·nv=33` 오차 **1505.68%**, `nu=41·nv=17` 오차 **430.32%**. 두 셀은 **미해상으로 무효**다.

### §1-B 굽힘 서브스텝 수렴 — 등록 장면에서는 **수렴했다**


## §2-B 셋째 원인 좁히기 — 후보를 **값으로** 배제한다

### 배제 ① 멤브레인 강성 — **아니다**

```
paper nu=12 sub=4096:  kMem=5e5 → 85.28%   1e4 → 85.34%   1e2 → 85.35%
현/정지길이비 0.99983 (비신축)
```
4자릿수를 내려도 **0.07pp**. 배제.

### 배제 ② `ke = 4B` 교정값 — **아니다** (계기 2종이 독립으로 확인)

v3-03 §2-A'는 **균일 곡률**(원기둥)에서 비 → ¼. 이 판은 **외팔보의 비균일 곡률**에서
다시 쟀다 — 해석 소변형 형상을 얹고 이산 에너지 `Σ ke·θ²/(2·shape)`를
연속체 `∫½·B·W·κ²dx`와 비교:

```
nu   nv   이산/연속체(ke=B)      ¼·(1−1/(nu−1))
  8    3       0.17121              0.17857
 12    3       0.19736              0.20455
 16    3       0.21048              0.21667
 32    3       0.23014              0.23387
 64    3       0.23995              0.24206
128    3       0.24485              0.24606
 32    9       0.23014   ← nv를 3→9→17로 바꿔도 «자릿수 전부» 같다
 32   17       0.23014
```
**비균일 곡률에서도 ¼로 수렴한다.** ⟹ `ke = 4B`는 맞다. 배제.

### 배제 ③ 솔버가 최소를 못 찾는다 — **아니다**

시뮬 수렴 형상과 **허용 해석 형상**(둘째 고정 열에서 y=0·기울기 0인 클램프 외팔보)의
총 에너지(굽힘 + 중력 퍼텐셜)를 직접 비교:

```
nu=12  해석(허용) δ=1.3087mm  Eb=2.0543e-7  Eg=-4.6813e-7  총=-2.62703e-7
       시뮬      δ=2.4255mm  Eb=4.4355e-7  Eg=-8.8768e-7  총=-4.44134e-7   ← 시뮬이 «더 낮다»
nu=32  해석(허용) δ=1.6805mm  총=-3.32650e-7
       시뮬      δ=3.4330mm  총=-6.39625e-7                                ← 시뮬이 «더 낮다»
```
**솔버는 최소를 찾고 있다. 이산계가 실제로 더 처진 형상을 «선호»한다.**
(두 상태 모두 `E_bend / |E_grav| ≈ 0.44~0.50`으로 선형 평형의 비리얼 관계를 만족한다.) 배제.

> **1차 판정을 정정한다**: 처음엔 해석 형상을 x=0 클램프·길이 L로 얹어 「솔버 유죄」가
> 나왔다. 그 형상은 **시뮬의 둘째 고정 열에서 y≠0**이라 **허용 형상이 아니었다.**
> 허용 형상으로 고치자 부호가 뒤집혔다. **계기의 정의역(허용 집합)을 먼저 맞춘다.**

### 배제 ④ 대각 분할의 좌우 비대칭 — **아니다**

시뮬 형상은 **매끈하고 해석 형상을 1.853배 «비례 확대»한 것과 일치**한다(열 6~11에서
소수 3자리까지). 지그재그·모래시계 모드 **없음**. 다만 **폭 방향 비틀림 0.229 mm**
(끝단 처짐의 9.4%)가 있어 대각 고정 분할을 의심했다.

```
paper nu=12 sub=4096:  고정 오차=85.28% 비틀림=2.29e-1mm
                       교대 오차=84.11% 비틀림=1.28e-4mm   ← 비틀림은 «사라지는데»
```
**교대 분할이 비틀림을 3자릿수 없애는데 오차는 1.2pp만 움직인다.** 배제.

### **유력 후보 — 폭 방향 해상도(원소 종횡비)**

```
paper nu=12 sub=4096 · nv만 올린다
  nv= 3  dv/du=2.200  오차=85.28%
  nv= 5  dv/du=1.100  오차=45.95%
  nv= 9  dv/du=0.550  오차=24.68%
  nv=17  dv/du=0.275  오차=21.21%
```

**여기서 크게 움직인다.** 등록 장면의 `nv=3`은 폭 방향으로 **쿼드 2줄**뿐이고
원소 종횡비가 **2.2**다. 폭을 세분하면 오차가 85% → 21%로 4배 줄어든다.

**다만 ±10%에 도달하지 못했고, 더 세분하려면 서브스텝이 `1/d²`로 늘어야 한다**(§1) —
`nv=33`은 sub=1024에서 1505.68%로 터졌다(미해상 · 무효).
⟹ **「폭 해상도만으로 닫히는가」는 이 판에서 «미확정»**이다.

**정사각 원소를 유지하며 양쪽을 세분한 대조**(sub=1024 · 유효 셀만):
```
nu= 6 nv= 3 dv/du=1.000 오차= 77.69%
nu=11 nv= 5 dv/du=1.000 오차= 44.54%
nu=21 nv= 9 dv/du=1.000 오차= 40.03%
nu=41 nv=17 dv/du=1.000 오차=430.32%  ← 미해상 · 무효
```
정사각을 유지해도 40%에서 더 안 내려간다(유효 셀 기준). **종횡비만이 아니라
«폭 방향 절대 분할수»가 함께 작용할 가능성**이 남는다.

## §3 해상도 예산 — **착수 0**

회차 프롬프트의 순서 강제(「§2가 통과한 «뒤»에만 §3으로 간다. ②가 또 실패하면 §3 착수 0」)에
따라 **집행하지 않았다.** 사유는 프롬프트가 이미 적은 그대로다 — 원인이 셋째가 있는
상태에서 해상도를 함께 움직이면 원인이 섞인다.

**다만 §1이 #15에 직접 영향을 준다**: v3-04 §2-B의 예산표는 **멤브레인 기준(`n ∝ 1/d`)**
이라 **굽힘을 포함하면 과소**다. 굽힘은 `n ∝ 1/d²`이므로 해상도 후퇴의 이득이
v3-04가 적은 `1/d³`보다 **크다**(서브스텝 `1/d²` × 제약 수 `1/d²` ⟹ **비용 ∝ 1/d⁴**).
**값 산정은 §2가 닫힌 뒤에 한다** — 지금 표를 내면 셋째 원인이 섞인 수를 등재하게 된다.
