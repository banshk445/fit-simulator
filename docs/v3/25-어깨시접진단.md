```

   (나) 연결선(시접선)이 희미하게 «끊어져» 보인다 — 패널 사이 갭이 점선처럼 비침

**전략 단서 (가설이지 판정 아님)**

```
 (나) 시접 간극 채널이 회차 내내 중앙 **2.1~2.2mm** — 시뮬레이션이 이 갭을 «유지»한다.
      실물 재봉선의 갭은 ~0. **이 갭의 도출 근거(rest 거리·제약식)가 규명 대상.**
 (가) 후보 셋 — ① 소매산 패턴 이즈(재봉용 여유가 뭉침이 됨) ② 시접 제약이 만드는 능선
      ③ 굽힘 거동. **(가)(나)는 ②로 연결돼 있을 수 있다.**

### §0-2 ㉠ (나) 시접선 — 세 채널

```
 1) 갭 기하   시접 쌍(전 시접: 어깨선 · 옆선 · 소매 등)별 간극 분포 —
    중앙 / 최대 / p90 · **«구간별»**(시접을 따라가며 어디가 넓은가). C-브라우저 3종 blob.
 2) 가시량    v3-42 **M 계기 재사용** — 옷 실루엣 «내부»에서 시접 대역(시접 쌍 정점의
    투영 근방)에 찍히는 **비옷색 픽셀 수**. 뷰별(front-p·side-p·back-p **대응 구도의
    진단 래스터**). «끊김»의 픽셀 정량이다.
 3) 도출 추적  시접 제약의 rest 거리/형식이 **코드 어디서 어떤 등재량으로** 도출되는가 —
    **원 커밋과 근거 문서를 지목**한다. 손 상수면 **그 사실을 적는다**(#95 계열).
    «왜 0 이 아닌가»에 대한 설계 의도가 문서에 있으면 **인용**한다.
```

### §0-3 ㉡ (가) 어깨 상승 — 네 채널

```
 1) 상승고    몸 어깨 능선(삼각근 상면) 위 옷 정점의 **법선 방향 최대/중앙 이격** —
    어깨 대역(§1 에서 **몸 좌표로 정의 · 등재량 기반**)에 한정. **3원단 비교.**
 2) 소속      상승 상위 정점들이 **어느 패널·어느 패턴 좌표**(소매산? 몸판 어깨? 시접
    대역 ±k열?)에 속하는가 — **뭉친 원단의 «출신»을 특정**한다.
 3) 패턴 이즈  **소매산 둘레 vs 암홀 둘레**(휴지 길이 기준) — 이즈량[cm·%]을 3원단
    공통 치수에서 산출. **조립 코드의 도출 근거(원 커밋)를 지목**한다.
 4) 시접 연동  상승 능선과 시접선의 **공간 상관** — 상승 최대점들이 시접 대역
    **±2열 안에 있는 비율**. **(가)-(나) 연결 가설(②)의 직접 시험**이다.
```
