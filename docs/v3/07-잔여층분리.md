> 가설의 「폭(nv) 결손」이 반증됐다. **N×N 패치에서 잰 형태를 좁은 스트립에 옮길 때
> `N`이 어느 축인지 확인하지 않고 `nv`로 읽었다.** 실제 형태는 `¼·(1−1/(nu−1))`이고

## §1 종횡비 분리 — **세 계열**

전부 **경계 결손 교정(`ke = B/비`, v3-06)이 적용된 상태**다.
서브스텝은 `substepsForBending`(#16) 산정 + 하한 2048, 무거운 셀은 2배 수렴 확인.

### 계열 A — 원소 종횡비 = 1 고정 (nu·nv를 함께 올린다)

```
   nu×nv  dv/du    sub    ke/B       오차
     6×3  1.000   2048   5.526   28.67%
    11×5  1.000   2048   4.610   25.08%
    21×9  1.000   5044   4.278   22.48%  [2배 수렴차 0.239%]
   41×17  1.000  19832   4.135   20.81%
```

**0이 아닌 바닥으로 수렴한다** — 28.67 → 20.81%로 좁혀지며 **약 20%**에 머문다.
정점을 47배(18 → 697) 늘려도 오차가 1.4배밖에 안 준다. ⟹ **순수 이산화 오차가 아니다.**

### 계열 B — nv=3 고정 (nu만 올린다 · 종횡비가 찌그러진다)

```
     8×3  1.400   2048   4.955   41.93%
    12×3  2.200   2048   4.545   63.43%
    16×3  3.000   2048   4.382   76.20%
    32×3  6.200   6141   4.175   93.07%
```

v3-05가 본 「해상도를 올릴수록 나빠진다」의 정체다 — **해상도가 아니라 종횡비가 나빠지고 있었다.**

### 계열 C — nu=16 고정 · nv만 올린다 (종횡비 스윕) **[결정적]**

```
    16×3  3.000   2048   4.382   76.20%
    16×5  1.500   2074   4.382   43.71%
    16×9  0.750   3988   4.382   13.80%
   16×17  0.375  11643   4.382    5.59%   ← ±10% «안»
   16×33  0.188  42266   4.382    4.77%   ← ±10% «안»
```

**`nu`를 전혀 안 바꾸고 `nv`만 올려 오차를 76.20% → 4.77%로 떨어뜨렸다.**
`ke/B = 4.382`가 계열 C 내내 **고정**임에 주목 — 결손 교정은 nu의 함수라 여기서 상수다.
즉 **이 개선은 교정이 아니라 순수하게 종횡비에서 온다.**

> **⟹ 지배 변수는 «원소 종횡비 dv/du»다.**
> 통과 대역은 **dv/du ≲ 0.4**이고, 교차는 0.375(5.59% PASS)와 0.75(13.80% FAIL) 사이다.
> 종횡비 0.188에서 **4.77%**로 평탄해지므로 **바닥이 문턱 «아래»에 있다.**

## §2 세장 시편 «추가» — **세장비는 지배 변수가 «아니다»**

등록 장면은 `L/W = 2.5`인데 ASTM D1388 시편은 25×200 mm(`L/W = 8`)다.
참값(선형보)이 세장비를 요구하는지 확인하려고 **장면을 «추가»했다**(등록 장면은 유지).
`δ/Leff`를 5~6%로 맞춰 소변형 대역을 지켰고 **원소는 정사각(종횡비 1)**으로 잡았다.

```
   물성   L(mm)   W(mm)  L/W   nu×nv  dv/du    sub   δ/Leff      오차
  paper    55.0    6.88  8.0    25×4  1.000   5969   5.66%   26.04% → FAIL [2배 수렴차 0.318%]
  alu      38.0    4.75  8.0    25×4  1.000   7270   5.52%   26.06% → FAIL [2배 수렴차 0.318%]
```

**세장비를 2.5 → 8로 3.2배 올려도 오차가 26%로 계열 A(종횡비 1)의 대역에 그대로 앉는다.**
그리고 **paper와 aluminium이 26.04% / 26.06%로 «같은 값»**이다 — 물성(B가 4.2배 차이)이
바뀌어도 오차가 안 변한다. ⟹ **순수 이산화/기하 효과이고, 지배 변수는 종횡비다.**

**⟹ 갈래 A(시험 설계 문제) 불성립.** 등록 장면의 `L/W=2.5`가 원인이 아니었다.

## §3 시뮬 «수렴 형상»의 이산/연속체 에너지 비 — **(다) 확인됨**

연속체는 시뮬 형상의 중앙 행에서 곡률을 유한차분으로 뽑아 `∫½BWκ²dx`.
**교정된 `ke`로 계산했으므로 «1.0이면 이산 = 연속체»**다.

```
   nu×nv   해석형상비   시뮬형상비   뿌리절반   자유단절반
    12×3     0.22002     0.74058    0.74870     0.57856
    32×3     0.23952     0.55836    0.55724     0.60068
    21×9     0.23375     0.91502    0.91413     0.94251
```

**시뮬이 실제로 앉은 형상에서 이산 에너지가 연속체보다 «낮다»** — 21×9(종횡비 1)에서
8.5% 낮고, 32×3(종횡비 6.2)에서 **44% 낮다**. 처방(해석) 형상에서는 교정 후 1.0이
되도록 맞췄으므로, **이 차이가 곧 「시뮬이 이산 모델에서 «싼» 형상을 찾았다」는 증거**다.
⟹ **(다) 기울기 불일치 확인.** 그리고 **그 크기가 종횡비의 함수**다(0.915 → 0.558).

**뿌리/자유단 분리 — v3-06 §7-1의 「클램프 경계」 가설은 «약화»된다**:
뿌리 절반과 자유단 절반의 비가 서로 크게 다르지 않다(12×3에서 0.749 vs 0.579 —
오히려 **자유단이 더 나쁘다**. 32×3에서 0.557 vs 0.601, 21×9에서 0.914 vs 0.943).
**뿌리에 국한된 현상이 아니다.** ⟹ 클램프 모델링은 1순위에서 내린다.

## §4 갈래 판정 — **G (주) + C·D (종횡비 ≥ 1 대역)**

| 갈래 | 성립? | 근거 |
|---|---|---|
| A 세장 장면 ±10% 통과 | **불성립** | 26.04 / 26.06% FAIL. 세장비는 지배 변수가 아니다 |
| B 계열 A가 0으로 수렴 | **불성립** | 20.81%에서 멈춘다(정점 47배에 오차 1.4배 감소) |
| **C 계열 A가 0 아닌 바닥** | **성립(대역 한정)** | 종횡비 1에서 **20.81%** |
| **D 시뮬 형상 비가 크게 다르다** | **성립** | 0.915(종횡비1) ~ 0.558(6.2) vs 처방 기준 1.0 |
| E 서브스텝 미해상으로 계열 불가 | **불성립** | 2배 수렴차 0.239% · 0.318% |
| F 판정창 이탈 부수 결과 | **성립(부수)** | 계열 C의 16×9(13.80%)가 「종횡비 ≲0.4면 통과」 서술의 창 밖이다 — 교차가 0.375~0.75 사이임을 명시한다 |
| **G A와 C가 대역별로 갈림** | **성립(주)** | **종횡비 ≲0.4 → 통과(5.59·4.77%) · ≳1 → 실패(20.8~93.1%)** |
| H 판정 불가 | — | G로 적힌다 |

**주 판정 = G.** C·D는 **「종횡비 ≥ 1 대역」의 서술**이고, 대역을 낮추면 **둘 다 사라진다**.

> **C의 «결론»은 채택하지 않는다.** 갈래 C의 문언은 「힌지 모델의 일관성 문제 ⟹
> 이차형(Bergou) 재검토가 열린다」인데, **종횡비를 낮추면 같은 힌지 모델이 ±10%를 낸다**
> (4.77%). 모델의 한계가 아니라 **메시 조건**이다. **이차형 검토는 열지 않는다.**
