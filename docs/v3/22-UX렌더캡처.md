### §0-3 ㉡ 렌더 — 정착 상태를 «읽기 전용»으로 표시

```
 기존 **C-브라우저 정착 blob 3종**(gray d9 · swim d10 · sweat d9)을 **주입**해 표시한다.
 **물리 실행 0프레임.** v2 제품 렌더러는 건드리지 않는다 — `?v3=1` 패널 안의 **별도 씬**.

 **무변조 판정**(clean-render 함정 · 등재분)
   렌더 «전» 상태 blob sha256 **=** 렌더 «후» sha256 — **렌더가 상태를 한 비트도 바꾸지 않는다.**
   렌더 층이 하는 보정(노멀 재계산 · 스무딩 셰이딩 등)은 전부 **«렌더 기여»로 목록화**한다 —
   뒤 판이 **화면 결함을 물리로 오귀속**하지 않게 하기 위해서다(등재된 함정).
```

### §0-4 ㉢ 캡처 — **CC 자체 화면 판정 0**

```
 **3종 × 3방향 = 9장.** 각 장에 **원단·해상도·프레임·blob sha 앞 8자**를 파일명으로 표기.
 **캡처 파일 경로와 재현 절차**(URL · 주입 파일 · 조작 순서)를 보고서에 **명기**한다 —
 사용자가 같은 화면을 **직접 띄울 수 있어야 한다**.
 **CC 는 화면의 좋고 나쁨을 판정하지 않는다.** 캡처와 재현 절차만 낸다.
 방향은 **등재된 3뷰 프리셋**(`front` · `sideXplus` · `back` · `scripts/v3Render.ts` VIEWS)을 쓴다 —
 v3-19 이래 모든 캡처가 그 구도다. **프리셋을 바꾸지 않는다**(바꾸면 회차 간 대조가 끊긴다).
```
