사용자가 「매끈」이라 한 sweat 가 평면 벌에서 이미 계단 **0.392** 로 나머지의 **절반 이하**다 —
계단 채널이 사용자 판정과 **같은 순서**로 정렬한다. 보간을 켜면 각짐이 **36 · 34%** 준다.
**이것은 판정이 아니다.** 다음 판이 표시 층을 열 때 쓸 값이다.

**왜 C 가 아닌가.** C 의 조건절(「어느 쪽도 절반을 못 가른다」)은 문자 그대로 충족된다.
그러나 C 가 이름 붙인 상태는 **ㄷ = 「두 성분이 겹친다」**이고, 같은 측정이 그 전제를 반증한다 —
**ㄱ 은 0%**, ㄴ 은 19~29% 이며, **71~81% 를 두 가설 어느 쪽도 아닌 제3 기전이 지고 있다.**
C 라고 답하면 「두 성분이 겹쳐서 안 갈린다」로 읽히는데 실측은 「두 성분 다 아니다」다.
그래서 **갈래에 없는 결과 = 판정 불가(E)** 로 적고 정지한다(CLAUDE.md 회차 상시 규약).

**정지한다.** 수정 착수 0 · 다음 수 제안 0 — §0 대로 귀속으로 끝낸다.
