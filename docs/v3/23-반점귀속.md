## §0 판정 기준 — **실행 «전»에 등록**

> 이 절을 커밋한 «뒤»에만 계기·시험으로 간다. 이후 결과를 보고 어떤 수도 고치지 않는다.

### §0-1 배경 — 사용자 화면 판정 «불합격»(수령분)

```
 (주) **sideXplus 어깨~소매 캡 대역의 몸색 반점** — 3종 전부 같은 대역
 (부) **back 뷰 어깨 구김의 각진 느낌** — gray · swim (sweat 는 매끈)
 이 판은 **귀속»만** 한다. 결과에 따라 다음 판이 «표시 층»이냐 «물리»냐로 갈린다.
```

    거의 평행(edge-on)이라 투영 폭이 **픽셀 미만** ⟹ 커버리지 구멍으로 뒤의 팔이 점점이 비친다.
