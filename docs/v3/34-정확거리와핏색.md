### §0-1a **CC 의 구현 판단 1건 — 집행 «전»에 등재한다**

```
 §0-1 의 처방은 「거리 = **three-mesh-bvh** 최근접점 질의」다. **CC 는 그 대신
 `src/v3/instruments.ts` 의 `exactBodyDist` 를 쓴다.** 이유를 먼저 적고 집행한다(사후 정당화 아님):

     **G1 이 v2 임포트를 0 으로 잠갔다**. v3 안에 BVH 를 새로 세우면 **같은 양의 세 번째 구현**이 된다.
  ㉢ `exactBodyDist` 는 **정확 거리**다(격자는 «후보 좁히기»일 뿐 값은 브루트포스와 같다 —

```

```
 영향을 받는 것은 **「SDF 값을 «거리»로 직접 읽는」 채널**이고, 그것이 곧 이 판의 리포트 층이다.
```

### §4-1 이 판이 «닫은» 것 / «연» 것

```
 닫음  **포화는 풀린다** — 정확 거리로 바꾸면 허리 중앙이 8.90(상한) → **28.65~51.86mm** 실값이 된다
       **부호 논증이 성립한다** — 게이트가 관통 ≤ 0.5mm ≪ 밴드를 보장하므로 밴드 밖은 «+» 확정
       **부호 일치율 100% · 눌림 3종 전부 0** — 신·구 채널이 «안/밖»에서는 한 점도 안 갈린다
       **게이트는 무영향** — ③a 는 정확 거리로 판정하고 SDF 는 39.5mm 거르기에만 쓴다(§2-2)
       **불일치의 자리** — 잡음 초과가 **밴드 가장자리(6~8.9mm)에 몰린다**(19.5~88.9%)

       **2mm 경계의 1~4정점 흔들림을 어떻게 처분할 것인가**(§4-2)
       **색 · 캡처 · 4/5 완결** — 전부 다음 판
```
