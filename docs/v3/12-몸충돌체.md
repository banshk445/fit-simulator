## §2 설계 결정 5건

### 1. 표현 — **복셀 SDF** (메시 질의 아님)

S3의 해석 충돌체는 `sdf(c,x,y,z,out) → 부호 있는 거리` **하나**의 인터페이스로 들어온다
(`solver.ts` `Collider`/`sdf`). 복셀 격자는 그것을 그대로 만족하면서 질의가 O(1)이고,
무엇보다 **부호 문제를 「굽는 단계 한 번」으로 국한한다.** 메시 질의로 가면 매 질의마다
부호를 정해야 하고(최근접 면 법선은 모서리·오목부에서 뒤집힌다 — v1 Stage 1a 부호 모순
2.95%), 서브스텝이 **1211**인 이 솔버에서 그 비용과 위험이 «매 질의»로 곱해진다.

### 2. 격자 간격 — **도출**(손 상수 0)

```
band   = thickness + 2h          (접촉 판정 띠 + 삼선형 스텐실)
margin = band + 2h
n_k    = floor((L_k + 2·margin)/h) + 1
메모리 = 4 bytes × nx·ny·nz  ≤  예산       ⟹  h는 이를 만족하는 «가장 작은» 값
```
패딩이 h에 의존해 닫힌 형식이 아니므로 이분 탐색으로 푼다 — 값은 여전히
**예산·두께·몸 크기에서만** 나온다.

**예산의 근거**: 이미 상주하는 GLB 자산이 **36.8 MB**다. 그것이 근사하는 대상보다 더 큰
SDF는 정당화되지 않으므로 **그 위의 2의 거듭제곱 = 64 MB**를 상한으로 둔다.

```
⟹ h = 3.951 mm · band = 8.902 mm · 격자 459×456×80 = 1.674e7 복셀 · 63.9 MB
```

**h ≤ 두께는 원리적으로 불가능하다** — 이 몸 bbox(0.886 m³)에서 h=1mm면 **3.30 GB**다.

```
 h[mm]     복셀수      메모리
  1.00   8.860e+08   3379.7 MB   ← 불가능
  2.00   1.107e+08    422.5 MB
  3.95   1.674e+07     63.9 MB   ← 채택
  8.00   1.730e+06      6.6 MB
```

**그러므로 h > 두께를 받아들이고 «오차를 정량화»한다.** 삼선형 보간의 주 오차항은
곡률에서 온다: `ε ≈ h²/(4R)`.

```
 h=3.951mm  R=40mm → 0.098mm (두께의 9.8%)   R=20mm → 0.195mm   R=10mm → 0.390mm
```
티셔츠의 접촉 대역은 몸통·어깨·상완(R ≳ 40mm)이다. 손가락·코(R≈10mm)는 접촉 대역이 아니다.

### 3. 부호 결정 — **레이 패리티**

§1이 원본을 **수밀**로 실측했으므로(χ=2 · 종수 0) 패리티가 **원리적으로 정확**하다 —
근사가 아니다. 최근접 면 법선(모서리에서 뒤집힘)도 winding number(전 삼각형 순회로
가장 비쌈)도 필요 없다. v3-10 §1-1 표의 후보 3종 중 **레이 패리티의 실패 조건(비수밀)이
이 입력에서 성립하지 않는다**는 것이 §1의 결과다.

**이 몸에서의 실패 위험**: 격자 노드가 메시의 정점·엣지에 «정확히» 얹히면 교차가 두 번
세어져 패리티가 뒤집힌다. 측도 0이지만 격자는 규칙적이라 무시할 수 없다 ⟹ §3-③이
독립 방법과 교차 검증한다.

### 4. 몸이 바뀌면 — **재굽기 비용만 잰다**(캐시 정책 미정)

§3-⑤에서 굽기 시간을 잰다. **이 판에서 캐시 정책은 정하지 않는다**(프롬프트 조항).

### 5. 격자 밖 — **「밖(자유 공간)」으로 간주** · 외삽 0

`sampleSdf`가 격자 밖에서 `band`(양수)를 돌려준다 ⟹ `d ≥ 0`이라 해소가 **아무 일도
하지 않는다.** **흡착이 아니라 «충돌 없음»이므로 절대 조항에 저촉되지 않는다** —
`resolveCollisions`의 `if (d >= 0) continue;` 가드가 그것을 값으로 보장한다.

## §1 문턱 재도출 — 유도에서 · v3-13 실측을 «보지 않고» 고정

**유도**: [0,h]에서 f의 선형 보간은 `L(t) − f(th) = (f''h²/2)·t(1−t)`이고 t=½에서 최대
`f''h²/8`이다(f''>0이면 보간이 «과대평가»). 삼선형은 축 3개의 1차 오차 합이므로 최악
셀 위상에서 `d̃ − d = (h²/8)·∇²d`. 표면에서 `∇²d = κ₁+κ₂` 이므로

```
P_pred = (h²/8)·(κ₁+κ₂)        구 h²/(4R) · 원기둥 h²/(8R) · 평면 0
```

천 정점은 `d̃ = 두께`인 자리에 앉으므로 **관통 = 보간 오차 그 자체**다. 즉 P_pred는 이
표현의 **원리적 하한**이고, **1µm 문턱은 해석 SDF(오차 0)에서 나온 값**이라 이 표현에
요구할 수 없는 정확도였다. 문턱 재도출은 «완화»가 아니라 **정의역 정정**이다.

**사전 등록**(순서: 아래를 «먼저» 고정하고 §3이 판정한다):

```
문턱      관통 ≤ P_pred × (1 + 0.25)          — 고정 상수 아님. 예측값의 함수다
여유근거  버린 다음 항이 P_pred 대비 O(h·κ) = h/R. h=3.951mm에서 h/R ≤ 0.20 ⟺ R ≥ 19.8mm
유효범위  R ≥ 20mm (더 뾰족한 특징은 §2-③ 소관)
일치조건  실측 / P_pred ∈ [0.5, 1.25]         — 「작다」가 아니라 「설명된다」
  상한 = 문턱과 같다(그 위는 설명되지 않는 초과분)
  하한 0.5 = 접촉 정점이 수백 개면 셀 위상 t_k가 조밀히 표집되므로 최댓값이 최악
            위상값의 절반에는 도달해야 한다. 훨씬 작으면 곡률 기전이 지배적이지
            않다는 뜻이고 「설명된다」를 주장할 근거가 없다(작다고 통과시키지 않는다)
평면      P_pred = 0 ⟹ 비가 정의되지 않는다 ⟹ 관통 = 0 을 «정확히» 요구
```

**미채택 등재(전략 세션 처분)**: (b) 곡률 보정 — `R_local`을 격자 라플라시안에서 뽑으면

상완은 반팔 소매 접촉 대역이며 원기둥형이라 **S3 ①의 원기둥 시험을 실제 몸에서 반복**하는 셈이다.

> 장면을 두 번 고쳤다(둘 다 실측으로): 어깨 «위»에 얹은 판은 **미끄러져 떨어졌다**
> (접촉 0 · |v| 1765mm/s — 어깨 경사가 μ=0.3의 임계각보다 가파르다). 그 다음 상완 판은
> z 중심을 +0.02로 잡아 **팔 옆으로 흘렀다**(접촉 0) — 메시에서 팔의 실제 z 중심이
> −0.038임을 확인하고 맞췄다. **초기 적법성은 매번 확인**했다(정확한 메시 거리 최소 62.47mm).

```
 정점 225 · sub 236 · T 3s · |v|max 0.12mm/s(정착) · 접촉 정점 135
 관통 정점 69 · 최대 관통 0.3581mm
 P_pred(접촉점 최대) 0.1620mm · 문턱 0.2025mm       ⟹ 문턱 FAIL
 실측 / 예측 = 2.211  ∉ [0.5, 1.25]                 ⟹ 일치 FAIL
```

**해석 0.982 vs 실제 몸 2.211.** 같은 h·같은 코드·같은 문턱인데 **2.25배 갈린다.**

**차이의 크기와 부호**: 실측이 예측보다 **크다**(+0.196mm = 예측의 +121%). 부호가 «크다»
쪽이므로 **알려진 기전으로 설명되지 않는 초과분이 존재**한다.

**후보(단정 0)** — 해석면과 실제 메시의 차이는 «면분할»이다. 몸 메시는 엣지 중앙 12.43mm의
**평면 조각들**이고, 조각 경계마다 거리장에 **크레이스(기울기 불연속)**가 생긴다. 삼선형은
크레이스에서 O(h²)가 아니라 **O(h)**다 — v3-13이 뚜껑 있는 원기둥 모서리에서 **28.30% of h**로
이미 특성화한 바로 그 기전이다. 매끈한 해석 구·원기둥에는 크레이스가 없고 실제 메시에는
있다는 점이 **대역 갈림(갈래 I)의 방향과 일치**한다. **확인은 다음 판**(#30).
