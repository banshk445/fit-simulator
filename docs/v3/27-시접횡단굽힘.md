### §0-1 배경 (전략 세션 판정 수령분)

```

 시접을 «가로지르는» 굽힘 결합이 0 이라면, 두 패널은 rest 2mm 만 지킨 채 **자유 회전**한다.
 실물 재봉선의 **회전 연속성이 결핍** ⟹
   · 시접선 집힘(농축 **1.6~2.4배** · v3-44 ㉡4)
   · 소매 텐팅(상위 5%의 **50~58%** · v3-44 ㉡2)
   · 뒤 암홀 쐐기(**6~9mm** · v3-45 §2-1)
   · 코너 확폭(**8.09mm** · v3-44 ㉠1)
 가 **한 결핍으로 설명**된다.
 이는 **보조 힘이 아니라 «결핍 물리의 보충»**이며, 상수는 전부 기존 등재분에서 온다
 (**원단 자신의 B · 휴지 기하 — 새 수 0**).
```

### §0-3 ㉡ 구현 — 시접 «횡단» 굽힘 요소

```

   강성  = **그 원단의 B**(등재 물성 · v3-13 원칙 재사용: 「이음선을 원단보다 뻣뻣하게 만들지 않는다」)
   휴지각 = **휴지 기하에서 도출**(평평한 패턴 두 장 ⟹ 패널 내부와 «같은 도출식»)
   **새 수 0.** 시접 rest(SEP)·자기충돌·기타 물리 전 항목 **무변경**.

```
