## §1 굽힘 구현 — 힌지형 (이차형 미구현)

`src/v3/solver.ts`에 `BendConstraint` · `makeBend` · `dihedral` · `projectBend` 추가.

**컴플라이언스 유도**(ARCSim `physics.cpp:113-129`):

```cpp
double shape = sq(edge->l)/(2*a);              // a = adjf[0]->a + adjf[1]->a
return ke*shape*sq(theta - edge->theta_ideal)/4;
```

⟹ `E = ke·l²·(θ−θ₀)²/(8a)`. XPBD 제약 하나의 에너지가 `C²/(2α)`이고 `C = θ−θ₀`이므로

```
1/(2α) = ke·l²/(8a)   ⟹   α = 4a/(ke·l²)
```

`shape = 4a/l²`를 정지 2D 좌표에서 미리 접고 `α = shape/ke`로 쓴다.
`l`·`a`는 **정지 2D 좌표(restUV)에서 직접 뜬다** — 별도 배열을 만들지 않는다(함정 12).

**정지 각도는 0**으로 둔다(2D 제도가 평면 · v3-01 §3). 그 전제를 실측으로 확인한다(①).

**이차형(Bergou)은 구현하지 않았다.** 사유: v3-01 §3이 「데이터의 방향·곡률 의존을
버려야 쓴다」로 대가를 이미 확정했고, 이는 ⓐ 채택과 **같은 논리**(데이터를 살린다)다.
비교하려면 데이터 손실을 값으로 재야 하는데 그것은 별도 판이다.
⟹ **§6 #9를 「측정 대기」에서 내리고 「미구현 · 사유 등재」로 바꾼다.** 설계 개정 4에 반영.

**자기검사(상시)**: `∇θ`를 유한차분과 대조한다. XPBD는 `Δx_i = w_i·Δλ·∇C_i`이므로
모든 성분에서 `Δx_i/w_i`가 **같은 배율로** `∇θ_i`와 일치해야 한다. 배율을 최소제곱으로
뽑고 잔차를 본다 — **12성분 최대상대오차 1.22e-9.** 기울기는 맞다.

### §2-A' 원인 특정 ① — 순수 굽힘 «에너지» 교정 **[신규 계기]**

연속체 `½·B·κ²·A`와 직접 비교한다. 비가 1이면 `ke`가 곧 굽힘강성 B다.

**비가 `¼·(1−1/(N−1))`과 «자릿수 전부» 일치한다** — 괄호는 힌지가 없는 경계 엣지의

> **⟹ ARCSim 에너지 `E = ke·l²θ²/(8a)`의 굽힘강성은 `B_eff = ke/4`다.**
> **`ke`를 B로 그대로 넣으면 4배 무르다.**

**각도 규약 차이가 아니다.** ARCSim `dihedral_angle`(`geometry.cpp:249-262`)은
`theta = atan2(dot(e, cross(n0,n1)), dot(n0,n1))` — 면 법선 기반이고 평면에서 0으로,
우리 구현과 **같은 규약**이다. §0이 읽어낸 `alpha = curv/2 = κ/2`가 이 계수 4의 자리다
(에너지가 θ²에 비례하므로 곡률 절반 ⟹ 계수 4).

## §3 신규 관측 — **결합 제약계의 «정지 해»가 서브스텝 수에 의존한다**

이 판에서 가장 중요한 발견이다. **S1 게이트 ③이 원리적으로 못 보는 축**이다.

③은 제약이 **1개**인 계(단일 스프링)에서 잰다. 제약 1개는 항상 정확히 수렴하므로
**서브스텝 불변성이 자명하게 성립한다** — v3-02가 sub 1~64에서 `|Δx−mg/k| < 3e-13`을
얻은 것은 이 자명함의 확인이었다.

결합계에서는 다르다. 아래는 인장 사슬(k사용=2000 · F=4N)이고,
**전부 잔류속도 1e-12 이하 = 완전 정착한 부동점**이다.

```
사슬 길이 의존 (sub=16 · T=10s)
  ny= 2 (사슬  1칸) λ=1.00973355 k실측/k사용=1.0125 잔류=3.3e-16
  ny= 3 (사슬  2칸) λ=1.01029051 k실측/k사용=0.9569 잔류=8.2e-16
  ny= 5 (사슬  4칸) λ=1.01308298 k실측/k사용=0.7496 잔류=1.2e-13
  ny= 9 (사슬  8칸) λ=1.02529340 k실측/k사용=0.3808 잔류=1.7e-13
  ny=21 (사슬 20칸) λ=1.12157899 k실측/k사용=0.0691 잔류=2.7e-13

서브스텝 의존 (ny=21 · T=60s)
  sub= 16 λ=1.12157899 k실측/k사용=0.0691 잔류=2.1e-13
  sub= 64 λ=1.01572580 k실측/k사용=0.6212 잔류=8.6e-13
  sub=256 λ=1.01028971 k실측/k사용=0.9570 잔류=7.3e-12
```

**읽어낸 것 3가지**:

1. **사슬이 길수록 «물러진다».** 20칸에서 실효 강성이 명목의 **6.9%**까지 떨어진다.
   시간을 6배(10s→60s) 늘려도 값이 한 자리도 안 변한다 — **미정착이 아니라 부동점
   자체가 다르다.**
2. **서브스텝을 올리면 회복된다**(0.069 → 0.621 → 0.957). 필요한 서브스텝 수가
   **사슬 길이·강성과 함께 커진다.**
3. **이것이 §2-A의 「해상도를 올릴수록 더 무르다」를 그대로 설명한다** — 외팔보를
   세분화하면 사슬이 길어지고, 같은 서브스텝 예산에서 더 물러진다.

**설계 함의**: 「XPBD는 강성을 dt·반복수와 분리한다」는 주장은 **제약 1개에서 실증됐고
결합계에서는 그대로 성립하지 않는다.** small-steps 논문의 주장은 「같은 총 작업량이면
서브스텝 다수 × 1반복이 낫다」이지 「1반복이 수렴한다」가 아니다. v3는
**서브스텝 예산을 메시의 제약 사슬 길이에 맞춰 정하거나, 서브스텝당 반복을 늘리거나,
사슬을 짧게 만드는 전처리(다중격자·장거리 제약)를 도입해야 한다.**

**⟹ S1 게이트 ③을 「결합계 버전」으로 승격할 것을 제안한다** — v3-02 §3-2가 이미
「시트를 게이트로 승격하려면 단일 평형 경계가 필요하다」고 적었고, 여기에
**해석해가 있는 결합계(균일 인장 사슬)**라는 더 나은 후보가 생겼다.

| [자기검사] ∇θ 유한차분 12성분 | 최대상대오차 **1.22e-9** → OK |
| **① 정지 이면각 최대** | **0.00e+0 rad** (힌지 73개) → **PASS** |
| **② 외팔보 ±10%** | 최고 해상도 nu=32에서 오차 913~2897% → **FAIL** |
| **③ S1 회귀 완전 일치** | 낙하 4.915218750 m = 해석 `½gh²n(n+1)` · 스프링 sub8 0.0196200032 m · sub16 0.0196200106 m → **PASS** |
| **④ ×2 배율 판별** | 실효 = JSON×2 (합성 **2.0000** 정확) · **단 알루미늄 행 1.7273이 판정창 이탈** |

**갈래 = B**(② 실패 · 굽힘 단위 환산 의심 · 원인 특정 · 문턱 조정 0 · 정지).

**갈래 문언과의 불일치를 명시한다**: B는 「②만 실패」인데 ④의 판정창도 1행이 벗어났다.
④의 **실질** 결론은 나왔고(×2 · 합성 행 정확) 이탈 원인도 특정됐지만(미수렴),
**문언상 「②만」은 아니다.** 창을 넓히지 않았다. 이 조합을 F(판정 불가)로 볼지 B로 볼지는
전략 세션의 판단 자리이며, **이 판은 B로 적고 정지한다** — ②의 실패가 주된 것이고
원인이 값으로 닫혔기 때문이다.

**③이 통과한 것이 중요하다** — 갈래 D(굽힘이 기존 제약을 오염)는 **불성립**이다.
굽힘 제약이 없는 장면의 값이 v3-02와 자릿수 전부 일치한다.

> **v3-02 정정 1건**: v3-02 노트의 낙하 실측을 「4.915219 m」로 적었는데 정확한 값은
> **4.915218750 m**이고 해석식 `½·g·h²·n(n+1)`과 **완전히** 일치한다. 이 판의 하네스는
> 참조값을 손으로 적지 않고 **식에서 유도**한다(함정 13). 실제로 1차 실행에서 손으로 적은
> 참조 상수가 틀려 ③이 거짓 FAIL을 냈고, 유도식으로 바꿔 해소했다.
