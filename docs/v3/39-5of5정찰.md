## §2 프린트 UV — **요구 판독**

### §2-1 v3 는 UV 를 **이미 낸다** — 다만 «단위»가 다르다

```
 **낸다**: `garmentScene.ts:352-364` `coons()` 가 패널마다 `uv`(2D 정지 좌표)를 Coons 사상으로 채우고,
   `:682-686` `assemble()` 이 전역 `uv`(`n × 2`)로 모은다. **결손 «없음».**
 **그러나 단위가 «패턴 미터»다** — 제도 좌표 그대로이고 **[0,1] 정규화가 아니다**.
 **v2 프린트 계약**(`src/lib/patternGarment.ts:306-321`) — **패널별 bbox → 공통 `scale` 정규화**:
     scale = max(모든 패널의 max(폭, 높이))
     u = (x − b.xMin) / scale
     v = **1 − (y − b.yMin) / scale**   ← 「패턴 y 는 아래로 증가하므로 뒤집는다(텍스처 위 = 어깨)」
   그 값이 `patternDressCore.ts:1193` → `PatternPreview.tsx:362-372` `geo.setAttribute("uv", …)` 로 간다.
 ⟹ **결손 = «정규화 층» 하나**다(패널 bbox + 공통 scale + v 뒤집기).
   **기하·조립은 이미 있다.** 이것이 §2 의 핵심 사실이다.
```

### §2-2 **정규화 규약의 «성질»**(값으로 특정 · 판정 아님)

```
 · **공통 `scale`** 이므로 **패널 간 «축척이 보존»**된다(패널마다 늘어나지 않는다)
 · **패널별 `xMin`/`yMin`** 이므로 **각 패널이 자기 bbox 좌하단으로 «이동»**한다
   ⟹ **네 패널이 UV 공간에서 «겹친다»**(각자 [0, w/scale] × [0, h/scale] 에 놓인다)
   ⟹ v2 는 **패널별 `map` 을 분리**해 그린다(`PatternPreview.tsx:128` 「앞판 = 대표색 + 가슴 프린트 /
```
