## §0 관측량과 예측 — **실행 «전»에 등록한다**

### §0-1 두 순서가 «다르다» — 그것이 이 판의 판별력이다

```
 ℓ 순서(굽힘 길이 · 주름 파장 지배)   gray 23.30 < denim 27.23 < sweat 30.02 < swim 31.11 [mm]
 k 순서(멤브레인 · 늘어남 지배)       sweat 25.0 < gray 69.0 < swim 209.2 < denim 2027.8 [N/m]
```

**두 순서가 어긋난다**(gray↔sweat, denim↔swim의 자리가 뒤바뀐다). 따라서 관측량이
**어느 순서를 따르는지**가 「무엇이 형상을 지배하는가」를 가른다. 전략 세션은 `ℓ`을 지목했고,
이 판은 그 예측을 **어긋날 수 있는 형태로** 등록한다.

### §0-2 관측량 4종 — 정의를 값으로

| # | 관측량 | 정의(계산 가능하게) | 무엇을 재는가 |
|---|---|---|---|
| **O1** | **밑단 둘레** [cm] | 앞판 밑단 행 + 뒤판 밑단 행을 옆선에서 이어 만든 **닫힌 고리의 3D 폴리라인 길이**. 정지 = 2×품 = 110.0cm | **벌어짐**(텐트형의 크기) |
| **O2** | **밑단 주름 파장** [cm] | 밑단 고리를 호길이로 균일 재샘플(256점) → 축 `(x=0, z=AXIS_Z)`에서의 **수평 반지름 `r(s)`** → `r`에서 **이동평균(창 = 고리 길이/8)**을 뺀 잔차의 **영교차 수 `N`** → `λ = 고리길이 / (N/2)` | **주름 구조** — `ℓ`과 이론적으로 직결되는 채널 |
| **O3** | **몸–옷 간극 중앙** [mm] | 옷 정점 전체의 **몸 SDF 거리**(격자) 중앙값 | **밀착도** |
| **O4** | **접촉 정점 비율** [%] | 몸 SDF 거리 ≤ 2×두께(2mm)인 정점 / 전체 | 밀착도(O3의 짝 · **부분과 전체를 함께**) |

**O2가 「`ℓ`과 이론적으로 연결되는 것」**이다 — 굽힘–중력 길이가 주름 파장을 정한다(설계 R3).

### §0-3 예측 — 관측량별로 «방향»을 적는다

| 관측량 | `ℓ` 가설이 예측하는 순서 | `k` 가설이 예측하는 순서 | 근거 |
|---|---|---|---|
| **O2 파장** | **gray < denim < sweat < swim**(ℓ 순) | **예측 없음** | 파장 ∝ ℓ (설계 R3). k는 파장을 정하지 않는다 |
| **O1 밑단 둘레** | gray < denim < sweat < swim | sweat < gray < swim < denim | ℓ이 클수록 덜 접혀 더 벌어진다 / k가 클수록 덜 늘어나 형태 유지 |
| **O3 간극 중앙** | gray < denim < sweat < swim | 예측 없음 | ℓ이 클수록 몸에서 뜬다 |
| **O4 접촉 비율** | **역순** swim < sweat < denim < gray | 예측 없음 | O3의 짝 |

**억지 예측을 하지 않는다** — `k` 가설이 방향을 주지 못하는 칸은 **「예측 없음」**으로 둔다.

## §0-5 **사전 등록 변경 1건** — `swim`의 상한만 600 → 300 (전략 세션 판단)

**도출 근거는 「정착 프레임 관측 2건」이지 「남은 시간」이 아니다.**

```
 관측된 정착 프레임   sweat 190 · gray 170  ⟹ 170~190 대역에 «몰려 있다»
 ⟹ 원단이 정착 프레임을 크게 바꾸지 않는다는 신호
 swim 상한 300 = 관측 최대(190)의 **1.58배 여유**
```

**바꾸지 않은 것**(한 글자도): §0 관측량 4종 · 예측 · 판정 기준 ㉠㉡ · **denim 상한 600**
(f=175로 이미 판정창에 근접했다) · 원단 4종 · d = 11.0mm · 서브스텝 산정.
**3종으로 줄이지 않는다** — `swim`을 빼면 `ℓ` 최댓값(31.11)이 빠져 폭이 33.5% → 16.9%로
반토막이고 **§0 기준을 통과한 근거 자체가 사라진다.**

**300에서 안 서면 「미정착」으로 적고 갈래 D로 참고 산출한다. 추정 0.**

**집행 방식**(실행 중인 `denim`을 죽이지 않기 위해): `swim`은 상한 600으로 시작하되
**f=300에서 정착 미도달이면 중단**하고, f=300 체크포인트에서 `FRAMES=300`으로 재개해
보고를 산출한다 — **상한 300과 값이 같다**(루프가 한 번도 안 돈다).

## §1 잡음 바닥 (#47)

v3는 결정적이라 같은 입력의 재실행 산포가 0이다 ⟹ **물리를 바꾸지 않는 변경**에서
관측량이 얼마나 움직이는지로 바닥을 잡는다. **서브스텝 2배**를 쓴다 — 정확도 축이지
물리 축이 아니므로 **관측량이 안 변해야 정상**이고, 변한 만큼이 바닥이다.
대상은 가장 싼 원단 `navy-sparkle-sweat`.

```
 서브스텝 2배(130 → 260) · 다른 조건 전부 동일 · `navy-sparkle-sweat`
 관측량            ×1(sub 130)   ×2(sub 260)   **잡음 바닥**
 O1 밑단 둘레        110.40cm      110.40cm       **0.00 cm**
 O2 주름 파장         36.80cm       36.80cm       **0.00 cm**  (영교차 6 = 6)
 O3 간극 중앙         8.902mm       8.902mm       **0.000 mm**
 O4 접촉 비율          23.06%        22.81%       **0.25 pp**
 정착 프레임              190           190        **0**
 비용                14.25 s/f     30.14 s/f     (2.11배 — 서브스텝 2배와 일치)
```

**O1·O2·O3의 바닥은 인쇄 분해능 아래**다. O4만 «문턱 기반 계수»라 0.25pp가 남는다
(2mm 경계에 걸친 정점이 옮겨 다닌다). 정착 프레임도 동일하다.
⟹ **서브스텝은 정확도 축이지 물리 축이 아니다**가 값으로 확인된다.
**바닥이 이만큼 낮으면 §0-4 ㉠의 판별력은 관측량의 «인접 차이»가 정한다.**
