## 1. 처분 — **저장소 추적**(갈래 A · LFS 없음)

```
 blob 5종 **합계 2,550,653 B = 2.43 MB** ≤ **25 MB** ⟹ **`.gitignore` 예외로 저장소에 넣는다.**
 `.gitignore` 는 디렉터리형(`public/v3diag/`)이면 git 이 안으로 내려가지 않아 `!` 예외가 듣지 않는다.
 그래서 **`public/v3diag/*`(내용물 무시) + 5줄의 `!` 예외**로 적었다 — **무시 범위는 그대로**이고
 프로브·중간 blob(`d10-gray-220.bin` 등)은 **계속 무시된다**.
 근거: 재현이 원단당 **61~66분**이라, 파일이 사라지면 3/5 종결 구성이 되살아나지 않는다
 (v3-48 §6-3 한계 **9항**). 이 처분으로 **그 한계는 해소**된다.
```

```
 **두 sha 의 차이** — 파일명·표시에 쓰는 것은 «**페이로드**» sha(4바이트 길이 + JSON 헤더를 «뺀» 나머지)다.
 헤더의 `frame` 은 상태를 재발행하면 바뀌므로, **헤더를 넣고 잰 blob sha 는 파일명에 쓰지 않는다**
 (v3-47 §3-2 등재 규약). 확인은 아래 4절 명령으로 둘 다 뜬다.
```

## 4. 확인 명령

```bash
# 페이로드 sha (파일명·캡처에 쓰는 값) + 헤더
python3 - <<'PY'
import struct, hashlib, json, glob
for f in sorted(glob.glob('public/v3diag/settled-*.bin')):
    d = open(f, 'rb').read()
    hl = struct.unpack_from('<I', d, 0)[0]
    print(f, len(d), hashlib.sha256(d[4+hl:]).hexdigest()[:16],
          json.dumps(json.loads(d[4:4+hl].decode()), ensure_ascii=False))
PY

# blob sha (파일 전체)
shasum -a 256 public/v3diag/settled-*.bin
```

## 5. 재생성 절차 — 파일이 사라졌을 때

**한 원단당 브라우저 단독 61~66분이다.** `d` 와 프레임 수는 아래 값을 그대로 쓴다.

```
 1. npm run dev  →  http://localhost:5173/?v3=1
 2. v3 패널에서  원단 · 프레임 · d  를 아래 표대로 넣고 [실행]
       gray   d 9mm  · 220프레임      swim  d 9mm · 260프레임      sweat  d 8mm · 330프레임
    **단독으로 돌린다**(다른 무거운 작업 없이). 시스템 부하를 전·중·후로 남긴다(#79 · #107).
 3. 끝나면 콘솔에 `[v3] sha256=… frame=… `, `window.__v3s4` 에 게이트 결과가 뜬다.
    **하드 게이트 통과 확인**: `pass: true` · `fails: []`
 4. [상태 저장] → `~/Downloads/v3-browser-<원단>-<프레임>.bin`
 5. `public/v3diag/` 의 해당 이름으로 옮기고 **2절 표의 sha 와 대조**한다.
 **Node 대안**(탭 유실이 반복될 때): `FRAMES=330 FAB=sweat D_MM=8 OUT=<경로> npx tsx scripts/v3Gate.ts`
   — **채널이 다르다**. Node 로 만든 상태를 정본에 넣으려면 **20프레임 blob 브라우저↔Node 비트 대조**를
   함께 등재해야 한다(v3-48 §0-3 조항).
```

### 5-1 재생성이 sha 를 그대로 낼 것인가 — **보장하지 않는다**

```
 **같은 코드·같은 입력이면 같은 값이 나온다**는 것은 v3-37 #71(브라우저 자체 재현성 · 조립 채널이
 리로드를 넘어 동일)까지 확인된 사실이고, **부동소수 결과 전량의 비트 동일성은 이 저장소가
 «장기»로는 확인하지 않았다**(엔진·플랫폼이 바뀌면 갈릴 수 있다 — v2 계열에서 캡처 산출물이
 세션 내 4/5 로 후퇴한 관측이 있다).
 ⟹ **파일을 보존하는 것이 1순위이고, 재생성은 «되살리는 길»이지 «sha 보장»이 아니다.**
   재생성분이 sha 를 못 맞추면 **그 사실을 등재하고 새 sha 로 갱신**한다(추정 0).
```
