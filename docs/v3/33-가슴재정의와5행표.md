## §1 규칙 확정 — **수치 대입 0**

> 구현·실행 «전»에 커밋한다(v3-40 규율 · v3-51 과 같은 순서). **아래에 숫자는 하나도 없다.**

### §1-1 chestY 재정의 — **근거는 «규격 의미론»이지 데이터가 아니다**

```
 **바꾸는 것은 «정의»다.** 옛 정의(「몸통 둘레의 «내부» 최대」)는 **v3-51 §1-3 이 우리가 «가정»한 것**이고,
 v3-51 §3-2 ③ 이 **이 몸에서 그 형태가 없음을 반증**했다.
 **새 정의의 근거는 «의류 치수 규격의 의미론»(ISO 8559 계열) 이다** —
 「**가슴둘레 = 겨드랑이 «밑»의 수평 최대 둘레**」.
 **데이터가 새 정의를 «정당화»하지 않는다** — 데이터가 한 일은 **옛 정의의 반증**뿐이다.
 (이 구분을 명시하는 이유: 결과를 보고 규칙을 고치는 것[함정 14 계열]과 «정의의 출처를 밖에서
  가져오는 것»은 다르다. 출처가 저장소 «밖»의 규격이므로 **사후 조정이 아니다**.)
 **부수 효과 — 팔 배제 기준이 «불필요»해진다**: 정의역이 겨드랑이 «아래»로 잘리므로
 **팔이 평면에 들어오는 대역에서 아예 재지 않는다**. ⟹ **골격 0 · v2 임포트 0**(v3-51 갈래 C 해소).
```

### §1-2 도출 규칙

```
 **기계는 v3-51 §1-1 그대로다**(평면 정확 단면 → union-find 성분 → 축점 몸통 고리 →
 monotone chain 볼록 껍질 둘레 C(y)). **규칙 «절»만 바꾼다.**

 **`Y_ARM`** = `Y_LOW` «위»로 올라가며 단면 성분이 **1 → >1** 로 바뀌는 **«첫» 전이 높이**.
    **가랑이(`Y_LOW`)와 «같은 계열»의 위상 사실**이고, `TOL_SELF` 까지 **이분**한다.
    (아래에서 위로 «첫» 전이를 잡는다 — v3-51 이 «위에서 아래로 첫 성분 ≥3» 을 잡아
     팔 융합 대역을 집었던 것과 **방향이 반대**이며, 그 방향 차이가 규칙 교체의 내용이다.)
 **`chestY`** = **`Y_ARM` 직하의 «순수 몸통 대역» 상단** = **이분 구간의 «아래쪽 끝»**
    (성분이 아직 1인 마지막 높이). **새 수 0** — 이분이 이미 `TOL_SELF` 까지 좁힌 값이다.
    `C_chest` = 그 높이의 몸통 껍질 둘레.
    **규격 의미론과의 대응**: C(y) 가 그 대역에서 «어떻게 움직이든» 정의는 **「겨드랑이 밑」**이다.
    v3-51 §3-1 의 **단조 증가 사실은 「그러므로 최대가 상단에 온다」는 «정합 확인»**이고,
    **정의의 근거가 아니다**(위 §1-1).
 **`waistY`** = 구간 **(`Y_LOW`, `chestY`)** 안 C(y) 의 **«내부» 최소** —
    **v3-51 §1-3 의 원 규칙 그대로**다. **끝에 붙으면 갈래 B**(격자 이웃 비교 · 문턱 0).
```

### §1-3 한계 — **사전 등재**

```
 처진 팔 포즈에서 **`Y_ARM` 이 «해부학적 겨드랑이»보다 낮게 잡힐 수 있다** —
 아래에서 올라갈 때 평면에 **먼저 들어오는 것이 «손끝»** 일 수 있기 때문이다.
 그 경우 `chestY` 는 **실제 가슴보다 아래**가 되고, **둘레는 «작게»** 나온다 ⟹ **보수적 오차**.
 **값으로 확인해 등재한다**: 전이 높이에서 «새로 생긴 성분»들의 **|x| 위치를 인쇄**하고,
 **팔 원위(손·전완)인지 근위(상완·겨드랑이)인지 «사실»만** 적는다. **보정하지 않는다.**
```

### §1-4 5행 표 규칙

```
 **값 c** = 정착 blob 의 **정점별 몸 부호거리**(`sampleSdf(bodyG, ·)`) — **`v3O4` 와 같은 계기**.
   **물리 0프레임**(주입만).
 **국면**(#110 Q1): **눌림 c < 0** · **밀착 0 ≤ c ≤ `SEP`** · **여유 c > `SEP`**.
 **행 5개와 그 정의역**
   ① **목선** = `s4Gate` 가 쓰는 링(`neckF` ∪ `neckB`) — **같은 집합**을 쓴다(함정 12 규범).
   ② **가슴** = **몸통 패널**(front · back) 정점 중 |y − `chestY`| ≤ **d**
   ③ **허리** = 몸통 패널 정점 중 |y − `waistY`| ≤ **d**
   ④ **밑단** = 밑단 사슬(앞판 j=0 행 ∪ 뒤판 j=0 행) — 하네스 `hemIx` 와 **같은 정의**
   ⑤ **소매** = 소매 패널(`slv`) 정점 전량
 **대역 반폭 = 그 원단의 `d`** — **도출 근거**: `d` 는 그 원단의 **격자 간격**(등재 사다리값)이고,
   **표본 한 칸**이다. 대역을 그보다 좁히면 **한 줄도 안 잡힐 수 있고**, 넓히면 **다른 높이가 섞인다**.
   v2 의 ±2.5cm 는 **v2 슬라이스 간격에서 온 v2 문언**이라 v3 에서 쓸 근거가 없다(전략 처방).
   ⟹ **새 수 0**(원단마다 값이 다르고, 전부 등재 사다리에서 온다).
 **행 산출**: **중앙 · p25~p75 · 국면별 개수 · 표본 수/정의역 수**.
 **G5**: 화면이 **경계 `SEP` = 2mm 와 그 도출**(`SEP = 2 × THICK`)을 **스스로 밝힌다**.
 **G6 자기검사**: **같은 blob** 에서 리포트 층의 c 와 `s4Gate` 의 `bodyClearance` 를 대조해
   **최대차**와 **부호 일치율**을 낸다. **v2 의 `sleeveSignAgreePct` 를 대체한다**(#110 Q3).
```
