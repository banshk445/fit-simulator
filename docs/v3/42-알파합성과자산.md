### §0-3a **판정 규칙 — 집행 «전» 확정**(§2 가 요구한 「결정적 지표」)

> **스캔을 돌리기 «전»에 못박는다. 결과를 보고 고치지 않는다.**

```
 자산이 «**그래픽 전용**»이려면 **셋을 모두** 만족한다:
   **㉠ 알파 보유** — 반투명/투명 화소(α < 250)가 **1개 이상**. 없으면 **불합격**(전면 불투명 사진).
   **㉡ 불투명 영역이 «프레임을 채우지 않는다»** — 불투명(α ≥ 250) 화소의 **bbox 가
      프레임의 «가로·세로 어느 쪽도» `PRINT_MAX_FRAME_FRACTION`(= 0.9) 이상을 차지하지 않는다**.
      **문턱은 «새 수»가 아니라 v2 계약의 등재값 «그대로»**(`garmentTextureComposite.ts:109`) —
      「프레임을 거의 채우면 그것은 «옷 사진»이지 «그래픽»이 아니다」는 **같은 판정**이기 때문이다.
   **㉢ 알파 «경계»가 그래픽 윤곽이다** — **프레임 «테두리 1픽셀»의 불투명 비율이 0**.
      («제품 사진»은 옷이 프레임 끝까지 닿거나 배경이 불투명하다. **그래픽»은 테두리가 비어 있다.)
      **새 수 0**(비율 0 = 「하나도 없다」이지 고른 문턱이 아니다).
 **셋 다 만족하는 자산이 «여럿»이면** — **불투명 bbox 가 프레임에서 «가장 작은» 것**을 고른다
   (가장 «그래픽에 가깝다»). **동률이면 파일명 사전순**(결정적 · 임의 0).
```
