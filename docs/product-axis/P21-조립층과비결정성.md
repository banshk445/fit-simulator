## §1 조립 층 전수 점검

### §1-1 조립 층이 채우는 버퍼 — **전량**

| 버퍼 | 무엇 | 패널 수에 열려 있나 |
|---|---|---|
| `panelStarts` | 패널별 시작 오프셋 | ✔ (`panelCounts` 순회) |
| `pos2` | 패턴 2D | ✔ **P20이 고침**(`p<4`) |
| `tris` · `panelTriRanges` | 삼각형 | ✔ **P20이 고침** |
| `uv` | UV(+ 공통 축척 `bbox`) | ✔ **P20이 고침** · `bbox`는 `panelPos2.map`이라 원래 열림 |
| `edgePairs` | 엣지 = **structural 제약 입력** | ✔ **P20이 고침** |
| `mirrorOf` | 미러 맵 | ✔ (P18 미러 표) |
| `necklineRing` | 목선 링 | ✘ 패널 0·1 고정 — **티셔츠 전제**(P19 §6 #5·#6) |
| `seams` · `seamGroups` | 시접 테이블 | ✔ (`draft.seams` 순회 · Map 조회) |
| `shoulderPairs` | 어깨 시접 | ✔ (`kind === "shoulder"` 필터) |
| **`selfCollisionMinDistM`** | 자기충돌 문턱 | ✘ → **P21 수리 ①** |
| **`quality`** | 삼각화 품질 보고 | ✘ → **P21 수리 ②** |
| `positions` | 3D 배치 | ✔ (배치는 §1 P19 장착 표 + `mapTorso`) |

### §1-2 수리 2건

- **① `edgeMinM`** — `Math.min(front, back, sleeve)` 리터럴 3개. **밴드가 빠져 있었다.**
  자기충돌 문턱은 「가장 짧은 엣지 × 0.6」(§3.2)인데 밴드가 더 짧으면 문턱이 **과대**해진다.
  ⟹ 패널 목록에서 도출하도록 바꿨다.
- **② `quality`** — 배열 리터럴 3개. ⟹ `check:pattern`의 **삼각화 품질 게이트가 밴드를
  아예 안 봤다.** 같은 목록에서 내도록 바꿨다.

둘 다 **밴드가 없으면 종전과 같은 값**이다(3개 중 최소 = 3개 중 최소 · 배열 동일) ⟹ 항등.

### §1-3 검색으로 찾은 잔여 — 없음(단, 천장 1건 등재)

`p < 4` 패턴 외에 숫자 리터럴·`length ===`·배열 초기 크기·`slice/subarray` 상한·
미러 하드코딩을 훑었다. **조립 층에 남은 패널 수 고정은 없다.**

**천장 1건**: `pairKey = min·1_000_000 + max` — **총 정점 < 1,000,000**을 전제한다.
현재 5,258이라 문제없고 결함도 아니지만 **한계로 등재**한다.

### §1-4 P18 §4 표에 「조립 층」 절 신설

P18 표는 **소비 층 / 생산 층**만 갈랐고 그 사이의 **조립 층**(패널 배열 → 전역 버퍼)이 없었다.
그래서 P20의 `p<4` 4곳도, 이번 2곳도 표 밖이었다.

```
조립 층 (신설)
  해소  pos2 · tris/panelTriRanges · uv · edgePairs   (P20)
  해소  selfCollisionMinDistM · quality               (P21)
  남음  necklineRing(패널 0·1 고정)                    → 셔츠(P19 §6 #5·#6과 같은 자리)
  천장  pairKey 총 정점 < 1e6
```

### §2-3 **증폭 경로는 값으로 확정됐다**

갈라진 두 실행에서 **세 입력 해시가 전부 같다**:

```
bodyDigest 82e4aa48 · bodyIndexDigest 26e6095d · armDigest 5ebe1e9a   ← 두 실행 동일
cuffArmGirthM  0.26042751797057434  vs  0.26042751797057445   ← **ULP 11**
cuffHalfWidthM 0.17434168234494637  vs  0.17434168234494646
정점            5256                 vs  5258                  ← **2개 차이**
제약            29478                vs  29486
```

**제도의 ULP 차이가 정점 수 ±2로 증폭된다.** 경로:
`girthAtArc(armSection, …)`의 마지막 비트 → `cuffHalfM` → 밴드/소매 세그먼트 길이 →
`sampleBySizeField`의 **`count = max(2, round(total) + 1)`** 정수 경계 → 표본 수 ±1 →
삼각화·엣지·배치·정착 전부.

**`round()` 경계가 증폭기다.** 밴드가 없을 때 이 경계에 걸리는 세그먼트가 하나 적어
기준선 B-2가 정확히 재현되는 것과 모순되지 않는다.

## §3 갈래 판정 — **E (판정 불가)**

| 갈래 | 문언 | 실측 | 판정 |
|---|---|---|---|
| A | 입력이 갈린다 | 세 입력 해시 **전부 동일** — 다만 해시가 **0.01mm로 반올림**하므로 **ULP 동일을 증명하지 못한다** | **가릴 수 없다** |
| B | 입력은 같은데 초기화가 갈린다 | 갈리는 자리는 **초기화가 아니라 «제도»**다(`cuffHalfWidthM`가 이미 다르다) | 불성립(자리가 다르다) |
| C | 입력·초기화 같고 정착만 갈린다 | **형상부터 다르다**(정점 수·제약 수·배치 해시) — 시점만 갈리는 것이 아니다 | 불성립 |
| D | §1 수리가 비결정성을 없앤다 | 수리 후 3회 전부 다르다 | **불성립** |
| **E** | 위 어디에도 안 걸린다 | **A를 가르는 데 필요한 정밀도가 계기에 없다** | **성립 — 판정 불가** |

**갈래 E로 적고 상태를 원문으로 남긴다:**

> 입력 해시 3종(메시 좌표 · 메시 인덱스 · 팔 관절)이 같은 상태에서 **제도값이 ULP로 갈리고**,
> 그것이 `round()` 경계에서 **정점 수 ±2**로 증폭돼 이후 전 단계가 달라진다.
> 해시가 0.01mm 반올림이라 **입력이 ULP 수준에서도 같은지는 확인되지 않았다** —
> 그래서 「제도가 비결정적이다」와 「입력이 ULP로 흔들린다」를 **가르지 못한다.**
> 다음 판이 그것을 가르려면 **반올림 없는 비트 해시**가 먼저다.

**사후 갈래 신설 0.** E는 실행 전에 catch-all로 등재해 둔 것이다.

## §5 남은 것

1. **비결정성의 A/B를 가르는 것** — 선행은 **반올림 없는 비트 해시**(현재 해시는 0.01mm).
   그 다음이 「제도가 비결정적인가 / 입력이 ULP로 흔들리는가」다.
2. **증폭기 `round(total)+1`** — 경계 근처에서 표본 수가 튄다. 이것을 완화할지는
   **문턱·상수 문제**라 별도 판이고, 이 판은 **손대지 않았다**.
3. **긴팔+밴드 실패** — P20 §6-1 그대로 이월(이 판의 표적 아님).
4. **조립 층 잔여**: `necklineRing` 패널 0·1 고정(셔츠와 같은 자리) · `pairKey` 1e6 천장.
5. 이월: 셔츠 · fixture 재생성 · 관통 처방 · 어깨너비 범위 · 캡 높이 붕괴.
