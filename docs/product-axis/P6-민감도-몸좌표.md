# 민감도 등재 — v2 착장 채널은 몸 좌표 0.14mm에 반응한다

**출처**: P5b §1-3 실측 · **성격**: 계기 결함이 아니라 **시스템의 민감도**
**이 문서는 사실만 등재한다. 과거 판정을 뒤집지 않는다.**

## 실측

같은 코드·같은 옷 치수·같은 env(`RINGTOTAL=0`)에서 **몸만** 두 출처로 바꿔 재면:

| 몸 | 출처 |
|---|---|
| 커밋 fixture `9e8b2bf13925` | 과거에 v1 `exportCollision`으로 구운 스냅샷 |
| 라이브 스냅샷 | 지금의 마네킹을 `bodySnapshot.bakeBodySnapshot`으로 구운 것 |

두 몸의 **정점 좌표 차이**(15,882정점 전수 대조):

```
평균 0.021mm · 최대 0.14mm @정점 4767(y 0.805)
```

bbox·topY·centerZ·어깨 핀 간격·정점 수는 **소수 3자리까지 일치**한다. 패턴 구조도
같다(정점 5,244 · 삼각형 9,846 · 시접 240쌍 · 자기충돌 문턱 3.21mm).

그 0.14mm가 채널을 이만큼 움직인다:

| 채널 | fixture 몸 (기준선 A) | 라이브 몸 (기준선 B) | 차 |
|---|---|---|---|
| **자기교차(엣지-삼각형)** | **1889** | **2143** | **+254 (+13.4%)** |
| **밑단 사슬 합** | **112.57cm** | **114.04cm** | **+1.47cm** |
| cov 몸통 | 6.8% (118/1728) | 7.0% (121/1728) | +0.2pp |
| maxSeamGap | 11.14mm | 11.19mm | +0.05mm |
| maxStrain | 2.661 (정점 2146) | 2.662 (정점 2146) | +0.001 |
| Δ20 | 5.16mm | 5.17mm | +0.01mm |
| 관통 | 50 / 5244 | 49 / 5244 | −1 |
| 종료 | DONE f=260 | DONE f=260 | 0 |
| 목선 링 | 61.80cm | 61.78cm | −0.02cm |

**둘 다 재현성이 있다** — 기준선 A는 md5 비트 동일(재생성 20회 이상), 기준선 B는 3회 실행
9채널 일치(P6 §1). 즉 **잡음이 아니라 서로 다른 결정적 상태**다.

## 왜 이것이 중요한가

**기준선 A의 비트 재현성은 「같은 fixture」의 성질이지 «몸에 대한 안정성»이 아니다.**

캠페인은 fixture를 고정한 채 처방을 넣고 채널 이동으로 판정해 왔다. 그 판정의 전제는
「fixture가 고정이면 채널도 고정」인데, 이 실측이 보여주는 것은 **몸이 0.14mm만 달라도
자기교차가 13% 움직인다**는 것이다. 처방이 만든 이동과 이 크기의 이동을 구별하려면
문턱이 그보다 커야 한다.

예: 캠페인 하드 게이트의 `자기교차 ≤ 2266`(기준선 1889 대비 +20%). 몸 0.14mm 차이가
이미 +13.4%를 만든다 — **문턱 여유의 3분의 2를 몸 재현성이 먹는다.**

## 이 문서가 «하지 않는» 것

- **과거 판정을 뒤집지 않는다.** 79회차 이후 판정들은 전부 «같은 fixture» 위에서 났고,
  그 안에서는 여전히 유효하다.
- **문턱을 바꾸지 않는다.**
- 몸 0.14mm의 출처(fixture를 구운 시점 이후 마네킹 코드·모델 변화)를 추적하지 않는다.

## 캠페인 복귀 시 재검토 대상

1. **fixture 고정 = 캠페인 기준선 / 라이브 = 제품 경로**로 갈라 둔 것을 유지할 것
   (섞으면 이 13%가 처방 효과로 오독된다).
2. 문턱의 여유가 **몸 재현성보다 충분히 큰지** 채널별로 다시 볼 것.
3. fixture를 다시 굽는 결정을 하면 **기준선 A 전량이 무효**가 된다 — 별도 판으로 다룰 것.
