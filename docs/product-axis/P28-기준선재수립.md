## §4 부수 등재 3건 (구현 금지)

### §4-1 `excludeArms`의 정의역 — 계기가 대상보다 넓다

`MannequinCollisionMesh.bake`(`src/lib/meshCollision.ts:155~170`)에서
`position`은 `positionAttr` **전량**이고(`Float32Array.from(positionAttr.array)`),
`excludeArms`는 **인덱스만** 걸러 `torsoOnlyIndex`를 만든다.
⟹ 충돌면(앞·뒤판)은 몸통뿐인데 **`bodyPos` 해시는 팔 정점까지 잰다.**
**물리에는 무해**(안 쓰는 정점은 삼각형에 안 들어간다)하나, 해시가 갈릴 때
「몸통이 바뀌었다」로 읽으면 오독이다. **함정 13(한 이름 두 규약) 계열로 등재.**

### §4-2 갈래 G 판정 결과 — **불성립 · 채택**

전략 세션 판정(P27c 캡처 4장): 기본값·가슴 129 **둘 다 파탄 없음** ⟹ **갈래 G 불성립** ·
**roll 규약(bind 기준 최소호) 채택.**
**관측 이월 1건**: 가슴 129에서 **팔 각도가 P6 §2 캡처보다 높아 보인다** — 그러나
**누적곱판 대조군이 없어 미확정**이다(같은 조건의 누적곱판 캡처가 저장소에 없다).
방향은 P27 §1-1이 예고한 대가와 일치한다. **기전 귀속 0 · 처방 0.**

### §4-3 캡처 구도 편차 — 재촬영하지 않는다

P27c: 「착장하기」를 누를 JS 채널이 Chrome **디버깅 인포바 57.5pt**를 띄워 뷰포트가
820 → 762pt(−7.1%)였다. **판정에 무영향**(갈래 G가 이미 판정됐다) ⟹ **재촬영 0.**
