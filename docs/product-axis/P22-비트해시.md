## §1 비트 해시 계기 — 반올림 0

`patternDressCore`의 기존 `digestOf`는 **0.01mm로 반올림**한다(`Math.round(v*100000)`).
그것이 P21이 갈래 A를 못 가른 이유다. 그 옆에 원시 바이트를 세는 해시를 **병설**했다
(기존 해시는 제거 0 · 대조용으로 남아 있다).

```ts
const bitHash = (view: ArrayBufferView): string => {
  const b = new Uint8Array(view.buffer, view.byteOffset, view.byteLength);
  let h = 0x811c9dc5;
  for (let i = 0; i < b.length; i++) { h ^= b[i]; h = Math.imul(h, 0x01000193); }
  return (h >>> 0).toString(16).padStart(8, "0");
};
const bitHashNums = (nums: readonly number[]): string => bitHash(Float64Array.from(nums));
```

`metrics.diag.bits`에 실린다. **인쇄 전용 · 물리 0줄** — 전부 지표 산출 시점에 읽기만 한다
(`subarray`는 뷰이고 복사·변형이 없다).

| 층 | 채널 | 무엇의 비트인가 |
|---|---|---|
| 입력 | `bodyPos` | 굽힌 몸 메시 좌표(`Float32Array`) |
| 입력 | `bodyIdx` | 몸 메시 인덱스 |
| 입력 | `armsAxis` | 어깨·팔꿈치·손·길이 (f64) — **제도가 쓰는 축** |
| 입력 | `armsDir` | 팔 방향 단위벡터 (f64) |
| 입력 | `arms` | 위 둘 합본(P21 `armDigest`의 비트판) |
| 몸 실측 | `armProfile` `slices` `ridge` | 팔 축 단면 전량 · 슬라이스 둘레 · 능선 |
| 제도 | `draftDims` `segLens` `segCounts` | 소맷부리 반폭·여유·팔둘레·캡 등 9값 · 세그먼트 길이 전량 · **표본 수 전량** |
| 조립 | `pos2` `tris` `edges` | 패턴 2D · 삼각형 · 엣지 쌍 |
| 배치·정착 | `placed` `settled` | 3D 좌표(`Float32Array`) |

진입: 콘솔 `[dress·P22 비트]` 한 줄(단계 순서대로) · `window.__fitDebug.dressMetrics().diag.bits`.

## §3 갈래 판정 — **A′**

| 갈래 | 문언 | 실측 | 판정 |
|---|---|---|---|
| **A′** | 입력(1·2)에서 이미 비트가 갈린다 | `bodyPos` 6회 중 5종 · `arms` **6회 6종** · `bodyIdx`만 불변 | **성립** |
| B′ | 입력 동일인데 몸 실측에서 갈린다 | 입력이 이미 갈린다 | 불성립 |
| C′ | 1~3 동일인데 제도에서 갈린다 | 같음 | 불성립 |
| D′ | 1~4 동일인데 조립 이후 | 같음 | 불성립 |
| E′ | 전 단계 동일인데 결과가 갈린다 | 해당 없음 | 불성립 |
| F′ | 6회에서 한 번도 안 갈린다 | 6회 중 6회 갈렸다 | 불성립 |
| G′ | 어디에도 안 걸린다 | — | 불성립 |

**A′ 확정.** 자리를 값으로 적으면:

> 마네킹 포즈가 「준비됨」 뒤에도 계속 미세 이동하고, **몸 메시는 float32 저장이 그 표류를
> 잘라내는데 팔 포즈만 f64로 실려 간다.** 그래서 `armsAxis`가 새 로드마다 달라지고 →
> `armSection` 프로파일 → 제도 `cuffHalfM` → `sampleBySizeField`의 `round(total)+1`
> 정수 경계 → 표본 수 ±1 → 정점 ±2 → 이후 전 단계가 갈린다.
> 밴드 0에서는 그 경계에 걸리는 세그먼트가 없어 대개 흡수되지만, **스냅샷 시점이 이르면
> 몸 메시 자체가 아직 안 수렴해 밴드 0도 갈린다**(§2-4).

`POSE_SETTLE_EPS 1e-4`는 **건드리지 않았다**(A′ 문언 · 회차 조항).

## §7 남은 것

1. **A′의 수리** — fround는 밴드 0을 깼다. 대안 두 갈래:
   (a) 팔 축을 **몸 메시에서** 뜬다(이미 수렴하는 입력) — 값이 바뀌므로 기준선 재수립 판
   (b) 굽기 시점을 결정적으로 만든다 = `bodyReady` 이후 포즈가 실제로 멈췄는지 보는 조건.
   **둘 다 기준선을 움직이므로 사용자 판단이 먼저다.**
2. **밴드 0 착장 실패**(S1 정체 f≈1200 · seamGap 8.8~8.9mm) — 계기 있는 상태에서도,
   fround 상태에서도 관측됐다. **반팔 기본 경로의 실패**라 우선순위가 높다.
3. 증폭기 `round(total)+1` — P21 §5-2 그대로 이월(이 판 미착수).
4. 이월: 긴팔+밴드 실패 · 셔츠 · fixture 재생성 · 관통 처방 · 어깨너비 범위 ·
   `necklineRing` 패널 0·1 고정 · `pairKey` 1e6 천장.
