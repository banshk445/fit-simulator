# 측정 로그

드레이프 개선(A안 → B안 재설계)의 매 단계 실측을 누적 기록한다. 한 실행 =
블록 하나, 파일 끝에 append. 코드 커밋과 구분되도록 이 파일 커밋은
`metrics: <단계명>` 으로만 쓴다.

**측정 하네스 두 종류를 섞지 말 것**

- `npm run sweep:pattern` — 12콤보, 캡슐 충돌만(BVH/자체충돌/스무딩 없음).
  절대값이 브라우저와 구조적으로 다르다. A단계 기록이 이쪽이다.
- `FIXTURE=scripts/fixtures/collision-fixture.json npm run sweep:pattern` —
  브라우저 스냅샷으로 워커 전체 파이프라인 재현(품55/소매통18 단일 조합).
  브라우저 실측과 seamGap/bodyGap이 자릿수까지 일치한다(M0 검증). M1 이후
  기록은 전부 이쪽이다.

스위치: `NEWCORE=1`(암홀 용접+직결 렌더) `FRICTION=1`(SDF 마찰)
`MU=0.4`(마찰 계수) `SIDEDNESS=1`(반평면 클램프 복원) `SMOOTHING=0`(스무딩
끔) `SMOOTH_BLEND=0.3`(라플라시안 blend) `COVERAGE_DUMP=경로`(노출 좌표).

지표 정의는 `src/lib/drapeMetrics.ts` / `src/lib/coverageMetric.ts` 주석 참고.
**지표가 전부 통과해도 화면이 실패할 수 있다** — A-③·C가 그랬다. 최종
판정은 사용자 화면 확인이다.
