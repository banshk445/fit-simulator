# 소매 매개변수화 재설계 (범위 A)

## 문제

armRowFactor가 세 가지 역할을 동시에 하고 있다:

1. 게이트 — row >= ARM_ROWS에서 0이 되어 겨드랑이 아래를 소매에서 제외
2. 윤곽 다듬기 — 소매 끝이 어깨에서 "가시"처럼 뾰족해지는 문제 완화
3. 단면 반경 축소 — 의도치 않은 부작용. 소맷부리 단면이 아래로 갈수록
   쪼그라들어 삼각형 날개가 됨

이전 실험에서 3번만 떼려다 1번까지 같이 떼어, row9~27이 앞뒤 간격
9.68cm로 얼어붙어 옆선에 고정폭 돌출이 생겼다(폐기).

근본 원인: reach(팔 방향 뻗음)가 행에 의존해서, 한 열의 정점들이
팔 축상 서로 다른 위치에 놓인다. 열이 팔에 수직인 고리가 아니다.

## 새 매개변수화

sleeveT (열에서 결정) = 팔 축 방향 위치.  암홀 0 → 소맷부리 1
angle   (행에서 결정) = 팔 둘레 방향 각도. 어깨 능선 0 → 겨드랑이 ARM_ANGLE_MAX

position = anchor
         + armDir * (armLength * sleeveT)                    // reach: 열만
         + radius(sleeveT) * (cos·right + sin·panelSign·up)  // 반경은 열, 각도는 행

row >= ARM_ROWS: 소매 아님. 소매 공식을 적용하지 않는 하드 경계로 분리.
(부드러운 계수로 두지 않는다 — 실수로 함께 사라지는 것을 막기 위해)

## 검증 기준

- 소맷부리 팔 축 거리: col0의 row0~8이 팔 축상 같은 위치
- 단면 원형도: col0의 (최대−최소) 거리가 0에 근접
- 앞뒤 간격: 0 / 0.40 / 1.45 / 2.95 / 4.67 / 6.34 / 7.77 / 8.82 / 9.46
- 몸통 옆선: row9~27이 현재와 완전히 동일 (변하면 게이트 실패)
- 어깨 가시: 어깨~소매 경계에 뾰족한 돌출 없음 (육안)

앞뒤 간격만으로는 불충분하다. 이전 실험에서 간격이 완벽히 일치했는데도
단면 spread는 오히려 악화됐다. 원형도를 함께 봐야 한다.

## 범위 밖

- ARM_ANGLE_MAX (57.6°, 열린 반통) — A 완료 후 재검토
- 암홀 곡선 / 소매산 봉제 — 범위 B
- 옆선 갈라짐(겨드랑이~밑단) — 별도 항목
