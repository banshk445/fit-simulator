### §0-5 판별력 문턱 — **0.01** (집행 «전» 등재 · 출처를 명시한다)

```
 **보존비 ≤ 0.01 ⟹ 그 시험계는 층2 «적격»(수축계)** · **> 0.01 ⟹ 부적격**(그 시험 착수 0 · 사유 등재).
 ★★ **이 0.01 은 v4-04 실측(strip 0.000946 ↔ hinge 1.00)의 «사이»에서 뽑은 수가 «아니다».**
   「수축한다」의 **문면**이다 — 섭동이 **두 자릿수 이상 줄어야** 수축이라 부른다.
   두 실측 어느 쪽에서도 **유도하지 않았다**(함정 36: 판정 집합의 값으로 문턱을 만들지 않는다).
   그 결과로 두 실측이 문턱의 양쪽에 «크게» 떨어져 있는 것은 **사후 관찰**이지 근거가 아니다.
```

**섭동의 «정의»도 집행 전에 못 박는다**(v4-04 와 «같은» 계기를 쓴다 — 회차 간 대조가 끊기지 않게):

```
 섭동 = **자유 정점 «전량»의 x 좌표에 +1e-7 m**(v4-04 `scripts/v4Converge.ts:PERTURB` 와 같은 정의).
 ★ 이것은 **강체 병진**이다 — 고정점도 접촉도 없으면 «중립»일 수밖에 없는 방향이다.
   그래서 이 섭동은 **「그 계가 강체 모드를 구속하는가」를 정면으로 묻는다.**
   정답지 1칸은 고정점이 **0개**이고 구속은 **몸 충돌 + 마찰**에서만 온다 ⟹ 물음이 실질적이다.
 보존비 = (최종 좌표차 최대) / 1e-7.
```

### §0-7 착수 «전» 알려진 사실

```
 · 몸 충돌은 **몸 SDF 격자**가 필요하다(`bakeSdf` 산출 · `GridSdf` = ox·oy·oz·h·nx·ny·nz·band·data).

 · 정답지 1칸에는 **고정점이 0개**다(`assignMassFromMesh(..., new Set())`) ⟹
   **옷을 붙들고 있는 것은 몸 충돌과 마찰뿐**이다. 그래서 ① 의 물음이 실질적이다.
 · 정답지 1칸의 v3 제약은 `[...inplane, ...bends, ...seamCons]` 다. **봉제(`dist`)는 아직 이식 0** ⟹
   이 판의 대조는 **늘어남·굽힘·몸충돌**로 정의역을 «맞춰» 돌린다(v3 쪽도 같은 부분집합).
   **봉제를 뺀 것이 v3 정본 장면과 다르다는 사실을 여기 적어 둔다**(숨기지 않는다).
```
