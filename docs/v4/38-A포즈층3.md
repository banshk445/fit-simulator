## §1-② 규칙 일반화 — **(가) T포즈 동일 + A포즈 5레벨 성립**

**바꾼 것은 한 줄이다**(`src/v3/bodyLevels.ts:142-157` · +10/−2 · 주석 포함) —
허리 최소를 찾는 **창의 상한**을 `chestY` → **몸통 고리가 존재하는 높이 전부**(`y <= yTop`)로 넓혔다.

```
 구 규칙  for (let y = Y_LOW + GRID_M; y < chestY;  y += GRID_M)
 새 규칙  for (let y = Y_LOW + GRID_M; y <= yTop;   y += GRID_M)   ← C 가 유한한 높이만 담긴다(기존 필터 그대로)
```

**유도 근거(몸에서 · 손 상수 0)** — 상한을 `chestY` 로 둔 것은 「팔이 단면에 들어오면 몸통 판정이 흐려진다」는
우려에서 왔는데, `containsAxis` 가 **축점을 품는 고리**만 고르므로 그 우려는 이 코드에서 성립하지 않는다
(`armFirst` 가 그 사실을 v3-52 부터 인쇄해 왔다). ⟹ 정의역을 **몸통 고리가 존재하는 구간 전체**로 되돌린다.
**새 상수 0 · 새 문턱 0**(`yTop` 은 이미 이 함수의 인자다).
