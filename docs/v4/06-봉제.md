### §0-4 시험계의 «정의역»을 집행 전에 못 박는다 (사후 해석 금지)

```
 §1-② 의 세 시험계는 **몸 충돌과 중력을 «공통»으로 포함**한다 — 나열된 것은 «옷 제약»의 부분집합이다:
   ㄱ **늘어남 + 봉제**            (+ 몸 충돌 + 중력)
   ㄴ **굽힘 + 봉제**              (+ 몸 충돌 + 중력)
   ㄷ **늘어남 + 굽힘 + 봉제**      (+ 몸 충돌 + 중력)   ← ③ 이 쓰는 것
```
