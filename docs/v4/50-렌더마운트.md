### §0-3 사전 등재 갈래 (회차 프롬프트 원문 · 사후 신설 0 · 단위 명시)

**★ 단위** — sha 는 **hex 64자** · 바이트는 **B** · 칸은 **칸**.

| 항 | 갈래 |
|---|---|
| **①** 마운트 사실 | **(가)** 자리 특정(파일:줄 · 어떤 상태가 캔버스를 세우는가) / **(나)** 불가 |
| **②** 수정 | 최소 diff · 구판 불변 |
| **③** 검증 | tsc · dev 200 · 가능하면 DOM 캔버스 확인 + 승혁 스모크 재개 |

**§4** — A = ①~③ ⟹ 스모크 재개 / B = 막힘 ⟹ 사실 상신.

### §0-4 사전 결정 4건 (값 보기 «전» · CC 집행 설계)

```
 ㄱ **「캔버스가 없다」를 코드의 «상태»로 번역한다** — 어떤 `useState` 가 캔버스를 감추는지 찾고,
    그 상태를 세우는 경로에서 **어디서 끊기는지**를 줄 단위로 짚는다.
 ㄴ **구판과의 «차이»는 코드가 아니라 자산일 수 있다** — 같은 코드가 T포즈에서 서는지 확인한다.
 ㄷ **자산의 «기록값»이 규약과 다르면 정정한다** — 규약은 **T포즈 정본으로 검증**한 뒤 인용하고,
    blob 바이트는 건드리지 않는다(§0-2 해석).
 ㄹ **폴백 0 을 지킨다** — 대조를 끄거나 우회하지 않는다(그것은 「조용한 성공」이다).
```
