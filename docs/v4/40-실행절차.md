```bash
cd ~/projects/fit-simulator
```

## 1단계 — 수신기 띄우기(터미널 A · 이 창은 그대로 둔다)

브라우저는 자동 다운로드를 막으므로 **산출 바이트는 수신기가 받는다**(v3-86 규약 · sha 대조 후 저장).

```bash
npx tsx scripts/v3Receiver.ts --out gpu/oracle/export/grid27 --n 82
```

- `--n 82` = 27칸 × 3파일(몸 bin · 축 json · 원점 json) + 색인 1 = **82개**를 받으면 **자동 종료**한다.
- 뜨면 이런 줄이 나온다: `수신기 대기 … 127.0.0.1:5199 → gpu/oracle/export/grid27`

**막히면 보낼 것** — 이 명령의 출력 전체(포트 충돌이면 `--port 5200` 으로 바꾸고 CC 에게 알린다).

## 2단계 — dev 서버 띄우기(터미널 B)

```bash
cd ~/projects/fit-simulator
npm run dev
```

출력에 뜨는 주소(대개 `http://localhost:5173/`)를 쓴다.

**막히면 보낼 것** — 터미널 출력 전체.

## 3단계 — 브라우저에서 열기

주소창에 **`?v3=1` 을 붙여서** 연다:

```
http://localhost:5173/?v3=1
```

- 화면 오른쪽/아래에 **V3 패널**이 뜬다. 그 안에 「그리드 몸 굽기(27칸)」 버튼이 있는 줄이 있고,
  **그 바로 아래**에 새 상자가 있다: **「A포즈 그리드 몸 굽기(27칸)」**.
- 화면에 마네킹이 보이는지 확인한다(마네킹이 없으면 굽기가 실패한다).

**막히면 보낼 것** — 화면 전체 스크린샷 1장 + 브라우저 콘솔(⌥⌘I → Console) 스크린샷 1장.

## 4단계 — 굽기 실행(클릭 1번)

**「A포즈 그리드 몸 굽기(27칸)」** 버튼을 누른다. 그 뒤에는 **아무것도 만지지 않는다**
(탭을 다른 창으로 바꾸면 프레임이 멈출 수 있다 — **이 탭을 맨 앞에 두고 기다린다**).

- 버튼 옆에 `3/27 · c100-h170-s45` 처럼 진행이 표시된다.
- 아래 표에 칸마다 한 줄씩 쌓인다: **결과(통과/실패/던짐) · 전진 프레임 · 잔차 · 높이 · 반출(3)**.
- 한 칸에 몇 초씩 걸린다(27칸 × 약 1~3초 + 대기 0.7초).

**막히면 보낼 것** — 표가 보이는 스크린샷 + 콘솔 스크린샷(빨간 줄이 있으면 그 줄 전체).

## 5단계 — 완료 확인

두 가지가 동시에 맞아야 한다.

1. 브라우저: 버튼 옆에 **`완료 — 통과 27/27`**.
2. 터미널 A(수신기): **82개**를 받고 스스로 종료(프롬프트가 돌아온다).

빠르게 세어보려면(터미널 A 가 종료된 뒤):

```bash
ls gpu/oracle/export/grid27 | wc -l        # → 82
```

**막히면 보낼 것** — 위 `ls … | wc -l` 결과 + 브라우저 표 스크린샷.
※ 실패 칸이 있으면 그 칸만 다시 구울 수 있다:
`http://localhost:5173/?v3=1&apoonly=<칸 이름>` 로 열고 같은 버튼을 누른다(수신기는 `--n 3` 으로 다시 띄운다).
