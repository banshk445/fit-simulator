## §4 회차 갈래 — **A**(①(가) + ②③ ⟹ 스모크 재개)

**넘기는 것 6건**

1. ★★★ **캔버스는 «부재»가 아니라 `hidden`** — `V3ProductV1.tsx:414` 의 `hidden={!scened}` 이고
   `scened` 는 워커 `done` 의 **맨 끝**(`:178`)에서만 켜진다.
2. ★★★ **끊긴 자리는 정본 sha 대조**(`:172-176`) — 실패하면 `setErr` 후 `return` 이라
   `setScened(true)` 에 못 간다. 오류는 **화면에만** 뜨고 콘솔엔 안 찍힌다(판정문 「콘솔 무오류」와 정합).
3. ★★★ **원인은 «등재 sha 의 정의»** — 규약은 **blob 헤더 제외 본문의 sha256**(T포즈 정본으로 검증:
   등재 `757d9c9a…` = 본문 sha) 인데, v4-47 색인은 **굽기 산출 파일(위치만)** 의 sha 를 넣었다 ⟹ 33칸 전부 불일치.
4. ★★ **처방은 기록값 정정** — 33칸 sha 재계산 · **대조 재현 33/33 일치** · blob·`src/` **0**.
5. ★★ **코드는 제 역할을 했다** — 「폴백 0」이 작동한 것이고, 대조를 끄지 않았다(§0-4ㄹ).
6. ★ **CC 는 DOM 확인 불가**(브라우저 채널 미연결) ⟹ 3D 표시 여부는 **승혁 스모크**가 판정한다.
