1. ★★★ **배선은 섰다** — `dressRun.ts` +7/−1 로 `armAxis` 가 `createScene` 까지 간다.
   **T포즈 108칸 조립 108/108 · 조립 성공 82/82 비트 동일**(패턴해시 포함) ⟹ 승인 조건 충족.
2. ★★★ **실측 축을 넣으면 소매가 전부 NaN 이다** — `sleeveR` 510 + `sleeveL` 510 = **1,020 정점**(몸통 0 · uv 0).
   ⟹ ②는 **(다) 조립 실패** · 굽기 착수 0 · 캡처 0.
3. ★★★ **자리는 `armProfile` 의 «축 대역»이다**(코드 + 값) — `axDot`(`:661`)은 **세계 원점**에서 잰 투영인데
   대역 경계 `[SW/2+CAP_H, SW/2+SLEN]` 은 **어깨에서 잰 길이**다. 둘이 같은 뜻이 되는 것은 축이 **+x** 일 때뿐.
   A포즈 축에서 대역 안 몸 정점 = **0**(+x 에서는 493) ⟹ `ARM.yc/zc = NaN` ⟹ 소매 전부 NaN.
   기울기 민감도 — 15~20°에서 정점이 **3~4배로 부풀고**(다른 부위를 고른다) **25~30°부터 0**이 된다.
4. ★★ **배치 자체는 «옳은 방향»으로 움직였다** — 소매 반지름 `SLV_R` **178.741 → 56.431 mm**
   (T포즈 정본 61.510 mm 에 근접). ⟹ 축을 넘기는 것이 관찰 ①(가슴 텐트)에 닿는 축이라는 **정황**은 늘었다(단정 0).
5. ★★ **처방은 이 판의 정의역 밖** — 고치려면 `garmentScene.ts`(대역 산정·원통 중심)를 손대야 하고,
   그것은 **v3 동결 예외 대장 확장**(3건째)이 필요하다. §0-2 는 v4-19 상태 유지를 명시했다.
6. ★ **관찰 3건의 자연 실험은 «아직» 서지 않았다** — 화면 기록은 v4-24 캡처가 그대로 정본이다.

**이 판이 하지 않은 판단** — `garmentScene` 수정 여부 · 대역 재정의(어깨 원점 기준) · A포즈 굽기 · 화면.
