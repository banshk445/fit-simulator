### §0-4 사전 결정 4건 (값 보기 «전» · CC 집행 설계)

```
 ㄱ **N 은 «빈 구간»에서 유도한다** — 관측된 두 끝(미달 최대 **1** · 성립 최소 **343**)의 **중점**을 쓴다:
    `N = (1 + 343) / 2 = 172`(정수). 두 끝에서 «가장 멀다» ⟹ 재굽기·재측정에서 흔들릴 여지가 최소다.
    **어느 칸의 값도 아니고**(결과에 맞춘 수가 아니다) 분포의 «틈»에서 나온다.

    **좌우 «합»**(v4-30 계기가 좌우를 가르지 않는다) · 위치는 **제품이 읽는 blob**에서 읽는다.

 ㄹ **강등 칸은 지우지 않는다** — 색인에 **보류 + 사유(값 포함)** 로 남긴다(T포즈 규약 동형).
```
