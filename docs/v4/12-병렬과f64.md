### §0-4 집행 «전» 사전 결정 6건 (값을 보기 «전»에 적는다)

```
 ㄱ **① 「감소 추세」의 정의** — v3 의 모양(f10 1.600e-02 → f60 2.531e-04 = 1/63)에서 «유도»한다.
    (가) = ㉠ net(f60) ≤ net(f10)/10 **그리고** ㉡ f40·f50·f60 이 모두 net(f10) 미만이고 «단조 비증가».
    (나) = ㉠㉡ 중 하나라도 불성립. **30프레임에서 정지한 경우**는 ㉠' net(f30) ≤ net(f10)/3 ·
    ㉡' f20·f30 단조 비증가 로 같은 규칙을 축약 적용하고 «축약했다는 사실»을 등재한다.
    창 순변위 식·N_WIN(10)·창 정의는 v4-10/11 과 **같은 것**을 쓴다(새 수 0).

 ㄴ **① arch 선택 규약** — CUDA f64 와 x64 f64 를 각각 **1프레임** 재고 60프레임 벽시계를 추정한다.
    더 빠른 쪽으로 60프레임을 돌린다. 둘 다 60프레임 추정이 **2시간**을 넘으면 **30프레임**으로 자르고
    그 사실을 등재한다(회차 프롬프트 ★). 폴백이면 `current_cfg().arch` 를 그대로 인쇄해 등재(함정 1).
    ★ f64 실행이 **CPU(x64)** 로 가면 GPU 를 다투지 않으므로 ②③ 과 «동시»에 돌 수 있다 —
      그 경우에만 동시 실행을 허용하고, CUDA 로 가면 v4-11 대로 **줄 세운다**.

 ㄷ **② 대조의 정의** — v3 는 f64 위치를 프레임마다 덤프(`scripts/v4FrameDump.ts` 신설 · 물리 경로 diff 0 ·
    `v4CellConverge.ts` 의 `prepare`·제약 집합 `all`·`params` 를 그대로 인용) · v4 는 같은 blob 을 f32 로
    캐스팅해 **1프레임씩** 덤프. 프레임 f 마다 ㉠ 최대 좌표차(성분 절대차 max · mm) ㉡ 최대 정점 거리(mm)
    ㉢ **중앙 정점 거리**(mm) 를 인쇄한다. **f=0(캐스팅만) 도 인쇄한다** — 이것이 ULP 급의 «척도»다.
    (가)/(나) 의 가름 = **f=1 의 최대 좌표차 ≤ 10 × f=0 의 최대 좌표차** 면 「ULP 급」(가), 넘으면 (나).
    참고 상수(계기 아님): f32 ULP(1.0 m) = 2^-23 = 1.192e-07 m = **1.192e-04 mm**.

 ㄹ **③ 「코드에서 센 수」** — 예측 1 + λ초기화 3 + 늘어남 8색 + 굽힘 14색 + 봉제 1 + 몸충돌 1 +
    속도갱신 1 = **29 / 서브스텝**(v4-10 이 센 수와 같은 정의). ㄱ 은 이 29 와 프로파일러 레코드를
    «같은 판 안에서» 대조한다(함정 42 규범 ①).

 ㅁ **③ 정확도 채널** — 색 순서가 v3 배열 순서와 다르므로 직렬판과 «갈릴 수 있다»(v4-10 §0 등재).
    따라서 ㄴ 은 **판정 0** — 궤적 모양과 리포트 5행을 «값으로만» 적는다. 배수는 **v4-11 §1-① 의
    12.703/12.795 가 아니라 회차 프롬프트가 지정한 12.690**(v4-10 직렬)로 나눈다.

 ㅂ **정지** — ③ㄱ 이 불성립이면 ㄴ 착수 0(회차 프롬프트). 발산·NaN 이면 (라) 로 적고 그 프레임을 등재한다.
```
