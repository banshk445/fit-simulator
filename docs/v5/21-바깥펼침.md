### §0-3 §1-① 형식화 — **값 보기 «전» 등재**(사후 신설 0)

```

    몸 SDF 기울기 단위 `n̂` 을 읽고(이 파일의 `nHat` · S4 가 쓰는 그 중앙차분 · 새 식 0)

    (판정문 「몸 법선 n 의 바깥 + −y 합성」의 직역이다. 능선 꼭대기점은 링의 `|x|` 최대점이므로
     `n̂ ≈ ±x̂` 이고 목선 토막은 `n̂ ≈ ±ẑ` 라 합이 0 이 되지 않는다.)
    `n̂` 이 없거나 `|n̂ + (−ŷ)| ≤ 1e-9` 이면 **`d̂ = (0, −1, 0)`** 로 떨어뜨리고 **그 열 수를 값으로 인쇄**한다.
 ㄴ **펼침 구간 행 범위** — **`N_side < j < nvB`**. 행 `nvB` 는 S1/S2 배치 그대로(봉제선) ·
    **`j ≤ N_side` 는 튜브 스냅숏 그대로**(판정문 「실루엣 튜브 행은 현행」).
```
