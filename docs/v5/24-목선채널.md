```

**ㄷ. ③ `N_sh` 후보와 선택 규칙 — 값 보기 «전» 고정**

```

   ㉢ 높이 걸음 ≤ `d`      : `… , ceil(SH_DROP/d))`           … 가장 약한 상한(대조군)
 ★ 셋 다 **새 수 0** — `SEP`·`THICK`·`d` 는 등재된 양이다.
