### §0-3 사전 등재 갈래 (회차 프롬프트 원문 · 사후 신설 0 · 단위 명시)

**★ 단위** — 목선 값은 **cm** · 높이는 **m** · 교차는 **개** · 어깨 채널은 **정점 개수**.

| 항 | 갈래 |
|---|---|
| **①** 종속 사실 | 목선이 «어느 치수의 함수»인지 코드로 · 4사이즈 값 표 · 두 실측 병기 · **인과를 값으로** |
| **②** 분리 | ①의 사실대로 형식화(상수 / 항목 / **불필요**) · 4사이즈 **4/4 비트 동일** |
| **③** 재시험 | **(가)** pass / **(나)** fail(값) / **(다)** 조립 던짐 |
| **④** 캡처 | v5-3 과 같은 프리셋 |

**§4** — A = ③(가) / B = ③(나)(다) / C = ② 불변 조건 위반 ⟹ 복원 / D = 그 외 ⟹ 정지.

### §0-4 사전 결정 4건 (값 보기 «전» · CC 집행 설계)

```
 ㄱ **「종속」은 코드에서 읽는다** — `NECK_A`·`NECK_G` 가 무엇의 함수인지 식으로 확인하고,
    여섯 옷(차트 4 + 실측 2)에서 **같은 몸**으로 값을 뽑아 «옷 치수의 함수인가»를 값으로 가른다.
 ㄴ **판정문의 전제가 틀리면 그대로 적는다** — 전제를 지키려고 값을 비틀지 않는다(다툼 0 · 사실 병기).
    전제가 틀리면 **분리할 자유도가 없으므로 ②는 「불필요」로 적고 코드를 고치지 않는다**.
 ㄷ **게이트의 「링 cm」는 «정착 후» 양이다** — 패턴 값과 구별해 적는다.
    링이 «어디에» 앉았는지(높이)를 재서 인과 방향(원인 ↔ 결과)을 가른다.
 ㄹ **재시험은 ②가 코드를 바꿨을 때만 의미가 있다** — 안 바꿨으면 v5-3 산출이 곧 결과이고,
    그 사실을 적는다(굽기 예산은 인과 확정에 필요한 경우에만 쓴다).
```
