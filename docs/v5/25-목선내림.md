### §0-5 형식화 — 값 보기 «전» 등재(사후 신설 0)

**ㄱ. ① 채널 내림**

```
 판정 줄(`s4Gate.ts:159-162`)을 **삭제**하고, 그 자리에 「판정 제외 · 값 보고」 주석을 남긴다.
 `S4Result` 의 필드(`ringExcess`·`ringRestRatio`·`ringM`·`ringBodyM`·`ringAllowM`)는 **그대로** 둔다.
 ⟹ 게이트 판정 채널은 **넷**이 된다: ③a 관통 ≤ 0.5 mm · 자기관통 교차 0 · 정착 창 순변위 ≤ 0.1 mm · pinned 0.
 ★ **검증 조건(판정문)** = 「옛 29칸 편입 변동 **0**」.
   이 판이 실제로 확인할 수 있는 정의역 = **정본 정착 blob 이 있는 칸**(v5-24 실측 37칸) ·
   A포즈 29칸은 정본 정착 blob 이 T포즈 계열뿐이라 **재판정 불가**(v5-24 §2ㄹ 와 같은 한정) ⟹
   **37칸으로 확인하고 그 한정을 적는다.**
   ★ **구조적 예측도 함께 적는다**(값 보기 전) — 채널을 «내리는» 것은 `fails` 에서 한 항목을 빼는 일이므로
     `pass → fail` 은 **원리적으로 불가능**하고, `fail → pass` 는 **목선이 «단독» 실패 사유였던 칸**에서만 난다.
     v5-24 는 그 칸이 **0개**라고 쟀다 ⟹ **변동 0 이 예측이다.** 어긋나면 **갈래 C(즉시 정지)**.
```

**ㄴ. ② 분리 플래그 — 「두 줄」의 형식**(프롬프트가 허용한 범위)

```
 타입을 `asm1x?: boolean` → `asm1x?: boolean | 'anchor' | 'drop'` 로 넓히고 **두 줄**을 더한다:
   const A1X = cfg.asm1x === true || cfg.asm1x === 'anchor';   // 앵커만
   const D1X = cfg.asm1x === true || cfg.asm1x === 'drop';     // SH_DROP 만
 그리고 기존 두 자리를 각각 `A1X`·`D1X` 로 바꾼다:
   SH_DROP  = (ASM2 || D1X) ? ASM2_SH_DROP : 0
   Y_ANCHOR = (ASM2 || A1X) ? Y_NECK : Y_TOP
 ★ `asm1x: true` 면 **둘 다 켜져 v5-22~24 와 항등**이다(회귀 없음) · 키가 없으면 off 그대로.
 ★ 네 판본을 f0 로 잰다 — **off · anchor 만 · drop 만 · 둘 다**. 채널 = `back↔back` 최소쌍 · 최악 쌍의
   패널·(i, j)·y · `nuB`/`nvB`/`N_sh` · 던짐 문언.
 ★ **처방 0** — 어느 쪽이 원인이든 이 판은 고치지 않는다(사실만).
```
