### §0-3 사전 등재 갈래 (회차 프롬프트 원문 · 사후 신설 0 · 단위 명시)

**★ 단위** — 실측표는 **cm** · 패턴 상수는 **m**(조립이 받는 단위) · 대조는 **sha256 hex** · 사이즈는 **S·M·L·XL**.

| 항 | 갈래 |
|---|---|
| **①** 패턴 자유도 사실 | 치수 상수 전수(파일:줄·값·소속) · **총 자유도 수** |
| **②** 실측표 사상 | 5항이 «정하는 것 / 못 정하는 것» · 잔여는 **템플릿 상수로 명시**(숨은 상수 0) · 역함수 식 · 4사이즈 왕복 **오차 0** |
| **③** 재현 대조 | **(가)** 4/4 비트 동일 / **(나)** 불일치(사이즈·차이 값) / **(다)** 조립 불가 |

**§4** — A = ③(가) ⟹ 상신(다음 = 임의 실측표) / B = ③(나)(다) ⟹ 값 상신 / C = 그 외 ⟹ 정지.

### §0-4 사전 결정 4건 (값 보기 «전» · CC 집행 설계)

```
 ㄱ **「자유도」의 정의를 지금 고정한다** — 「조립이 **차트/입력에서 받는** 수」다.
    몸에서 도출되는 값(목선·소매산·암홀 깊이 등)은 **자유도가 아니라 «도출량»**이고, 그 사실을 적는다.
 ㄴ **잔여는 «템플릿 상수»로 이름·값을 적는다** — 숨기지 않는다(판정문 조항).
 ㄷ **왕복은 «오차 0»이어야 한다** — 부동소수 반올림조차 없어야 한다(항등 사상이면 그렇다).
    0이 아니면 **사상이 틀린 것**으로 적고 (나)로 간다.
 ㄹ **재현 대조는 조립 산출의 sha 로** — 기존 경로(`prepare`)를 **호출만** 하고, 입력만 갈아 끼운다.
```
