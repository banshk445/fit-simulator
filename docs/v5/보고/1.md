## §1-① 패턴 자유도 사실 — 조립이 «입력으로 받는» 수는 **5개**뿐이다

| 이름 | 뜻 | 출처(파일:줄) | S / M / L / XL [cm] |
|---|---|---|---|
| `L` | 총장 | `grid.ts:11-20` CHART `.L` → `:33` `/100` | **65 / 68 / 71 / 74** |
| `W` | 몸판 폭(= 가슴 단면) | CHART `.W` → `:33` | **48.5 / 51.5 / 54.5 / 58.5** |

## §1-② 실측표 사상 — 5항 중 **4항이 자유도** · 1항은 **종속** · 잔여는 **템플릿 상수 1개**

신설 모듈 **`src/v5/specToPattern.ts`**(기존 파일 diff 0).

```
 L    = totalLength / 100          ← 총장
 W    = chestFlat   / 100          ← 가슴«단면»(패널이 ±W/2 로 그려진다 · garmentScene.ts:422)
 SW   = shoulder    / 100          ← 어깨너비

```

**「밑단단면」의 처분** — 현행 패턴의 옆선은 **직선**이라(`garmentScene.ts:422` `line([W/2, 0], [W/2, Y_ARM])`)

모듈은 그때 **던진다**(조용한 무시 0) — 「A라인 밑단」은 **패턴 자유도 신설**이 필요하고 그것은 다음 판의 재료다.

## §4 회차 갈래 — **A**(③(가) ⟹ 상신 · 다음 = 임의 실측표 판)

**넘기는 것 7건**

1. ★★★ **조립이 받는 자유도는 5개뿐이다** — `L`·`W`·`SW`·`SLEN`·`ARM_G`(`garmentScene.ts:80`).
   차트 원행은 `{L, SW, W, hwa}` **4열**이고 `SLEN = hwa − SW/2`(`grid.ts:33`)다.
2. ★★★ **목선·소매산·암홀 깊이는 «몸에서 도출»된다** — 상수가 아니다(`:234-239`·`:250-263`·`:305`·`:311`·`:316`).
   ⟹ **실측표가 정할 대상이 아니다**(판정문의 「잔여」 우려에 대한 값 있는 답).
3. ★★★ **실측표 5항 중 4항이 자유도와 1:1** — 총장·가슴단면·어깨너비·소매길이 ↔ `L`·`W`·`SW`·`SLEN`.
4. ★★★ **「밑단단면」은 종속값이다** — 현행 옆선이 직선이라 밑단 폭 = 몸판 폭(`:422`).
   달라지면 **던진다**(조용한 무시 0) ⟹ 「A라인」은 **패턴 자유도 신설**이 필요하다(다음 판 재료).
5. ★★★ **템플릿 상수는 «하나»다** — `ARM_G = 0.4439 m`(차트에 없다 · 이름과 값을 모듈에 드러냈다 · 숨은 상수 0).
6. ★★ **왕복 오차 0 · 조립 비트 4/4 동일**(posSha·uvSha) — 사상이 항등임을 값으로 확인.
7. ★ **표시 자릿수 사실** — L 의 가슴단면이 `54.50000000000001` 로 찍히는 것은 m→cm 이진 표현이고,
   왕복은 다시 나누므로 **패턴 상수 차는 0**이다.

**이 판이 하지 않은 판단** — 임의 실측표의 허용 범위 · A라인 등 새 자유도 · 옷 종류 확장 · 굽기.
