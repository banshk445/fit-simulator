### ① 제도 — 어깨 경사 자유도

★★★ **「어깨선이 수평」은 배치가 아니라 «제도»의 성질이다.** `shL = line([−SW/2, L], [−NECK_A, L], N_sh)` ·
`shR = line([NECK_A, L], [SW/2, L], N_sh)`(`garmentScene.ts:416-417`) — 두 끝의 `py` 가 **같다**. 그리고
배치의 수직 사상은 **이미** `y = Y_TOP − (L − py)`(`:602`)로 `py` 를 높이로 옮긴다 ⟹ **제도에 경사를
넣으면 배치가 그대로 «따라온다»**.

★★★ **앵커가 어긋나 있다 — 정정 대상이다.** 실측표 정의는 「총장 `totalLength` **옷을 눕혀 «뒷목
중심»에서 밑단까지**」(`src/v5/specToPattern.ts:6` 원문)인데 코드는 `L = totalLength/100` 을
`Y_HEM = Y_TOP − L`(`:443`)로 **«어깨끝 높이»에 매단다**. 어긋남 = `Y_NECK − Y_TOP` =
**82.2598 mm**(mst-over · SW 52) / **48.5991 mm**(supima · SW 44.5). ⟹ **앵커 정정은 «선택»이 아니다.**
정정 형태 = `y = **Y_NECK** − (L − py)` · `Y_HEM = **Y_NECK** − L` ⟹ 그러면 어깨점의 3D 높이가
`Y_NECK − SH_DROP` 이고 **`SH_DROP = Y_NECK − Y_TOP` 이면 어깨점이 정확히 몸의 `Y_TOP` 에 앉는다**(산수).

형식화 = **`SH_DROP` 한 항**(낙차형) —
`shL = line([−SW/2, **L − SH_DROP**], [−NECK_A, L], N_sh)` · `shR` 대칭.
각도형 환산 `SH_ANGLE = atan(SH_DROP/SH_LEN)` = **25.19°**(atan(82.2598/174.969) · mst) ·
**19.48°**(atan(48.5991/137.443) · supima). 낙차형을 권하는 사실적 이유 — 제도 관행이 낙차(inch)로 적고,
코드가 이미 `py` 좌표로 돌며, 각도형은 `SH_LEN` 에 종속돼 **두 항이 엉킨다**.

값의 출처 세 선택지 — **고르지 않았다**(§0-4ㄴ). 판정 기준 ㉠~㉣ 를 함께 등재했다.

## 4. 기각·정정된 것

- ★ **앵커 어긋남 «발견»** — 실측표 총장은 **뒷목 중심** 기준인데 코드가 **어깨끝 높이**에 매단다
  (어긋남 **82.2598 / 48.5991 mm**). 이것은 2세대의 설계 항목이 아니라 **현행의 정정 항목**이다.

  능선점도 SDF 기울기 방향으로 민다.
- ★ **「과-드롭 상한 미지」 해소** — 코드 던짐 **SW > ≈147 cm** · 능선 단조 **SW ≤ ≈76 cm**(둘 다 비구속).
