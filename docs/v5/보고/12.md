## 4. 기각·정정된 것

- ★★★ **「이미 닫힌 = 거리 0」 기각** — 근거 = 봉제 주석 원문(「rest를 0으로 두면 자기충돌(분리 2×두께)과
  «서로 싸운다» … rest = 2×두께가 옳고」) + 자기검사 던짐(`front↔back 0.000mm`) ⟹ **「닫힌」 = 간극 0**
  (거리 = `SEP`)으로 설계서·판정문을 고쳐 적어야 한다. v5-10 의 「0.0000 mm」는 **자기검사를 거치지 않은
  f0 가상 실험** 값이었다(가능하다는 뜻이 아니었다).
- **능선 구성 정정** — `i` 마다 링을 뽑으면 `SLAB`(≈6.17 mm) > 어깨 표본 간격(≈3.3 mm)이라 **정점이
  겹친다**(`front↔front 0.000mm`) ⟹ **폴리라인 + 호길이 배치**로 구성만 바꿨다(규칙 불변).
- **남는 오차의 범위 정정** — 14.9·18.8 두 값이 아니라 **14.90 / 25.35 / 18.76 mm**(기본 M 이 최대).
