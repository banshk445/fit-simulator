### 먼저 — 코드 사실 정정 하나 (판정문의 전제 문언)

판정문은 허용식을 「`C_allow = C_body(링 높이) + 2π(THICK+TOL)`」로 적었는데, **코드는 「링 높이의 몸 둘레」를
쓰지 않는다**(`s4Gate.ts:124`):

```ts
const ringBodyM = closed(loop.map((v) => bd.nearestBodyPoint(pos[v*3], pos[v*3+1], pos[v*3+2])));
```

`ringBodyM` 은 **링 정점 각각의 최근접 몸점을 순서대로 이은 «닫힌 사영 다각형»의 길이**다.
⟹ 링이 몸에서 떨어져 있으면 그 사영 다각형이 **몸 위에서 더 좁은 자리로 모일 수 있고**, 그러면 허용이
**높이와 무관하게도** 줄어든다. 이 판의 ①은 그 사영 둘레를 직접 쟀다.

**「얹힘」의 자도 코드에서 유도했다**(새 수 0) — 닫힌 고리 둘레에 `2πr` 이 더해지는 것은 **반경이 `r` 만큼 커진 것**
이므로, 허용식은 「링이 몸 표면에서 `THICK + TOL_SELF` 만큼 떨어져 «얹혀» 있다」를 전제한다 ⟹
**`d_rest := THICK + TOL_SELF = 1.1 mm`**. 프롬프트가 말한 `SEP`(2 mm) 기준 비율도 **함께** 인쇄했다.
