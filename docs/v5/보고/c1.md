## ③ 채택 후보의 diff 원문 (`src/` 49줄 +· 4줄 − · 물리 0줄)

```ts
  /** ★ C1(캠페인) — 옷깃 후보 계열. `asm1x` 가 켜진 «안»에서만 읽힌다(off 경로 불변). */
  c1Var?: string;
  const C1 = (A1X || D1X || ASM2) ? (cfg.c1Var ?? '').split('+').filter(Boolean) : [];
  const c1Of = (tag: string) => C1.find((x) => x === tag || x.startsWith(tag + ':'));
  const c1Num = (tag: string, dflt: number) => { const f = c1Of(tag); const v = f?.includes(':') ? Number(f.split(':')[1]) : NaN; return Number.isFinite(v) ? v : dflt; };
  const BODY_DROP = Y_NECK - Y_TOP;                       // 몸에서 뜬 낙차(손 상수 0)
  const SH_DROP = c1Of('A') ? c1Num('A', 1) * BODY_DROP    // ★ 채택 후보 `A:1` 이 타는 자리
                : c1Of('B') ? Math.min(SH_DROP_TPL, BODY_DROP)
                : SH_DROP_TPL;
  const C1_ANCHOR_DROP = c1Of('C') ? c1Num('C', 1) * BODY_DROP : 0;
  const Y_ANCHOR = (ASM2 || A1X) ? Y_NECK - C1_ANCHOR_DROP : Y_TOP;
```
★ 계열 D(배치 후처리)는 `assemble()` 안 `if (c1Of('D'))` 블록이고 **채택 후보는 타지 않는다**.
★ **기본값 불변** — `c1Var` 가 없으면 `SH_DROP = SH_DROP_TPL`·`C1_ANCHOR_DROP = 0` ⟹ v5-27 의 `asm1x` 그대로.

## ⑥ 다음 캠페인 재료

```
 ㄱ **f0 대리 채널 재설계** — 「어깨 봉제선 여유」 = `hypot(SH_LEN, SH_DROP)` ↔ **몸 능선 호길이**(목 밑동 링의
   어깨쪽 점 → 어깨끝점). 이 여유가 정착 뭉침을 예측하는지 17칸(off 짝)으로 먼저 검증한다(굽기 0).
 ㄴ **G3(c) 의 자** — off 정착 자료가 없는 칸이 있다 ⟹ 「off 같은 칸」 대신 **몸에서 유도한 상한**
   (예: 어깨선 위 옷 두께의 기하 상한)을 세우는 것이 이 채널을 살리는 길이다.
 ㄷ **벌 성격 3분류를 정본화** — 뭉침(c100 계열) · 흘러내림(작은몸S · 링 −236.4 mm) · 정의역 밖(큰몸XL) ·
   처방은 부류마다 다르다. 「옷깃 뭉침」 캠페인은 **첫 부류에만** 적용된다.
 ㄹ **`A:1` 의 승격 판정** — 이 후보는 옷깃을 절반 고치고 게이트·층3·어깨를 유지하며 `vs 정본 중앙` 을
   70.77 → **53.67 mm** 로 줄였다(기본M). 108칸 재굽기로 제공 목록 변동을 보는 것이 다음 검증 국면이다.
 ㅁ **큰키L** — 유일하게 G3(a) 가 남았다(+5.3561). 그 벌의 몸 낙차는 54.787 mm 로 5벌 중 둘째로 크다 ·
```
