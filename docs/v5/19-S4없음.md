**ㄹ. S3 이 이미 밀어낸다 — `pushOut`**(`redrapeAsm2` · v5-15 (B) 도입분)

```ts
const pushOut = (q) => {
  const dd = sampleSdf(bodyG, q[0], q[1], q[2]);
  if (!(dd < SEP)) return q;
  const n = nHat(q[0], q[1], q[2]);   if (!n) return q;
  const st = SEP - dd;
  return [q[0] + n[0] * st, q[1] + n[1] * st, q[2] + n[2] * st];
```

★ BLEND 블록은 섞은 점마다 `pushOut` 을 **한 번** 건다 ⟹ **S4 를 빼도 「밀어냄이 전혀 없는」 것이 아니다.**
