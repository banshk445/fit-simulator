## §0-2 검수 결정의 «집행 형태» (값 보기 «전»에 고정한다)

```
 ① **`SH_DROP` = 0.0635 m(63.5 mm)** — 템플릿 상수. 이름·값·출처를 `src/v5/specToPattern.ts` 의
    `TEE_TEMPLATE` 에 `ARM_G` 와 나란히 공개한다(v5-1 규율 · 숨은 상수 0).
    출처 = My Golden Thimble 「On standard shoulders, the shoulder slope is **2 ½"**」
    (https://www.mygoldenthimble.com/how-to-draft-a-bodice-sloper/ · 2½ in × 25.4 = 63.5 mm) ·
    교차 출처 = Pattern Academy 「Back shoulder slope depth … **2''** for all sizes」
    (https://charnold.com/how-to-make-basic-bodice-block-tutorial/).
    **몸 도출은 기각**(결정 ①) ⟹ `SH_DROP` 은 몸을 **읽지 않는다**.
    ★ 남는 오차(설계서 ①-4㉢) = `|(Y_NECK − Y_TOP) − SH_DROP|` = **14.9 mm**(SW 44.5) ·
      **18.8 mm**(SW 52) — 이 판의 **측정 대상**이고 예측을 적지 않는다.
    「실측표 선택 항목 문」 = `TeeSpec` 에 선택 필드 `shoulderSlope?` 를 두고 **있으면 그것을 쓴다**
    (없으면 템플릿 상수) — 값은 등재된 두 실물 표에 없으므로 **항상 템플릿 상수 경로**다(사실).
 ② **능선 `z` — 기준 ㉠~㉣ 순차 적용의 결과를 여기 적는다**(설계서 ②-1 의 후보 4종·기준 그대로):
      ㉠ z 가 규칙으로 «결정»되는가 — 후보 1(측지선) ○ · 2(평면 절단) ○ · 3(배치 machinery) ○ ·
        4(앞뒤 대칭 평균) **△**(몸 앞뒤 비대칭에서 흔들린다) ⟹ **4 탈락**
      ㉡ 새 알고리즘·상수 «수» — **3: 0** < 2: 1(평면 선택) < 1: 알고리즘(측지선) ⟹ **3 이 최소**
      ㉢ 능선이 «몸 표면» 위인가 — 3 은 **✗**(볼록 껍질 + δ 위다)
      ㉣ v5-10 직선 하한(19.2396 / 14.5044 cm) 정합 — 셋 다 **검산 가능**
    ⟹ **순차 적용의 1순위는 후보 3**(㉠ 통과 · ㉡ 최소)이고, **㉢ 의 «껍질 위»는 설계서가 미리 정한
      처분대로 «옷이 몸에서 떠 있는 양»을 값으로 적는다**(설계서 ②-1 끝 · 숨기지 않는다).
      「동률 시 표면 최단 경로」 조항은 **동률이 아니므로 발동하지 않는다**(3 이 ㉡ 에서 단독 최소).
      ★ 이 판독을 §0 에 못 박고, ㉢ 의 값을 §1 에서 낸다 — 전략 세션이 판독을 뒤집으면 **후보 1/2 로
        가는 판**이 따로 필요하다(그 사실을 보고에 적는다).
    **구현 형태**(후보 3 · 새 규칙 0) — 각 높이 `y` 의 링
      `boundaryOf(supportAt(y, SLAB), DELTA, 1)` 에서 **`|x|` 가 최대인 점**을 쓴다.
      그 점이 **앞판과 뒤판이 만나는 자리**이므로 앞뒤에 **같은 점**을 주면 봉제쌍 거리가 **0** 이다(S2).
      `y` 는 목점(`Y_NECK`)에서 어깨점(`Y_NECK − SH_DROP`)까지 패턴 `py` 가 정하는 값이다.
 ③ **「동일」의 자** — off 는 **비트 동일**(R1·R2) · on 의 레귤러핏은 **v4-17 ①②**(대역 이름 5/5 ·
    게이트 `pass`·`fails` 일치) **+ ③(표시 5행 중앙 차)은 «보고만»** + 화면(캡처).
 ④ **R6 감소 수용** · 단 **레귤러핏이 줄면 회귀 신호 ⟹ 정지**(이 판에서는 R3 의 supima·기본 M 이 그 자리).
 ⑤ **앞/뒤 단일 경사** — `topB` 를 나누지 않는다(앞뒤 같은 상단 곡선 유지).
```

## §0-3 사전 등재 갈래 (설계서 ⑤ 초안 «그대로» · 사후 신설 0)

```
 **A** = ①(비트 불변 3검사 3/3 — R1 108/108 · R2 29/29 · 패턴 uv) + ②(f0 몸 여유 ≥ SEP **그리고**
        하위 행 신장이 현행과 같은 자릿수) + ③(세 칸 정착 도달 + mst-over 걸림 «정도» > 0)
```

## §0-4 diff 초안 (플래그 경로 · 값 보기 «전»)

```
 ㄱ **스위치** — `createScene` cfg 에 `asm2?: boolean`(기본 `undefined`) · `prepare` 가 넘긴다 ·
    계기는 `ASM2=1` env 로 켠다. **켜지지 않으면 한 줄도 다르게 돌지 않는다.**
 ㄴ **제도(S0)** — `SH_DROP = ASM2 ? TEE_TEMPLATE.SH_DROP : 0` ·
      `shL = line([−SW/2, L − SH_DROP], [−NECK_A, L], N_sh)` · `shR` 대칭 ·
      **암홀 강체 이동** — `armR` 의 위 끝점이 어깨점이므로 `Y_ARM` 을 `L − SH_DROP − ARM_D` 로 둔다
      (곡선 «모양»과 호길이가 보존된다 ⟹ `ARM_D = solveB(ARM_G/2, …)` 의 제약이 유지된다) ·
      `SH_LEN` 은 이름 그대로 **수평 길이**로 두고 분할 수는 **`hypot(SH_LEN, SH_DROP)`** 로 센다
      (설계서 ①-5 자리 7·8).
 ㄷ **앵커 정정** — `Y_ANCHOR = ASM2 ? Y_NECK : Y_TOP` 를 `Y_NECK` 산출 뒤에 둔다.
      «옷 높이대»를 뜻하는 자리 전부를 `Y_ANCHOR` 로 바꾼다 — `:443 Y_HEM` · `:468` · `:538 yOf` ·
      `:540 SLAB` · `:551` · `:580-581` · `:602 bodyPoint` · `:630` · `:740` · `:761`.
      «몸 어깨끝»을 뜻하는 자리는 **`Y_TOP` 그대로** 둔다 — `:186` 정의 · `:205 · 212` `neckBaseY` 탐색.
 ㄹ **배치(S1~S4)** — `assemble(d)` 안에서 기존 배치 루프 «뒤»에 도는 **후처리 한 덩이**로 넣는다
      (`place()` 는 건드리지 않는다 ⟹ off 경로 텍스트 불변):
      S1 목선 토막 → `arcOn(boundaryOf(supportAt(Y_NECK, SLAB), DELTA, 1), !front).at(±px)` · `y = Y_NECK`
      S2 어깨 토막 → 위 ②의 «링 `|x|` 최대 점»(앞뒤 **같은 점** ⟹ 봉제쌍 거리 0)
      S3 드레이프 → 각 열을 상단점에서 **2D 패턴 열 엣지 길이만큼 아래로**(−y) 누적해 내린다
      S4 밀어냄 → `clr < SEP` 인 정점을 **SDF 기울기 방향**으로 `SEP − clr` 만큼 민다(반복)
      S5 소매 → **손대지 않는다**(결정 ⑤ 승인 · v5-9 「소매 관 무죄」)
 ㅁ **S4 반복 상한 = 기존 자에서 «유도»한다**(새 상수 0) — 수렴 판정은 v3 가 「두 기하를 같다고 보는
    길이」인 **`TOL_SELF`(0.1 mm)**를 쓰고, 반복 상한은 **`substepsOf` 가 쓰는 것과 같은 방식으로
    «값으로» 인쇄**한다. 상한에 닿으면 **정지(갈래 E)** 이고 그 사실을 값으로 적는다.
 ㅂ **검사 3건**(집행 전에 건다) — ⓐ 패턴 uv 바이트 동일(off) ⓑ **R1 T포즈 108칸 asm 본문 sha 동일**
    ⓒ **R2 A포즈 29칸 asm 본문 sha 동일**. 기준선은 **구현 «전»에 이 브랜치에서 뜬다**(같은 코드로 두 번
    돌리는 것이 아니라 «구현 전 ↔ 구현 후» 대조여야 의미가 있다).
```
