### §0-6 ② 후보 형식화 — 값 보기 «전» 등재

#### 후보 ㉮ — 암홀 열의 블렌드 목표를 「팔 관 표면」으로

현행 BLEND 의 `w = 0` 쪽 재료(= 몸통 튜브 `tube`)를 **열에 따라** 팔 관 표면으로 바꾼다.

```
열 가중  u(i) := max(0, 1 − dEdge(i) / N_sh)        … i = 0 · nuB 에서 1 · dEdge ≥ N_sh 에서 0.
                                                      경계 열 형식화 = 이 한 식뿐이다(손 상수 0).
팔 관 사영  ArmProj(q) — q 를 팔 축(AX · 피벗 AP 또는 중심 (0, ARM.yc, ARM.zc))에 대해
            «반지름 SLV_R 의 관 표면»으로 «반경 방향» 옮긴다(축 좌표 t 와 위상 ph 는 보존).
            반경이 0 이면(축 위) q 를 그대로 둔다.
블렌드 목표  T(i, j) := (1 − u(i))·tube + u(i)·ArmProj(tube)
행 블렌드   q := (1 − w)·T + w·drape        (w 는 현행 그대로)  → pushOut(q)
```

★ `u ≡ 0` 이면 `T = tube` 이므로 **㉮ 는 BLEND 의 진확장**이다 — 목선 구간(dEdge > N_sh)은
현행과 «같은 계산»이고, 회귀 표면은 암홀 열에만 열린다.
★ 기대(등재) — **소매 캡↔암홀 봉제쌍 거리가 줄어든다**(암홀 열이 팔 둘레로 감기므로).
   줄지 않으면 ㉮ 의 전제가 거짓이다.
