### §0-5 ① 암홀 열 정의 — 등재된 양만으로 (손 상수 0)

위 ㄱ·ㄴ에서 **직접** 도출한다. 새 상수 0 · 새 문턱 0.

```
암홀 행  J := j ∈ (N_side, nvB]                       … 정확히 N_arm 행. ㄴ의 암홀 봉제선 행 범위와 같다.
어깨 토막 열 I := i ∈ [0, N_sh] ∪ [N_sh + N_nk, nuB]   … ㄱ의 topB 구성(shL / nk / shR)이 가르는 그 토막.
                                                        ㄴ의 「어깨L·어깨R」 봉제선 열 범위와 «같은 집합»이다.
암홀 열(이 판의 정의) := I                             … 판정문의 「어깨 토막 열 = «암홀 구간»(옷의 언어)」.
가장자리 거리 dEdge(i) := min(i, nuB − i)              … 열 단위. 암홀 봉제선(i = 0 · i = nuB)에서 몇 열인가.
```

`nuB = 2·N_sh + N_nk` 이므로 `i ∈ I ⟺ dEdge(i) ≤ N_sh` 이다(항등 · 증명 필요 없음).
⟹ **암홀 열 = 「암홀 봉제선에서 `N_sh` 열 이내」** 와 같은 말이다. ①의 표는 이 집합과
v5-17 잔여 열(`i` 1~9 · 47~60)의 일치 여부를 **실측 `N_sh`·`N_nk`·`nuB` 로** 채운다.

### §0-6 ② 후보 형식화 — 값 보기 «전» 등재

#### 후보 ㉮ — 암홀 열의 블렌드 목표를 「팔 관 표면」으로

현행 BLEND 의 `w = 0` 쪽 재료(= 몸통 튜브 `tube`)를 **열에 따라** 팔 관 표면으로 바꾼다.

```
열 가중  u(i) := max(0, 1 − dEdge(i) / N_sh)        … i = 0 · nuB 에서 1 · dEdge ≥ N_sh 에서 0.
                                                      경계 열 형식화 = 이 한 식뿐이다(손 상수 0).
팔 관 사영  ArmProj(q) — q 를 팔 축(AX · 피벗 AP 또는 중심 (0, ARM.yc, ARM.zc))에 대해
            «반지름 SLV_R 의 관 표면»으로 «반경 방향» 옮긴다(축 좌표 t 와 위상 ph 는 보존).
            반경이 0 이면(축 위) q 를 그대로 둔다.
블렌드 목표  T(i, j) := (1 − u(i))·tube + u(i)·ArmProj(tube)
행 블렌드   q := (1 − w)·T + w·drape        (w 는 현행 그대로)  → pushOut(q)
```

★ `u ≡ 0` 이면 `T = tube` 이므로 **㉮ 는 BLEND 의 진확장**이다 — 목선 구간(dEdge > N_sh)은
현행과 «같은 계산»이고, 회귀 표면은 암홀 열에만 열린다.
★ 기대(등재) — **소매 캡↔암홀 봉제쌍 거리가 줄어든다**(암홀 열이 팔 둘레로 감기므로).
   줄지 않으면 ㉮ 의 전제가 거짓이다.

#### 후보 ㉯ — 행·열 간격 «동시» 보존 항 ((ㄴ) 정정판)

v5-17 (ㄴ)`ABI` 는 **열 간격만** 잡았다(같은 행의 `i`↔`i+1`). 정정판은 **행 간격도 같이** 잡는다.

```
        (나) 모든 (j, j+1) 같은 열 쌍 → 같은 식
수렴 TOL_SELF · 상한 NY · 끝나고 pushOut.   … 셋 다 이미 등재된 값. 새 상수 0.
```
