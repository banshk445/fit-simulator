# 회차 보고 형식

**출력 위치 (59회차 요청 — 이것부터 지킨다).**
아래 §1~§7은 **회차 노트(`.obsidian-log/회차/2b-NN-*.md`)에 쓴다.**
**채팅에는 §8 raw 링크만 출력한다** — 표·수치·요약을 채팅에 다시 늘어놓지 않는다.
항목이 줄어드는 게 아니라 **자리가 옮겨가는 것**이다. 채팅이 짧아진 만큼
노트가 그 자체로 완결적이어야 한다(전략 세션은 링크로만 읽는다).
예외 3종만 링크 위에 **한 줄씩**: **검수 실패 · 정지/ABORT · 사용자 확인이 필요한 갈림**.

아래 순서 그대로 노트에 적는다. 빈 절은 지우지 말고 "해당 없음"으로 남긴다 —
무엇을 안 했는지가 보고의 절반이다.

## 1. 헤더 (git 스탬프)

```
NN회차 <제목> — <상태: 통과|실패·원복|애매·정지|진단only|미집행>
커밋 <해시> · 브랜치 <이름> · 기점 <해시> · 워크트리 <경로>
```

`git log --oneline -1` · `git branch --show-current` 로 직접 뜬다.
**기점**은 회차 시작 시 프롬프트가 지정한 커밋이다.

## 2. 실행 / 미실행

- 실행한 것: 명령과 **경과 시간**
- **실행하지 않은 것과 그 사유** — 컨텍스트 소진·정지 조건·선행 실패 등.
  침묵으로 넘기지 않는다.

## 3. 결과표

대조군을 **열로 병기**한다(예: 25회차 / 26회차 / 이번). 지표당 한 행:

| 지표 | 기준선 | 이번 | 판정 |

- 대역 요약은 **중앙값 · p99 · maxAt · 부호별 총량** 4종 병기(함정 18)
- 프레임·단위를 수치마다 적는다
- 산출 불가 항목은 **불가로 적는다** — 추정치로 채우지 않는다

## 4. 사전 등록 판정

회차 프롬프트가 등록한 갈래를 **이름으로** 지목하고 근거 수치를 인용한다.
어느 갈래에도 해당하지 않으면 **"판정 불가"**로 적고 정지 사유로 올린다.
사후에 갈래를 새로 만들지 않는다.

## 5. 등재만 (구현 금지)

이번 회차에서 발견했으나 변수가 아니라서 손대지 않은 것. 각각 한 줄:
관측 · 후보 기전 · 왜 이번 변수가 아닌지.

## 8. raw 링크 (보고 맨 끝 · 전량)

그 회차가 **만들거나 고친 `.obsidian-log/` 파일 전부 + `docs/metrics-log.md`**를
**신규 / 수정**으로 갈라, 파일마다 한 줄 요지를 달아 적는다. 회차 노트 1개만
적지 않는다 — 전략 세션이 볼트를 열지 않고 링크만으로 회차 전량에 닿아야 한다.

URL은 **커밋 SHA 고정**(브랜치 경로 금지 — 함정 20) · 경로는 **퍼센트 인코딩**.
목록은 손으로 적지 말고 뜬다:

```
git -c core.quotepath=false show --name-only --format= <노트커밋> <metrics커밋> \
  | grep -e '^\.obsidian-log' -e '^docs/' | sort -u | python3 -c "
import sys,urllib.parse
S='<전체 40자 SHA>'
for l in sys.stdin:
    p=l.strip()
    if p: print('- \`'+p+'\`\n  https://raw.githubusercontent.com/banshk445/fit-simulator/'+S+'/'+urllib.parse.quote(p))
"
```
